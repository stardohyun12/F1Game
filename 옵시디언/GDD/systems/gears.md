# GDD — 기어 시스템

> **신설:** 세션 10 D-030 K3+K5 결정 기반.
> **레퍼런스:** Forza Horizon 5 (`GDD/research/claude-web-findings-v2.md` U3, U5).
> **이전 결정 이력:** D-019 (F1 시뮬 기각, 자동 기본 채택), D-029 (수동 토글 절충안).

## 핵심 개념

기어는 **기본 자동, Manual은 보상형 토글**.
"신경 쓸 거리 추가"가 아니라 "원하면 더 깊은 컨트롤 + 보상"으로 설계.

---

## 기어 모드 (K3)

### Automatic (기본값)

- 게임이 자동 변속
- 기어 표시는 HUD에 보이지만 입력은 없음
- 부스트 충전율 = 표준 (×1.0)
- 신규 플레이어·게임패드 유저 기본
- **레퍼런스:** FH5의 기본 변속, Auto/Manual no-clutch

### Manual (토글)

- 플레이어가 시프트 버튼으로 기어 변경 (업/다운 2버튼)
- **부스트 충전율 +10%** (채널 A·B 양쪽 모두) — D-031 시도 후 D-032 철회로 부스트 보존
- **클러치는 없음** — 클러치는 패드 UX 희생 대비 이득 작음 (D-030 결정)
- 잘못된 RPM 변속 시 페널티 없음 (캐주얼 톤 유지)

### 토글 UX

설정 메뉴 1단 토글 (Auto / Manual). 주행 중 변경 불가.

> **D-030 K3 결정 사유:**
> - FH5 정성 사실: WR(세계 기록) 100% = Manual+Clutch, 캐주얼 = Auto, 중간층 = Manual no-clutch가 패드 최적
> - PIT CREW는 패드 우선 + 5~15분 런 = 캐주얼 톤이 메인
> - 단, "더 잘하면 더 보상받는" 레이어를 비우면 하드코어 유저 동기 부족 → +10% 인센티브로 절충
> - 클러치는 키보드/패드 둘 다 부담 큰데 차이는 미미 → 컷
> - 기어 수동 제안 3번째 응답이기도 함 (D-019, D-029, D-030 라인업)

## 기어 시프트 연출 (K5)

**샘플 조합 방식 3종 세트.** Kenny+아케이드 스케일에 맞춤.

| 큐 | 구현 | 비고 |
|---|---|---|
| **엔진 피치 순간 드롭** | 시프트 순간 RPM 사운드 0.1초 다운 → 0.2초에 걸쳐 회복 | 엔진 사운드는 D-020(외부 예외) 처리됨 |
| **0.1초 카메라쉐이크** | 미세 진폭, 한 번 펄스 | 가속감 강조 |
| **HUD 기어숫자 플래시** | 기어 숫자 박스가 0.15초 화이트→원래색 페이드 | 시프트 발생 명확화 |

### 비채택 — Granular Synthesis

FH5는 **Playground Games**(Turn 10 아님)가 Granular Synthesis + 90 FPS 오디오 + 차량별 Gear Cracks 별도 샘플로 시프트를 표현. **결정적 통찰: FH5는 시프트 전용 VFX 대신 엔진음 연속 재계산이 시프트를 표현.** 이는 PIT CREW 스코프에 과함 — 채택 안 함.

> **HUD 시프트 시각 큐 정량(셰이크 진폭, 플래시 색상 등)은 공개 자료 없음.** 위 3종 세트는 PIT CREW 자체 설계.

## RPM 표시 (선택)

| 모드 | RPM 게이지 |
|---|---|
| Automatic | HUD에 미표시 (단순화) |
| Manual | HUD 우하단 작은 게이지 + 시프트 권장 LED |

> Manual 사용자에게만 RPM 표시. Auto는 게이지 없이 기어 숫자만.

## 차량별 기어 단수

- 모든 차량 **5단 고정** (MVP 단순화)
- 4주차+ 확장 시 차량별 4~7단 가변 검토

## MVP 범위

| 주차 | 구현 범위 |
|---|---|
| **2주차** | Automatic만, HUD 기어 숫자 표시 |
| **3주차** | Manual 토글 + 부스트 인센티브 +10% 연동, K5 3종 세트 |
| **4주차** | RPM 게이지, 시프트 권장 LED |
| **Post-MVP** | 차량별 기어 단수, 클러치 옵션, 차량별 시프트 사운드 차별화 |
