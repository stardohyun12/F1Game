# GDD — 경로 계획 시스템

> **이 문서가 게임의 정체성을 정의한다.**
> 경로 계획이 없으면 PIT CREW는 그저 평범한 배달 게임.

## 핵심 철학

"출발 전 계획이 런의 절반이다."

플레이어는 차고에서 **두 번의 주요 결정**을 내린다:

1. **주문 선택** — 8개 중 3~5개
2. **경로 설계** — 선택한 배달지들의 순서와 피트 위치

이 두 결정이 **주행 단계의 난이도를 결정**한다.

## 맵 데이터 구조

게임 내 맵은 **노드-엣지 그래프**.

```
[A]──6km──[B]
 │         │
4km       3km
 │         │
[C]──5km──[D]──2km──[E]
```

- **노드:** 배달지, 피트 시설, 교차점, 특수 지점
- **엣지:** 도로 구간. 각자 속성 보유:
  - 거리 (km)
  - 노면 타입 (asphalt_dry / asphalt_wet / gravel / damaged)
  - 코너 수 (0~5, 타이어 마모 계산용)
  - 평균 통행 속도 예측
  - 혼잡도 등급 (MVP 이후)

## 주문 보드 화면

런 시작 시 "오늘의 주문" 표시.

```
┌──────────────────────────────────────┐
│  오늘의 주문 (최대 5개 선택)            │
├──────────────────────────────────────┤
│ ☐ A지점 일반박스      $50   (쉬움)    │
│ ☑ B지점 크리스탈      $200  Shock●●●●│
│ ☑ D지점 활어         $150  Spin●●●  │
│ ☑ E지점 케이크       $100  Tilt●●●  │
│ ☐ F지점 폭발물       $500  ALL ●●●●│
│ ☐ G지점 피자         $80   ⏱ 3분   │
│ ☐ H지점 서류         $70   (쉬움)    │
│ ☐ I지점 무거운장비    $120  무게+50% │
├──────────────────────────────────────┤
│  선택: 3/5     예상 수익: $450        │
│  [경로 설계로 →]                      │
└──────────────────────────────────────┘
```

### 주문 속성

각 주문은 다음을 가짐:
- **배달지** (맵의 노드 ID)
- **화물 타입** (cargo.md 참조)
- **보상** ($ / 평판 / XP)
- **제약** (시간 제한, 무게, 특수 조건)

### 주문 선택 전략

플레이어는 다음을 고민:
- "Shock 세 개만 받고 직선 위주로 갈까?"
- "한 번에 먼 곳만 모아서 연료 아끼기"
- "쉬운 거 다섯 개로 안전하게"
- "폭발물 하나에 다 걸기"

→ **덱빌딩의 "덱 구성" 감각을 "주문 선택"으로 치환.**

## 경로 설계 화면

주문 확정 후 지도 전체 표시.

```
┌──────────────────────────────────────────┐
│              경로 설계                     │
│                                            │
│   START ──→ [A] ──→ [B★] ──→ [D★] ──→ [E★]│
│   (차고)    6km    3km      2km    → END │
│                                            │
│  경로 옵션: [직행] [지름길1] [우회1]         │
│                                            │
│  예상 거리:  17 km                         │
│  예상 시간:  약 4분 20초                   │
│  예상 타이어 소비: ●●●○○ (Medium 권장)    │
│  예상 연료: 18 km                          │
│                                            │
│  피트 위치: [없음] [B이후] [D이후]           │
│                                            │
│  [← 주문 수정]    [타이어 세팅 →]         │
└──────────────────────────────────────────┘
```

### 경로 지정 UX (드래그 방식)

- 주문 목록을 드래그해 순서 변경
- 화면 하단에서 순서대로 배열
- 실시간으로 지도상 경로 하이라이트
- 실시간으로 예측 수치 업데이트

### 실시간 예측 수치

계획 변경마다 갱신:
- 총 거리 (km)
- 예상 소요 시간 (분/초)
- 타이어 마모 예측 범위 (막대 그래프)
- 연료 소비 예측
- 피트 필요 여부 경고

## 정보 공개 원칙 (게임 재미의 핵심 원칙)

**공개하는 정보 (기본):**
- 구간별 거리
- 구간별 노면 타입
- 화물 민감도 등급
- 타이어 수명 예측 범위

**숨기는 정보 (주행 중 발견):**
- 정확한 화물 데미지 수치 (운전 변수)
- 교통 이벤트 / 경쟁자 위치
- 랜덤 노면 손상

**업그레이드로 공개되는 정보 (진행 보상):**
- **팀 스카우트:** 이번 런 교통량 예측
- **기상 레이더:** 비 예보
- **스파이 정보망:** 경쟁자 배달 경로
- **정밀 측량:** 각 구간 정확한 마모 수치

**이게 업그레이드 트리의 일부로 들어간다 → "계산을 더 잘하게 해주는" 영구 진행.**

## 피트 배치

경로 중간에 피트 시설이 있는 노드에 "P" 마커 배치 가능.

- 피트 배치는 **사전 결정** (계획 단계에서)
- 주행 중 생각 바뀌면 **즉흥 피트**도 가능하지만 QTE 페널티
- 피트 시설 노드는 지도에 표시됨

## 숨겨진 지름길 (Progressive Disclosure)

**처음 플레이에서는 맵에 모든 길이 표시되지 않는다.**

- 주행 중 발견한 지름길 → 영구 등록
- 발견 시 "Shortcut Discovered!" 이벤트
- 재방문 시 계획 화면에 표시됨

**메타 진행 요소.** 플레이할수록 지도 정보가 풍부해짐.

## MVP 범위

**1주차:** 경로 계획 UI 없음. 단순 웨이포인트 따라 주행.
**2주차:** 노드-엣지 그래프 데이터 구조. 단순 순서 선택 UI.
**3주차:** 예측 수치 시스템. 피트 배치.
**4주차:** 주문 선택 보드. 기본 정보 공개 레벨.

**MVP 이후 확장:**
- 업그레이드로 정보 공개
- 지름길 발견 시스템
- 경쟁자 경로 표시
- 동적 이벤트 (교통 체증, 사고)
- 다중 차량 운영 (2인 팀 전략)

## 위험 요소

이 시스템이 복잡해서 **UX 설계가 어려움**.
MVP에서는 "선택 → 순서만 드래그"로 최소화.
정보 과잉 UI는 초기 사용자에게 진입장벽.
