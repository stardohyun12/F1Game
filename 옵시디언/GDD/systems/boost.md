## 핵심 개념

부스트는 **연료와 분리된 독자 자원**.
연료는 "주유 결정 빈도"를, 부스트는 "위험·완수 보상감"을 담당. 두 자원의 갱신 채널을 분리해야 둘 다 의미를 가짐.

> **D-030 K1 결정 사유:** 통합형(연료=부스트)을 MVP로 시도하려 했으나, Burnout 2차 조사에서 **충전 패턴의 이중 구조**(즉시 풀충전 이벤트 vs 점진 충전 행동)가 핵심 재미 요소로 확인됨. 이 구조는 연료와 통합되면 사라진다.

## 부스트 충전 = 이중 채널 (K1)

### 채널 A — 완수 이벤트 100% 즉시 충전

배달 게임의 정체성과 직접 연결되는 행동. 한 번 발동 시 **부스트 바를 0→100%까지 즉시 채움**.

| 트리거 | 조건 | 비고 |
|---|---|---|
| **배달 완료** | 화물 무파손 + 시간 내 | 완벽 배달 = 풀충전, 파손 있으면 70%만 |
| **완벽 정차** | 픽업·드롭존에 1초 이내 정확 정렬 | 정밀 운전 보상 |
| **(MVP 이후) 차량 회피 곡예** | Burnout Barrel Roll 등가 | 확장 후보, 4주차+ |

레퍼런스: Burnout의 Takedown(Aggression 차량) / Barrel Roll(전 차량) / Billboard 파괴(Stunt Run) 모두 풀충전 트리거.

### 채널 B — 위험 주행 점진 충전

주행 중 지속 행동. **초당 또는 이벤트당 소량씩 누적**.

| 트리거 | 충전량(초안) | 출처 패턴 |
|---|---|---|
| **드리프트 지속** | 초당 +5~8% | Burnout Drift |
| **근접 회피** (보행자/장애물) | 이벤트당 +3~5% | Burnout Near Miss |
| **고속 직진 주행** | 초당 +1~2% (속도 80% 이상에서만) | Burnout Oncoming/Speed |

> **수치 근거:** Burnout 행동별 정량 % 비중은 Criterion 비공개. K1 이중화 구조만 채택, **%는 MVP 구현 후 플레이 튜닝으로 결정** (D-030, Q3 결정).

## 부스트 발동 (K2)

| 항목 | 값 | 근거 |
|---|---|---|
| **풀바 지속시간** | **6~10초 범위, 기준 8초** | Burnout Speed Boost 풀바 = 정확히 8초 (위키 다중 출처 일치) |
| 발동 단위 | 풀바만 가능 (부분 발동 X, MVP 단순화) | Burnout 패턴 차용 |
| 쿨다운 | 없음 (재충전이 곧 쿨다운) | 단순화 |
| 속도 증가율 | **UNKNOWN — 플레이 튜닝** | Burnout 공개 수치 없음 (Ben Minto 인터뷰: "심리적 가속감 우선") |
| 중단 가능 | 발동 중 부스트 버튼 다시 누르면 즉시 중단 (남은 시간 보존 X) | 단순화 |

### 발동 빈도 가이드

5~15분 한 런에서 **런당 3~6회 발동**이 자연 빈도.
이를 만족하려면:
- 풀바 충전 평균 시간 = **약 1~3분**
- 채널 A(완수 이벤트) 평균 발동 = 런당 1~3회
- 채널 B(점진 충전)가 그 사이를 메움

## 확장 아이디어 (Post-MVP)

- **Burnout Chain 패턴 도입:** 풀바 소진 직전 채널 A 트리거 발동 시 즉시 풀충전 + 보너스 시간. 5~15분 런에서 1~2회 발동되면 짜릿한 순간이 됨.
- **차량 타입별 부스트 특성:** Burnout 3타입(Speed=짧고 강함, Aggression=둔하지만 누적, Stunt=짧고 자주). 다만 K1 이중화 구조 안에서 어떻게 표현할지 별도 설계 필요.
- **부스트 게이지 시각 효과 강화:** 풀바 시 모서리 글로우 + SFX. K5(기어 시프트 연출) 작업 후 같이 톤 정리.
