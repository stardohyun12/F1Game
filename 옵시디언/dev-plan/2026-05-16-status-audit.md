## 핵심 빚 (데모에 영향 큰 순)

### 🔴 1. 채널 7 — F1 복원 트리 미구현 (USP 직격)
- **현재**: UpgradeSystem은 일반 업그레이드 (속도+/타이어/박스). F1 부품 복원 메타가 없음.
- **데모 충격**: D-051 컨셉 "F1 그랑프리 복귀"가 5분 데모 안에 안 보임 → "그냥 배달 게임"으로 비춰짐. 모두창업/Steam 페이지 USP 약화.
- **작업**: W3 (5/27~6/2) 차고 + 부품 시스템 1주. brainstorm → spec → plan → 구현.
- **레퍼런스**: `옵시디언/research/garage-parts-reference.md` 완료.

### 🟠 2. 채널 4·6 — 화물 비주얼 차별화
- **현재**: 5종이 코드/데이터로만 구분, 외형은 같은 회색 큐브.
- **데모 충격**: 한 화면에 박스 5개 떠도 다 같은 것처럼 보임. "다양한 화물 = 다양한 손상 위험" 컨셉 전달 약함.
- **작업**: 화물별 머티리얼 색/텍스처 + 트렁크/미니맵 아이콘. 1일.

### 🟠 3. 채널 9 — 연료/스테미나 의미 약함
- **현재**: FuelSystem 작동하지만 데모 컨셉 "스타듀 스테미나" 가치 잘 안 보임. 5분 한 런에서 연료 압박 감 적음.
- **데모 충격**: 한 런 = 한 의미 있는 결정 단위라는 게임 리듬 약함.
- **작업**: 연료 = 가속/감속 시 차등 소모, 정비비/연료비 압박, 정산에서 표시. 1~2일.

### 🟡 4. 채널 1 — 화물 손상 인과 (D-068)
- **현재**: 차 G → 박스 슬라이드 → 트렁크 박음 → 손상. 코드 박힘.
- **데모 충격**: boxWallDamageMul 튜닝 안 됨. 실제 운전에서 손상 발생 빈도 미검증.
- **작업**: manual play → 튜닝. 0.5일.

### 🟡 5. 채널 5 슬라이드 deadzone 0.02
- **현재**: 약한 슬로프(25°)에서 화물 안 미끄러짐.
- **데모 충격**: "포장 잘해야 화물 안 박힘" 학습 기회 줄어듦.
- **작업**: deadzone 0.005 + accelScale 튜닝. 0.5일.

### 🟢 6. 손맛 (사운드/햅틱/카메라)
- **현재**: AudioCueBus 골격 있고 cue 7개 등록되어 있지만 실제 clip 미할당 (W5 예정).
- **데모 충격**: "괜찮음 → 좋다" 임계점 변수. 영상 시연 시 매우 큼.
- **작업**: clip 5~8개 + 보상 floating 숫자 + 충돌 카메라 흔들림. 2~3일.

### 🟢 7. 첫 30초 (인트로/튜토)
- **현재**: 메인 메뉴/인트로 없음. 시작 즉시 운전 가능 상태.
- **데모 충격**: 처음 켠 사람이 길을 잃음 → 영상 첫 30초가 컨셉 전달 안 됨.
- **작업**: 인트로 1컷 + 첫 런 가이드 오버레이. 2일.
