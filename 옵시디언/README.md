# PitCrew Obsidian Vault

PitCrew 프로젝트의 모든 문서(GDD, 세션 로그, 결정, 코드 docs, dev-plan, 학습 노트)는 여기 모여있음.

## 여는 법

Obsidian → Open folder as vault → `옵시디언/` 선택.

## 구조

- `🗺 Maps/` — 진입점 (Home, 시스템/코드/결정/학습 지도)
- `GDD/` — 게임 디자인 (`overview`, `decision-channels`, `systems/`, `architecture/`, `ui/`, `content/`, `research/`)
- `notes/` — 세션 로그, 결정 이력, 리뷰, 컨벤션
- `code/` — Unity 스크립트의 마크다운 문서 (`generate-obsidian-notes.ps1`로 동기화)
- `dev-plan/` — 기능 리스트/계획
- `_archive/` — 옛 문서

## Vault 밖 (repo 루트)

- `F1/` — Unity 프로젝트 본체
- `.claude/` — Claude Code 규칙/컨텍스트 (CLAUDE.md import 대상)
- `scripts/` — PowerShell 헬퍼
- `CLAUDE.md` — Claude 진입점

링크는 [[wikilink]] 스타일로 vault 내부 어디든 작동.
