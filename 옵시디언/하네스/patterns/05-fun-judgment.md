# 05. Fun Judgment

## 증상
AI가 "선택→효과→보상 루프 구현 완료"라고 보고. 실제 플레이해보면 선택의 의미 없고, 효과 안 보이고, 보상도 무감각. AI는 메커니즘 코드는 맞게 짰지만 그게 재미있는지는 모름.

## 왜 발생 (AI 한계)
- 재미는 dopamine·tension·anticipation 같은 인간 경험. AI에게 자체 경험 없음.
- AI는 "이 시스템이 작동하나"는 판단해도 "재미있나"는 판단 불가능.
- 부분 시스템 단위로 짜다 보면 전체 루프의 빈 곳을 모름.

## 회피책
- **즉시**: AI에게 재미 평가 위임 금지. "이 메커니즘이 재미있을까요?" 질문에 AI는 generic 답만 줌.
- **워크플로**: 매 마일스톤에 사용자 본인이 직접 플레이 테스트 → "어디가 재미 없었는가" 1줄 보고 → AI는 그 1줄을 fix.
- **도구**: 플레이테스트 일지 (`옵시디언/notes/playtest-log.md`) — 매 build마다 한 줄. "Day X: 포장이 무의미함 → 추천 시스템 필요" 같은.
- **AI 룰**: 새 메커니즘 추가 시 "이게 어떤 결정/긴장/보상을 만드는가" 명시. 셋 다 답 못 하면 추가 보류 (`ideas-parking`).

## 적용 신호
- "이 시스템 추가하면 더 재밌을까요?" AI에 묻고 싶을 때 → 본인 직감으로 판단할 것
- 메커니즘은 다 짰는데 플레이가 지루
- AI가 generic gamedev advice 늘어놓을 때 ("긴장과 보상의 균형이 중요합니다")
- 핵심 루프 5분 플레이도 안 해본 상태에서 새 기능 추가 논의 중일 때
