# Project Templates

새 게임 프로젝트 시작 시 부트스트랩용. AI 하네스 베이스라인.

## 인덱스 (작성 예정)

- `claude-md-game-base.md` — `CLAUDE.md` base. 게임개발 공통 룰 import 구조.
- `rules-base/` — `.claude/rules/*.md` 기본 셋 (scope, asset, session, communication).
- `active-context-base.md` — `activeContext.md` 빈 템플릿.
- `setup-checklist.md` — 새 프로젝트 시작 1일차 체크리스트 (unity-cli 설치, hooks, settings.json 등).

## 룰

- 템플릿은 **이미 검증된 프로젝트의 정수**만 추출. 추측으로 만들지 말 것.
- 1번 프로젝트 끝나고 정리 → 2번 프로젝트 시작 시 적용 → 3번 프로젝트에서 안정화.
