# 2~4주차 개발 계획 (요약)

> **중요:** 이 문서는 **1주차 완료 후 구체화**한다.
> 1주차 결과 (재미 검증) 에 따라 내용이 크게 바뀔 수 있음.
> 지금은 방향성만 기록.

---

## 2주차: 관리 시스템의 씨앗

### 목표
**"운전에 긴장감이 추가되는가"** 확인.

### 주요 작업
- [ ] 단순 화물 시스템 (Shock 민감도만, 박스 1종)
- [ ] 단순 타이어 시스템 (단일 수명, 바퀴 구분 없음)
- [ ] 단순 연료 시스템 (소비 + 고갈 시 정지)
- [ ] 간단한 HUD (화물 무결성, 타이어, 연료 게이지)
- [ ] 배달지 노드 3~4개 배치
- [ ] 시작 → 배달지 순회 → 복귀 기본 루프

### 체크포인트
- 화물이 손상될까봐 운전 스타일이 바뀌는가?
- 긴장감이 있는가?

### 금지
- 경로 계획 UI (아직)
- 주문 선택 보드 (아직)
- 피트스탑 QTE (아직)

## 3주차: 계획이 핵심으로

### 목표
**"경로 계획이 실제로 의미 있는가"** 확인.

### 주요 작업
- [ ] 노드-엣지 그래프 데이터 구조 설계
- [ ] 경로 계획 UI 프로토타입 (드래그로 순서 지정)
- [ ] 실시간 예측 수치 (거리, 시간)
- [ ] 타이어 3종 (Soft/Medium/Hard)
- [ ] 피트스탑 구현 (QTE는 MVP+1로 연기 가능)
- [ ] Spin 민감도 추가 (활어 등)
- [ ] 화물 종류 3~4종

### 체크포인트
- 계획하고 달리는 것과 즉흥으로 도는 것의 결과 차이가 느껴지는가?
- 20% 이상 성적 차이가 나는가?
- NO면 경로 시스템 튜닝 필수.

## 4주차: MVP 완성

### 목표
**"5~15분 한 런이 완결되게 굴러가는가"** 확인.

### 주요 작업
- [ ] 주문 선택 보드 (8개 중 3~5개)
- [ ] 정산 화면
- [ ] 기본 업그레이드 트리 1단계
- [ ] 서킷 2~3개 (카피/변형으로)
- [ ] Tilt 민감도 추가
- [ ] 코너 경고 UI
- [ ] 기본 사운드 배치 (Kenny Audio)
- [ ] 런 반복 메타 루프 (허브 → 런 → 허브)

### 체크포인트
- 런 시작부터 끝까지 플레이가 자연스럽게 흘러가는가?
- 두 번째 런을 하고 싶은가?
- 업그레이드가 다음 런의 감각을 바꾸는가?

### MVP 선언 기준
아래 전부 YES일 때 MVP 완성:
- [ ] 한 런 5~15분 안에 완료된다
- [ ] 계획 → 실행 → 정산 3단계가 모두 작동한다
- [ ] 실패해도 다시 하고 싶다
- [ ] 최소 3종의 화물이 서로 다른 운전 스타일을 강제한다
- [ ] 2~3종의 타이어가 전략적으로 의미 있다
- [ ] 사운드/비주얼이 "플레이스홀더" 수준이라도 플레이 가능하다
