## 보는 법 (내 정리)
- 우리 방(`../bad/01_room_no_dot.png`)이 싫었던 이유 후보: 소품이 적고 면이 매끈·단색인데 해상도는 높아 '벡터'로 읽힘. 06·07(EDC)과 비교하면 EDC 도 단색 면이지만 저해상 + 소품 수 + 어둠 안개로 공간이 선다.
- 축 1 '소품 수': 07·04(5개 이하) ↔ 06·10·12(30개↑). 축 2 '해상도': 06·07·10·11·12(저해상) ↔ 01·08·13(매끈). 축 3 '윤곽선': 10·11·12 만 있음.
- 풍경 기준과 가장 가까운 실내 = 06·07(EDC, 같은 렌더), 그다음 04(Jalopy 저폴리+점광). 도현이 '살아 있는 방'을 원하면 10·12 쪽(물건 수)이 답.
