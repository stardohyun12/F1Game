[EDITOR][포장 첫 튜토리얼 — 조작법을 다 띄운다 (D-301)]
도현 원문: "포장 어떻게 해야하는지 초반 튜토리얼이니까 조작법 다 띄워주고". **안내 글 0 규칙의 예외**: 1일차 첫 포장에서만. 23b(53660cf3) 위에. 시간 상자 30분, Play 2회, 캡처 1장. 여는 파일 Presentation/PackBoardView.cs(+새 PackTutorial.cs), Core/또는 World 에 "첫 포장 봤음" 플래그(DayState 에 bool packTutorialSeen, 저장되는 곳에).
① 보드가 처음 열릴 때(packTutorialSeen=false) 판 왼쪽 위에 조작법 전부를 작은 흰 글씨(기존 세계 글꼴, 검은 테두리)로: 「상자 끌어 가운데 → 열림 / 뽁뽁이 롤 → 물건 위에 놓으면 감싸짐(2겹까지) / 종이 롤 → 집으면 구겨짐, 틈에 놓기 / 알갱이 통 → 클릭=한 줌, 상자 위에서 놓기 / R 회전 / 테이프 끌어 상자 가로지르기 → 닫힘 / 닫힌 상자 쥐고 흔들기 → 덜그럭 확인 / 상자를 판 아래로 끌면 들고 나감」. ② **지금 할 단계 한 줄은 밝게, 한 단계는 보드 상태에서 자동 판정**(상자 없음→상자 고르기 … 닫힘→흔들기). ③ 다 하고 나가면 packTutorialSeen=true, 이후엔 안 뜸. H 키로 언제든 다시 보기(작은 "H" 기호만 구석에). ④ 글은 world.yaml 이 아니라 코드 상수(한국어).
