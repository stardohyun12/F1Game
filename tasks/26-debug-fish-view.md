[EDITOR][디버그 창 — 「바다로 가서 낚시」 한 번에 · 「마을 풍경 제일 잘 보이는 곳」 (도현 11/05)]
도현 원문: "디버그 창에서 바로 바다로 이동해서 낚시 할 수 있게 만들고 우리 마을 풍경이 가장 잘 보이는 곳으로 이동 할수 있도록 해줘". 여는 파일: Debug/DebugWindow.cs·DebugPlaces.cs, world/world.yaml places(새 장소 1개). 시간 상자 30분, Play 3회(TEAM_ALLOW_PLAY=1), 캡처 2장.
① 버튼 **「바다로 가서 낚시」**: GoPlace(노을 낚시 자리) → 노을(SetDusk 1) → 바로 Fish() 까지 한 번에(정적 함수 `GoFish()` 하나로, 봇도 쓰게). 카트는 낚시 자리 규칙대로. 눌렀을 때 낚싯줄이 바다에 들어가 있는 상태가 되어야 함(앉기 단계가 필요하면 자동으로).
② **「마을 풍경 자리」 찾기**: 후보를 자동으로 고른다 — 지형 위 걸을 수 있는 점(언덕 꼭대기·큰길 끝·부두·등대 길·택배 보관소 앞·찻집 뒤 등 기존 장소 + 지형 높은 점 격자 20개), 각 점에서 마을 중심(건물 무리 중심)을 바라보는 1× 캡처를 찍고 점수 = 화면에서 건물 픽셀 비율(10~40% 사이 최고) + 바다 보임(≥10%) + 하늘 ≥ 20% + 지형 가림 없음(건물 중심까지 레이 통과). 상위 3개 1× 캡처를 `docs/qa/evidence/debug-view/cand_{1,2,3}.png` 에 남기고, **1위를 world.yaml places 에 「마을 풍경」으로 추가**(좌표·yaw, role 에 점수 적기) → DebugPlaces 에 자동 반영(gen.py). 버튼 「마을 풍경」 = GoPlace(그 자리), 시간은 지금 시간 그대로.
③ 디버그 창 맨 위에 이 두 버튼을 크게(기존 장소 목록 위).
확인: 컴파일 0 · world_check(새 장소 좌표 불변 통과) · 캡처 2장(낚시 중 1×, 마을 풍경 1×) + 후보 3장. 보고 3줄 + 후보 3개 점수표.
