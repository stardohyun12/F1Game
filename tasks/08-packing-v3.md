1. 받는 곳: 보관소 안 선반(회색 대역)에 오늘 물건(첫날 1개: 달걀, 줄리아, 찻집)이 놓여 있고, 가까이 가면 물건 위에 받는 사람·배달지가 종이 꼬리표로 보인다(세상 속 물건, 화면 UI 아님). E 로 집는다 → 손에 보인다. 칠판·쪽지 흐름(NotePicked)은 이 물건 집기로 대체(신호는 그대로 쏴서 뒤 흐름이 안 깨지게).
2. 포장대: 선반에 상자 소·중·대, 뽁뽁이 롤, 종이 롤. 상자 집어 작업면에 놓기(E). 작은 상자는 물건이 안 들어감(물리로 — 코드 막기 아님: 들어가다 걸림), 큰 상자는 들어가되 흔들림↑.
3. 롤: 시선+E 로 한 장 당겨 손에 → 상자 안에 놓기. 바닥 1장 + 물건 넣고 + 덮기 1장. 종이/뽁뽁이는 Core 궁합(달걀=깨짐 → 뽁뽁이 효과 큼, 종이 작음).
4. 닫기·테이프·흔들기는 04 안대로(테이프 드래그, 들고 흔들면 소리·떨림). 결과는 기존 파손 3단으로.
5. 안내 0. 첫날만 직원이 옆에서 한 줄씩("(대사 자리 — 먼저 물건)" 등 4줄, 말풍선).
