## 핵심 개념

타이어가 "코너 관리"라면, 연료는 "장거리 관리".
**부스트는 별도 자원** — 통합 폐기. 두 자원의 갱신 채널을 분리해야 둘 다 의미를 가짐.

---

## 설계 기준 (K4)

**"한 런 안에 주유 결정 2~4번"** = 핵심 감각 기준.

수치 기준(분당 소비량, km당 효율)이 아니라 **의사결정 빈도**로 튠.
런 길이가 5~15분으로 유동적이므로 분당·km당 고정 수치는 깨지기 쉬움.
**구현 시 수치는 위 빈도가 나오는 값으로 역산.**

> **K4 결정 사유:** F1 공식 게임도 시간 시뮬 축약 없음 (5랩 모드든 100% 모드든 랩당 연비 동일, 1.6~1.9 kg/랩). PIT CREW가 110 kg/90분 현실을 5~15분에 맞추려면 18배+ 가속 축약 필요 — 이는 "시뮬레이션 충실도" 발상을 아예 버려야 함을 의미. 따라서 의사결정 빈도 기준으로 전환.

## 연료 소비 (감각 기준 → 수치 역산)

### 기준 행동별 상대 소비

| 행동 | 상대 소비 | 비고 |
|---|---|---|
| **정속 주행** | 1.0× (기준) | 80km/h대 정속 |
| **최고속 지속** | 2.0× | 마진 빠듯 |
| **급가속 (속도 70% 이상에서 풀쓰로틀)** | 1.5× | 이벤트성 |
| **공회전 (정지 중 시동 켬)** | 0.3× | 적신호 대기 등 |

### 탱크 용량 (감각 가이드)

런 시작 시 풀탱크 가정 시:
- **정속 주행만으로** → 한 런 1.5배 분량 = 여유 있음
- **공격적 주행** → 한 런의 60~80% = 빠듯 (1~2회 주유 결정)
- **부스트 자주 + 최고속 빈번** → 한 런 절반 = 잦은 주유 결정 (3~4회)

> 구현 시 "정속 주행만 = 풀탱크로 12분"이 시작 튠값. 플레이 보면서 조정.

## 주유소 (피트와 별개)

배달 게임의 정체성을 살리려면 **주유와 피트(타이어 교체)를 분리**.
- **주유소:** 맵에 다수 (4~8개), 셀프 또는 풀서비스
- **피트:** 맵에 1~2개, 타이어/정비 전용

| 주유 옵션 | 시간 | 효과 |
|---|---|---|
| **반만 채우기** | 3초 | 빠른 출발 |
| **꽉 채우기** | 5초 | 다음 주유까지 더 길게 |
| **(Post-MVP) 무게 트레이드오프** | - | 꽉 채우면 가속 -5% |

---

## 연료 고갈

연료 0% → 차량 정지.
**견인 호출 이벤트:**
- 30초 무력화
- 다음 배달지 근처에서 재시작
- 연료는 최소량만 보충 (절반)
- 시간 패널티 = 총점 감소

**견인은 한 번까지.** 두 번째 고갈 = 런 종료.
