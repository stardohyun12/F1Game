# GDD — 타이어 시스템

## 핵심 개념

F1의 타이어 전략을 배달에 가져온다.
"빠른 타이어는 빨리 닳는다"는 단순한 트레이드오프가 전략 깊이의 원천.

## 타이어 종류

| 종류 | 색상 | 그립 | 수명 | 적합 노면 |
|------|------|------|------|-----------|
| Soft   | 빨강 | ★★★★★ | 6~8 km   | 마른 아스팔트 |
| Medium | 노랑 | ★★★★   | 12~15 km | 범용 |
| Hard   | 백색 | ★★★    | 20+ km   | 장거리 |
| Wet    | 청색 | (비에서 최강) | 마른 노면에선 급속 소멸 | 젖은 노면 전용 |

## 마모 요인

다음 행동이 타이어를 갉아먹는다:

- **드리프트** — 가장 큼 (+5~10 / 초)
- **급제동** — 큼 (+3~5 / 이벤트)
- **코너링 속도 초과** — 중 (+2~3 / 코너)
- **노면 거칢** (자갈, 공사장) — 중 (+1~2 / 구간)
- **최고속도 지속** — 소 (+1 / 10초)
- **정속 주행** — 미미 (+0.1 / 10초)

## 그립 감소 곡선

타이어 수명 100% → 0%로 갈수록 **그립이 비선형으로 감소**.

```
그립 = max(0.3, 1.0 - (1 - lifespan_ratio)^2)

수명 100%: 그립 1.0
수명  75%: 그립 0.94
수명  50%: 그립 0.75
수명  25%: 그립 0.44
수명  10%: 그립 0.19 (클리프)
수명   0%: 펑크
```

**50% 지점을 지나면 급격히 위험해진다.** 이게 피트 타이밍 고민의 원천.

## 펑크

수명 0% → 그 바퀴 펑크. 차량이 한쪽으로 끌리고 최고속 -50%.
견인이 아니라 **"절뚝이며 피트까지 가기"**가 가능해서 리커버리 재미 있음.

## 노면 종류

- **마른 아스팔트** — 표준
- **젖은 아스팔트** — Wet 타이어 유리, 그 외 그립 -30%
- **자갈길** — 마모 +50%
- **공사장/손상 노면** — 마모 +80%, 그립 -10%

MVP에서는 **마른 아스팔트 + 젖은 아스팔트** 2종만 구현.
자갈/공사장은 3주차 이후.

## 피트스탑 시간

| 작업 | 시간 |
|------|------|
| 연료만 | 5초 |
| 타이어 교체 | 7초 |
| 연료 + 타이어 | 12초 |
| 화물 재고정 | +3초 |
| 전체 정비 | 18초 |

피트 QTE(아래)로 시간 단축 가능.

## 피트 QTE (리듬 액션)

피트 작업을 단순 대기로 만들면 지루함.
**각 작업마다 작은 리듬/타이밍 입력** 추가.

### 타이어 교체 QTE
4개 바퀴에 대해 순차적으로 버튼 프롬프트.
타이밍 맞추면 해당 바퀴 빨리 교체. 총 시간 -30% ~ +30% 변동.

### 연료 주입 QTE
게이지 바가 움직임. 원하는 양에서 정지 버튼 누르기.
꽉 채우면 시간 오래, 절반만 넣으면 빠름.

### 화물 재고정 QTE
간단한 2초짜리 매칭 퍼즐 (선택 사항, MVP 이후).

## 타이어 HUD

주행 중 상시 표시:

```
FL: ●●●○○ 65%  FR: ●●●●○ 80%
RL: ●●○○○ 40%  RR: ●●○○○ 42%
```

**각 바퀴별 개별 표시**가 중요. 드리프트는 특정 바퀴가 먼저 닳아서
"앞바퀴 오래 쓰려면 후륜 드리프트" 같은 스타일 전략 가능.

## MVP 범위

**1주차:** 타이어 시스템 없음.
**2주차:** 단일 타이어 수명 (바퀴 구분 없음). 0% 되면 경고.
**3주차:** 3종 타이어 (Soft/Medium/Hard). 피트스탑 구현.
**4주차:** 4바퀴 개별 마모. Wet 타이어.

## 확장 아이디어 (MVP 이후)

- 타이어 온도 시스템 (예열/과열)
- 타이어 제조사 선택 (브랜드별 특성)
- 타이어 압력 조절 (출발 전 세팅)
- 재생 타이어 (친환경 옵션, 수명 짧지만 저렴)
