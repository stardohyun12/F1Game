# GDD — 화물 시스템 (Cargo Integrity)

## 핵심 개념

플레이어의 운전 스타일이 화물에 실시간으로 영향.
**"빨리 달리고 싶은데 화물이 걱정된다"** 가 이 시스템이 만들어야 하는 감정.

## 화물 민감도 3축

각 화물은 세 가지 민감도를 가진다.

### Shock (충격)
- 트리거: 충돌, 급제동, 과속방지턱, 점프 착지
- 예시 영향 화물: 크리스탈, 계란, 도자기

### Spin (회전)
- 트리거: 급커브, 드리프트, 급턴
- 예시 영향 화물: 활어 수조, 액체 음료, 수프

### Tilt (기울기)
- 트리거: 경사로 오래 주행, 카메라상 차체 기울기 유지
- 예시 영향 화물: 생일 케이크, 탑을 쌓은 상자, 기계 부품

## 민감도 레벨

| 레벨 | 표기 | 허용 임계 | 데미지 배율 |
|------|------|-----------|-------------|
| None | — | 무제한 | 0x |
| Low | ● | 높음 | 1x |
| Mid | ●● | 중간 | 2x |
| High | ●●● | 낮음 | 4x |
| Extreme | ●●●● | 거의 없음 | 8x |

## 화물 무결성 수치

각 화물은 **100 → 0** 범위 무결성 수치 보유.

- **100~80:** 완전 (전액 보상)
- **80~50:** 약간 손상 (80% 보상)
- **50~20:** 크게 손상 (50% 보상)
- **20~1:** 거의 전파 (20% 보상)
- **0:** 전파 (0% 보상, 환불)

## 데미지 계산 (의사 코드)

```
on_event(event_type, intensity):
    sensitivity = cargo.get_sensitivity(event_type)
    # event_type ∈ {Shock, Spin, Tilt}
    if sensitivity == None:
        return
    damage = intensity * sensitivity_multiplier[sensitivity]
    damage *= difficulty_modifier
    cargo.integrity -= damage
    trigger_feedback(damage)  # 햅틱/사운드/UI
```

## 플레이어 피드백

화물이 손상되는 순간의 피드백이 게임 감각의 핵심.

- **시각:** 화면 가장자리 빨간 플래시, 화물 아이콘 흔들림
- **사운드:** 유리 깨지는 소리, 액체 출렁임, 금속 긁힘
- **UI:** 화물별 무결성 바 상단 HUD에 상주
- **예방 UI:** 위험한 코너 진입 시 경고 (선택적, 업그레이드로 활성)

## 코너 진입 경고 UI (중요)

화물 민감도가 높을수록 **코너 직전에 UI 경고**가 뜬다.

```
  [⚠ SHARP TURN 50m]
  [Crystals at risk: slow to 40 km/h]
```

이게 있어야 플레이어가 "어 감속해야지" 하는 판단을 내림.
경고 없이 느닷없이 손상되면 불공정하다고 느낌.

## MVP 범위

**1주차:** 무결성 시스템 없음. 그냥 운전 재미만 체크.
**2주차:** Shock 1종만 구현. 충돌 시 감소. 박스 1종.
**3주차:** Spin 추가. 화물 종류 3~4종.
**4주차:** Tilt 추가. 경고 UI 추가. MVP 완성.
