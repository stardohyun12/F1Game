# GDD — 게임 개요

## 원문장 피치

> 포뮬러 원 팀의 전략가가 매일 아침 오늘의 배달 계획을 세운다.
> 드라이버는 당신, 엔지니어도 당신, 전략가도 당신.

## 장르

레이싱 × 배달 × 경로 최적화 퍼즐 × 로그라이트

## USP — 차별점 4가지 (세션 10, 2026-04-23 명문화)

> 매 시스템 결정은 이 4가지 중 하나 이상을 강화해야 채택. 강화 안 하면 `ideas-parking.md` 직행.

1. **압축 폼팩터 — 5~15분 한 런** = 카페 한 잔/출퇴근 시간/티타임. EDC(무제한)·Pacific Drive(90분+)와 차별.
2. **결정 밀도 — 한 런에 핵심 결정 4개** (주문/경로/세팅/업그레이드). 카드게임 로그라이트 수준의 매 런 의미. Crazy Taxi·EDC·Burnout 모두 결정 0~1개/런.
3. **운전감 — Burnout급 아케이드 드리프트 + 시각적 즉각 피드백** (D-007 정체성). 시뮬 X, 코지 X. "운전 자체가 재미"라는 1주차 체크포인트의 의미.
4. **로그라이트 정산 — 업그레이드가 다음 런 감각을 바꿈** (core-loop.md 체크리스트). 단방향 진보(EDC) 아님, 매 런이 다른 빌드.

### 시장 빈 칸 (왜 이 조합인가)

| 게임 | 길이 | 결정/런 | 정산→다음런 |
|---|---|---|---|
| Easy Delivery Co. | 무제한 (총 5h) | 낮음 | 단방향 |
| Crazy Taxi | 라운드 짧음 | 1 | 없음 |
| Burnout Paradise | 이벤트 짧음 | 0 | 차량 잠금 |
| Pacific Drive | 90분+ 런 | 높음 | 로그라이트 |
| **PIT CREW** | **5~15분** | **4** | **로그라이트** |

위 4 게임 어느 것도 "5~15분 + 결정 밀도 + 로그라이트 + 운전감"을 동시에 만족하지 못함.

### 메커니즘은 빌려도 USP는 지킨다

EDC의 운전자 자원·장비 잠금해제 등 메커니즘 차용은 **USP 보조 도구**로만. USP 자체는 메커니즘이 아니라 위 구조에 있다.

위험 신호: "이 시스템이 어느 USP를 강화하는가?" 답이 모호하면 추가 금지.

## 톤

**쿨하고 스타일리시 + 박살내는 카타르시스.**
F1의 진지함과 "피자 배달"이라는 코믹한 갭이 게임의 매력.
Kenny 에셋의 귀여운 로우폴리 미학을 F1 브로드캐스트 UI 스타일과 대비시켜 사용.

## 타겟 경험

플레이어가 한 런 동안 느껴야 할 감정:

1. **계획할 때:** "어떤 순서로 돌까, 뭘 받을까" — 머리 쓰는 만족감
2. **출발할 때:** "가자" — 몰입 진입
3. **주행 중:** "빠르게 가고 싶은데 박스가 걱정된다" — 긴장
4. **코너:** "여기서 속도 줄여야 하나 말아야 하나" — 실시간 판단
5. **피트 결정:** "지금 들어갈까 한 바퀴 더 돌까" — 자원 관리
6. **완주:** "내 계획이 통했다 / 실패했다" — 성취 혹은 재도전 동기

## 플레이어 층

- **초보:** 한 번에 적게 배달, 쉬운 화물, 안전 운전
- **중수:** 복잡한 경로 짜기, Shock/Spin 화물 혼합, 피트 타이밍 실험
- **고수:** 숨겨진 지름길 + 최적 경로 + 타이어 전략으로 보상 극대화

## 한 런의 구조

```
[허브/차고]
  ↓
[오늘의 주문 보드]      ← 주문 선택 (8개 중 3~5개)
  ↓
[경로 계획 화면]        ← 노드 순서 지정, 피트 위치 결정
  ↓
[출발 전 세팅]          ← 타이어 종류 결정
  ↓
[주행]                 ← 실시간 컨트롤 (5~10분)
  ↓
[정산]                 ← 수익, 평판, XP
  ↓
[업그레이드]            ← 상점/트리
  ↓
[다시 허브]
```

## 핵심 가치 제안

**"자동차 게임 + 머리 쓰는 재미"의 교차점.**

대부분 자동차 게임은 반사신경 중심. 대부분 경로 퍼즐 게임은 액션이 없음.
PIT CREW는 둘을 합친다. 계획한 대로 달리는 만족감 = 이 게임의 고유한 매력.

## 비전투 게임

명시적 전투/무기 시스템 없음.
"경쟁자 배달원"과의 상호작용은 **블로킹/추월** 수준에 한정.
주제는 **운송**, 파괴가 아님.

## 개발 배경

도현은 이전에 **ExulMundi** (탑다운 2D 탄막 덱빌딩 로그라이트)를 Unity 6로 개발 중이었으나,
스코프가 지속적으로 부풀어 완성에 이르지 못함.

**PIT CREW는 "완성 가능한 프로젝트"를 최우선 목표로 한다.**
- 완성도 > 야망
- 스코프 고정 > 기능 추가
- 재미 검증 > 시스템 확장

## 영감 받은 게임들 (참고용, 복제 대상 아님)

- **F1 22 / F1 23:** 피트스탑, 타이어 전략, 무전 문화
- **Crazy Taxi:** 배달의 즉흥 속도감
- **Papers, Please:** 선택의 긴장감
- **Mini Metro / Mini Motorways:** 경로 최적화 UX의 미니멀리즘
- **Death Stranding:** 화물 관리의 긴장감
- **Slay the Spire:** 런 구조와 메타 업그레이드
- **Easy Delivery Co.:** 잡 보드 UI · 장비 잠금해제 · 이중 게이지 (운전자 자원). USP는 차별, 메커니즘만 차용. (`research/easy-delivery-co.md`)
- **Burnout Paradise:** 부스트 burst 액션. (`research/claude-web-findings-v2.md` U2 = 풀바 8초)
