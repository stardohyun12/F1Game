## 활용 매트릭스 (세션 11 기준)

| 유형 | 현재 사용 | 향후 활용 후보 |
|---|---|---|
| 직선 | `road-straight` | `road-straight-half`(1/2 셀), `road-straight-barrier` (edge) |
| 커브 | `road-bend` | `road-bend-sidewalk`, `road-curve` (2×2 큰 커브), `road-curve-intersection` (커브+T) |
| T 교차로 | `road-intersection` | `road-intersection-line`, `road-intersection-path` (pedestrian crossing) |
| + 교차로 | `road-crossroad` | `road-crossroad-line`, `road-crossroad-path` |
| Dead-end | `road-end` | `road-end-round`, `road-end-barrier` (cul-de-sac) |
| **Roundabout** | 없음 | `road-roundabout` — Downtown 중앙 허브 후보 |
| **Split (Y-분기)** | 없음 | `road-split` — 오픈월드 지름길 시작점 |
| **Side-entry/exit** | 없음 | `road-side-entry`, `road-side-exit` — 블록 진입/진출 |
| **Driveway** | 없음 | `road-driveway-single/double` — 건물 앞 진입로 |
| **Slant (경사)** | 없음 | `road-slant`, `road-slant-curve`, `road-slant-flat` — 언덕/오르막 |
| **Bridge** | 없음 | `road-bridge`, `bridge-pillar` — 다리 |
| **Square/Tile** | 없음 | `road-square`, `tile-high`, `tile-low`, `tile-slant`, `tile-slantHigh` — 광장/테라스 |
| **Crossing** | 없음 | `road-crossing` — 횡단보도 단독 |
| **Signs** | 없음 | `sign-highway`, `sign-highway-detailed`, `sign-highway-wide` — 랜드마크 후보 |
| **Lights** | 없음 | `light-square`, `light-curved`, `*-cross`, `*-double` — 디테일 프롭 (4주차 파킹) |
| **Construction** | 없음 | `construction-barrier/cone/light` — 장애물/데코 |
