# 도현 체크리스트 (모든 과제·판정자에 자동으로 붙음 — team.sh)
도현이 이미 한 번 거부한 것. 산출물이 하나라도 걸리면 "완료"가 아니다. 보고서 끝에 항목별 OK/걸림 표.

## 그림·아트
1. AI 생성 이미지·3D 금지(Hunyuan3D·Hyper3D·imagegen 포함). 재료는 CC0/PD 사진, 출처 기록.
2. 장난감·아기자기·동글이 모양 금지(실물 비례). 사람은 PS1 로우폴리 실물 비례.
3. 녹·때·곰팡이 얼룩 금지 — 손질된 낡은 칠은 좋음.
4. 빛·그림자를 텍스처에 굽지 않음(게임 안 실시간 빛).
5. 선명한 픽셀 계단·지글거림 금지, 사진 점무늬(더러움) 금지.
6. 깨끗한 흰 벽·벡터처럼 매끈한 단색 면 금지.
7. 간판 글자는 도현이 정한 이름만(예시 이름 지어내지 않기).

## 맵·건물
8. 아파트 느낌 금지: 4층 상자·격자 창·평지붕 일색(D-211).
9. 노출 기단 ≤0.8m, 솟은 받침 위 상자 금지(D-218).
10. 띄엄띄엄 금지 — 땅 필지 채움 80%+, 언덕은 층층(D-220).
11. 도현이 놓은 건물 위치·높이·노선은 바꾸지 않음(필요하면 멈추고 보고).
12. 트랙·서킷처럼 보이는 것 금지(마을 길 흰 선·잔디 교통섬).

## 일하는 방식
13. 도현이 정한 값(해상도 720 등)을 바꾸지 않음 — 다른 값은 비교 컷으로만.
14. 판정은 게임 화면(같은 카메라 전/후). 숫자만으로 "고쳤음" 금지.
15. 60분 안에 끝나는 크기로. 못 끝내면 멈추고 남은 일만 보고(반쯤 된 결과를 늘리지 않음).
