# Codex 실행 안내

이 폴더는 구현 요청과 사용자가 제공한 참고 이미지 패키지입니다. 제품 코드나 구현 완료본은 포함하지 않습니다.

1. 이 폴더를 `D:\Github\F1Game\docs\pitcrew_codex_handoff`에 압축 해제합니다. ZIP 안에 폴더가 있으므로 중복 폴더가 생기지 않게 확인합니다.
2. PitCrew 밖의 로컬 Codex에서 F1Game 저장소를 엽니다.
3. 아래 요청을 보냅니다.

```text
docs/pitcrew_codex_handoff/CODEX_PROMPT.md를 읽고 작업을 진행해 줘.
먼저 REFERENCE_GUIDE.md와 references/의 PNG 4장을 이미지 보기 기능으로 실제로 열어 확인해.
현재 구현과 사용자 변경을 보존하고, 첫 사용자 흐름을 단계적으로 구현·검증해.
파일명이나 이미지 설명만 읽고 이미지를 확인했다고 하지 마.
```

다른 위치에 압축을 풀었다면 위 경로만 실제 위치로 바꾸면 됩니다. Codex가 이미지를 열 수 없다면 PNG를 대화에 직접 첨부합니다.

포함 파일: CODEX_PROMPT.md(통합 구현 요청), REFERENCE_GUIDE.md(이미지 해석), references/PNG 4장(원본), SHA256SUMS.txt(무결성 확인).
