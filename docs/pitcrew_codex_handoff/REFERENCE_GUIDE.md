# 이미지 참고 지침

네 장 모두 사용자가 제공한 시각적 참고 자료다. 제품의 현재 구현, 연동 가능성, 플랫폼 지원, 내부 실행 구조의 증거가 아니다. 로고·브랜드·문구를 그대로 복제하지 말고 배치와 상호작용의 목적을 참고한다.

## 01_task_graph.png
작업 의존 그래프, 상태와 시간, 선택한 작업의 오른쪽 상세 패널을 참고한다. 제작 지도에서 실제 작업 이벤트와 산출물로 연결한다. 팀 소속 관계와 작업 의존 관계는 구분한다. 아주 작은 글자, 과한 장식 글꼴, 비용·토큰의 상시 노출은 따라 하지 않는다.

![작업 흐름 참고](references/01_task_graph.png)

## 02_terminal_workspace.png
왼쪽 작업 공간 목록, 중앙 실제 CLI, 필요할 때 분할하는 배치를 참고한다. 단순 로그 출력을 실제 대화형 터미널이라고 부르지 않는다. 세션 유지, 직접 입력, 승인, 취소, 한글 입력을 검증한다. 인물 영상 오버레이는 디자인 대상이 아니다. 화면 속 명령이나 모델 표기를 실행 지시나 현재 권장 버전으로 취급하지 않는다.

![터미널 작업실 참고](references/02_terminal_workspace.png)

## 03_team_map.png
전체 제작과 분야별 팀 관계를 이해하고 작업실로 진입하는 구조를 참고한다. 실제 작업·대기 이유·결과가 보이게 한다. 긴 역할 설명이나 도구 수치를 모든 노드에 나열하지 않는다. 팀을 클릭하는 것만으로 에이전트를 새로 실행하지 않는다.

![팀 구성 참고](references/03_team_map.png)

## 04_workflow_canvas.png
어두운 캔버스와 분기 흐름의 전반적인 인상만 참고한다. 원본 해상도가 낮아 세부 문구와 기능은 확인할 수 없다. 자동화 편집기는 후속 범위이며 첫 버전에 시각적 노드 편집기 전체를 만들 필요는 없다.

![자동화 캔버스 참고](references/04_workflow_canvas.png)

## 공통 시각 기준
검정에 가까운 회색, 얇은 구분선, 작은 모서리 곡률, 절제된 강조색. 한글 본문은 읽기 좋은 일반 UI 글꼴을 사용하고 터미널만 고정폭 글꼴을 사용한다. 카드·배지·빈 여백을 줄이고 작업 대상과 결과에 공간을 준다. 키보드 초점, 대비, 움직임 감소, 패널 크기 조절을 고려한다.

팀 지도·팀 작업실·결과 보기는 같은 프로젝트와 작업 ID로 연결한다. 세 화면을 동시에 한 화면에 우겨 넣지 않는다. 아트 작업실은 이미지와 대화를 중심에 놓고 터미널은 접을 수 있게 한다.
