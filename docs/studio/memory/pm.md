## 교훈
- 구현 완료 ≠ 닫힘. 차고 Task 1~11처럼 커밋만 있고 검증 없는 항목이 쌓인다. PM 부활 시 git log vs 검증 여부 cross-check 필수.
- 맵 아트 항목이 backlog 상단에 있으면 임계경로 착시 유발. 폴리싱은 항상 3순위 아래.
- brief:ready는 파일 실존 시만. 이번 이전엔 briefs/ 폴더가 비어있었음에도 backlog에 ready 표시된 항목 있었음 (항구 ground 등).
