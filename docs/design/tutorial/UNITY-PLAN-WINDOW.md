# Unity 기획 도구 — 씬 뷰에서 바로

1. 씬 뷰 오른쪽 아래 **[💬 코멘트]**(또는 **C**)를 켠다. 위에 안내 한 줄이 뜬다.
2. **클릭** = 물건/땅에 입력칸 → 쓰고 **Enter**(스샷 자동 저장) · **Esc** 취소. **드래그** = 빨간 선, 글 없이 Enter 해도 됨, **Backspace** = 마지막 선 지우기.
3. 저장한 코멘트는 주황 **핀(번호)**. 핀 클릭 = 내용·스샷·[처리됨]. 처리된 핀은 회색, [처리된 핀 숨김]으로 감춘다. 목록은 메뉴 `PitCrew/기획 창`.
4. 건물 옮기기는 평소처럼 하고 **Ctrl+S** 만 — 저장할 때 `placements.yaml` 에 자동 기록. 새 건물은 [건물 놓기…]에서 고르고 씬을 클릭.
5. 모드를 켜 두거나 기획 창을 열어 두면 AI 팀원의 에디터 작업이 기다린다.
