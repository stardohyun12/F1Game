# Unity 기획 도구 — 씬 뷰에서 바로

1. 씬 뷰 오른쪽 아래 **[💬 코멘트]**(또는 **C**)를 켠다. 위에 안내 한 줄이 뜬다.
2. **클릭** = 물건/땅에 입력칸 → 쓰고 **Enter**(스샷 자동 저장) · **Esc** 취소. **드래그** = 빨간 선, 글 없이 Enter 해도 됨, **Backspace** = 마지막 선 지우기.
3. 저장한 코멘트는 **핀(번호)**: 흰색 = 할 일, **초록 = 팀원이 고쳤음(내가 볼 차례)**, 회색 = 끝. 핀 클릭 = 내용·팀원 답·스샷. 목록은 메뉴 `PitCrew/기획 창`.
4. 초록 줄엔 팀원 답(2줄)과 전/후 스샷. 됐으면 **[넘기기]**(끝), 아직이면 **[다시]** → 입력칸에 쓰고 Enter → 그 줄이 다시 「할 일」로, 내 글이 대화에 붙는다. 맨 위 필터 = 고쳤음 n / 할 일 n, 끝난 것은 [끝난 것 보기]. 회색 [배치] 줄은 자동 기록이라 할 일 없음.
5. 팀원은 `python scripts/fb.py list` 로 할 일을 보고, 고치면 `fb.py fixed <id> "무엇을 고쳤나" --shot 후.png`(끝으로는 못 바꾼다). 웹 뷰어 코멘트도 같은 파일 형식.
6. 건물 옮기기는 평소처럼 하고 **Ctrl+S** 만 — 저장할 때 `placements.yaml` 에 자동 기록. 새 건물은 [건물 놓기…]에서 고르고 씬을 클릭.
7. 모드를 켜 두거나 기획 창을 열어 두면 AI 팀원의 에디터 작업이 기다린다(F1 = `editor.lock`, 건물 스튜디오 F1Studio = `studio.lock`).
