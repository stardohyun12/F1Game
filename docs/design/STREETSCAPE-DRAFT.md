## 1. 마을의 향기 — 달리는 카트에서 "사람이 사는 동네"로 읽히는 것

### 1-1. 도모노우라 (tomo — 항구 심장)
- **조야토 돌 등대**: 1859년, 등 5.7m + 받침 3.4m, 바닥 석축까지 10m 넘음, 항구 남서 끝, "마을의 상징". [확인] https://visittomonoura.com/qr-item/highlight-tomonoura/?lang=en · https://www.japan-guide.com/blog/a-stroll-through/240427.html
- **간기(雁木) 선창 돌계단**: 물때와 상관없이 배를 대려고 만든 계단식 선창, 총 길이 약 150m, 가장 넓은 곳 24단, 항구를 빙 두름, 1811년부터 지금도 선착장. [확인] 위 두 쪽
- **하토(돌 방파제) 셋 · 후나반쇼(망루) 돌담·돌계단 · 종루** — "에도 항구 다섯 시설이 다 남은 곳". [확인] 위 두 쪽
- **길·집**: "처마끼리 이어 붙은 좁은 줄집, 바다로 열리는 좁은 길·골목", 반원 항구에 자갈돌 포장. [확인] 같은 쪽
- **앞면**: 좁은 정면 + 안으로 긴 집, **처마 높이가 집마다 다름**, 에도 집과 서양식 집이 섞이고 문·난간 모양이 집마다 다름, 회벽 + 판자벽(누름대) + **무사창 격자창**, 쐐기돌을 끼운 옛 부두 석축(겐치이시). [확인] https://visittomonoura.com/qr-item/important-preservation-district/?lang=en
- **간판·노렌**: 출처 원문에서 직접 확인 못 함 → 도현이 고른 사진 D1(쌀가게)·D2(소바집 노렌)(`art/source/photo-picks/PICKS.md`)으로 대신. [요약만/사진]
- → 우리 해석: **항구는 "돌"과 "처마"의 동네**. 길가 눈높이 = 돌계단·돌담·석축 + 들쭉날쭉 처마 + 격자창. 운전 중 랜드마크 = 조야토(항구 방향 표지).

## 2. 길가 요소 팔레트 (4층)

읽기 계산(가설): 카메라 B FOV 64°, 내부 720 → 거리 d m 에서 1m ≈ 576/d px (10m 58px · 20m 29px · 40m 14px · 60m 10px). 카트 속도 가정 12~17m/s → 100m ≈ 6~8초. **20m 밖에서 0.3m 미만은 점**이 되고, 운전 신호는 40m(≈2.5초 전)에서 10px 이상이어야 한다.
표기: 왜 마을 / 자리 규칙 / 100m당 / 720 읽힘 / 운전 신호.

### 2-1. 도로 자체
- **연석·낮은 경계(8~12cm)**: 사람 공간과 차 공간을 가르는 첫 신호(D-139) / village·main 양쪽, alley 없음, 갈림목 다각형 안에선 둥글게 끊음 / 연속 / 밝은 띠 한 줄로 길 모양을 그려 줌 — 좋음 / **코너 모양을 미리 보여 줌**(가장 값싼 운전 신호). 넘으면 화물 흔들림(대가).
- **배수로(U형 덮개·돌 홈)**: "사람이 깎은 길"(D-133) / 산 쪽 가장자리, 경사 >4% 구간, 커브 안쪽엔 빗물받이 / 연속 + 빗물받이 1~2 / 어두운 선 한 줄로 읽힘 / 산 쪽이 어딘지 알려 줌.

## 5. 만드는 방법
- **규칙 배치(대부분)**: 입력 = RoadNetV2 의 사슬(`V2L`: id·kind·폭 w·중심선 p·끝 마디 n0/n1) + 갈림목 다각형(`jPolys`) + `env-buildings.json`(유형·front_road_id·front_setback_m·sparse) + 구역(piece).
  - 사슬마다 **호 길이로 걸어가며** 요소별 간격(위 100m당 값) + 사슬 id 해시 지터(±20%, 재실행 = 같은 결과).
  - **옆 정하기**: 산 쪽/바다 쪽(지형 높이 기울기 부호), 전봇대 = 산 쪽, 난간·가로등 = 바다 쪽, 소품 = 건물 front_edge 가 닿은 쪽.
  - **오프셋**: w/2 + 연석(0.15) + 인도/길가띠, 연석에 **정렬**(접선 yaw), 땅 높이는 레이캐스트(도로 콜라이더 제외 레이어).
  - **피하기**: 갈림목 다각형 + 4m 안 금지(볼록거울·전봇대 모서리 하나만 예외), 건물 폴리곤 + 0.3m, 계단·alley 입구 2m, 경사 >15% 구간엔 소품 X(석축만).
  - **이유 묶음**: 가게(shop_house) 앞 = 차양+진열+자판기 무리 / 계단 입구 = 화분 양옆+볼록거울 / 선창 = 어구 / 성긴 집 = 담·대문·텃밭 세트. 낱개 흩뿌림 금지.
  - **같은 부품 반복 제한**: 한 화면(카메라 앞 60m)에 같은 메시 변형 ≤2(ART-RULES 3 "6채 중 2채").
  - 출력 = 배치 목록 json(`docs/map/streetscape-*.json`, 요소·좌표·yaw·이유) → Unity 는 그걸 읽어 별도 루트 `STREET_*` 로 깔기만. 되돌리기 함수 + 공유 .mat 수정 0(씬 전용 사본). 평면 목록은 Unity 없이 뷰어 맵(`export_map.py`)·평면 PNG 로도 볼 수 있음.
  - 콜라이더: 전봇대·가로등·자판기·주차 차 = 상자, 화분·어구·빨래·데칼 = 없음, 과속방지턱 = 낮은 범프, 연석 = `groundLayer` 에서 뺀 레이어(바퀴 레이가 타고 넘지 않게 — 스킬 함정).
- **손 배치(히어로 6~8곳, D-151·D-191 — 배치는 도현)**: 조야토+간기(tomo 항구) · 항구 찻집 앞 · 카몰리 산책로 끝(큰 팬 자리) · 핵심 4채 능선 광장 · posi 헤어핀 계단 다발 하나 · 꼭대기 집 앞 · 등대. 팀은 자리 후보·소품 세트만, 위치는 도현이 기획 창에서.
- **검증**
  - 접지: `scripts/fb_geom.py` 식 일괄 레이캐스트(소품 바닥 네 모서리 뜸·묻힘 >5cm 0, 길 띠 침범 0, 건물 겹침 0).
  - 맵 카메라 시트: 이름 붙은 카메라 `Cam_ST_tomoHarbor`·`Cam_ST_tomoMain`·`Cam_ST_camoCoast`·`Cam_ST_ridge`·`Cam_ST_posiHairpin`(카트 B 높이) 720 Nearest + Kuwahara 3~4 로 없음|있음 나란히, `audit_lite.py` 수치 + TONE 질문 5개 + "흩뿌려 보이나 / 장난감 같나 / 같은 물건 반복".
  - 주행: `TownPathBot` 같은 경로 Box·Wheels 전후 — 끼임·멈춤·화물 충격 수(±6 흔들림 안이면 "같음"), 소품 콜라이더 충돌 횟수 따로.
  - 8초 주행 깜빡임 지표(전선·난간 같은 가는 선이 지글거리나, D-149).

## 6. 도현에게 물을 것 (고르기)
1. **세 마을 그대로 vs 한국 요소 섞기**: (가) 도모노우라·카몰리·포지타노 길가 요소만 / (나) 세 마을 + 한국 눈높이 층 조금(전봇대·전선·볼록거울·화분 줄·함석, 벽화 X) — **추천** / (다) 한국 해안 마을 느낌을 크게(동피랑·흰여울 골목 감성 전면).
2. **길가 밀도**: (가) 성기게(100m당 소품 무리 2~3, EDC 처럼 비어 있는 쉼) / (나) 구역 강약 — tomo 빽빽·camo 보통·posi 꽃만·능선 성김 — **추천** / (다) 어디나 빽빽(정지 화면은 좋지만 달릴 때 시끄러움).
3. **길 안내 방식**: (가) 길가 사물만(볼록거울·전선·연석·랜드마크, 화살표 0) — **추천**(MKW "화살표는 세계를 비좁게") / (나) 사물 + 최소 표지판(글자 없는 아이콘) / (다) 지금처럼 화면 표지.
4. **소품 표면 출처**: (가) A4e 키트(pole·bicycle = CC-BY 포함)를 albedo 로 다시 칠해 씀 / (나) CC0 만(무료 팩 + 사진 부품), CC-BY 는 교체 — **추천** / (다) 핵심 몇 개(전봇대·자판기·볼록거울)만 artlive 로 새로.
5. **연석 넘기**: (가) 낮은 연석, 넘으면 화물 흔들림(D-139 그대로) — **추천** / (나) 연석 없음, 색 다른 길가띠만(더 자유롭지만 길 모양이 덜 읽힘) / (다) 구역별(tomo 연석, posi 배수로 홈).
6. **움직이는 것 먼저 무엇**: (가) 빨래·차양 흔들림 / (나) 갈매기(소리 같이) / (다) 고양이 — 사람은 보류 유지.
