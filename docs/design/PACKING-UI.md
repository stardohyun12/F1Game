상위: STORY.md(방학 28일·알아가는 이야기·1인칭), D-227~236(노을 장면 = 분위기 기준), TONE.md.

## 1. 지금 무엇이 안 어울리나 (캡처 근거)
- 주행 HUD(docs/qa/evidence/feature2/f2_05_hud_target.png): 크림색 사각 패널(속도 km/h·화물 % 초록 막대), 검은 GEAR N 상자, TRUNK CAM 창, 노란 화살표, 영문 "tea" — 1080 매끈한 벡터 글꼴이 360 도트 세상 위에 떠 있음. 앱/대시보드 문법.
- 대화(f2_03_talk_1.png): 화면 아래 반투명 검은 띠 + 흰 고딕 — 영화 자막. 인물·장소와 연결 없음.
- 포장(20261023-qa-6-packing-all.png): 짙은 남색 관리 화면, 재료 목록(₩/m), 비용 표, 면별 보호 % 막대, 타이머 — 엑셀·경영 시뮬. "손으로 싸는" 감각 없음.
- 공통 원인: ① UI 가 360 화면 격자 밖(원해상도)에서 그려짐 ② 숫자·막대로 상태를 알려 줌 ③ 이야기·인물과 무관한 중립 디자인.

## 2. 원칙 (제안)
1. **화면보다 세상 안에(디에제틱 먼저)**: 정보는 가능하면 세상 속 물건이 알려 준다 — 배달 전표(종이), 카트 계기(바늘 하나), 화물이 흔들리는 소리·모습, 방 벽 달력, 일기장.
2. **남는 화면 UI 는 도트 세상과 같은 격자**: 360 렌더 안(또는 같은 배율)으로 그리고, 도트 글꼴(Galmuri, OFL — 이미 프로젝트에 있음), 게임 팔레트(종이 크림·남보라·노을 주황), 손으로 그린 듯한 테두리.
3. **숫자 대신 감각**: 화물 % 막대 → 상자 안에서 덜그럭 소리·카트 짐칸 흔들림·손에 닿는 진동(패드). 속도 → 엔진음·바람·화면 흔들림. 정확한 값은 원하면 볼 수 있게(전표 뒷면 등).
4. **인물과 이어지게**: 대화창은 말하는 사람 쪽에서 나오는 말풍선(A Short Hike·동물의 숲 문법), 이름표, 한 글자씩. 단골마다 말투.

## 3. 택배 포장 — 다시 생각
지금: 출발 전 피트스탑 미니게임(시간 안에 재료로 면을 칠해 보호 % 올리기, 재료비 차감).
제안: **1인칭으로 실제로 싸는 작업대 장면**(정비소 한쪽 또는 받는 집 문간).
1. 물건이 이야기다: 달걀 한 판, 유리병 레몬청, 화분, 편지 다발, 케이크 — 보내는 사람·받는 사람이 정해져 있고, 물건에 쪽지가 붙어 있기도(STORY "알아가는 이야기"의 입구).
2. 손으로 하는 단계(각 단계 몇 초, 마우스/패드로 실물 조작):
   상자 고르기(크기·종류) → 바닥에 완충재 깔기(신문지 구기기·뽁뽁이·볏짚 — 동네 물건) → 물건 넣기(방향: "이쪽 위") → 빈틈 채우기 → 뚜껑 닫고 테이프 → 라벨에 주소 쓰기(받는 사람 이름이 손글씨로).
3. 결과는 숫자가 아니라 시험: 다 싸고 상자를 들어 한 번 흔들어 보면 덜그럭 소리로 안다(물리 그대로 — CargoShakeSimulator 재사용). 잘 쌌으면 조용.
4. 재료는 돈 표가 아니라 선반의 실물 수량(뽁뽁이 한 롤이 줄어듦), 사는 건 가게에서.
5. 시간 압박: 평일 주문은 "몇 시까지" 약속(라디오·전표에 시각)만, 포장 화면에 째깍이는 타이머는 없음 — 서두르면 대충 싸게 되는 정도.
6. 카트 싣기: 짐칸에 상자를 놓고 끈 걸기(놓는 위치가 흔들림에 영향).

## 4. 주행·걷기 UI — 다시 생각
- 목적지: 화살표·미니맵 대신 **전표**(카트 손잡이에 끼운 종이: 받는 사람 이름·주소·손으로 그린 약도). 키 하나로 전표를 들어 봄(1인칭 걷기 때도). 길을 헤매도 되는 게임(D-138 은근히 자유).
- 화물 상태: % 막대 삭제 → 짐칸 상자가 흔들리는 모습(뒤돌아보기)·덜그럭 소리, 크게 위험하면 상자 쪽 작은 도트 아이콘 한 번.
- 속도·기어: 카트 계기 바늘 하나(카트 모델에 붙은 실물) — 화면 패널 삭제. TRUNK CAM 삭제(뒤돌아보기로).
- 상호작용 안내: 물건 옆 작은 도트 키 아이콘([E])만, 문장 띠 삭제.
- 대화: 말하는 사람 머리 위 쪽 말풍선(도트 테두리, 꼬리), 이름표, 한 글자씩 + 말소리(짧은 웅얼거림).
- 하루: 방 벽 달력(날짜·축제까지 남은 날), 밤에 일기 한 줄(손글씨 도트), 화면 시계 없음(필요하면 손목시계 보기 키).
- 메뉴: 일시정지 = 주인공 수첩(종이·도트).
