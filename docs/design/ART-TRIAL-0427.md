# 아트 개선 시도 계획 (D-168, 2026-10-27 새벽 — 도현 수면 중 자율 진행)

근거: docs/research/2026-10-27-ref-games-production.md · art-pipeline-options.md · community-solutions.md · art-internal-audit.md.

## 원인 요약 (무게 순)
1. **면 안이 텅 빔** — v5 게임 컷의 면 83%가 거의 단색(기준 ① 45%·⑥ 46%·⑫ 8%), 면 안 변화량 0.4(기준 1.7~3.4), 화면 아래 빈 칸 32%(기준 1~19%), 밝기 폭 0.44(기준 0.55~0.72). "너무 쨍함"은 채도가 아니라 평평한 면·좁은 밝기 폭 때문.
2. **기준 게임은 디테일을 모델이 아니라 텍스처(사진 포토배싱·사진에서 뽑은 팔레트·손그림 명암)와 카메라 셰이더·안개에 넣는다.** EDC 환경 = 실사진 포토배싱, 그림자 없음, 주변광 한 색 = 안개 색. Crow Country = 최종 셰이더를 켠 화면에서 제작. A Short Hike = 팔레트 텍스처 + 거의 unlit + 계단 명암.
3. **AI 모델링은 무에서 만드는 데 약하고 배치·조립에 강하다**(BlenderGym·3D-GPT·LayoutVLM). 우리는 반대로 썼다.
4. **판정이 게임 밖(블렌더 렌더)·AI 점수가 도현 눈과 따로 논다.**
5. **PD 지시 오류·기준 변경** — 예: "큰 면은 단색에 가깝게(①)"가 오히려 단색 비율을 61→85% 로 올림.

## 오늘 밤 시도 (같은 장면 = 정비소 앞 게임 컷, Unity 720 화면에서만 판정)
| 판 | 방법 | 출처 |
|---|---|---|
| V0 | 지금 v5 그대로 (기준선) | — |
| V1 | **EDC 방식**: 같은 단순 형태 + CC0 실사진 포토배싱 텍스처(조명 평탄화 → 잔디테일 제거 → 부드럽게 축소 64~256px → 8~16색, 디더 없음) + 그림자 끔·주변광 = 안개 한 색 | ⑥ |
| V2 | **A Short Hike 방식**: 가을 사진에서 뽑은 팔레트 텍스처(UV 를 색 칸에) + 거의 unlit + 계단 명암 + 안개 | ① |
| V3 | V1 + 전역 Look 셰이더 면 변화(세로 그라데이션·땅 닿는 곳 어둡게·큰 색 얼룩) | 감사 처방 1 |
- 숫자 게이트(audit_compare.py): 거의 단색 면 ≤50%, 면 안 변화 ≥1.5, 아래 빈 칸 ≤20%, 밝기 폭 ≥0.55 — 통과한 판만 도현에게.
- 판정 질문 하나: "①⑥⑫ 와 같은 게임 계열로 보이나". 점수 대신 나란히 시트.

- AI 생성 3D(mcp-for-blender 의 Hyper3D·Hunyuan3D 기능) — 금지.
