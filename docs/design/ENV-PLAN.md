## 도현이 아침에 읽을 한 문단

지금 맵 건물 1,149채는 회색 상자 + 쨍한 주황 지붕 하나뿐이고, 나무·풀·구름·먼 산은 0개, 바다는 한 색 평판이다. 그래서 **배경 건물은 "가까운 곳은 손으로 만든 조각 키트로 조립, 먼 곳은 같은 색을 칠한 단순 껍데기"(C안)** 로 가려고 한다. berat-racer 처럼 전부 규칙으로 만들면 형태는 맞아도 "절차 생성 티"가 나고(네가 D-162에서 거부한 것), 열몇 채를 손으로 만들어 복사하면 같은 집이 반복돼 보인다. 첫 단계는 **"마을집" 한 종류만** 스튜디오에서 조각 8개로 만들어 3채를 손으로 조립해 보여 주고, 네가 통과시키면 같은 조각으로 실제 맵 한 블록(20채)을 자동 조립해 게임 화면에서 회색 상자와 나란히 보여 준다. 색은 우리 집·우체국·보관소 텍스처에서 뽑은 바랜 모래색·크림·세이지 회벽과 테라코타 지붕으로 쓴다(지금 지붕 주황은 너무 쨍함). 자연은 건물 다음에 **바다 물가 → 나무 → 먼 산 → 구름 → 풀·꽃 → 바위** 순서로, 하나마다 맵 그 자리에 임시 목업을 놓고 찍은 한 장을 보여 주고 고르게 하겠다.

## 1.4 LOD·거리 규칙 (720p, 카메라 B FOV 64 기준 계산)
- 화면 1m = 720 / (2·d·tan32°) px → 40m 14px · 60m 9.6px · 100m 5.8px · 200m 2.9px · 400m 1.4px.
- **L0 (0~60m)**: 키트 조립 메시, 32px/m albedo, 소품 포함. 창 1.2m = 12px 이상 → 덧창·창틀이 읽힘.
- **L1 (60~200m)**: 벽 = 상자(층 띠만), 지붕 = 실제 경사, 텍스처 = L0 를 정면으로 찍어 구운 **파사드 칸 albedo**(빛 없음 — D-185 유지). 창은 3~6px 점.
- **L2 (200m+)**: 블록 단위 합친 덩어리, 면당 1~2색 + 지붕색. 안개(지금 선형 70~900m)가 녹임.
- 전환은 크로스페이드 없이 거리 기준 + **카메라 이동 중 전환 금지 거리 폭 10m**(팝 방지). 지글거림 금지(D-149) → L1/L2 텍스처 밉 사용 여부는 첫 시험에서 "멀리서 지글거리나" 도현 확인.
- 성능 목표(가설): 건물 전체 draw call ≤ 300, 삼각형 ≤ 1.5M, 720p 렌더 ≤ 4ms. L0 는 조각 GPU 인스턴싱, L1/L2 는 64m 타일별 통합 메시(재질 ≤ 4).
