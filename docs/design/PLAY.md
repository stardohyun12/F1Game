# 플레이 먼저 — 배달 주행이 재미있는 맵 (D-155)

순서: **회색 박스로 재미를 확인 → 그 길 위에 마을·비주얼을 입힌다.** TONE·PLACES·Look 은 이 다음 단계.

## 재미 4기둥 (도현이 넷 다 고름)
| 기둥 | 플레이어가 하는 결정 | 맵이 줘야 할 것 |
|---|---|---|
| 1 화물 긴장 | 지금 밟을까, 화물 때문에 참을까 | 요철·턱·급커브·내리막 같은 "흔들리는 곳"이 빠른 길 위에 있다. 화물마다 견디는 정도가 다르다 |
| 2 길 고르기 | 큰길로 갈까, 거친 지름길로 갈까 | 배달마다 안전한 길 vs 빠르지만 거친 길 2개 이상. 지름길은 보이지만 표시는 없다(찾는 맛) |
| 3 운전 실력 | 어디서 브레이크, 어떤 라인 | 브레이킹 포인트가 분명한 헤어핀·시케인, 라인을 잘 타면 확실히 빨라지는 굽이. 반복할수록 줄어드는 시간 |
| 4 지형 변화 | 구간마다 다르게 몬다 | 해안 고속 직선, 오르막 헤어핀, 내리막 가속, 좁은 골목(벽 가까움), 돌길 요철, 언덕 넘기 |

## 기둥이 겹치는 곳이 재미 (설계 원칙)
- 지름길(2)은 거칠다(1·4): 돌길·계단 옆 비탈·좁은 골목 → 빠르지만 화물이 흔들림.
- 큰길(2)은 길지만 실력(3)으로 줄인다: 헤어핀·직선 브레이킹.
- 깨지기 쉬운 화물이면 같은 지름길이 "못 가는 길"이 된다 → 화물이 길 선택을 바꾼다.
- 리듬: 긴장 구간(골목·요철) 뒤엔 숨 쉬는 구간(트인 해안 직선). TONE 의 "바쁨 → 해소"와 같은 곡선.

## 회색 박스 놀이터 (첫 산출물)
- 따로 된 씬 `Proto_Play01`. 질감·소품·건물 장식 0, 회색 박스와 색 구분(길 종류별 단색)만.
- 차고 1 + 배달점 4. 차고→각 배달점마다 큰길/지름길 2개 이상. 한 배달 40~90초.
- 구간 라이브러리 위 6종을 다 포함. 기존 차 조작(ArcadeCarController)·화물 흔들림 시스템 그대로.
- 판정은 **도현이 직접 몰아서**. 팀원은 사람처럼 운전하지 않는다 — 경로 따라가는 자동 주행(봇)으로 "끼임·멈춤·못 오름"만 확인하고, 구간별 시간·화물 충격을 숫자로 낸다.
- 도현 판정 질문: 지름길을 찾고 싶었나 / 화물 때문에 망설인 순간이 있었나 / 다시 하면 더 빨리 갈 수 있을 것 같나 / 구간마다 감각이 달랐나.
- 통과하면 이 길 배치를 BayLoop 의 새 길망으로 삼고, 엽서 장소(PLACES.md)를 그 위에 얹는다.
