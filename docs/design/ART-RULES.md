# ART-RULES — 지금 유효한 아트 규칙 한 장 (2026-10-27, D-180)

이 문서가 D-145~D-179 의 아트 결정을 대신한다. 충돌하면 이 문서가 이긴다. 바꿀 땐 D-번호와 함께 이 문서를 고친다.

## 0. 기준
- **렌더링 = ⑥ Easy Delivery Co., 질감·색·분위기 = ① A Short Hike** (D-170). 빛 = 밝은 늦가을 오후 (D-148).
- 기준 장면 = **Scene_A6d_Town (정비소 앞 거리)**. 이 장면을 8점까지 끝내고 고정한 뒤 맵 전체로 넓힌다 (D-180).
- 도현이 OK 한 것 = 기준 실물: A4e 환경(땅·길·풀·나무·덤불·소품·정비소·하늘), 집 j판(괜찮음), 카트 v6 노이즈 + v6b 색(=v6c).

## 1. 화면
- 내부 1280×720, Nearest 확대, 정수배 끔, 정점 스냅 끔 (D-164/165, D-149 지글거림 금지).
- 하늘 = 그라데이션 + 계단(픽셀) 구름. 매끈한 벡터 구름 금지 (A3 판정).
- 안개는 원경만 옅게. 화면 전체 회색 헤이즈 금지 (D-170 — 어두워 보인 원인).
- 색: 채도를 깎지 않는다. 밝은 쪽만 하얗게 날아가지 않게 누른다(p95 ≤ ~195). 부드러움은 **약한 노이즈**로 — 표면 고정 결 기본, 정적 화면 그레인은 선택 (D-171 → D-179, `A6dGrainToggles`).

## 2. 재료 (모든 물체 공통 — "한 화면 한 그림체", D-175/176/178)
- 방식 = **V5**: CC0 사진 텍스처 바탕(약한 결) × Blender 로 구운 늦가을 빛·하늘빛·AO → 팔레트 양자화(디더 없음) → 조명 없이 텍스처 그대로.
- 텍셀 1m ≈ 32 (정비소 기준). 팔레트 = 정비소 32색 + 칠 색 칸(현재 40색, `art/export/scene-a4-houses-j/palette40.gpl`).
- 결·얼룩: 사진 결은 약하게(명도 ±2~4%). 얼룩·녹은 아래·모서리·이음매·빗물 자리만(면의 ≤12~25%). **벽 전체에 깐 사진 점무늬 금지** (b·d판 "지저분함").
- **완전 평면 단색 금지** (c·i판 "AI 티"/"안 맞음"). **큰 위장 얼룩 금지** (f·g판).
- 그늘 = 청록 쪽 한 색, 검정 금지. 실내·처마 밑도 검게 떨어지지 않게(p5 ≥ 55~60).
- 원래 검정·회색인 물체(가로등·전선·타이어·금속)는 무채 숯색 + 명도 결만. 색 노이즈 금지. 재질 `_Sat` 은 1.2 이하 (2.6 이 청록을 부풀려 초록 카트·노이즈 가로등을 만들었다).
- 1px 고립 반점 ≤ 0.3%.

## 3. 건물 (D-173/174/177/178)
- 형식 = **환경 재료(2절) + EDC 정면 구성**: 짙은 유리 + 밝은 창틀·살 격자, 처마 끝 짙은 띠, 1층 가게는 큰 유리 띠 + 색 띠, 층 사이 옅은 줄눈.
- 집마다 이야기(`docs/design/HOUSES.md`): 정면이 기능을 말한다 — 읽히는 간판 글자(FISH·CAFE·ROOMS…), 가게 진열, 창≠문≠가게 유리.
- AI 티 금지 목록(`docs/research/2026-10-27-ai-look-*.md`): 같은 부품 반복(같은 덧창·화분은 6채 중 2채까지), 완전 대칭, 창 크기 1~2종, 손댄 흔적 0. 넣을 것 = 덧댄 차양·막은 창·보수 칠·이어진 홈통·생활 소품(집 앞 0.1~0.2개/m²).
- 형태: 실제 크기, 이탈리아 해안 마을 실루엣 + 일본식 눈높이 생활 소품 (D-137, D-167).

## 4. 차
- 고카트 실치수(1.80 × 1.28 × 0.82m), 바퀴 4개 굴림 + 앞바퀴 조향, 최고 65km/h(가설), 이 장면 기본 주행 Wheels (D-174).
- 외형 = 실물 사진 기반(v6), 색 = 바랜 주황빨강 차체 · 무채 타이어/금속 · 번호 07, 노이즈 결은 v6 수준 (v6c, D-179).
- 물리·카메라 B(높이 2.8 · 거리 5.6 · FOV 64)는 바꾸지 않는다 (D-143).

## 5. 사람 (보류)
- PS1 시절 로우폴리 실물 비례, 귀여운 4~5등신·동물 거부 (D-148). 기준 장면 합격 뒤 그 화면에서 발주.
