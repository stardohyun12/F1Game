고민 요소 (long-running concerns)

(a) 데모 컨셉 갭이 크다 — 한 런 8~12초 vs 5~15분 = 200~900배. 거리+escalation 둘 다 필요.
(b) 도현 결단 회피 — 정리/audit/리서치로 회피. 해법: 30분 prototype 쪼개기, 또는 타이머 자기 강제. 음성은 input 속도지 결정 속도 X.
(c) 채널 5 slide 튜닝 — velocityDeadZone(0.02) 약한 사면(25°)에서 안 미끄러짐. fix: deadzone 0.005 + accelScale 1.5 (W4 페이싱).
(d) 화물 비주얼 회색 큐브 5종 — 영상 시연 시 "다양한 화물" 컨셉 전달 X. 1일 작업, W5.
(e) AI 차량/교통 — 풀게임 야망, 데모 비목표. 그래프 깨끗하게만. W6 이후.
(f) 사운드 부재 — 골격 있지만 clip 미할당. 영상 임팩트 매우 큼. W5 핵심.
(g) 첫 30초 — 메뉴/인트로 없음. 영상 첫 30초가 컨셉 전달 X. W5b.
(h) 정산 ↔ 복원 연결 미구현 — 돈으로 차고에서 부품 사는 흐름 없음. W3 차고 + W4 연결.
