## 0. 계획 전에 확인한 사실 (2026-10-20, 파일 열어 확인)

1. **빌드 첫 씬은 지금 ComplexTrack 이 아니다.** `F1/ProjectSettings/EditorBuildSettings.asset` 의 씬 목록 = `Assets/Scenes/SampleScene.unity` 하나뿐. "메인 씬" = 지금까지 실제로 작업·회귀하던 `Assets/ComplexTrack.unity`(열어 둔 씬) 로 읽었다. 교체 = 빌드 목록 첫 칸을 새 씬으로 + 회귀·QA 도구의 대상 씬을 새 씬으로.
2. **회귀 하네스는 "지금 열린 씬"을 잰다.** `scripts/regression-check.sh` 는 씬을 열지 않는다(29행 `CheckCoreServicesPresent` 등을 그냥 exec). → 대상 씬을 여는 단계가 따로 필요.
3. **시스템 복원 도구가 ComplexTrack 을 코드에 박아 두었다.**
   - `F1/Assets/Editor/_Recovery/RunFullRebuild.cs:28`, `F1/Assets/Editor/SetupOrderSystem.cs:62` — `ComplexTrackLayout` SO 를 찾아 배달 셀을 만든다(격자 `TrackLayout` 기준).
   - `F1/Assets/Editor/FormulaGameplayInstaller.cs:26` — 씬 경로가 `Assets/ComplexTrack.unity` 가 아니면 예외.
   - QA 합성 주행 `docs/qa/tools/synthetic-drive.cs.txt` 등 4개도 ComplexTrack 을 언급.
   → 아말피 씬은 격자 `TrackLayout` 이 없으므로 "8단계 복원 체인"을 **그대로 돌릴 수 없다.** 배달지는 생성기 `gameMap` 에서, 나머지 배선은 씬 경로를 인자로 받게 고쳐야 한다(조각 17).
4. TownGen 씬은 `TownGen_Structure_v14.unity` 까지 있다(STRUCTURE-14.md 는 없음 — v14 내용 미확인, 프로그래밍팀 확인).

### 조각 15a — 상자 확장 + 윗길 고리 (길만)
- 할 일: 생성 범위에 윗길 가지(Via Pimenio secondary → Via Primo Maggio)를 넣고, 상자 서쪽 경계 밖 공유 노드(40.6171748, 14.5689036)까지 OSM 을 받아 Via Miramare 와 **22m 이음**. 콘카 입구 잇기(7b, 44m) 유지. 씬 = `TownGen_Structure_v15.unity`.
- `measure.json` 에 `carGraph`(노드·간선·도로 종류·잇기 표시) 추가.
- 수용 기준
  - R6: 실제 지도에 없는 잇기 합 ≤ 50m(경계 이음 1개; 7b 잇기는 별도 표기).
  - R1: `carGraph` 로 항구 (2830,2266) ↔ 콘카 광장 서로 다른 경로 ≥ 2, 하나는 SS163 위주·하나는 윗길 secondary 위주. 길이 차 예상 +18%(허용 +10~+30%).
  - R2: 항구 ↔ 윗길 마을 서로 다른 경로 ≥ 2.
  - R5: 항구 400m 안 고리 ≥ 1.
  - 큰길 경사: 기존 BUG-005 기준을 윗길에도 적용, 위반 구간 목록.
- 시안 게이트: 관통·끊긴 길·바다 위 길만.
- **결과(2026-10-20, STRUCTURE-15A)**: R6·R5·경사 PASS, R1 FAIL(+45.7%, 7b 지름길 탓), R2 PASS(참고). 기획 판단 = 스펙 §11.

### 조각 15a-2 — 실제 콘카 입구 + 경계 헤어핀 (15a 판단 반영)
- 할 일: ① realEntry 변형을 기본으로(7b 잇기 0) ② 경계 잇기가 다듬기에서 사라지지 않게 — 상자 안 (16,455) 근처 반경 ≥ 8m·경사 ≤ 5% 헤어핀 패드 ③ 콘카 반경 100m 안 차도 = 두 경로가 지나는 way 만(town-structure §4.4), 나머지 골목 ④ OSM 선 이탈 48m 원인 찾아 ≤ 6m.
- 수용 기준: R1 ≥ 2(+10~+30%) · R6 ≤ 50m + 경계 잇기 그려짐·중간점 ↔ 그래프 ≤ 1m · 헤어핀 ≥ 8m · OSM 이탈 ≤ 6m · 마을 차도 굽이 ≥ 8m · town-structure §4.4 기준 · R2 는 참고 수치만(최종 = 조각 16, 윗길 배달지 6곳 중 ≥ 3곳).

- **결과(2026-10-20, STRUCTURE-15A2)·기획 판단**: R1 +18.7%·R6·헤어핀 8.3m·이탈 5.9m PASS. 콘카 굽이 R10.4 (246,504)는 **PASS** — 마을 안 OSM 모퉁이는 ≥ 8m 가 스펙 §11 기준이고, 생성기 M3 가 콘카 씨앗 100m 안에도 큰길 ≥ 12 를 쓴 것이 검사 쪽 불일치. 검사 고침은 15b 첫 항목. (246,504)는 조각 9 주행 확인 지점에 추가. → **15b 착수 가능.**

## 3. 멈춤 조건 (기획이 다시 판단)
- 조각 8 이 60fps 에 크게 못 미침(예: 30fps 아래) → 15b 범위 줄이기. 윗길 고리(D-116)는 유지하고 먼 집부터 뺀다.
