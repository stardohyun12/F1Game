# 스펙: 마을 2개 + 해안도로 — 아말피형 배달 맵 (2026-10-13, 기획 대화 결과)

> 결정 D-096~D-101 을 한 장으로. 확정은 도현 결정만, "제안"은 표시. 구현 착수는 별도 승인.

## 1. 한 줄
**절벽 위·바다 앞 작은 마을 2개를 굽이치는 해안도로가 잇는다.** 한 런 = 마을 골목(1~2분) + 해안도로(2~3분) + 다음 마을 = 5~8분. 경사는 막지 않고 비싸다.

## 2. 확정된 것 (도현)
- 아트: Codex 로파이 키트(D-096) + Codex 건물 세트 11종(D-097). 변형은 간판 교체 금지 — 실루엣·정면 기능이 달라야 함.
- 해상도: 내부 640×360 ×3 최근접(URP Render Scale 0.333 + Point) 적용됨.
- 구조(D-098): 마을 2개(지금의 항구 마을 + 절벽 위 마을) + 해안도로 1.5~2km 한 줄(쉼터 1). 고도 허용. 마을 = 6m 타일 격자(연결 검사기 유지) / 해안도로 = 스플라인 메시(곡선·고도).
- 마을 안(D-099): 대체로 평지 + 일부 경사. 경사 = 보이지 않는 난이도·경제 장치(초반 파손 → 패드 업그레이드로 지름길).
- 진행(D-100): 높이 = 진행 단계(항구 평지 → 언덕 마을 → 해안도로 너머). 생성기 규칙 셋: ① 언덕은 절대 막지 않는다 ② 언덕마다 평지 우회로 하나 ③ 꼭대기엔 랜드마크.
- 색감(D-101): 아말피 한낮 기준. 시간대 변화는 후속.
- 지금 마을 배치는 버리고 새 규칙으로 다시 만든다(키트·소품·설치 코드는 재사용).

## 3. 생성 레시피 (논문 기반, `옵시디언/research/urban-morphology-2026-10-13.md`) — 제안
두 겹: **길 찾기는 칸(roadMask·BFS 그대로) / 보이는 도로는 스플라인**.
1. 지형 먼저: 고도맵(계곡 1·해안 절벽·항구 평지), SO. 50~150줄.
2. 해안도로: 칸 A*(상태=칸+방향, 비용=거리×(1+k·경사²), 경사 12% 초과 금지, 급꺾임 벌점) → Catmull-Rom/Unity Splines → 도로 메시(RoadArchitect MIT 또는 자체). 150~250줄.
3. 마을 씨앗: 관심도(바다 가까움+계곡 입구+낮은 경사) 최댓값 = 항구. 30~60줄.
4. 중심 길 항구→광장: 2 재사용.
5. 마을 격자: 구역 → 블록 반복 이등분(다운타운 3×3, 외곽 6×5) → 끊긴 곳 잇기. 약 170줄. 경사 구간은 등고선 따라 + 헤어핀은 평평한 원형 패드(가장 어려운 단계, 200~400줄).
6. 필지·건물: 길 양옆 좁고 깊게, 높이차는 기단/옹벽. 건물 11종 + 소품 규칙(CoastalTownDensity) 재사용. 100~200줄.
7. 가게 자리: 길 그래프 BFS 통합도 상위 길(공간구문론). 50~100줄. 가게가 운전 시점에 보여야 함(게이트 5차 지적).
8. 랜드마크(Lynch): 광장 종탑·언덕 꼭대기 등대/카페, 배달지마다 보이는지 레이캐스트 검사. 50~100줄.
합계 C# 800~1,300줄. 외부: Unity Splines(공식), 선택적으로 DeBroglie(MIT)·RoadArchitect(MIT)·building_tools(MIT, Blender).

## 4. 기획 규칙 (생성기 밖, `옵시디언/research/soft-gating-level-design-2026-10-13.md`)
- 첫 언덕은 짧고 보이게, 싼 화물(계란)로. 미끄러짐은 트렁크캠 + 정산 문구("○○ 언덕 경사에서 −₩")로 원인 표시.
- 패드 업그레이드 = 비쌈→지름길(잠김→열림 아님). 언덕 벌금 < 지름길 이득(측정). 구역 해금은 벽이 아니라 거리·보수.
- 백로그: 미끄럼 방지 패드(차고 부품), 하루 시간대 주기, AI 차량(unity-traffic-simulation MIT), 보행자.

## 5. 단계와 공수 (제안, 측정값 아님)
- P0 색감 한낮 패스(조명·안개·벽 칸·바다) — 반나절. 캡처 전/후 + 게이트.
- P1 해안도로 프로토: 지형 1 + 언덕 2 + 스플라인 1.5km, 지금 마을에 이어 붙여 차로 왕복, 화물 미끄러짐 확인 — 1~2일. **새 기술 위험은 여기뿐.**
- P2 마을 생성기(3~5단계) + 지금 항구 마을 재생성 — 2~3일.
- P3 두 번째 마을(언덕 위) + 랜드마크 + 가게 노출 — 2일.
- P4 진행 연결: 해금(거리·보수), 정산 문구, 첫 언덕 튜토리얼 배달 — 1~2일.
각 단계 끝 = graphic-gate(운전 시점 캡처) + verifier(컴파일·회귀·스모크) + 도현 판정.

## 6. 미정 / 위험

- 성능: 건물 삼각형 3~4k × 230채 + 나무 500 — FPS 미측정.
