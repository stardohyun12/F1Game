## 2. 비주얼 아이덴티티 고정안 (가설)

### 2.1 한 줄 정의
**"한낮 아말피 골목의 낡은 배달 사무소"** — 3D 는 D-096 로파이 아틀라스 + D-101 흰 햇빛, UI 는 그 사무소의 **종이·도장·법랑 간판**. 어두운 개발자 패널을 버리고 밝은 종이 위 진한 잉크로 간다(한낮 화면 위에서 대비가 오히려 좋아짐).

### 2.4 UI 형태 언어
- **종이 전표**: 주문 카드 = 배달 전표(크림 종이, 위쪽 절취선, 화물 아이콘 크게, 핵심 3줄만 — 배달지·제한시간·보상). 긴급 = 전표 위에 찍히는 빨간 **"URGENTE/긴급" 도장** + 전화 쪽지. 정산 = 영수증(아래로 출력되며 줄마다 금액이 붙는 연출).
- **모양**: 모서리 반경 8px, 테두리 `ink` 3px, 그림자는 **흐림 없는 평면 오프셋(4px, ink 40%)** — 점 업스케일 3D 와 같은 "덩어리감". 그라데이션·글로스(현 Kenney gloss 스프라이트) 금지.
- **HUD**: 주행 중엔 종이 대신 **법랑 표지판**(흰 판·두꺼운 테·큰 숫자). 화면 가장자리 4곳 고정: 좌상 = 배달 목록, 우상 = 시계, 하단 중앙 = 화물 상태(가장 큼), 우하 = 속도. 미니맵은 프로토타입 뒤.
- **아이콘**: 단색 `ink` 실루엣 + 강조 1색, 64px 격자에서 그려 2배로만 씀.
- **움직임**: 등장 0.15s 튀어나옴(1.0→1.06→1.0), 도장 쾅(흔들림 2프레임), 숫자 카운트업. 화면 전환 페이드 금지(짧게 밀기).

## 3. 에셋 조달 방법 비교

| 방법 | 장점 | 단점 | 이 프로젝트 이력 |
|---|---|---|---|
| A. AI 생성(Meshy) + 리토폴 | 유기 형태 빠름 | 결과 2.7만~7.5만 tris·UV 조각(BUG-001), 깎으면 깨짐(세션 21 케이크), 아틀라스 규칙 불가, 리토폴은 사람 손 시간 큼 | 화물 4종 실패 |
| B. 무료·유료 팩 | 즉시, 품질 보장 | 룩 불일치(Kenney 교외 = 아말피 아님), 우리 치수(D-103)·아틀라스와 안 맞음, 라이선스 확인 | Kenney 6팩 사용 중 |
| C. Blender 코드 생성(`bpy`) | 결정적·재생성, 예산을 처음부터 통제, 아틀라스·팔레트 강제, OSM 윤곽에 맞춤 | 초기 스크립트 비용, 유기 형태 약함 | 건물 `lofi_pilot.py`·`harbor_*`·`race_v2` 성공 |

**추천**
- **화물 → C 기본, 유기 1~2종만 A 를 "원형"으로.** 상자·케이크·계란판·와인병은 원기둥·상자 조합이라 코드로 300~1,500 tris 에 나온다. 생선만 Meshy 결과를 **실루엣 참조**로 두고 Blender 에서 저폴리로 다시 감싸(수동 리토폴 ≤1,500 tris) 아틀라스 칸에 굽는다. 이유: 예산·UV 문제를 근본에서 없애고, 손상 단계(금 간 케이크·깨진 계란)를 같은 스크립트 변형으로 뽑을 수 있다. CC0 팩(Kenney Food Kit 등)은 **형태 참고·임시 대체**로만 — 수록 품목·룩 일치는 확인 필요.
- **건물 → C 유지(D-095·D-096·D-106).** OSM 실제 윤곽(D-114)에 맞는 집은 팩으로 못 산다. 필요한 건 생성기 쪽 "모듈 키트 다양화"(문·창·발코니·차양·레몬 화분 부품)와 아틀라스 칸 추가. 랜드마크(성당·광장 분수) 1~2개만 손모델링.
- **UI → 직접 제작(소량) + CC0 아이콘.** 필요한 스프라이트가 20개 안팎(전표·도장·버튼 3상태·법랑판·아이콘 12)이라 팩을 사 와도 결국 다시 칠한다. 아이콘은 Kenney Game Icons(CC0) 를 바탕으로 `ink` 단색 재작업. AI 이미지 생성은 **원화·분위기 목업에만**(9-slice·아이콘 정합은 못 맞춤).
- **차 → C(`race_v2` 계열) 재개 + "낡음" 아틀라스 칸.** 현 Kenney 차는 깨끗해서 "낡은 F1" 정체성을 못 냄.

## 4. 우선순위

### 4.1 지금 해도 안 버려지는 것 (메커니즘과 무관)
1. **폰트 교체(출시 차단)** — Pretendard + 제목체 정적 SDF 굽기, malgun 계열 제거, 어절 줄바꿈. 화면 구조가 바뀌어도 그대로 쓴다.
