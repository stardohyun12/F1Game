
## 2. 역전 순간 ("아슬아슬 도착")

### C1. 판정 규칙 — 비용 낮음

마지막 배달 도착(`RunController.OnAllCompleted`, `:376`) 순간 두 값을 **먼저 저장**하고 시계를 얼린다.

| 값 | 읽는 곳 |
|---|---|
| `remaining = ParTime − Elapsed` | `TimeRemaining`, `RunController.cs:120-124` |
| `integrity` (0–1) | `Cargo.IntegrityPercent`, `CargoBox.cs:78` |

```
clutch  = (0 < remaining ≤ T_c)  &&  (integrity ≥ I_c)  &&  !stalled
T_c = 5 s   [가설, 시험 3 / 5 / 8]
I_c = 0.80  [기존 정산 배수가 1.0 인 경계(80 %) 와 같은 값 — 새 경계를 만들지 않음, RunController.cs:508]
```

- 시계는 **150 s 전체**(고르기·포장 포함)를 쓴다. "포장에 시간을 쓰고 → 주행으로 만회"가 곧 "내가 고른 위험"이라는 해석 [추정, 도현 확인 필요].
- 화물이 상했으면 clutch 가 아니다 (그냥 "겨우 도착"). 도현 해체의 핵심은 "운이 아니라 실력의 증명"이므로, 시간만 빠듯한 것은 역전이 아니다.
- **꼼수 방지 (C4)**: 목적지 앞에서 멈춰 시간을 버리면 누구나 clutch 가 된다. 그래서 `stalled` = "도착 직전 20 s 중 속도 < 3 km/h 인 시간의 합 ≥ 4 s". 구현은 최근 20 s 속도 샘플(0.5 s 간격 40칸)을 도는 버퍼 — 낮음.
