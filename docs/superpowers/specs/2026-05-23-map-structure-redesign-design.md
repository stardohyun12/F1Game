## 4. 구성 요소 (각 단위)

| 요소 | 무엇 | 재료 | 단위 |
|---|---|---|---|
| **다운타운** | 조밀 3~4셀 블록, 고층(`H`) | roadMask/buildingMask 데이터 | 마스크 편집 |
| **공업지** | 큰 8셀 블록 + 굵은 간선 1축, 공장(`F`)·창고(`W`)·굴뚝(`T`) | 데이터 | 마스크 편집 |
| **항구** | 불규칙 + 빗살 부두 dead-end + 가장자리 바다 평면, 창고(`W`) | 데이터 + 바다 쿼드 1개 | 마스크 + 씬 오브젝트 |
| **간선 큰길** | 도로 폭 2~3타일로 넓혀 위계 (지구 잇는 척추) | 데이터 | 마스크 |
| **배달지 11개** | 실제 도로셀 위 + 지구별 분산 재배치 | 데이터 | deliveries 편집 |

(중앙 랜드마크 행 제거 — §3 결정. legibility는 지구 차이 + 항구 물가로.)

**핵심**: 거의 다 마스크 데이터. 코드/씬은 단 하나 — **항구 가장자리 단색 바다 평면(쿼드 1개)**.

## 5. 재료 제약 (타일 어휘 감사 결과)

- **`#` = 도로** (확정. 이웃 개수로 직선/곡선(90°)/T/십자/막다른길 자동 추론). `X`=횡단보도, `D`=진입로 dead-end, `P`=광장(주행가능), `B`=다리.
- buildingMask: `S`주택 `C/K`상업 `H`고층 `T`굴뚝 `F`공장 `W`창고 `P`광장.
- **불가**: 대각선 도로, 진짜 곡선(호), 물 타일. **추가 쉬움(후속)**: 로터리·분기로(미사용 fbx 존재).
- **함정**: `TrackConnectivityVerifier.IsRoad`는 `# X D`만 도로로 인정 (다리/경사 제외) → 평지 맵이라 이번엔 무관.

## 6. 검증 게이트 (asset.md 준수)

1. roadMask 수정 → **`TrackConnectivityVerifier` 필수**: 고립 0, 모든 지구 도달, End는 의도된 부두 dead-end만.
2. **배달지 11개 전부 도로셀(`#`) 위** — `unity-cli exec`로 `IsRoad(col,row)` 전수 확인 (현재 경계셀 박힘 의심 → 반드시 재확인).
3. `RunFullRebuild` 후 BuildingPlacer 경고(도로 위 building 등) 0건.
4. **시각 확인**: top-down 스크린샷으로 지구 3개가 다른 리듬으로 읽히는지 + 항구 바다 보이는지 눈으로.

## 7. 리스크

- 30×22 손 ASCII 재작성은 connectivity 반복 수정 필요(초안→verifier→수정). 복붙 아님.
- 바다 평면은 씬 오브젝트라 씬 저장/회귀에 포함되는지 확인.
- 배달지 좌표를 새 roadMask와 동기화 안 하면 마커 도로 미접속.
