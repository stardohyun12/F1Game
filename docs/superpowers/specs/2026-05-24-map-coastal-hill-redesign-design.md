## 운영 계약 (이 작업의 핵심)

- 나(Claude)는 시각물에 **"됐다·좋다·괜찮다"를 말하지 않는다.** 자기판정 권한 없음.
- 매 수정 후 **컨텍스트 0 fresh 리뷰어**가 점수(/10) + 결함을 냄. 나는 raw 점수·결함만 전달.
- **합격선 = 리뷰어 ≥ 7/10.** 그 전엔 도현에게 안 가져감 (도현 결정). 최종 "됐다"는 도현만.
- 도현 개입: 리뷰어가 7 넘을 때만 보고 (도현 선택, 2026-05-24).

## 컨셉

해안 소도시. 항구(tier 0, 낮음) → 다운타운(중간) → 내륙 주택지(언덕, 높음). 고저차로 ① 땅이 살고 ② 위에서 town이 읽히고(legibility) ③ 소도시→도시 성장 서사와 맞음.

## 순서 (한 단계씩, 각 단계 리뷰어 게이트)

1. **지형** (근본 먼저) — heightMask 3~4 tier. 단 차이는 slope 타일(D-050)로만 연결. 도로 셀에 height 직접 넣지 않음(단절 방지). 물가는 항구로 한두 칸 들어오게.
2. **도로 배치** — 격자 복붙 깨기, 지구별 리듬(항구 부두/다운타운 조밀/주택지 골목). 마킹 적은 도로 타일 변형으로 교체(키트 `-path`/plain). roadMask 수정 → TrackConnectivityVerifier 필수(asset.md/D-038).
3. **건물 배치** — 모든 칸 채우기 X, 블록 여백·공원·setback 변화, 복붙 깨기.
4. **색·톤** (마지막 폴리시) — MoodController 따뜻한 톤+그림자, 지붕 어스톤.

## 제약 (asset.md)
