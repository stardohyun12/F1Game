## 0. 먼저 알아야 할 사실 (실측, 2026-10-20)

측정 = OSM 캐시 `tools/town-gen/out/structure_a/network.json`(상자 A) 의 차도(primary·secondary·residential·unclassified·living_street·service)를 같은 좌표 점끼리 이어 만든 그래프. 좌표는 상자 남서 모서리 기준 m(x 동, y 북) — STRUCTURE-*.md 와 같은 틀. 스크립트 `.ai_logs/route-diversity/graph.js`·`branches.js`·`gaps.js`·`shortcuts.js`·`dest.js`(기획 측정용, 게임 코드 아님).

1. **상자 A 의 실제 차도는 거의 '나무 모양'이다.** 큰 덩어리 17.9km 안에 고리는 3개뿐 — 아말피 항구 앞 316m(SS163 + Piazza Flavio Gioia + Lungomare), 항구 서쪽 147m, 콘카 Piazza Olmo 94m. 나머지는 SS163 한 줄에서 가지가 뻗은 꼴.
2. **그래서 OSM 그대로 자르면 아말피 ↔ 콘카는 길이 한 갈래다.** 대안 경로 4개를 뽑아도 1번 경로와 96~99% 겹친다.
3. **원인은 상자 경계다.** 비탈 위 윗길(Via Pimenio secondary → Via Primo Maggio)과 콘카 Via Miramare 가 상자 서쪽 경계 **약 8m 밖**에서 실제로 한 점을 공유한다(Overpass 2026-10-20 확인: 노드 40.6171748, 14.5689036 — way 147083906 · 522140502 · 536405704). 상자에서 잘려 끊겼을 뿐이다.
4. 그 22m 를 잇고 콘카 입구 잇기(조각 7b 에 이미 있음, 44m)를 같이 두면: — **정정(15a 실측): 7b 입구 잇기는 44m 가 아니라 214m(생성기가 SS163 (514,567) 에서 마을로 바로 올린 길, 실제 지도에 없음). 아래 표 경로 1 은 7b 잇기 없이 OSM 마을 오르막(878m)을 탄 값이다. 7b 를 넣으면 해안 경로가 3,870m 로 짧아져 +45.7% 가 된다 → §11.**

## 2. 규칙과 흐름

### 2.1 한 판 흐름 (기존 루프 그대로, 바뀌는 것만 굵게)
주문판(Board) → 경로 순서 정하기(Routing) → 포장(Packing) → 운전(Driving) → 정산(Result) — `RunController` 단계 그대로.
- **출발·복귀 = 아말피 항구 가게 1곳**(`DeliveryManager.startReturn`). 마지막 배달 후 가게로 돌아와야 정산(기존 동작).
- **목적지 = 실제 OSM 건물 1채 + 그 집의 '정차 자리' 1곳.** 도착 판정은 정차 자리 트리거(기존 `DeliveryPoint`, 반경 3m)에 차가 들어오면. 걸어서 전하는 동작은 없다(D-115 의 걷기 = ideas-parking).
- 주문 1개 = 목적지 1~3곳(기존 `OrderJob.destinationLabels`, 1~3 클램프). 여러 주문을 한 판에 묶는 것도 기존 그대로.

### 2.2 가게 (가설)
- 위치: 아말피 항구 앞 Piazza Flavio Gioia 일대 — 항구 고리(316m) 위, SS163 과 바로 이어짐. 좌표 후보 (2830,2266) 근처 차도 옆 평지(조각 3 의 중심 광장 판 재사용 가능).
- 꼴: 차를 대는 자리 6×2.5m + 가게 건물 1채(OSM 건물 중 골라 표시, 새 아트 없음 — 간판 표시는 §4).
- 이유: ① 아말피 중심·해안·콘카·윗길 어디로 가도 첫 갈림이 항구에서 시작 ② 지금 생성기가 제일 잘 만든 구역(v13).

### 2.3 목적지 고르기 규칙 (생성기가 자동으로)
1. 후보 = 씬에 놓인 OSM 건물(규칙 집 제외 — 실제 사람이 사는 집이 배달지). 교회·예배당(church/chapel)·바다 위 구조물 제외.
2. 정차 자리 = 그 건물 윤곽에서 가장 가까운 **차가 닿는 차도**(큰길 BFS 로 가게에서 도달) 위 점에 6×2.5m 직사각형. 조건: 다른 건물·광장 면·바다에 안 걸림, 큰길 차로를 막지 않는 쪽(갓길/좁은 차로 끝). 조각 12 의 광장 포켓 규칙과 같은 코드 경로.
3. 종류:
   - **차로 닿음**: 건물 윤곽 ↔ 정차 자리 가장자리 ≤ 15m.
   - **정차 후 걸어서**: 15m < 거리 ≤ 60m. 지금은 정차 자리 도착 = 완료. 주문 카드에 "걸어서 약 N m" 표시만(직선 거리, 가설 — 보행망 거리는 걷기 기능 때).
   - 60m 넘는 집은 배달지로 안 씀.
   - 광장 안 집(D-115) = 광장 포켓(조각 12, 5곳)이 정차 자리, 종류는 "걸어서".
4. 개수(가설, 1차): **30곳** — 아말피 중심 10 · 해안 SS163 외딴집 6 · 콘카 6 · 윗길 마을 6(D-116 확정). 같은 집 중복 없음, 정차 자리끼리 ≥ 20m(트리거 겹침 방지).
   - 종류 비율: 차로 닿음 ≥ 60%, 걸어서 ≤ 40%(가설 — 걸어서가 많으면 "차를 대고 아무 일도 안 일어나는" 순간이 늘어남).
   - 고르는 법: 가지별로 가게에서의 **도로 거리**를 3구간(가까움/중간/멂)으로 나눠 구간마다 고르게, 시드 고정.
   - **윗길 마을 6곳(15a 뒤 정함, §11-③)** = 윗길 고리 위(콘카 씨앗 (296,510) 에서 200m 밖) 건물 중에서. 고리 위 모임 = (464,662) 16채 · (598,789) 8채 · (979,1256) 6채(반경 100m, 윗길 60m 안 OSM 건물). Pogerola 쪽 갈래 끝(2091,2499) 11채는 고리가 아니라 막다른 갈래라 이번엔 안 씀(§7).
5. 라벨 = `<가지>_<번호>`(예: `Amalfi_03`, `Conca_02`, `Coast_05`, `Upper_01`). GameObject 이름 = 라벨(`DeliveryPoint.Awake` 폴백과 맞춤). 이름 있는 건물은 카드 표시명에 OSM name(예: "Chiesa..." 는 제외 대상이므로 주로 무명 → "콘카 2번 집").

### 2.4 구역 해금(채널 3)과 묶기
| 구역 Zone | 들어가는 배달지 | unlockCost(가설) | 비고 |
|---|---|---|---|
| `amalfi_centro` 아말피 중심 | Amalfi_* 10 | 0 (시작) | 가게 주변, 짧은 주문 |
| `costiera` 해안길 | Coast_* 6 | 1,000 | 외딴집, 중거리 |

### 2.5 주문 꼴 (가설 — 한 판 5~15분을 노림)
평균 주행 속도 13m/s(가설, 조각 9 실측으로 교체) 기준.
| 주문 꼴 | 목적지 | 왕복 도로 거리(가설) | 예상 운전 시간 |
|---|---|---|---|
| 동네 | 아말피 중심 2~3곳 | 0.8~2km | 1~3분 |
| 해안 | 해안 외딴집 1~2곳 | 2~5km | 3~6분 |
| 콘카 | 콘카 1~2곳(+해안 1) | 9~10km | 11~13분 |
| 윗길 | 윗길 마을 1~2곳 | 6~9km | 8~12분 |
- `timeLimitSec` = 예상 운전 시간 × 1.5(가설), 0(무제한)인 주문 1개는 남겨 둔다(초보용).
- `baseReward` 는 왕복 거리에 비례(가설: 1km 당 150, 최소 200). 지금 값(500 고정 근처)은 100m 맵 기준이라 그대로 쓰면 해금 속도가 깨진다 — 튜닝 포인트.

### 2.6 경로 순서 화면(Routing)
- 지금 `RoutePlanScreen` 은 가게 → 목적지를 **직선**(`LineRenderer`)으로 잇는다. 100m 맵에선 문제없었지만 3km 땅에선 바다·산을 가로지르는 선이 된다.
- 1차(가설): 직선은 유지하되 **오버뷰 카메라가 상자 A 전체 차도를 한 화면에 보여 줌**(`OverviewCamera` 범위를 이 씬 크기로). 플레이어는 지도에 보이는 길을 보고 경로를 고민한다.
- 길 따라 그린 경로 선·운전 중 길 안내는 2차(§7 범위 밖). 1차 플레이에서 헤매는지가 §10 질문 2.

### 2.7 예외
- 정차 자리를 못 만든 건물 → 후보에서 뺌(생성 로그에 개수).
- 차가 목적지 트리거를 지나쳐 버림 → 기존 동작(다시 들어오면 판정). 큰길 갓길 정차 자리는 **차로 바깥**에 둬서 지나가기만 해도 판정되는 일을 막는다.
- 주문 목적지 라벨이 씬에 없음 → `CheckOrderDestinationsResolve` FAIL(기존 회귀가 막음).

- 이유 ① +45.7% 면 윗길은 늘 지는 길이다. D-116 이 고른 "해안이냐 윗길이냐" 고민이 안 생긴다(§1 경험 목표가 없어짐). ② 7b 214m 는 생성기가 만든 길이라 D-111(실제 길 우선)·R6 취지에 어긋난다. §0.4 의 "44m" 는 기획이 잘못 적은 사실 — 정정함. ③ 1.3배 기준을 늘려 맞추지 않는다(결과를 보고 기준을 바꾸면 측정이 아니라 합리화).
- 대가: 콘카는 SS163 서쪽 (536,266) 에서 Via Don G. Amodio → Via Miramare 로 올라간다. 조각 7b 의 "SS163 에서 바로 오르는 입구 길" 모양은 사라진다. 아말피 → 콘카 해안 경로 +989m(13m/s 가설로 약 +1분 16초).
- **다시 빌드할 때 고칠 것(프로그래밍, 15a-2)** — realEntry 측정에서 나온 문제:
  1. 경계 잇기가 다듬기에서 사라짐(그린 길이 0m, 그래프에서 12.8m 떨어짐). → R6 새 조건(그려짐 + 중간점 ≤ 1m). 지금 윗길 5,623m 는 경계 잇기 없이 콘카 마을 길로 돌아 나온 값이라 다시 잰다.
  2. 헤어핀 2.6m — 경계에서 Via Primo Maggio ↔ Via Miramare 가 실제로 V 자로 만나는 자리. → 상자 안 (16,455) 근처에 반경 ≥ 8m·경사 ≤ 5% 헤어핀 패드. 패드로 늘어나는 길이도 R6 50m 안.
  3. OSM 선 이탈 최대 48m(M3 상한 6m) — 위치와 원인 보고(입구 쪽 다듬기로 추정).

### ② 콘카 안 차도 — 두 경로가 지나는 길만 차도, 나머지는 골목 (기획 결정)
- D-115(마을 길 = 웬만하면 차로)·D-116(고리가 마을을 지나야 함)이 town-structure §4.3 "입구 길 1개" 보다 나중 결정이다 → town-structure 스펙 §4.4 로 개정.
- 규칙: 콘카 씨앗 100m 안에서는 **R1 경로 1·2(해안 입구 → 광장, 경계 잇기 → 광장)가 지나는 OSM way 만 차도**. 그 밖 반경 안 way(이번에 secondary 로 올라간 Via Roma·Via Umberto I 등 중 경로에 안 드는 것)는 §4.3 대로 골목·계단. 반경 **밖** 윗길 가지는 지금처럼 통째 차도(끊김·생성 잇기 7개 방지 — STRUCTURE-15A 2번).
- 마을 차도 굽이: 실제 OSM 모퉁이는 큰길 M3(≥ 12m) 대신 **≥ 8m 허용**(가설 — 좁은 차로. 조각 9 에서 차가 실제로 도는지 확인, 못 돌면 그 모퉁이만 패드). 헤어핀 8m 은 그대로.
- v15 의 Via Roma 8.9m 굽이는 realEntry 에선 안 나옴(최소 12.2m).

### ③ 윗길 마을 위치 — 가설 (414.6,681.3) 유지, 데이터로 맞음. 뜻은 도현 확인 1건
