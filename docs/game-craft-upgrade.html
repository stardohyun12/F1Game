M3 · ErgoConstraints SO

M5 · 자기비판 5문항

  • ① 클릭 영역 손가락 안 들어갈 만큼 작지 않나?

  • ③ 처음 보는 사람이 "뭐 해야 되지" 5초 안에 알 수 있나?
  • ④ 변경 전/후 screenshot 비교했을 때 후가 명확히 나아 보이나?
  • ⑤ 다른 부분이 이 변경 때문에 더 이상해 보이진 않나?
