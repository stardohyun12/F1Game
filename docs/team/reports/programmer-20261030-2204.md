# programmer 20261030-2204 — 길 그리기 도구 1판 (D-215)

> 상태: 완료. 검증 3개(새 길 / 점 옮김 = 그 구간만 / 재빌드 뒤 유지) + Ctrl+Z 통과. 테스트 길 지우고 원래 지도로 재빌드함. **적용은 ~95 s 전체 재빌드, 목표였던 10 s 구역 재빌드는 못 함.**

## 도현용 사용법 (5줄)
1. 메뉴 `PitCrew/길 그리기` → 집·차고 120 m 안 길이 색 선으로 뜸 (주황 큰길 · 노랑 마을길 · 하늘 골목 · 초록 보도/계단)
2. 선 클릭 → Splines 기본 손잡이로 점 끌기 · Ctrl+클릭 점 추가 · Delete. 아래 단추로 종류 바꾸기 / 이 길 지우기
3. `N` → 빈 땅 클릭으로 점 찍기, Enter 로 끝 (끝점이 다른 길 3 m 안이면 갈림목으로 붙음)
4. 빨간 점 = 규칙 위반 + 자동 보정값 (예: "R 2.7 m → 너무 급함", "경사 87% → 11% (깎기 2.3 m)")
5. 씬에서 Enter = 적용 (길·지형·축대 재생성, 약 95 s). Ctrl+Z 됨. 다시 메뉴 = 끄기 (손 길은 `docs/map/roads-hand.json`)

## 설계 (가설 포함)
- **원본 = 빌더 입력 노선.** 스플라인 하나 = 빌더가 읽는 원본 길 하나(차길 = 씬 `TownV6_Gray/Roads` RoadSurface 중심선 122개, 걷는 길 = `town-v6b.json` alley/stairs 327개). 결과(RoadsV2 사슬)를 스플라인으로 만들면 갈림목에서 잘린 끝이 다시 입력으로 들어가 틈이 생기므로 입력 쪽을 편집한다.
- **저장 = `docs/map/roads-hand.json`** — 바뀐 길(점·종류·폭)·새 길·지운 길 id 만. 빌더(`RoadNetV2Build`)가 원본을 모은 직후 이 파일로 덮어쓴다 → `RoadNetV2BuildAll` 을 다시 돌려도 손 길 유지.
- **씬 오염 0** — 스플라인 루트 `RoadPaint` 는 `DontSave` (씬에 안 써짐). 끄고 켜면 json+원본에서 다시 만든다.
- **편집 = Splines 기본 핸들** (점 이동·Ctrl 클릭 추가·Delete). 새 길 = Splines 기본 "Draw Spline" 도구(`EditorSplineUtility.SetKnotPlacementTool`) — 그려진 컨테이너를 루트로 입양.
- **종류 4개**: 큰길 6 m(main) / 마을길 4.5(village) / 골목 3(village 3 m, 차 규칙 적용) / 보도·계단 1.5(alley, 지형 위에 덮기만).
- **적용 = 전체 재빌드** (`RoadNetV2BuildAll` + `TerraceBlock.Build(집,60)`). 구역만 재빌드는 빌더가 시작에서 전체를 되돌리는 구조라 1판에선 안 함 → 시간 실측해 적는다(기존 실측 88~145 s, 대부분 걷는 길 덮기).
- **규칙 위반 표시는 즉시(빌드 전)**: 스플라인 1 m 표본마다 반경(차길 R<10)·경사(지형 따라 11% 초과) → 빨간 점 + "→ 자동 보정" 값.

## 4. 남은 이슈
- **적용 10 s 미달 — ~95 s 전체 재빌드.** 빌더가 시작에서 전체를 되돌리고 지형(25 s)·TerraceBlock(55 s)을 통째로 만든다. 구역 재빌드는 지형 정점 영역 잘라 붙이기 + TerraceBlock 반경 제한이 필요 → 2판 과제. 결과는 이미 국소적이라(위 diff) 구역만 다시 만드는 건 가능해 보임(가설).
- **단축키 R 없음** — R 은 Unity Scale 도구와 충돌. 메뉴 토글만. 필요하면 `Shift+R` 등으로 정해 달라.
- **실제 마우스·키 입력은 안 해봄.** 그리기 도구·선 클릭 고르기·Enter·단추는 코드로 같은 경로를 불러 검증. QA 가 손으로 꼭 해볼 것.
- 도메인 리로드 뒤 자동 다시 켜기는 `delayCall` 에 기댐 — 에디터가 뒤에 있을 땐 안 뜸(실측), 앞에 있을 때는 미검증.
- 짧은 새 길은 넓은 길 띠 안에 든 부분이 잘린다(검증 1: 그린 길 중 5 m 만 남음). 갈림목 근처에 붙이는 길은 길게 그려야 함.
- 점 하나 옮기면 DP 로 줄인 꺾은선 매듭이라 반경 위반이 쉽게 뜬다(검증 2: R 2.7 m). 빌더가 펴 주지만 모양이 그린 것과 달라질 수 있음.
- 새 걷는 길(보도·계단) 재질 = 첫 alley 재질. 계단 모양은 안 만듦(지형 위에 덮기만).
- **빌더 재실행 시 씬 메시 사본 손 수정은 사라진다**(기존 규칙). 손 길은 json 이라 살아남음.
- HEAD 대비 집 마당 지형 +45 정점 차이(위 되돌림 항목) — 밭 투입 커밋 뒤 아무도 재빌드 안 했던 것으로 추정. PD 가 커밋 때 지형 asset 포함 여부 판단.
