## 4. 남은 이슈 / 도현 손 확인
- **도현 손 확인 1줄:** C → 건물 클릭 → 뜬 팝업에 "가나다" 를 치고 Enter → 마지막 "다" 까지 저장되는지, 팝업이 클릭한 자리 옆에 뜨는지.

- 팝업은 포커스를 잃어도 안 닫힌다. 닫는 길은 Enter·Esc·C(모드 끄기). 도메인 리로드(스크립트 컴파일) 뒤 남은 팝업은 Esc 로 닫힌다.
