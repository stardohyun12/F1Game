# build-20261103-1827 — 첫 한 판 메모 3개 (D-283)

**메모 1 원인(한 줄):** 카트 칩은 시선 광선(Gaze)이 카트 몸통을 맞힐 때만 떴고, 상자를 들었는지와 상관없이 문구도 키 없는 "포장 먼저"류라서 — 게다가 첫날 카트가 정비소에 있어 상자를 든 채 카트에 닿는 길 자체가 없었다.

1. **한 것** — (1) 상자 든 채 카트 2 m 안이면 시선과 무관하게 `E 싣고 타기` 칩, 안 들었으면 `상자부터 실어`, 카트 위에 "!"(화면 밖이면 좌우 끝). (2) 첫날 카트는 보관소 앞(DepotCart 273.5, 29.6, -37.4 yaw 90)에서 시작, 집 앞 단서 = 큰길가 소포 표지판(`DepotRoadSign`, 보관소 건물 아이콘 아틀라스의 소포 칸 재사용, 충돌체 없음, 화면 화살표 없음) + 집 앞 시선 돌림/안내글이 표지판을 향함. (3) 작업대 칩이 `상자 고르기 → 바닥 깔기 → 물건 넣기 → 빈틈 채우기 → 닫고 테이프(E) → 들어서 흔들기 → Q 물러나기` 순서로 바뀜(안내만, 손 순서는 막지 않음). 상자 들면 카트 "!" 가 방향을 알림.
2. **확인** — 컴파일 0 에러. `bash scripts/world_check.sh` → `OK 12/12`(새 불변 조건 1개: "상자 든 채 카트 칩" — 칩 문구 + 씬에 카트 + 카트 자리 땅·포장 자리와 25 m 이내). 손 입력 시뮬(`MemoSim`: simMove·SimInteract·PackBench.BotRun·SimPackLeave)으로 집 앞 → 큰길 걸어서 보관소(51 s) → 쪽지 → 작업대 포장 → 상자 들기 → 카트 `E 싣고 타기` → 탑승(주문 시작) **막힘 0곳, 순간이동 0회**. 카트를 70° 돌아본 채(1.6 m)로도 칩이 뜬다.
3. **증거** — `docs/qa/evidence/first-memo/`: `1-workbench-first-chip.png`(작업대 첫 칩 "상자 고르기") · `2-cart-chip.png`(상자 든 채 `E 싣고 타기` + "!" + "상자를 카트에 실자") · `3-depot-clue.png`(집 앞에서 소포 표지판) · `sim_log.txt`(칩 순서·걸음·막힘 로그). 모두 1× 저해상 캡처.
4. **남은 것** — (a) 집 → 보관소 걷기는 큰길 중심선을 따라 약 51 s(보관소 앞은 헤어핀) — 길 위 걷기 맛은 도현 판정. (b) 기존 `OnFootRouteBot` 의 DepotLeg(정비소 카트로 자유 주행) 는 첫날 카트가 보관소에 있어 옛 경로가 안 맞음 — 봇 전체 경로는 PD 몫(훅 D-270 이라 건드리지 않음). (c) 표지판·화살은 회색/크림 대역(새 아트 아님). (d) `DepotOrderSetup` 를 다시 돌리면 표지판 자리도 같이 다시 잡힘(빌더 재실행 시 씬 메시 사본 수정 소실 주의). (e) `docs/qa/tmp/`(스크래치, 미추적) 는 삭제 권한이 없어 남아 있음 — 지워도 됨.

## 도현 Play 순서 3줄 (바뀐 부분만)
1. 집을 나서면 고개가 큰길가 **소포 표지판** 쪽으로 돌아간다 — 그 길을 따라 걸으면 보관소, 카트는 이미 보관소 앞에 서 있다.
2. 작업대 앞 칩이 **상자 고르기 → 바닥 깔기 → 물건 넣기 → 빈틈 채우기 → 닫고 테이프 → 들어서 흔들기** 순으로 바뀐다(순서를 어겨도 안 막힘).
3. 포장 끝나면 [E 상자 들기] → 카트 쪽 "!" 를 따라가 카트 2 m 안에서 **[E 싣고 타기]**.
