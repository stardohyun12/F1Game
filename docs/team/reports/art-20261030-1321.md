# art 20261030-1321 — 길가 배치 계획기 dry-run

## 1. 만든 것·경로

| 산출물 | 경로 |
|---|---|
| Python 계획기 | `tools/map/plan_streetscape.py` |
| 요소 목록·밀도·검증·입력 해시 | `docs/map/streetscape-plan.json` |
| 전체 지도·범례·100m당 표·확대 3곳 | `docs/map/streetscape-plan.png` |
| 도현 검토 시트 | `art/_review/2026-10-30-streetscape-plan/sheet.png`, `index.html` |

- 입력은 `town-v6b.json` 원본 knots. 길 입력은 `load_roads()` 하나로 분리했다. 향후 V2 사슬 어댑터가 같은 내부 형식을 반환하면 배치 코드는 재사용 가능하다.
- 연석 구간·볼록거울·방지턱 후보, 전봇대·전선 경간·화분 줄·빨래·우체통·벤치·어구 상자·자전거, 차양·갈매기 자리·고양이, 글자 없는 아이콘 표지를 기록했다. 빨래는 한 요소에 움직임 슬롯을 붙여 중복 계수하지 않는다.
- 필수 `{kind, zone, pos, yaw, side, road_id, why}` 외에 이유 무리 ID, 예약 발자국 또는 경간, 경로상 거리, 부착 검토 상태를 기록한다. 출력 pos는 **Unity [x,y,z]**, 입력 knots는 **[x,z,y]**, yaw는 `atan2(dx,dz)`도, left/right는 원본 knot 진행 방향 기준이다.
- `env-buildings.json` 분류·앞면을 우선 사용한다. 그 파일의 건물 선택 범위 밖 camo/posi는 원본 건물의 자유 벽면에서 앞면을 추정하고 **유형 미분류**로 표시한다. 삭제된 `removed.osm_ways`는 무리의 이유로 쓰지 않는다.
- `roadv2_disabled.txt`는 옛 Unity 도로 객체 교체 목록이다. 원본 길 제외 목록으로 사용하지 않았다. `town-v6b.removed.roads`만 제외한다.

## 2. 확인 방법

```powershell
py -X utf8 tools/map/plan_streetscape.py
py -X utf8 tools/map/plan_streetscape.py --check
```

- 기존 Python 3.13 환경 사용. 일반 `python`은 이 세션에서 Shapely 없는 3.14를 가리키므로 `py`를 사용한다. 패키지 설치 없음.
- 첫 명령은 JSON·PNG·검토 시트를 생성하고, 두 번째는 파일 수정 없이 다시 계산하여 저장 JSON과 동일한지, 저장 요소가 규칙을 만족하는지 확인한다. 실패하면 종료 코드 1이다.
- PNG는 전체 지도와 tomo 큰길, posi main의 50m 접선 반전이 가장 큰 헤어핀, 능선 핵심 4채를 확대한다. A/B/C/D 위치는 `env-buildings`의 2026-10-29 23:30 저장본이며 최신 `placements.yaml`과 일치한다. Unity 현재 위치를 읽은 것은 아니다.

### 측정 정의

- 분모는 구역 내 **main+village 중심선 수평 길이**, 양쪽 길가 항목을 한 도로 길이로 나눈다. alley·stairs 길이는 분모에서 제외하되 충돌·입구 검사는 포함한다.
- 능선은 핵심 4채 바깥 경계에 28m 여유를 준 영역과 `ridge_*` 길이다. 해당 camo 길 길이는 camo 분모에서 차감한다. 공간 경계는 시트에 표시한 **dry-run 가정**이다.
- **밀도는 개별 소품과 무리 두 지표로 검사**한다. 연석 구간·전선 경간은 연속 구조이므로 밀도 비교에서 제외하고 m와 개수를 별도 기록한다. 모든 JSON 레코드를 섞어 센 `total_per_100m`는 연석의 4m 분할에 좌우되므로 D-205 소품 밀도 지표가 아니다.
- 갈림목: 모든 길의 교차선 분할 후 3방향 이상 접속, 1m 이내 끝점→중간 접속. 반경은 연결 도로의 최대 반폭+4m이며 예외를 두지 않았다. 실제 V2 갈림목 다각형이 아닌 보수적 대체값이다.
- 소품 중심은 길 가장자리+0.3~1.5m. **전체 예약 발자국**은 모든 도로 밖, 건물에서 0.3m 이상, 계단·alley 입구에서 2m 이상이어야 한다. 길 원본 경사 15% 초과 소품은 제외한다. 자전거는 갈림목 중심에서 10m 추가 회피한다.
- 연석·전선도 **전체 선분 폭**으로 검사한다. 소품끼리 0.35m, 연석과 소품 사이 0.15m를 확보한다. 전선은 실제 생성된 같은 길·같은 쪽 두 전봇대만 연결한다.
- 건물 금지 발자국은 원본의 배경·삭제 건물도 보수적으로 남겼다. 핵심 4채는 실측 bounds가 없으므로 각 위치에 **12×12m 임시 예약**을 추가했다. 따라서 “위반 0”은 이 입력·예약 모델에 대한 평면 결과다.

### 실제 실행한 검증

- Shapely 공식 예제 `LineString([(0,0),(0,1),(1,1)]).interpolate(1.5)`를 같은 조건으로 실행해 `(0.5,1)`을 얻고 `project`의 역관계 1.5를 확인했다.
- 길 안쪽·건물 여유·선분 중간 관통 fixture 실행. 독립 검토자는 저장 요소를 메모리에서 도로 안·건물 안·연석과 겹치도록 바꿔 모두 FAIL 검출을 확인했다.
- 독립 검토에서 발견한 연석–소품 겹침 44쌍, posi 고양이 32마리, 전체 PNG 경계 밖 요소, 삭제된 건물 앞 무리를 수정했다. 고양이·갈매기는 각각 구역당 최대 3마리/자리로 제한했다.
- pos/yaw와 예약 발자국, 원본 길 접선·옆·거리의 일치 검사도 추가했다. 단순히 저장된 발자국만 믿지 않는다.
- 생성 PNG를 직접 열어 전체와 확대도를 확인했다. 별도 시각 검토에서 지적한 표 열 어긋남, C/D 이름 겹침, 삼각형 범례 누락을 수정했다.

## 5. 승인 필요·남은 이슈·다음 단계

- **도현 승인 필요:** 밀도·이유 무리·자리 미리보기. 실제 모델 제작·게임 적용 승인으로 해석하지 않는다.
- **과속방지턱은 실제 범프가 아니다.** “길 안쪽 금지”를 우선하여 `status=roadside_candidate_marker_only`인 길가 설치 검토 표식으로만 출력했다. 실제 차로 횡단 범프·콜라이더는 후속 과제다.
- 핵심 4채 중 직접 연결된 무리는 **우리 집만** 확보했다. 나머지 3채는 예약 발자국·입구·갈림목·경사·무리 간격 조건 때문에 안전한 두 소품 무리를 확보하지 못했다. 빈자리를 채워 통과시키지 않았다.
- 전봇대 25~35m, 화분 줄 2~4무리/100m 등 초안 수치는 배치 후보 기준이며, 실제 안전 검사 후 밀도는 더 낮다. 기하학적으로 거절한 자리는 강제로 보충하지 않았다. 전선은 안전한 8경간만 남았다.
- y는 원본 도로 높이의 대용값. 접지 레이캐스트·절벽/바다 쪽 판정·실제 모델 크기·차양/빨래 벽 부착·반복 메시 제한·주행·애니메이션·충돌은 **미실행/미검증**이다. 장면 아트 게이트 통과 보고가 아니다.
