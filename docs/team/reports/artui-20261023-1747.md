## 임포트 표

여백은 PNG 원본 픽셀 **L/B/R/T**. 크기·여백은 이전 D-123 그대로다. 모든 PNG **Point / 무압축 / Mip Maps OFF / NPOT None / Full Rect / Image.color=Color.white**. 승인된 PNG 10개만 투입한다.

| 슬롯 | PNG 크기 | L/B/R/T | Image.Type |
|---|---:|---:|---|
| UITheme.paperPanel | 256×256 | 16/24/16/16 | Tiled |
| UITheme.paperCard | 256×320 | 16/24/16/40 | Tiled |
| UITheme.slipHeader | 256×64 | 16/16/16/16 | Tiled |
| UITheme.stampRing | 256×256 | 0/0/0/0 | Simple |
| UITheme.buttonPlate | 256×80 | 16/16/16/16 | Sliced |
| UITheme.enamelPlate | 256×128 | 20/20/20/20 | Sliced |
| UITheme.gaugeFill | 128×24 | 8/8/8/8 | Sliced |
| PackingScreen.stampSprite | 300×300 | 0/0/0/0 | Simple |
| PackingScreen.gaugeTrackSprite | 256×32 | 12/12/12/12 | Sliced |
| PackingScreen.gaugeFillSprite | 128×24 | 8/8/8/8 | Sliced |

960 논리 Canvas/referencePPU 100 + Sprite PPU 200 + Image multiplier 1을 적용 후보로 제안한다. 원본 4px 셀을 논리 2px로 표시한다. 도장은 128²/150² 고정, 패널 위치·크기는 짝수 픽셀. 현재 공용 Canvas 1920×1080와 Packing 자체 Canvas 1280×720을 맞춰야 하며 실제 배율은 Unity 미검증.
