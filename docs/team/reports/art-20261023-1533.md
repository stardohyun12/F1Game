## 실제 수치 검증

| 항목 | 32판 | 64판 |
|---|---:|---:|
| 삼각형 | 168 | 168 |
| 외측 치수 | 400×300×300mm | 같음 |
| 주축 밀도 px/m | 31.990~32.001 | 63.980~64.002 |
| 최종 아틀라스 | 64×64 | 64×64 |
| 팔레트 밖 색 | 0 | 0 |
| 단색8×8 창 | 0/90 | 0/1200 |
| 바탕 명도:위/앞/옆/바닥 | 149.85/132.33/112.52/90.59 | 149.37/131.75/111.56/90.56 |

명도는 스탬프 전 사다리층의 RGB 가중 평균으로,렌더 조명 측정값이 아니다. 실제 GLB 바이너리의 정점·UV·노드 변환에서 모든 삼각형 두 주축 밀도를 계산했다. 최종 PNG와 GLB 내장 텍스처·출처 SHA 일치도 검사했다.

증거:`validation/check-32.json`, `check-64.json`; 단색 검사 합성 fixture9개와 v01/v02 기존 회귀 통과. 단색8×8검사는 주면 내부 stride1,거터·빈공간 제외. 8×8보다 작은 표식·가독성·무작위처럼 보이는 얼룩은 자동판정 대상이 아니다.

## 무엇을 가져왔고 바꿨나

- [EDC 제작자 인터뷰](https://80.lv/articles/inside-the-making-of-easy-delivery-co)를 다시 열어 최소 지오메트리·텍스처 중심·소품 픽셀아트·456×256 판정·텍스처 명암을 확인했다. 우리에게 적용한 것은 폴리168 유지와 텍스처층/저해상도 비교다. EDC는 태양광 없는 방식이고 우리는 기존 아말피 한낮 태양광을 유지했으므로 동일 파이프라인 재현이라고 하지 않는다.
- Visceral Carnage의 스탬프/노이즈는 리서치팀 원문 확인 보고를 참고했다. 이번 [itch 링크](https://itch.io/devlog/437062/texturing-styles.amp) 직접 재접속은 실패했다. Pixel8r·Substance Painter를 실행하지 않았고, 우리 스크립트의 성긴 거리 기반 점 배치는 원본 블루노이즈 알고리즘 재현 주장이 아니다.
- CC0 실제 사진은 바탕에만 사용. 테이프·마모·송장·기호·AO는 팔레트 픽셀로 직접 작성했다. 원화는 색 참고와 리뷰 합성 배경이며 게임 텍스처에 넣지 않았다.
- 중간 `_00_downscaled.png`는 원천 확인용 사진이고 32색 검사 대상인 최종 텍스처가 아니다. 출시 후보 아틀라스는 별도 표시·장부 등록했다.

## 독립 게이트와 결함 3개

컨텍스트 없는 새 리뷰어가 비교/480×270/두 근접 렌더를 직접 열었다. **32판7/10,64판8/10, 같은 게임의 택배 상자인가:둘 다 예.** 64판을 선호하지만480×270에서는 차이가 작다는 판정이다. 원문:`art/_review/2026-10-23-cargo-box-v03/visual-gate.md`.

1. **테이프 끝이 두껍다:** 접착 띠보다 별도 딱딱한 조각처럼 보임.
2. **붉은 표식이 모호하다:** 화살표/기호가 즉시 읽히지 않음.
3. **네모 얼룩이 부자연스럽다:** 특히64판에서 재료 결보다 반복된 사각 패치처럼 보이는 부분.
