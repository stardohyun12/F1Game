## 프로젝트 규칙 제안 (전부 제안 — 도현 승인 전엔 확정 아님)
1. 세상 물건이 먼저(방향=길 위 물건+전표 약도, 속도=계기 바늘·소리, 화물=흔들림·소리), HUD 는 **대상에 붙는 작은 것**만.
2. 상시 HUD 면적은 **4% 부터 시작**(기존 초안 8%/3% 와 겹침). 대화·정산은 말할 때만 3.5~4%. 하단 큰 상자(12~20%)는 쓰지 않는다.
3. UI 는 세계와 같은 **960×540 격자**(D-124)에 그린다. `UIRoot.cs` 1920×1080 Overlay 는 격자 밖(10-23 지적) — 구현은 구현팀.
4. 상호작용 키 = 물건 곁 [E] 칩 하나(문장 띠 없음). 위험 경고 = 상자 곁 도트 "!" 한 번 + 소리(% 막대 없음).
5. 전표 = Jalopy 수첩 문법(들어서 읽는 종이). DS 홀로그램은 참고하지 않는다. 타이머 없음(D-238)과 충돌하는 DS 상단 타이머 문법은 쓰지 않는다.
6. 대화 문법은 ⓐ 작은 말풍선+꼬리(Short Hike) ⓑ 박스 없는 도트 글자+그림자(EDC) 중 하나로 고정 — **도현이 고른다.**
7. 이 문서의 %는 타사 홍보 컷 수치다 — **우리 화면 같은 카메라 전/후로 다시 잰다.**

### 후보 표 요약 ("조금은 보여줘야 하는 것", 전체는 본문 5절)
- **방향**: 길 위·길가 물건 + 전표 약도 / 대안: 작은 나침반(DREDGE 식, 상시 약 1%)
- **위험**: 상자 곁 도트 "!" (Unpacking) · **키**: 물건 곁 [E] 칩(DREDGE·Mail Time·Wheel World)
- **속도**: 계기 바늘(Jalopy) · **약속 시각**: 전표 · **대화**: 말풍선/글자만 · **정산**: 떠오르는 도트 글자(EDC) · **메뉴**: 풀스크린 노트/엽서

**도현이 정할 것**: ① 방향을 "세상 물건+전표만(상시 0%)"으로 갈지 "작은 나침반 하나(~1%)"를 더 둘지 ② 대화를 말풍선형으로 갈지 글자만형으로 갈지.

## 모르는 것
- **게임 평균 HUD**: 스토어 컷은 선별본 — HUD 가 빠졌을 수 있다(Short Hike 깃털·체력, Webfishing 낚시 HUD, Jalopy 경고등 컷에 없음). 실제 플레이 영상 필요.
- 한 글자씩 표시·글자 소리: 정지 컷으로 불가 **[미확인]**.
- 상호작용 키 안내: 6곳(Lil Gator[세계 속], Jalopy, TOEM, Webfishing, Short Hike, EDC)은 컷에 안 나왔다.
- DS 종이 라벨의 가독성, 개발자 UI 설계 글(Short Hike·EDC 외 못 찾음), EDC 80.lv 원문 재확인.
- 검색 도구(WebSearch/WebFetch)로는 개발자 UI 글이 얇게 나왔다 — 제 한계.
