# programmer 0506 — 주행 방식 비교판: Box(지금) vs Wheels(바퀴 4개)

**도현이 직접 비교하는 법**
1. `Assets/Scenes/Map_BayLoop.unity`(해안 연석) 또는 `Map_TownV6.unity`(언덕 마을)를 연다 → Play.
2. 운전 중 **F9** 를 누를 때마다 Box ↔ Wheels 가 바뀐다(콘솔에 `주행 방식 → Wheels (F9)`). 인스펙터 Race › ArcadeCarController › 「주행 방식 비교판」에서도 바꿀 수 있다.
3. 같은 곳(연석 비스듬히 오르기, 가파른 꺾임, 갈림목 턱)을 두 방식으로 번갈아 지나가 본다. 기본값은 Box 다(씬 값 안 바꿈).

## 결론 (봇·측정만, 운전 판정 아님)
- **연석: Wheels 가 확실히 낫다.** 5 m/s 로 연석 진입 10회 — Box 3회 멈춤(1.5 m 가고 끝, 처음 도현 버그와 같은 모양), Wheels 10/10 넘음.
- **언덕 마을 봇: 실패 수는 줄지 않았다.** Box 21 / Wheels 21·30·27(같은 설정을 다시 돌려도 21→27 — 판마다 ±6 흔들림). 대신 Wheels 는 바다로 **추락 4~6판**이 새로 생겼다.
- **덜컹은 줄었다.** 차체 수직 가속 RMS 평균 Box 6.11 → Wheels 3.5~3.8 m/s²(약 40% ↓), 중앙 피크 31.6 → 14~17.
- 가설: 실패가 안 준 이유는 이 맵에서 남은 실패가 상자 박힘보다 **경사 자체(20~41 %)와 길 위 건물(Walls_0)** 이라서다. 박힘 몫은 Wheels 가 고치지만, Wheels 는 꺾임 꼭대기에서 바퀴가 다 뜨면 추진력이 끊겨(접지 = 실제 바퀴 접촉) 못오름·추락이 생긴다.

## 1. 한 것
- `F1/Assets/Scripts/ArcadeCarController.cs:86-175` 비교판 블록 추가. 다른 로직은 그대로(가속·조향·그립·드리프트 공용).
  - `:87` `DriveMode { Box, Wheels }`, 기본 Box. `:119` F9 토글 + 인스펙터 변경 감지. `SetDriveMode()` 공개(봇·QA용).
  - `:129` `ApplyDriveMode`: Wheels 때 차체 BoxCollider **바닥만 0.25 m 올림**(윗면 그대로), Box 로 돌리면 원래 크기 복원.
  - `:142` `ApplyWheels`: 차체 안에서 반지름 0.28 m 구를 아래로 4개 쏨(차 상자 반폭×0.8, 반길이×0.72 위치). 스프링 5000 N/m·댐퍼 560 N·s/m, 힘 방향 = **접지 법선**, 상한 질량×25 m/s². 법선 y < 0.35(벽면)는 안 밟음. 평형 높이 = Box 때 상자 바닥 높이(평지 차 높이 차이 3 cm).
  - 구름 저항 3.2 m/s² — Box 는 상자 바닥 마찰(CarLowFriction)로 덜 나가므로 0→60 을 맞추는 값.
  - `:285` Wheels 일 때 `isGrounded` = 바퀴 하나라도 닿음(Box 는 기존 중심 레이 2 m).
- 측정 도구(새로 만듦): `docs/qa/tmp/drive_perf.cs`(평판 성능표), `curb0506.cs`(BayLoop 연석 10회 + 화물 G), `botsum.py`(봇 요약), `car_info.cs`.

## 4. 화물 흔들림(CargoShakeSimulator 입력값)
- 시뮬레이터 입력 = 좌우 G + 앞뒤 G + 차체 기울기(`CargoShakeSimulator.cs:199-203`). **위아래 가속은 안 들어간다** — 그래서 Wheels 로 줄어든 덜컹은 화물 흔들림에 직접 안 보인다.
- 연석 10회 중 넘어간 판 기준(입력 RMS, g): Box 0.14~0.28 / Wheels 0.23~0.33. 최대 기울기(sin): Box 0.18~0.67 / Wheels 0.18~0.92.
- CargoBox HP 감소: Box 0~6.3 / Wheels 0~15.3. 큰 손상은 둘 다 R 쪽(인도 넘어 바다 쪽으로 기울며 내려감) 판에서. Wheels 는 멈추지 않고 넘어가서 그 내리막까지 가므로 손상이 더 크다.
- 판정: Wheels 에서도 값이 0 이 아니고 상황별로 갈린다 → **의미 있게 반응함.** 다만 위아래 충격을 흔들림에 넣을지는 기획 결정.
