- 원형 FBX를 Blender에 먼저 불러 원본 PNG 상태를 렌더하고 같은 카메라에서 교체 PNG를 렌더. 메시·UV·알파 변경 없음. 원본 폴더·houses-*·F1/Assets 수정 없음.

- 기존 CREDITS와 원형 kit.json의 CC0/CC-BY 기록을 보존. 자전거·전신주 출처/수정 표시는 결과 CREDITS.md에 유지. 외부 라이선스 페이지 재확인 안 함. AI 이미지·소리 도구 사용 안 함.

## 남은 이슈 / 승인 항목

1. **도현 승인 필요:** 소품의 덩어리 명암과 자연 3색 패턴. 게임 적용 승인으로 간주하지 않음.
2. 자연 렌더는 동일 대용 메시의 전/후다. Unity 실제 삼각형별 UV와 셰이더에서 같은 결과인지는 아직 미검증. 자연 접지 한 단은 현 smoothstep 셰이더로 대체할 수 없어 프로그래밍팀 수정 필요(APPLY.md).
3. 원본 나무는 게임 컷보다 어둡고 복잡하다. 게임의 셰이더·색 보정을 재현하지 않은 Blender 기준이므로 **그림체 통일 통과를 주장하지 않음**. 최종 판정은 카메라 B의 집·나무·소품·길 크롭과 주행 영상 필요.
4. 철망 알파·자전거 살·전선의 작은 형상은 형태 보존 지시대로 남김. STYLE 규칙4와 움직임 지글거림은 별도 QA 확인 필요. 나무 원본 텍셀 크기도 이번 작업에서 변경하지 않음.
5. Unity 실행·Play·임포트·씬 저장·커밋·push 안 함. 다음: 도현 시안 판정 → 승인 항목만 QA/프로그래밍 임포트 → 실제 게임 컷 검수.

## 별도 시각 검수와 1회 보완

- 작성자와 분리된 이미지 리뷰: **아니오 / 5점**. 기준 나무의 촘촘한 표면과 후 소품의 큰 색면 차이, 자전거 고무/프레임 구분 약화, 드럼·화분 입구 구분 약화 지적.
- 보완: 자전거 원본의 어두운 재질 삼각형은 청록 암부로 구분, 화분 안쪽을 청록 한 덩어리로, 드럼 윗면을 별도 청록 면으로 변경. 사진 무늬는 복원하지 않음.
- 기준 게임 나무 크롭 `art/_review/2026-10-27-kit-style/tree-game-reference.png` 별도 제공. Blender 원본 나무와 게임 셰이더 결과가 다른 사실을 숨기지 않음. 전체 통일감 판정은 보류이며 시안 제출 상태.
- 보완 후 재검수: 화분 입구·드럼 윗면은 분리됨. 다만 자전거 고무/프레임 색 차이, 화분 깊이감, 드럼 테두리·띠의 약화가 남음. **전체 그림체 통일 미통과 유지**. PIPELINE §10 시안 수정 1회 제한에 따라 남은 결함을 숨기지 않고 도현 판정용으로 제출.
