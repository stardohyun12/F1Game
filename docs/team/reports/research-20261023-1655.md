# 리서치 보고 — 속도감(F1 더 무비) + 규모감(EDC) (PD 20261023-1655)

근거 원문: `docs/research/2026-10-23-speed-and-scale.md` (링크·[확인]/[2차]/[측정]/[추정]/[미확인] 표시는 거기)

## 결론 3줄
1. **EDC 의 "속도감"·"규모감 만드는 법"은 개발자 원문에 없다**(80.lv 에는 같은 색 안개+앰비언트 한 색, 456×256 뿐; 안개 거리·원경·맵 경계·카메라 언급 없음). 리뷰는 EDC 를 "덜컹거리는 촉감", "미니맵 없음·표지판으로 길 찾기"로 묘사한다. 규모감 손잡이는 확인 2개 + 리뷰 + 내 추정이다. 도현이 EDC 에서 속도감을 느낀 장면을 짚어주면 좋다.
2. **F1 더 무비 속도감 = 광각(차 안 10·12·15mm)+아주 가까운 카메라+실제 속도+후반 롤+점멸 조명**(ASC 원문). 게임으로는 FOV·카메라 높이·롤·스침 물체로 번역된다. 소리는 "실차 마이크, 한 대를 코너에서 따로 들음"까지만 확인 — 도플러·바람 처리는 **미확인**. 레이싱 게임 쪽은 NFS Unbound 오디오 디렉터가 "고속에서 엔진을 빼고 공기음·스침음을 키웠다"고 말한 것이 가장 직접적이다.
3. **맵 끝은 "색부터(즉시) → 방향별 시야 차단 띠(단계적)"** 추천. 모션블러는 근거가 약하고(Disney 무효·Aalborg 역효과) 우리 렌더와 충돌 가능성이 있어 쓰지 않는다. 안개는 대비를 낮춰 속도감을 깎으므로 **거리 구간으로 속도 층(0~40m)과 규모 층(120m~)을 나눈다.**

## 프로젝트 규칙 제안
**갈 때 (F1 속도감) 손잡이 5 — 비용**
1. FOV 보간 곡선 조정 (50→100 유지, 100°는 시험) — 낮음
2. 카메라 더 낮고 가깝게 (시험안 y 2~2.5) — 낮음
3. 길가 스침 물체 간격·최소 크기 (2×2 블록 기준 폭 ≥3~4블록) — 중간
4. 소리: 고속에서 엔진↓, 바람·스침음↑ (물체 감지기) — 중간
5. 코너 롤 + 흔들림은 2px 단위 — 낮음

**항상·돌아올 때 (EDC 규모감) 손잡이 5 — 비용**
1. 앰비언트=안개 한 색, **경계물도 같은 규칙** — 낮음(기존)
2. 안개 끝 거리 시험 3종 fogEnd 100/160/240 (맵 대각선 240m) — 낮음
3. 먼 실루엣 2~3겹 (층마다 안개색에 가깝게) — 중간
4. 미니맵·위치 표시 최소, 표지판 길 찾기 — 중간 *(게임 설계, 도현 결정)*
5. 맵 끝 도로가 굽이/안개 속으로 이어짐 — 높음 *(근거 없음, 추정)*

**거리 구간 규칙**: 0~40m 속도 층(대비↑, 스침 물체) / 40~120m 전환 층 / 120m~ 규모 층(안개색에 녹는 실루엣). 모션블러는 쓰지 않는다.

**맵 끝 (노란 레일·옹벽 1.1m, `BuildMapBoundary.cs:22,39`)**
- **A (즉시, 낮음)**: 레일 제거·덮개/몸통을 안개색 쪽 저채도 한 색으로. 상수 수정+재생성.
- **B (추천, 중간)**: 북=바다라 옹벽 제거(낮은 방파제 턱+수평선), 서·동·남=언덕·나무·건물 띠(20~80m)로 시야 차단 + 보이지 않는 콜라이더. 바깥은 안개.
- C (높음): 소프트 경계(감속+페이드).
- ⚠ 생성기는 루트를 지우고 다시 만든다 → 수동 수정은 스크립트로 옮겨야 함.
- 판정: 시험 캡처를 도현이 1× → 흑실루엣 → 4× 로.

## 모르는 것
- EDC 의 안개 거리·원경·맵 경계·도로·카메라 처리 (원문 없음). 도현이 EDC 에서 "속도감"이라 느낀 장면.
- F1 영화 도플러·바람·차 안/밖 시점 음향 처리, British Cinematographer 원문(403), Aalborg 본문(403).
