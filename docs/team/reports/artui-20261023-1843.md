## 확인 방법·검증 증거

- `py art/_review/2026-10-23-course-ui/verify.py`: **7PNG/10목업/42투영/HTML PASS**, 결과는 [review.json](../../../art/_review/2026-10-23-course-ui/validation/review.json). PNG 팔레트·POT·활성UV 선언밀도32·레이어 일치·provenance SHA,960/정확한2×,HUD비움,거리 공식,로컬브라우저 창1440/600 확인. 실제 메시 밀도 검증 아님.
- 재사용 UI10종은 `check_asset.py --ui-manifest` **10/10 PASS**: [ui-slots-check.json](../../../art/_review/2026-10-23-course-ui/validation/ui-slots-check.json). 이전 크기·여백 유지.
- 최초 정적 검사는 과수원 ‘03’과 이름의 글자 경계상자1texel 교차를 잡았다. 실제 글자 잉크 마스크는 겹침0으로 확인되어, 검사를 경계상자 기록+실제 잉크 충돌검사로 구분했다. PNG는 바꾸지 않았으며 독립 재검토 당시 해시와 일치한다.
- [독립 게이트 원문](../../../art/_review/2026-10-23-course-ui/validation/independent-gate.md): 세계표지6.5→7.5(아니오), HUD8→8.5(예), A6.5→8(예), B7.5/C8(예·1차 유지). MART 겹침과 A 차량 가림을 1회 수정했다. 점수 기준과 가독성 전체 통과를 구분한다.
- `PIPELINE.md` §10의 “시안 단계에서는 고치기·재판정 왕복을 1회로 제한하고, 남은 건 목록으로 붙여 도현에게 보여 준다”에 따라 남은 거리 문제를 첨부했다.
- **미실행:** Unity/임포트/컴파일/Play, 실제 속도·안개 중 판독, TMP 래스터 일치, 사운드·애니메이션·귀로 상태 전환, 출시 빌드 전수 감사. F1/Assets 수정·3D 화물 제작·commit/push 없음.
