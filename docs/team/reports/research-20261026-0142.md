## 결론 3줄

1. **Freesound 원본 다운로드는 로그인이 필요하다.** 소리 페이지의 다운로드 버튼 문구가 **"Login to download"**, 다운로드 주소를 열면 **"Log in to Freesound" 로그인 화면**이 나온다 [확인]. 과제의 정지 조건("로그인/API 키를 요구하면 멈추고 보고")에 해당해 여기서 멈췄다.
2. **미리듣기(previews)만 받을 수 있는지는 확인하지 못했고, 받지 않았다.** 소리 페이지 내용에서 미리듣기 MP3/OGG 주소가 보이지 않았다 [확인]. 어차피 과제가 "미리듣기만 가능하면 받지 말 것"이라 했다.
3. **풀리는 길은 도현이 브라우저에서 직접 로그인해 파일 10개를 받는 것이다**(아래 목록, 약 5분 [추정]). 파일이 `art/source/audio/freesound/` 에 들어오면 가공(OGG 44.1 kHz·루프·볼륨)과 장부 기입은 리서치팀이 이어서 한다. 비밀번호·키는 요청하지 않는다.

## 도현이 받는 법 (제안 — 결정은 PD·도현)

1. 브라우저에서 Freesound 에 **본인 계정으로 로그인**한다(리서치팀은 계정·키를 만들거나 요청하지 않는다).
2. 위 10개 URL 을 열어 **Download** 로 받는다. 브라우저가 저장하는 이름(`<id>__<작가>__<이름>.wav`)을 그대로 둔다.
3. 받은 파일을 `art/source/audio/freesound/` 에 넣는다(폴더가 없으면 만들어도 된다).
4. 리서치팀이 이어서:
   - 각 페이지 License 줄 재확인(CC0 만) → 받은 파일의 sha256 계산
   - ffmpeg 로 44.1 kHz OGG, 20~40초, 앞뒤 3초 크로스페이드 루프, 볼륨 대략 맞춤(loudnorm) → `F1/Assets/Sound/Ambience/<층>_<이름>.ogg`
   - `art/provenance.csv` 에 소리마다 한 줄(URL·작가·`CC0-1.0`·받은 날짜·가공·`ai_generated=no`·sha256)
   - ffmpeg 가 승인 때문에 안 돌면 PD 가 허용해 줄 것(아니면 Python 라이브러리 설치 승인 필요)
