## 참고 → 재현 → 적용

ART-TRIAL-0427·내부 감사·ref-games-production을 읽고 A Short Hike·EDC·Crow Country·Jalopy 스크린샷을 직접 열었다. EDC의 텍스처 명암과 PS1의 미리 굽는 조명 원리를 적용했으며 해당 게임의 원본 제작 환경을 재현했다고 주장하지 않는다.

작은 큐브에서 Cycles DIFFUSE 베이크를 먼저 확인했다. 전체 장면의 AO 셰이더 경로가 지나치게 느려 DIFFUSE와 AO를 별도 패스로 굽는 방식으로 변경했다. 임시 결합 복제본만 베이크하고 원래 객체와 배치는 보존했다.

V5 복사본의 기존 손픽셀 색·문자를 재사용했다. 청록 벽·크림 판자·따뜻한 지붕·황토 바닥에 낮은 따뜻한 해와 청록 하늘빛을 적용했다. 반복 격자처럼 보이던 색 변화는 비주기적인 넓은 붓 자국 8개로 대체했다. 사진·AI 이미지 추가 없음.

Cycles 128 samples → DIFFUSE + 별도 AO → 노출 +1stop·청록 암부 보정 → Median 3 / Gaussian 0.65texel → 공용 24색 MEDIANCUT(디더 없음). 최종 GPL 팔레트를 고정하여 재실행 시 재학습하지 않는다.

정비소·카트·소품 40texel/m, 지면·도로·안벽 32texel/m. **800m 바다는 원경 배경 예외 0.32texel/m**이며 모든 면이 요구 밀도라고 주장하지 않는다. SourceUV와 BakedUV를 분리하고 내보낼 때 BakedUV를 UV0으로 남겼다.

게임 카메라는 카트 뒤 5.6m·높이 2.8m·세로 FOV64. Emission만으로 1280×720 렌더 후 1920×1080 Nearest 1.5배 확대했다. 시트는 비교용 축소 배치이며 정확한 배율은 개별 1080 이미지로 확인한다.

## 검증 증거

- 원본과 복사본 SHA256 일치, 311개 메시·평가 후 3,512tris. 원본의 월드 정점 위치·삼각형 수 보존 검사 통과.
- FBX 7개 재임포트 UV·tris 검사 통과. 최종 Blender 표면 모두 Emission 확인.
- 100,000 세기 빨간 조명 추가 전후 렌더 픽셀 차이 0: 조명 독립 출력 확인.
- 최종 PNG 7개 전체 색 합집합 24색. 화면의 하늘·경계 픽셀까지 24색이라는 뜻은 아니다.
- 최종 게임 컷 직접 확인. 별도 독립 리뷰어 점수는 받지 않았다.

## 남은 결함·다음 단계

1. 넓은 지면과 벽에 색이 뭉친 영역이 남는다. 노이즈를 더해 수치만 낮추지 않고 재질별 명암 단계 배분을 다시 설계해야 한다.
2. 내부 선반·공구가 어둠에 묻힌다. 내부 전용 부드러운 보조광을 베이크하는 후속 시험이 필요하다.
3. 카트가 지면과 비슷한 저채도 색으로 섞인다. 차체와 바퀴의 밝기 분리를 우선해야 한다.

현재 파일은 고정 장면 실험용이다. 지면에 카트/소품 그림자가 구워져 있어 이동시키면 그림자가 남는다. 동적 카트용 출력은 별도 정적 지면 베이크가 필요하다. FBX는 Unity Unlit 셰이더를 설정하지 못하므로 프로그래머가 PNG를 Unlit BaseMap에 연결해야 한다(`SPEC.md`). QA/프로그래밍 임포트 필요. Unity 임포트·실제 게임 카메라·움직임 검증은 실행하지 않았다. **도현 판정 필요, 화질 통과품으로 투입하지 않음.**
