## 참고 → 적용 → 개선

- 도현이 고른 F2/F3/G1/G2/G3/H1/H2/H3만 사용. 기존 SOURCES.md의 CC0 확인 기록을 재사용했으며 라이선스를 새로 웹 검증한 것은 아니다. AI 이미지 사용 없음.
- `tools/asset-gen/scene_a_v5_bake.py` 및 기존 정비소 baked-lit.blend의 태양·하늘빛·AO 설정 재사용. Cycles 128 samples로 실제 구웠다. 사진 원근/날짜 크롭 → 빛 평탄화 → 약 32 texel/m 축소 → 베이크 → 디더 없는 팔레트.
- 실측 기준은 Fuji 자판기 표준 1.181×0.731×1.83m, 우정박물관 13호 우체통 0.81×0.56×1.38m, Mitsubishi 실외기 동급 0.80×0.285×0.55m. 정확한 사진 속 제조 모델 치수를 확인했다는 뜻은 아니다. 원문 링크는 APPLY.md.
- 첫 결과에서 함석 명암이 끊기고 돌담에 다색 얼룩이 생겼다. 재료별 회색·붉은 명암 범위를 추가했고, 함석은 원본 세로 골의 평균 명암을 살리며 길이 방향 잡음을 제한했다. 임의 얼룩 레이어 없음. 실외기는 무채색으로 제한.
- 독립 1차 시각 리뷰는 6/10: 함석 골 약화, 실외기 팬·우체통 기능 디테일 손실, H2 작은 돌 뭉침을 지적했다. 함석 세로 골과 실외기 전처리를 수정했다. 해당 점수는 수정 전 Blender 참고 시트 평가이며 게임 품질 합격 점수가 아니다.

## 승인 항목·다음 단계

소품 4종의 기능 식별, F2/F3 함석 선택, H1~H3 돌담의 거리별 읽힘은 **도현 승인 필요**. H2는 작은 돌이라 축소 시 H1/H3보다 식별이 약하고, 32 texel/m 소품의 작은 글자는 읽히지 않는다. 반복 무늬는 남아 구간별 종류 분산을 APPLY.md에 적었다.

최종 산출 11 PNG 모두 공용 69색 안에 포함, 출처·산출 23건 SHA256 일치, FBX 연결용 .fbm 사본과 동명 PNG 일치까지 확인했다. 정비소 비함석 영역의 기존 반점은 이번 교체 범위 밖이라 보존했다.
