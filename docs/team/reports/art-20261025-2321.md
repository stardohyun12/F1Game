## 실제로 적용한 방법·검증

참고: [arjun988/blender-skills](https://github.com/arjun988/blender-skills), 로컬 커밋 `8f778d2405a214b508d4c7d80742be8e43acdd52`, MIT. 원문 94개 중 **8개만 직접 읽었다**: blender-director, vehicle-artist, prop-artist, uv-workflow, materials, qa-review, lowpoly-style, unity-export. MIT 고지는 원본 폴더 `BLENDER-SKILLS-LICENSE.txt`에 보존. 전역 설치·vendor 수정 없음.

브리프를 먼저 쓰고, BlenderMCP를 헤드리스 bpy 질의·생성·JSON 검사·실제 Cycles 렌더로 바꿨다. 부품별 mesh와 SM_/MAT_ 명명, 실제 미터 치수, 접합·비례 기록, 최종 내보내기를 적용했다. 스킬은 방법 문서이며 동일한 모델 예제를 원본 조건으로 재현한 것은 아니다. 기존 프로젝트의 렌더·검사 조건을 기준선으로 재사용했다. 실루엣 진단 렌더는 상세 geometry 이후 생성했으므로 스킬의 ‘상세 제작 전 시각 승인’까지 재현했다고 주장하지 않는다.

사진은 기존 CC0 Poly Haven 자료를 재사용했다. 금속은 rusty_painted_metal의 보호된 국소 영역, 천은 rough_linen을 실물 크기로 축소한 후 공용 팔레트로 양자화했다. 첫 판의 큰 흰 얼룩을 줄이고, 최종 판에서 자동차의 창 상단 반사 띠 제거·문과 필러 정렬, 삼륜차 차대 단축·접합 보강, 천의 큰 주름·노멀·UV를 수정했다. AI 생성과 절차적 랜덤 노이즈는 사용하지 않았다.

## 남은 결함 3개씩·다음 단계

| parked_car_02 | 01과 거의 같은 차종 인상 / 검은 판 같은 유리 / 평행 띠로 평평한 전면 |
| parked_car_03 | 마모보다 위장무늬로 읽히는 얼룩 / 바퀴 대비 무거운 객실 / 다른 두 차와 같은 전면 |
| three_wheeler_01 | 운전실·적재함 재질 구분 부족 / 막힌 검은 창 / 두꺼운 거울·타일 같은 전조등 |
| laundry_line_01 | 잘라낸 판 같은 셔츠 목·소매 / 바지 허리 접합·긴 판 같은 다리 / 긴 천 밑단 접촉과 측면 평면감 |

자동차는 위 시각 결함 외에 단색 주요 면 8개씩도 남았다. 다음 제작에서는 사진 UV 위치와 해당 부품을 먼저 수정하고, 자동차 01/02 차종 실루엣을 실제 해치백 사진에 맞춰 블록아웃 단계에서 검토해야 한다. 삼륜차는 차대 연결 개선을 유지하되 유리·금속의 명도 구분과 작은 부품을 다듬는다. 빨래 설치 참고 렌더는 별도 제공했으나 점수에 사용하지 않았으며 판 같은 구조 문제는 해결되지 않았다.

쓸 만한 스킬은 **blender-director·vehicle-artist·prop-artist·qa-review·unity-export**다. uv-workflow·materials·lowpoly-style은 프로젝트 기준과 대조하는 보조 자료로 쓴다. 특히 UV 문서의 월드 길이가 빠진 밀도식, 높은 텍셀/폴리 예산, Noise/PBR·고유 UV 요구는 채택하지 않았다. 상세 충돌표는 `skill-usage.md` 참조.

이번 시험은 보류 원본·검사 실패·독립 점수를 공개하는 것으로 종료한다. 추후 통과본이 생기면 **QA/프로그래밍 임포트 필요**, 도현의 최종 판단은 인게임 캡처에서 받는다.
