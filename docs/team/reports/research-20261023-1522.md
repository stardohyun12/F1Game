# 리서치 보고 — 로파이 소품 제작 기법 (PD 20261023-1522)

근거 원문: `docs/research/2026-10-23-lofi-prop-craft.md` (링크·[확인]/[2차]/[추정]/[미확인] 표시는 거기)

## 결론 3줄
1. 게이트 6/10 의 뿌리는 "12 tris" 보다 **"12 tris 인데 텍스처도 비어 있음"**. 읽은 개발자 원문 3곳(EDC·Dusk·Visceral Carnage)은 전부 **폴리는 아끼고 디테일을 텍스처에 몰고**, 손으로 얹는 층(스탬프·노이즈·디더)을 따로 둔다. 큰 흰 라벨은 **실물 비례 위반**(A6 라벨은 32px/m 에서 약 3×5 텍셀 → 읽히지 않으니 키웠다 → 표지판).
2. **저해상도 렌더는 도입 추천(시험 후 확정), 팔레트·디더 화면 후처리는 보류.** 후처리는 이질감을 덮을 뿐 형태·구도 문제는 못 덮고, 우리는 팔레트를 이미 텍스처에 쓴다. 이미 `PC_RPAsset` 에 렌더 스케일 0.5 + 업스케일 필터 2가 있으나 **후처리가 켜져 있으면 Nearest 가 안 먹는다는 Unity 문서** 때문에 *지금 포인트로 나오는지부터 확인*해야 한다.
3. **못 찾은 것**: Lethal Company·Content Warning·Mouthwashing·Haunted PS1 개발자 본인의 제작 발언. 이 게임들에 관한 서술은 제3자 해설이라 규칙의 근거로 쓰지 않았다.

## 프로젝트 규칙 제안 — 상자 v02 체크리스트 (10개)
1. **실루엣**: 윗 뚜껑 두 장+3~5mm 틈, 윗 가장자리 chamfer, 윗면 가운데 2~3mm 처짐. 지오메트리는 100~300 tris 안(상한은 시도값, 근거 약함).
2. **비대칭**: 한 모서리 ≤8mm 눌림, 테이프 약간 삐뚤게. 인스턴스마다 시드로 치수 ±2%·텍스처 오프셋 변주.
3. **라벨 비례**: 송장은 면 폭의 ≤30%(A6=105×148mm 가 상한), 흰색 대신 팔레트의 바랜 크림. 숫자는 라벨이 아니라 **스탬프/마커 글씨**로 따로.
4. **단색 면 금지 검사**: 어느 8×8 텍셀 창에도 팔레트색 ≥2 (스크립트로 통과/실패). 윗면·옆면은 서로 다른 명도 단계.
5. **텍스처 순서**: CC0 사진 → 다운스케일 → 32색 양자화 → 약한 Bayer 디더 → **스탬프층**(테이프 끝·접힘선·모서리 닳음, 위치 규칙표) → 단색 구역엔 블루노이즈 층.
6. **화물 텍셀 밀도 = 64px/m**(월드 32px/m 의 정수 2배)로 예외 허용 — 라벨·테이프가 읽히는 최소선. 이유: 32px/m 에서 한 면이 약 13 텍셀이라 비례를 지키면 라벨이 안 읽힌다. 도현 승인 필요(원칙 3 "격자 하나"의 예외).
7. **AO**: 접지면·접힘선 안쪽을 텍스처에 굽는다(버텍스 컬러는 기본 Lit 이 안 써서 보류).
8. **색 사다리**: 윗면 > 앞면 > 옆면 > 접지 순 명도, 테이프는 다른 재질색. 표식(화살표)은 십자 모양 금지 — 머리를 삼각으로 확실히.
9. **게임 해상도 판정**: 480×270(또는 정해진 해상도)로 줄여 렌더한 컷과 1×·흑실루엣을 *도현이 직접* 본다. Blender 1280×720 만으로 통과시키지 않는다.
10. **출처 장부**에 상자 질감 원천(CC0 URL) 기록 — 지난 보고 규칙 8.

## 화면 후처리 추천
- **도입: 저해상도 렌더(포인트 업스케일)** — 단, 확정 전 시험 3종(480×270 / 640×360 / 960×540) 캡처를 도현이 판정. 계산상 480×270 은 화물 텍셀(32px/m)과 화면 픽셀이 거의 1:1 이 돼 "격자 하나"가 자동으로 지켜지고, 상자 폭은 약 17px 로 줄어 **실루엣·대비가 더 중요해진다.**
- **순서**: ① 현재 0.5+필터2 가 정말 포인트인지 캡처로 확인 → ② 안 나오면 후처리 끄고 색보정을 텍스처에 굽거나 → ③ 그때 커스텀 RT 패스(Render Graph 새로 작성 필요, 검증된 예 없음).
- **보류: 팔레트·디더 화면 포스트.** Dusk·Visceral Carnage 모두 텍스처 단계에서 처리했고, 우리도 공용 32색이 텍스처에 있다.
- 비용: 화면 픽셀 수 기준 960×540 → 480×270 은 1/4. **프레임 시간은 실측하지 않았다.**

## 모르는 것
- Lethal Company·Content Warning·Mouthwashing·Haunted PS1 개발자 원문(트위터/블루스카이/GDC 포함).
- 저해상도 렌더가 에셋 이질감을 얼마나 덮는지의 정량 근거 — 위 시험 캡처로 직접 확인하는 수밖에 없다.
- `m_UpscalingFilter: 2` 가 Point 인지(enum 순서는 내 기억, 에디터 확인 필요), 6000.3 에서도 "후처리 켜면 Nearest 무효"인지.
- 버텍스 컬러 AO 가 URP Lit 에서 쓰이는지(내 추정: 안 쓰임).
- 게이트의 "기본 큐브로 읽힘"은 게이트 문서에 없는 PD 서술 — 게이트가 직접 확인한 결함은 옆면 표식·단조로운 면·축소 가독성 3개.
