## 결함 수정·선행 방법 적용

`docs/research/2026-10-23-non-ai-art-codex.md` §9⑧·§10, 브리프 규칙1~14와 이전 A1 보고서를 읽었다. 기존 `photo_to_pixel.py`의 사진→실측 BOX 축소→공용 팔레트·무디더 기준판을 먼저 만들고 손질 전 결과를 보존했다. 외부 작가의 전체 제작 과정을 재현했다고 주장하지 않는다.

| 이전 결함 | 이번 적용 / 선택 근거 |
|---|---|
| 기와가 압착 목재처럼 보임 | 실제 다른 CC0 사진 `ceramic_roof_01`, `clay_roof_tiles_02`, `grey_roof_tiles` 3개를 직접 다운로드해 같은1m·64px·팔레트로 비교. 큰 가로 겹침과 아래 음영이 남는 Ceramic 선택. 기존 사진 색 재조정 반복 없음. 최종2m 크롭, 재착색 없음. |
| 목재 가는 선·밝은 자국 반복 | 여러 실제 판재 사진 비교. 첫 판 `wooden_planks`는 여전히 가는 줄이 강해, 마지막은 판 폭 차이·옹이·마모가 보이는 `wooden_rough_planks` 전체2m 반복 단위로 변경. 90° 회전, 재착색 없음. 사진의 수리 역사·현지 촬영지는 확인하지 못함. |
| 회벽 박락이 인쇄 얼룩처럼 보임 | `rough_plaster_broken` 사진 속 국소 박락 두 곳을 윤곽대로 골라 실측 크기로 합성. 마지막 판은 실제 주변 회벽 영역도 포함해 잘라 붙인 경계를 완화. 마스크·좌표·RGB 보정값을 스크립트/manifest에 기록. |

공급자 [CC0 라이선스](https://polyhaven.com/license), [사진 기반 제작 FAQ](https://docs.polyhaven.com/en/faq), [텍스처 기술 규격](https://docs.polyhaven.com/en/technical-standards/textures)을 참고했다. 직접 diffuse 파일·공급자 MD5·SHA·실측·저자 정보를 보관했다. 공급자의 사진 기반/비AI 설명과 다운로드 파일 대조를 확인한 것이며, 개별 촬영 방식·장소를 독립 입증한 것은 아니다. **AI 생성 이미지·에셋·검토판 배경0**. 배경 포함 실제 Blender 렌더만 검토했다.

## 독립 게이트·남은 결함 3개

제작 의도·이전 점수 없이 각각 새 리뷰어가 실제960×540 렌더 두 장을 직접 봤다. 이번 첫 판 **예·6.5/10** → 마지막 판 **예·7/10**, 목표 도달로 종료했다. 제작자 자체 판정도 **7/10·시험본 통과**에 동의한다. 본 적용 승인을 뜻하지 않는다.

1. 기와 중앙~하단 얼룩이 강하고 검증용 평면 외곽이 얇아 점토 기와/목재 슁글 구별이 흔들린다.
2. 목재 중앙 손상 잔점이 길게 이어지는 나뭇결보다 먼저 읽힌다.
3. 회벽 가장자리 박락과 넓은 중앙 면 사이의 마모 연결이 여전히 약하다.

## 승인 필요·다음 단계

**도현 승인 필요:** 최종 시험본의 분위기와 본 적용. 시험 PNG 교체는 이번 과제의 명시 승인 범위로 완료했다.

**QA/프로그래밍 임포트 필요:** Point·Repeat·무압축·원본 크기 및 실제 UV를 확인해야 한다. 목재 반복은 이전1m→2m, 기와는4m→2m로 바뀌었다. PNG만 교체했고 UV/재료를 수정하지 않았으므로 **실제 게임 안64px/m는 아직 검증되지 않았다.** 반복 경계2px 색 보정은 기하학적 무봉제를 보장하지 않는다. 실제960×540 정면·사선·이동/안개 화면에서 재료 인식과 경계·떨림을 별도 확인한다. 기존 LofiAtlas 제안 칸4 wood·41 quaystone·0 plaster·44 roof_clay는 유지하되 아틀라스에 투입하지 않았다.
