- 기존 프로젝트의 split_1857.py(1mm 가상 용접·2cm 부품 묶음), snap_1950.py(받침 ray cast), 탐색 _isl_dump.py/_pen2.py를 먼저 실행·대조했다.

- 외부 코드/에셋 다운로드 없음, 기존 Blender 5.2.2 API와 프로젝트 코드를 재사용. 추가 설치·비용·AI 생성 없음.
