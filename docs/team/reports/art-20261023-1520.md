## 바꾼 것과 근거

- 리서치 보고와 갱신 규칙 1~11을 읽었다. EDC의 소품은 손 픽셀이고 사진은 환경이라는 구분을 유지했다. 우리 상자는 CC0 골판지 사진을 바탕에만 쓰고, 정보층은 스크립트 픽셀로 만든다. 이 구현을 EDC 파이프라인 그대로 재현한 것이라고 주장하지 않는다.
- [FEFCO 공식 구조 자료](https://www.fefco.org/technical-information/fefco-code)와 [Blender Bevel 문서](https://docs.blender.org/manual/en/5.0/modeling/modifiers/generate/bevel.html)를 참고했다. 실제 TART 외측 규격 400×300×300mm는 유지했다. 직접 실측은 하지 않았다.
- 형상: 12 → **168 tris**. 5mm 한 단 베벨, 덮개 2장·2mm 중앙 틈, 3mm 돌출 테이프, 앞 왼쪽 모서리 5/3/3mm 눌림. 작은 변형은 제작 선택이며 제조사 치수표의 세부 실측이 아니다.
- 정보층: 큰 `1` 삭제. 앞면에 작은 직사각 송장·바코드 줄·주소 줄, 오른쪽에 방향 표식, 왼쪽에 잔 기호. 전체 랜덤 마모 추가 없음.
- 비교: 회색 빈 공간 대신 원화의 오렌지 화물 자리에 **126×114px** 크기로 합성. 단일 따뜻한 태양광, 주변광과 동일한 해무 색 2.5%. 앞쪽 차량 난간을 명시적인 마스크로 복원했다. 이는 외관 검토용 합성이지 게임 캡처나 실제 카메라 크기 검증은 아니다. 원화/합성은 리뷰 폴더에만 있다.
- 출처: 기존 v01 행을 보존하고 v02 행 추가. 원천 URL·CC0·확인 날짜·스크립트·비AI·최종 PNG SHA256 기록. 모델에 AI 이미지/파생 텍스처를 넣지 않았다. 원화는 색 참고/합성 배경으로만 사용했다.

## 미충족·결정 필요

**‘조심’ 모델 적용은 미완료.** 32px/m에서 앞면 전체가 약 13×10px라 작은 송장 안에 Galmuri ‘조심’과 바코드·주소 3줄을 읽히게 함께 넣을 수 없다. 실제 Galmuri11 기본 12px로 찍은 `label-font-candidate_NOT_APPLIED.png`는 32×24px 검토용이며 모델에는 쓰지 않았다. 글자를 가짜 픽셀로 줄여 넣거나 밀도 기준을 몰래 바꾸지 않았다.

질문한 선택: ①32px/m 유지·‘조심’은 포장 UI 표시 ②송장 정보층만 고밀도 예외. 응답 전에는 ①의 모델 규격을 유지했으며, 포장 UI 구현은 다른 팀 영역이라 수행하지 않았다. 현재 송장·기호의 세부 가독성은 이 제약 때문에 남은 이슈다.
