## 2. 검증 증거
### 봇 시험
- 스크립트: `docs/qa/tmp/a6d_wallbot2.cs`. 결과는 SessionState `a4e.wall` 에 남는다.
- 방식은 a4e_wallbot 과 같다: 집마다 35°·90°, 40km/h, 풀스로틀 3초.
- 판정은 a4e_wallbot 과 다르게 **담 기준**이다.
  - 옛 판정(길 끝에서 0.3m)은 담이 길 끝보다 안쪽에 있으면 막혀도 「나감」으로 셌다. 0.42m 「나감」인데 그 자리에 0km/h 로 서 있었다.
  - 새 판정: 차 중심이 담 뒷면을 넘으면 실패다.

높이별 결과:
- 옛 투명 상자 (기준): 12/12 막힘
- 0.55m + MeshCollider: 5/12
  - 90° 에서 차 중심이 담 뒤 1.2~1.7m 까지 들어갔다. 담을 타고 넘었다.
- 0.55m + 상자 콜라이더: 4/12
- 0.75m + 상자: 7/12
  - 마찰 0 을 더해도 7/12 다.
  - 35° 는 담 끝 모서리를 돌아 나갔고, 카페 90° 는 타고 넘었다.
- **0.9m + 상자 + 양 끝 1m 연장: 12/12 막힘**
  - 차 중심이 멈춘 자리는 담 앞 0.80~1.07m 다.
  - 35° 샵은 57km/h 로 담을 긁고 지나갔다. 옛 상자에서도 58km/h 였다.
