## 폰트·참고·검증 범위

- [Galmuri 공식 v2.40.4](https://github.com/quiple/galmuri/releases/tag/v2.40.4)의 **SIL OFL 1.1** 실제 동봉 파일 확인·보존. Galmuri11은 이름과 달리 공식 기준 **12px**; 주행24px·제목36px. 18px 보조 글자는 제작 때 12/24px로 정리 필요. 긴 본문은 Pretendard 비교판까지 만들었고 이번 두 줄 대사는 Galmuri 유지.
- [Easy Delivery Co. 제작자 페이지](https://sweaters.itch.io/easydeliveryco)에서 풍경·운전·레트로 그래픽 방향 확인. 원본 게임 실행·프로젝트 재현·자산 추출은 하지 않았다. D-123 브리프·기준 원화가 주된 적용 근거다.
- 실제 수행: Chrome Canvas 슬롯 출력, HTML 목업 PNG 렌더, PNG 직접 보기, 슬롯 명세·PNG 크기·RGBA·로컬 링크 정적 검사(`validation.json`).
- 정적 검사 결과: 슬롯 명세 D-121과 동일, 크기 10/10, RGBA 10/10, 누락 로컬 링크 0건, 화면 5장 각1280×720·비교판1600×1880.
- **64×64 아틀라스·6면 UV·≤2,000tris는 제작 목표**다. 원화의 픽셀 표현을 실제 64px 텍스처/모델 실측으로 주장하지 않는다.
- 예상 tris: 상자240 / 케이크1,440 / 계란판960 / 와인560 / 생선+상자1,520. 치수와 앞면 배치는 `cargo-sheet.png`에 표기.
