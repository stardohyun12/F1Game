**3위 R1 면 방향 명암 — 효과 3.09**
- 해 방향 하나만 읽어 3단 계단 명암을 넣었다(SceneA3Look.shader frag 의 "R1" 블록).
  - 해 방향은 (−0.5, 0.75, 0.45)다. 카메라 B 의 왼쪽 뒤 위에서 비춘다.
  - 해와 면이 이루는 값이 0.6 을 넘으면 밝은 단 = 텍스처 그대로다. 0.2 를 넘으면 중간 단, 그 아래는 그늘 단이다.
  - 그늘 단 색 = 안개색 × 0.72.
  - 위를 보는 평지는 값이 0.75 라 밝은 단에 든다. 그래서 땅·길 색은 그대로이고, 기울어진 면과 옆면만 어두워진다.
- 그림자는 없다(그림자 켠 빛 0개, build 출력).
- 빼고 적용한 것: 나무·전깃줄·하늘·바다·마른 풀 띠. 판(카드)이라 법선이 의미가 없어서다.

**4위 M2 접지·경계 — 효과 1.42**

**5위 R2 텍셀 크기 통일 — 효과 1.40**
- 먼저 재질별 텍셀 밀도를 쟀다(`docs/qa/tmp/a3_probe.cs`, 텍셀/m = √(UV 면적 × 텍스처 픽셀 수 ÷ 월드 면적)).
  - 나무 46~67/m. 다만 A2f 에서 1/4 로 뭉갰으므로 실제 블록은 약 16/m 다.
  - 마른 풀 띠 10.5/m.
  - 길 25.5/m: 160 px 텍스처가 2의 거듭제곱으로 늘려져 128 이 돼 있었다.
  - 하늘은 구름 한 텍셀이 화면 약 9 px.
  - 나머지 근경(풀 31.5 · 담 32.1 · 드럼 32.5 · 카트 35.4 · 정비소 32.4)은 이미 약 32/m 였다.
- 고친 것(`docs/qa/tmp/a3_tex.py` → `F1/Assets/Art/SceneA3/Gen/`):
  - 나무: 원본 × 32/실측 크기로 다시 3단 칠. 01 491×3924 · 02 510×4077 · 03 611×4891 · 05 706×2825.
  - 마른 풀 띠: 3배 해상도.
  - 길: 사본 텍스처를 늘리지 않고 그대로 들여왔다(npot None).
  - 하늘: 4096×1024 = 구름 한 텍셀이 화면 약 1.1 px. 같은 구름 배치를 8배 해상도로 다시 그렸다.
- 일부러 안 맞춘 것: 원경 집·테라스·바다·원경 지붕. 100 m 밖에서 32/m 면 화면 1 px 에 텍셀 3개 이상이 들어가 반짝인다(가설).
- **판정에서는 오히려 손해였다.** 하늘이 "매끈한 벡터 구름"이 됐다.

**6위 R3 외곽선 — 효과 0.28**
- 셰이더 둘째 패스로 껍데기를 뒤집어 그린다(Cull Front).
  - 법선을 화면 공간으로 1 px 밀었다. 기준은 렌더 크기 1280×720 의 `_ScreenParams` 다.
  - 선 색은 물체 텍스처색 × 0.45, 채도 ×1.15. 검정은 쓰지 않았다.
- 적용 대상: 소품·건물·담·카트·둔덕·바위·덤불·울타리. 땅·길·나무는 뺐다.
- 효과가 작다. 4× 로 보면 드럼 가장자리에 1 px 선이 생기지만 군데군데 끊긴다(`docs/qa/tmp/a3_r3crop.png`, 왼쪽 끔 / 오른쪽 켬).
  - 원인 가설: 키트 메시는 면마다 법선이 갈라져 있다. 그래서 껍데기가 모서리에서 벌어지고, 1 px 선이 이어지지 않는다.
- 깊이·노멀 엣지 후처리는 안 했다. URP 렌더러 에셋에 렌더러 피처를 넣어야 하는데, 그러면 모든 씬에 걸린다. 그래서 정하지 않고 남겼다.

## 3. 검증 증거
측정 조건
- 320×180 bilinear 로 줄임, PIL.
- 밝기 = L 평균, 채도 = HSV S 평균, p10 = L 하위 10 %.
- **아래 빈 칸** = 화면 아래 절반을 16×16 칸으로 나눠, L 표준편차가 6 미만인 칸의 비율이다. 이 정의는 가설이다.
- 게임 컷은 Play 중 720 Nearest 로 캡처했다(캡처 로그 `(1280, 720)`).

밝기 / 채도 / p10 / 아래 빈 칸
- A2f B: 159 / 76 / 118 / 27 % → **A3 B: 154 / 85 / 99 / 18 %**
- A2f 소개: 162 / 84 / 113 / 28 % → **A3 소개: 157 / 97 / 89 / 9 %**
- A3 D: 145 / 81 / 92 / 27 %
- ①_1: 142 / 140 / 97 / 7 % · ①_2: 120 / 167 / 65 / 5 %
- ⑥_1: 118 / 28 / 54 / 31 % · ⑥_2: 127 / 6 / 82 / 48 %

해석
- 아래 빈 칸이 B 27 → 18 %, 소개 28 → 9 % 로 줄었다. 소개 컷은 ① 수준(5~7 %)에 가까워졌다.
- p10 이 118 → 99 로 내려가 ①_1 의 97 과 거의 같다. R1 그늘과 M2 데칼 덕이다.
- 채도는 76 → 85 로 올랐지만 ①(140~167)과는 아직 멀다.

판정(`judge_pair.py --refs16`, 원문은 `docs/qa/tmp/a3_judge_*.txt`)
- A3 vs A2f, 두 번 호출(각 호출이 내부에서 양순서를 돈다): 두 번 모두 "A2f 가 양 순서 모두 이김".
- R2 만 끈 판 vs A2f, 두 번 호출: 한 번은 "순서에 따라 갈림", 한 번은 A2f 승.
- 게이트(A3 B): X35 승 · X32 승 · X65 갈림 → "갈림 → 도현 30초 판정". 앞 판 A2f 는 X35 가 갈림이었으니 X35 가 한 단계 올랐다.
