## 분류·자료 계약

| 항목 | 적용한 기준 |
|---|---|
| 선택 범위 | 원본 1,383채에서 닫힘 점 제거 후 **꼭짓점 평균**의 `abs(x), abs(z) <= 390`인 1,149채; 면적 중심이 아니다. Unity float32 누적을 재현. 범위 밖 234채 제외 |
| 층수 | 빌더 그대로 `2 + ((osm_way * 2654435761 & 0x7fffffff) % 3)`; 2층 397·3층 373·4층 379. 부속채를 임의로 1층으로 바꾸지 않음 |
| ID·변 번호 | `id = piece_osm_way`; 원본 배열 위치 `source_index`, 원본 `osm_way`도 보존. `poly`는 닫힘 중복점 없는 반시계 배열. `front_edge`와 맞벽 `edge`는 **출력 poly의 0부터 시작하는 인덱스** |
| 면적·거리 | XZ 평면 m² / m. Y고도는 분류에만 이용. 3D 길이·길찾기 거리 아님 |
| 앞면 | `main`/`village` 차길 폭을 반영한 노면까지 가장 가까운 비공유 변. 거리 동률은 변 중점 거리→긴 변→인덱스 순. 모든 변에 일부 접촉이 있으면 가장 가까운 변을 고르고 `front_all_edges_shared=true` |
| 맞벽 | 서로 반대 방향인 반시계 변, 방향차 15° 이내, 간격 ≤0.3m, 끝을 늘리지 않은 평평한 buffer 안 양쪽 접촉 길이가 각각 >0.000001m. 모서리만 닿는 것은 제외. `neighbor_id`, `neighbor_edge`, 양쪽 접촉 길이, 해당 변의 접촉 비율, 간격을 대칭 기록 |
| 부분 맞벽 | 10m 벽의 2m만 닿아도 양쪽에 기록. **일부 접촉을 전체 벽에 창을 내지 말라는 뜻으로 쓰면 안 됨**. 후속 조립기에서 접촉 구간을 다시 구하고 비접촉 구간을 구분할 것 |
| 단순 사각 | 0.1m 단순화 후 볼록 4꼭짓점·각도 85~95°·최소 회전 사각형 대비 면적 ≥97%·경계 차이 ≤0.2m; **294채** |
| 지붕 | `roof.gable_possible` = 위 사각 판정에 따른 형상 후보. `recommended`는 terrace/apartment 또는 복잡한 터=flat, 단순 annex=shed, 단순 detached=hip, 그 외 단순 터=gable. 지붕 메시·처마 돌출은 제작하지 않아 검증하지 않음 |
| 경로 거리 | `dist_to_route` = 터에서 **저장된 배달 고리 또는 kind=main 길 중심선**까지의 최솟값. `dist_to_delivery_loop_m`, `dist_to_main_road_m`도 각각 보존 |
| 큰길·길가 가설 | 상점은 앞면 차길이 main 또는 폭 ≥6m이고 노면 이격 ≤6m. 광장 폴리곤이 없어 광장 접근은 판정하지 않음. 마을집의 길가는 이격 ≤12m |
| 성긴 배치 가설 | 맞벽 없음 + 터에서 25m 이내 다른 터 ≤2채 + 가장 가까운 터와 ≥8m. 선택 범위 안 이웃 기준 |

겹치는 유형 조건은 아래 순서로 처음 맞는 하나만 부여했다.

1. `<40m²` → annex.
2. `(y<4 및 ≥150m²) 또는 (tomo 및 ≥300m²)` → harbor_shed.
3. `y>40, 60~200m², 성긴 배치` → detached.
4. `tomo/camo, ≥150m², 4층` → apartment.
5. `tomo, 40~200m², 위 큰길 앞면 조건` → shop_house.
6. 나머지 posi → terrace_house.
7. `40≤면적<150, 2~3층, 길가` → town_house.
8. 나머지 ≥150m² → apartment 보완 분류 **50채**; 나머지 중간 크기 → town_house 보완 분류 **176채**.

보완 분류 226채는 `classification_fallback=true`와 `classification_rule`로 전부 검색 가능하다. 엄격한 1.3 조건만 맞춘 apartment는 19채, town_house는 90채다. 기존 층수와 초안 유형 조건을 동시에 강제하면 빠지는 건물이 있어 이 빈틈을 숨기지 않았다.
