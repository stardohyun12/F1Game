## 검증 증거·확인 방법

- [FBX 재읽기 검사](../../../art/_review/2026-11-02-packing-materials/evidence/fbx_readback.json): 12개 모델의 삼각형 수·외경·피벗·UV·법선·텍스처 경로. 화물 최대1984≤2000, 나머지 최대1280≤1500. 시트만 의도한 얇은 양면 재질용 열린 면이다.
- 상자마다 힌지4개가 각자의 날개를 움직이는지 지정 축/±112°의 0·25·50·75·100% 단계에서 공식 좌표와 대조. 날개 누락을 의도적으로 가정하면 검사 실패. 이것은 수학/메시 검증이며 게임 연속 애니메이션 검증은 아니다.
- 달걀30개·콜라이더 범위, 신문공 단위 구 내부와 구김 시작(.440,.0275,.440)/완료(.048³) 배율 검사. 달걀1개 누락은 실패.
- 어댑터5개는 월드 bounds뿐 아니라 **FBX 원시 정점의 Y-up 로컬 크기·중심**을 읽어 확인. 기존 루트 배율을 곱하면 현행 실크기. 실크기 FBX를 같은 루트에 다시 축소하면 틀리는 음성 대조도 포함.
- 테이프·라벨은 `TakeTool()`의 첫 Renderer 복제에 맞춰 단일 렌더 메시로 합쳤다. 실제 복제/들기 동작은 미실행.
- [납품 검사](../../../art/_review/2026-11-02-packing-materials/evidence/delivery_check.json): 파일 수·PNG 크기·해시·빈 렌더 여부·HTML 로컬 링크 검사. 독립 시각 검토 기록은 `evidence/independent_review.md`.

## 선행 사례·수정 이력

[FEFCO 원본 코드 북](https://www.fefco.org/download/file/fid/3064)과 [Macfarlane 제조사 가이드](https://www.macfarlanepackaging.com/wp-content/uploads/2023/03/Macfarlane-Packaging-Cardboard-Boxes-Guide-2023-Web-Ready.pdf)의 0201 중앙 맞댐 날개를 참고하여 직접 모델링했다. 게임의 정사각 내경·시각 벽 두께에 맞춘 후보이며 제조용 전개도·접착 구조의 원본 재현이나 규격 인증은 아니다.

기존 ambientCG CC0 골판지 사진을 인쇄 없는 부분만 잘라 종이 결로 재사용했고, [CC0 뽁뽁이 사진](https://www.rawpixel.com/image/6040280/photo-image-texture-public-domain-plastic) 1장을 추가 다운로드했다. 원본·라이선스 페이지·해시를 `reference/`와 `art/provenance.csv`에 기록했다. 사진 반사광을 albedo에 그대로 넣지 않고 관찰한 알갱이 윤곽을 높이/법선/알파로 직접 해석했다. 실제 기사·로고·주소를 쓰지 않고 흐린 막대열만 그렸다. **AI 생성 이미지·3D·소리 사용 없음.**

①의 1m 큐브 FBX 기준 왕복을 재사용했다. 상자 다층 계층은 변환 베이크 옵션에서 실제 축 오류를 발견하여 [Blender 공식 API](https://docs.blender.org/api/5.1/bpy.ops.export_scene.html)의 기본값인 False로 수정하고 왕복 검사했다. GPU 동시 렌더 시험의 메모리 오류는 직렬 처리로 해결하고 실패 이미지를 새 렌더로 덮어썼다.

독립 검토의 상자 승인 후보 판정과 함께 신문공 A의 규칙적 뾰족함·달걀의 각진 상부·옅은 시트 식별성을 지적받아 각각 형태/면 배분/투명도를 수정했다. 종이의 넓은 얼룩 인상은 사진 결을 작게 반복하고 ±3.5% 명암으로 낮춰 보완했다. 변경/실패 기록: `evidence/iteration_log.json`.

## 다음 단계·남은 이슈

2. **QA/프로그래밍 임포트 필요.** Unity 에디터·임포트·Play·포장 조작·동적 충돌·게임 카메라 전후·투명 정렬 검증은 **하지 않았다**. commit/push 하지 않았다.
3. 4날개는 현재 단일 `Shell/LidPivot` 동작과 자동 호환되지 않는다. 기존 충돌 뚜껑을 유지하고 시각 날개4개의 닫힘 순서/0.35초 동기화 필요. FBX 기본 자세는 닫힘, blend는 열림 전시.
4. `BubbleSheet`에 현재 UV가 없다. 기존 유연 메시/콜라이더를 유지하며 실제 길이 기준 `.024m` 반복 UV와 URP 투명·양면·normal 설정 추가 필요. `.fbx` 시트는 참고본이다. 겹친 롤은 다층 외피, 풀린 시트는 반투명 재질로 분리했다.
5. 실크기 FBX와 `adapters/`를 혼용하면 이중 스케일. 특히 신문공은 지름1 그대로 기존 동적 scale을 사용해야 한다. 자세한 연결법과 셰이더 한계는 [원본 README](../../../art/source/packing-materials/README.md).
