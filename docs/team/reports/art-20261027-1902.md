## 현재 씬과 연결할 때

- **나무의 실제 활성 입력은 soft 기본맵이 아닌 `_BaseMapR2`**: SA6d 나무01·02·03·05 재질에서 `_R2=1`, `_HasR2=1` 확인. 해당 R2 PNG를 기준으로 잎을 보존했다. 새 PNG를 BaseMap에만 넣으면 갈색 줄기가 보이지 않으므로 **활성 R2 슬롯도 교체 필요**.
- 나무04는 SceneA6d 재질 목록에 없지만 요청대로 제작. 기존 `SceneA2/Gen/autumn_tree_04_soft.png` 기준이며, 배치 시 사용하는 활성 슬롯에 연결한다.
- 전기함은 `_Sat=2.6`이어서 새 회청색도 과장될 수 있다. ART-RULES의 금속 규칙에 따라 **1.0 기준·최대1.2 검토 요청**. 셰이더의 기존 면 그늘·화이트밸런스도 결과에 영향을 준다. F1 재질/셰이더는 읽기만 했다.
- 자세한 슬롯·필터·알파 적용: `art/export/scene-a2-kit-po1/APPLY.md`, `material-audit.json`.

## 검증 증거·한계

- 카트 FBX 재임포트: **66 mesh / 1,980 tris**, v6d와 면 연결 동일, 정점·UV·행렬 최대 차 <1e−6. **1.80×1.28×0.82m**, k_tire/k_hub 8개 이름·피벗 유지.
- 나무 출력 해상도는 활성/기존 soft 사본을 따른다: 01 491×3924, 02 510×4077, 03 611×4891, 05 706×2825. 04 해상도 포함 정확한 값·소스 SHA256은 texture-validation.json. 원본의 정규화 UV는 동일하다.
- 카트 대비 수치는 sRGB 코드값 가중 명도(0.2126R+0.7152G+0.0722B), 셰이더 적용 후 게임 휘도가 아니다.
- 증거: `scene-a2-kit-po1/texture-validation.json`, `kart-v6e/geometry-validation.json`, `validation.json`; 재현 코드·로그 `art/source/po1/`.
- 생성형 이미지 없음. 기존 자료의 결·형태·UV 재사용, 코드로 색과 큰 디테일만 수정. 새로운 사진/외부 이미지 사용 없음.

- 독립 Blender 참고 검토: 전기 배전함, 기대어 놓은 타이어2개/쌓은 타이어3개, 단풍나무 줄기, 주황 고카트로 판독. 지적된 경고 표식 단절과 줄기 경계는 표식 잉크·UV 여백을 보완했다. 타이어 톱니/각진 고무 면, 각진 뿌리, 카트 범퍼/짐 비례는 기존 형상에서 오는 한계로 남겼다. 게임 합격 판정은 하지 않음.
- 타이어 현재 재질 `_Sat=1.3`도 확인. PNG는 무채색이지만 규칙 상한1.2 이하·기준1.0 적용 검토 요청.
