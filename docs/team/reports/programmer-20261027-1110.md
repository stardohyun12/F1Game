# 프로그래머 보고 — 과제 20261027-1110 (장면 A2f — A2d 기반, ① 질감 마무리)

**결론:** 판정은 **갈림**이다. 판정자가 두 가지 잣대 사이에서 흔들린다.
- **쌍대비교(A2f vs A2d, `--refs16`):** 순서에 따라 답이 갈렸다. 두 번 모두 오른쪽에 놓인 쪽이 이겼다.
  - A2f 가 이긴 순서의 이유: "① 처럼 큰 색 덩어리 나무·연두 풀, A2d 는 점무늬 노이즈".
  - A2f 가 진 순서의 이유: "길·풀이 질감 없는 깨끗한 단색, 장난감 같음".
- **게이트:** X35 갈림 · X32 승 · X65 승. 이 판정에서는 갈림 = 도현 판정이다.
- 바로 앞 판은 게이트에서 X35 에 졌다(돌려보냄). 드럼·풀을 고친 최종 판에서 X35 가 갈림으로 올라왔다.

## 1. 한 것

**새 씬** `F1/Assets/Scenes/Scene_A2f_Town.unity`
- A2d 를 복사했다. 배치·카메라·렌더링은 그대로다.
- 생성 스크립트: `docs/qa/tmp/scene_a2f_build.cs`. 다시 돌리면 A2d 에서 새로 복사한다.
- 재질은 `Assets/Art/SceneA2/MatsF/SA2f_*` 로 만들었다. 메시 사본도 같은 폴더에 있다.
- 텍스처는 `docs/qa/tmp/a2f_tex.py` 로 만들어 `F1/Assets/Art/SceneA2/GenF/` 에 넣었다.
- 모든 얼룩은 같은 방식으로 만든다: 저해상도 난수 장을 부드럽게 키운 뒤 3단으로 자른다. 그래서 1px 반점은 늘지 않는다.

**(1) 길** — 텍스처 `GenF/Gen/road_a2f.png`, 160×640, 폭 5 m × 길이 20 m
- 따뜻한 회색 3단 큰 얼룩. 모든 색이 R ≥ G ≥ B 라 청·보라 끼가 없다.
- 가장자리 흙먼지 3단. 경계는 얼룩으로 흔들어 곧은 줄을 피했다.
- 중앙에 바랜 크림 점선(2.5 m 칠 / 2.5 m 빈칸, 군데군데 벗겨짐).
- 길 메시 UV 를 다시 매겼다(`scene_a2f_build.cs` "(1) 길 UV"). 폭 방향 u 0..2.5 → 0..1, 길이 방향은 20 m 마다 반복.
- 길 재질은 채도 ×1, WB 흰색, 청록 들어올림 0 으로 바꿨다. A2d 의 청록 들어올림이 회색을 푸르게 끌던 것을 끈 것이다.

**(2) 풀** — 텍스처 `GenF/Gen/grass_tile_soft.png`
- 원본과 같은 크기·UV 에서 연두~황록 3단으로 칠했다: (118,150,58) / (146,176,70) / (176,198,92).
- 큰 얼룩 2겹에 중간 크기 장 1겹을 섞어 경계에 작은 섬이 생기게 했다.
- **마른 풀 띠:** 새 메시 `DryVerge`(`MatsF/f_dry_verge.asset`)를 길 양쪽 가장자리에서 바깥으로 1.8 m 깔았다.
  - 정점 488개 전부 땅 높이에 맞췄다(땅 +4 cm). 임시 MeshCollider 로 위에서 내려 쏘아 높이를 잡고, 저장 전에 콜라이더를 지웠다.
  - 텍스처 `dry_strip.png`: 마른 풀 3색. 바깥 가장자리는 들쭉날쭉하게 잘라냈다(컷아웃).

**(3) 나무·드럼·타이어**
- 나무 아틀라스는 빛이 구워져 있다. 그늘은 거의 검정이고 빛은 주황 반점이다.
  - 1/4 로 줄여 반점을 덩어리로 뭉갠 뒤 밝기로 3단을 나눴다(하위 45 % / 80 %).
  - 나무마다 단풍 3색을 입혔다: 01 주황, 02 노랑, 03 빨강, 05 주황노랑. 그늘도 검정이 아니라 붉은 갈색이다.
  - 면 안의 1px 구멍은 메웠다(알파 닫기).
- 드럼: 같은 방법으로 3단을 나눴다. 01 칙칙한 청록, 02 녹 주황, 03 크림 노랑.
  - 원본 라벨·테 무늬를 40 % 남겼다. 앞 판의 밝은 하늘색 드럼은 판정자가 "레고 블록"이라고 했다.
- 타이어: 원본 색 위에 밝기 3단을 입혔다. 채도는 ×1.3.
- 나무·드럼 재질은 채도 ×1, WB 흰색으로 바꿨다. 색이 텍스처에 이미 정해져 있어서 ×2.6 이면 형광이 된다.

**(4) 원경 지붕**
- 원경 집 18채에서 위를 보는 면을 둘째 서브메시로 떼어냈다. 기준은 법선 y > 0.35, 그리고 바닥에서 1.2 m 위다. 삼각형 1806개.
- 떼어낸 면에 주황 2단 지붕 재질 `SA2f_far_roof_farfog` 를 입혔다. 안개 최대치는 55 → 40 % 로 낮췄다.

**렌더링 (A2d 그대로)**
- 720 Nearest (캡처 로그 `RenderSize=(1280, 720)`, Point).
- 그림자 켠 빛 0 개 (build 출력).
- 주변광 = 안개색, 거리 안개, unlit 으로 빛은 텍스처에 구움.

## 3. 검증 증거

측정 조건: 320×180 bilinear 로 줄임, PIL. 밝기 = L 평균, 채도 = HSV S 평균, p10 = L 하위 10 %. 게임 컷은 Play 중 720 Nearest 로 캡처했다.

밝기 / 채도 / p10
- A2d B: 146 / 79 / 94 · 소개 155 / 96 / 108
- **A2f B: 159 / 76 / 118** · 소개 162 / 84 / 113 · D 150 / 76 / 98
- ①_1: 142 / 140 / 97 · ①_2: 120 / 167 / 65
- ⑥_1: 118 / 28 / 54 · ⑥_2: 127 / 6 / 82

해석
- A2f 는 A2d 보다 밝기 +13, p10 +24 다. 검게 죽던 그늘이 없어진 결과다.
- 채도는 거의 같다(79 → 76). 길이 무채색 회색이라 화면 아래쪽이 평균을 누른다.
- 밝기 159 는 ①_1 의 142 보다 높다. 판정자가 "하늘 쨍, 깨끗"이라고 한 것과 같은 방향이다.

반복 기록 (B 컷)
- 1차: 160 / 78 / 118. 나무가 밝은 단 하나로 납작했고, 드럼은 형광 얼룩이었다.
- 2차: 160 / 78 / 118. 나무 3단 범위를 넓혔고, 드럼은 단색 3단으로 칠했다.
  - 판정: 쌍대비교 갈림, 게이트 X35 **패** → 돌려보냄.
  - 판정자: "빈 단색 면, 하늘색 상자가 레고 블록".
- 3차(최종): 159 / 76 / 118. 드럼을 칙칙하게 바꾸고 원본 무늬를 40 % 남겼다. 풀 경계에 중간 크기 섬을 넣었다.
  - 판정: 쌍대비교 갈림, 게이트 X35 **갈림** · X32 승 · X65 승.

판정 원문
- 2차: `docs/qa/tmp/a2f_judge_pair.txt`, `a2f_judge_gate.txt`
- 최종: `docs/qa/tmp/a2f_judge_pair2.txt`, `a2f_judge_gate2.txt`
- 최종 판 쌍대비교는 두 번 모두 오른쪽 자리가 이겼다. 자리 쏠림일 수 있다(가설).
