## 3. 검증 증거

  - 전체 화면: 20 / 21 / 21 / 21 / 20%

- 2차 지형 + drop 1.9: 같은 방법으로 18%(z 159). 이 측정은 마을 집이 콜라이더가 없어서 집 뒤 땅 높이로 판정한다. ±2%p 쯤 흔들리는 근사로 봐야 한다.

## 4. 남은 이슈 / QA 체크리스트
- [ ] **① 25% 미달(20~21%)**. 내 가설로는 남은 수단이 둘이다.
  - 꼭대기 구역에서만 카메라를 1~2m 올리기. 내 계산으로 앞 모서리가 시선 밑으로 더 숨어서 +5%p 안팎이 기대된다. 조작은 안 뺏지만 PD 가 정한 「피치만」 범위를 벗어난다.
  - 꼭대기에서 길이 바다 쪽을 정면으로 보게 바꾸기. 지금은 우회전이라 오른쪽 절반이 평지다. 길을 크게 바꾸는 일이다.
  - 둘 다 PD/도현 판단이 필요하다.
- [ ] 흰 난간(높이 0.9m)이 꼭대기에서 눈높이 선을 가로질러 열림을 자른다. 난간을 더 낮추거나 기둥만 남기는 게 다음 후보다.
- [ ] 꼭대기에서 사람 실루엣이 안 보인다. 문 윗부분만 보인다.
- [ ] 깎은 면 시작 쐐기가 2-uphill 에서 튄다 → 끝단을 지형 속으로 묻어야 한다.
- [ ] 벼랑 바위 덧칠이 넓은 회색 판으로 보인다(7-stairs, 1-terrain).
- [ ] 차로 계단 입구를 들이받아 끼는지는 **안 해 봤다** → QA 가 직접 운전해서 확인할 것.
- [ ] DeliveryHUD 화살표가 5m 위로 뜨는 것이 ComplexTrack 에서도 괜찮은지 → QA 눈 확인 필요. 회귀 항목에는 없다.
