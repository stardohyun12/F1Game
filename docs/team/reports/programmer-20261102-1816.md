## 4. 남은 이슈 / QA 체크리스트
### 남은 이슈
1. **엔진 소리 없음** — Map_TownV6 의 EngineAudio 클립이 비어 있다(Race.prefab 엔 guid 07fc7d2a… 있음). 엔진 부하 코드는 들어갔지만 못 들음. 씬에 클립을 넣을지는 PD/도현 결정(소리 취향) — 안 넣었다.
2. **C 의 45kg 상자는 7초 안에 40km/h 를 못 낸다** — "무게감"이 과할 수 있음. `DriveFeel.C.weightInfluence 0.8 → 0.5` 로 줄이면 B 수준.
3. **Wheels 서스펜션은 안 씀** — 1차 실측 급정거·비탈 실패. 다시 보려면 Wheels 쪽 마찰·제동부터 손봐야 함(이번 범위 밖).
4. **반 페달로 살살 가면 B·C 는 오르막에서 설 수 있다**(봇 반 페달 29~33곳). 사람은 보통 끝까지 밟지만 도현이 타 볼 때 오르막 출발을 꼭 봐야 함. 약하면 B accelTime 2.9 → 2.5.
5. CartBodyMotion 기울기 방향(코너 바깥으로 기우는지)은 숫자만 봤다 — 화면에서 눈으로 확인 필요. 프레임이 작아 내가 판단 못 함.
6. CarVisualLean(예전 기울기)은 TownV6 에서 꺼진 그대로 둠 — 둘이 겹치지 않게.
7. 디버그 창 "주행감" 버튼 줄은 손으로 눌러 보지 않았다(코드 경로 `SetFeel` 은 프로브·봇에서 씀).
8. 씬 값은 안 바꿔서 씬 저장할 게 없었다. ComplexTrack 씬 오버라이드는 A 값 그대로 — B 로 덮이는 건 런타임(`feelPreset` 기본 B).
9. 봇에 `FullThrottleWhenSlow` 정적 플래그를 새로 넣었다(기본 꺼짐, 다른 검사 결과 안 바뀜).
10. 임시 파일: `docs/qa/tmp/df_*.cs`(측정 실행용). `scripts/df_probe_wait.sh` 는 만들었다가 지움.
