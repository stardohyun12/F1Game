## 추천 (가설 — 결정은 도현)
- **섞어서 고르기를 추천.** 주행 = **A + B 의 "방향 점" 하나**. 걷기 = **A**(키 칩을 물건 곁에). 대화 = **A**(말풍선). 포장 = **A**(단계 글자 없이).
- 이유 1. D-238 "조금은 보여줘야" 에서 제일 아쉬운 건 방향이다. A 는 화살표 하나라 덜 보이고, B 의 방향 점은 0.1% 남짓이라 거의 공짜다. B 의 왼쪽 위 목적지 칸은 전표를 꺼내 보는 키와 겹치니 뺄 수 있다.
- 이유 2. 대화 B(하단 종이 상자)는 화면 10% 를 가리고 말하는 사람과 떨어져 있다(리서치 §4 의 19% 계열). A 말풍선은 1.65% 이고 머리에 붙는다. 다만 사장이 화면 밖이면 A 는 깨진다 → 화면 밖일 때만 B 로 대체하는 규칙이 필요(아래 이슈 2).

## 4. 남은 이슈 / QA 체크리스트
1. **주행 A 의 전표·계기는 2D 덧칠이다(3D 모델 아님).** 그리고 추격 카메라에선 핸들이 짐 상자 뒤에 가려 안 보인다 → 전표를 상자 뒷면으로, 계기를 엔진 위로 옮겨 그렸다. 9×8px 는 "종이가 있다" 정도라 읽을 수는 없다. 그래서 A 를 고르면 "전표 들어 보기 키"(꺼내면 화면 크게)가 같이 필요하다 — 이번 목업엔 없다.
2. 대화 A 는 말하는 사람이 화면 안일 때만 된다. 화면 밖일 때를 어떻게 할지(가장자리 고정 / B 로 대체)는 다음 판.
3. 바탕은 낮 장면이다. 노을 9판 장면 위에서 보면 크림 종이가 더 튈 수 있다 — 고른 안을 낚시 자리 컷으로 한 번 더 찍어 보면 좋다.
4. 포장 작업대는 회색 대역이다. 상자 앞 날개가 앞벽과 겹쳐 구김 몇 개가 비친다(대역 결함, UI 판정과 무관).
5. 3배 컷 판정 순서: 1× → 흑실루엣 → 3×. 흑실루엣은 만들지 않았다(UI 목업이라 생략).
6. 이름: "사장" 은 직함, "언덕 위 찻집" 은 튜토리얼 설계·코드에 있던 이름. 인물 이름(줄리아 등)은 넣지 않았다. 대사 내용은 `OnFootDirector.cs:58-60` 그대로이고, 3줄째는 코드 주석상 "도현 확인 필요" 상태다(이번 컷에선 2줄째만 사용).
