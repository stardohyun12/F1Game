## 3. 검증 증거
- 영상: ffprobe 로 450프레임·30fps·1080×1350/1080×1080 확인(`_scripts/probe.py`), 프레임 1/7/14초 추출해 변화 확인.
- **3×3 블록 균일 검사**(정수 확대 증거): overlay 없이 찍은 장면은 162000블록 중 비균일 **0.0%**(max diff 0) → 렌더 자체는 360 격자의 정확한 3배. overlay(게임의 DuskRim) 를 켠 최종 스틸은 7.6~18.1% 블록이 비균일 — 원인이 overlay 임을 위 대조로 확인(게임이 쓰는 역광 테가 1080 해상도로 윤곽선을 덧그림). 즉 "정확히 3배 픽셀 격자 + 게임과 같은 테 효과".
- **이 변경 전용 검사**: ① overlay 유무 비교(위) ② 영상 t=1/t=14 프레임 비교(움직임 실재) ③ 점프 후 플레이어 y: 18.15→18.56, 카메라 19.7→20.2(발이 떴음을 수치로) ④ 전표 SimSlip: pickedJob 없으면 안 뜸(첫 시도 실패) → 리플렉션으로 설정해 뜸.
- **처음 보는 자리**: 항구(6), 언덕 꺼짐(7), 정비소 안(9), 찻집 앞(4) 새로 찍음. 언덕 꺼짐(7)은 회색 상자 건물뿐이라 탈락(체크 8).
- 콘솔: error 는 없고 warning 20건 전부 `Releasing render texture that is set to be RenderTexture.active!` — 내 캡처 헬퍼(RT 해제 순서)가 낸 것, 게임 코드와 무관. 마지막 20줄만 봄.
- **안 돌린 것**: 게임 Present 와 내 촬영 경로의 16:9 픽셀 단위 비교는 안 했다(overlay·Point 확대·같은 RT 설정이라 같은 경로라고 판단했으나 실측 아님). Game 뷰 직접 캡처 대조도 안 함. 소리 녹음 안 함. 영상 전체를 사람이 보진 않았다(프레임 3장 샘플만).
- 마감 상태: Play 꺼짐(`isPlaying=False`), `captureFramerate=0`, 씬 저장 안 함(`isDirty=False`), 폰트 SDF `git checkout --` 완료, 공유 .mat·ProjectSettings 변경 없음(`git status` 의 ProjectSettings.asset·LofiSurface.shader 변경은 세션 시작 전부터 dirty 였음).
