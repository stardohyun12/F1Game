# programmer 1943 — D-146 그림체 전환 1차 + 도현 스샷 버그

## 1. 한 것

### A. 버그
- **A1 풀·흙 점무늬 (1.png)**
  - 원인: 지형 아틀라스(사진)의 고주파 점무늬.
  - 해결: Look 4 에서는 지형 머티리얼이 `BL_TerrainAtlas_32ppm_retro.png` 를 쓴다. 칸마다 평균색 큰 면 하나에, 풀 가닥 5개(2~3텍셀)와 흙 점 몇 개만 남겼다. 위치: `tools/asset-gen/retro_clean.py:95-125`.
- **A2 포장 계단 조각 (2·3.png)**
  - 원인: 2m 지형 칸마다 Lot 머티리얼 4종을 서브메시로 골라 붙였다(GroundKind). 그래서 칸 모양 그대로 땅 위에 계단처럼 깔렸다.
  - 해결: 지형 메시를 서브메시 하나로 합쳤다(`BuildBayLoop.cs` TerrainMesh). 포장 여부는 이제 **부호 거리**로 정한다. 필지 사각형, 차길 사이 섬, 길가 기준으로 거리를 재는 `PaveDist`(`BuildBayLoop.Lived.cs`)를 만들었다.
  - 이 거리를 경사 텍스처의 G 채널에 굽는다(BakeSlope, RGBAHalf).
  - 셰이더(`TerrainSlope.shader` pave 분기)는 거리 < 0 인 곳만 `_PaveColor` + 1.5m 판석 줄눈으로 칠한다. 결과: 가장자리가 텍셀 단위의 매끈한 곡선이 되고, 땅과 같은 면이라 겹침이 없다.
  - 언덕 풀잎 배치도 같은 거리 함수를 쓴다(`BuildBayLoop.Hilltop.cs:57`).
- **A3 층무늬판·검은 덩어리·찢어진 삼각형 (4·5.png)**
  - 층무늬판 블록과 낙석망 띠를 뺐다(`BuildBayLoop.Coast.cs` 230-246, 주석으로 남김). 빌드 로그: `층무늬판 0, 낙석망 0m·기둥 0`.
  - 검은 덩어리 = 낙석망 띠(지형 +0.35m)였다.
  - 찢어진 초록·노랑 삼각형 = 밭 메시 FieldA(라임)·FieldB(노랑)였다. 밭 정점이 지형 2m 격자와 어긋나 있어서, 굽은 언덕에서 지형이 밭을 뚫고 올라왔다. z-fighting 이나 노멀 반전은 아니다.
    - 해결: 밭 정점을 지형 격자선과 사각형 끝에 맞추고 +0.08m 올렸다(`BuildBayLoop.cs` Fields() 의 `Lines`).
  - **깎은 면은 지형 자체를 바위로 칠한다.**
    - BakeSlope 가 B 채널에 "차길 바깥선 9m 안 + 28° 넘는 비탈"을 굽는다.
    - 셰이더는 그곳을 26° 부터 바위 타일로 칠한다(`TerrainSlope.shader` `sg.b>.5&&d>=26`).
    - 레트로 바위 칸은 사진 평균(77,72,63)이 그늘에서 검정으로 보였다. 그래서 1.9배 밝혀 회갈 석회암으로 만들었다(`retro_clean.py` rock).
