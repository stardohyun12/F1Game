## 4. 남은 이슈 / QA 체크리스트
- [도현 판정] 화살표 15px·"!" 11×14·칩·말풍선 크기가 1080 화면(도트 3배)에서 읽히는가. 크기는 전부 가설이다(Galmuri11 12px / Galmuri9 10px).
- [가설] 화물 "!" 기준 0.7(경고)·1.0(깜빡) — 깨짐 판정 기준치에 대한 비율이다. 실제 주행에서 너무 자주 켜지는지 QA 가 봐 줘야 한다.
- [가설] 전표 키 = Tab(누르는 동안만). 탑승 직후 6초 힌트.
- 운전 중에도 "E 내리기" 칩이 차 위에 뜬다(정지 상태 프롬프트). 운전 UI 를 더 줄이려면 끈다 — 취향 문제.
- 노을일 때 SunsetLook 역광 테 머티리얼이 UI 에도 먹는다. UI 가 같은 RT 안에 있으니 의도대로이기도 하다. 노을 캡처는 안 했다.
- 자연 흐름에서는 E 를 누르려면 사장을 봐야 해서, 시선 이동이 위아래 몇 도뿐이다. 화면 밖 화자 경우는 `ForceTalk()` 로만 검증했다. 다른 NPC 대화가 생기면 그때 자연 흐름으로 다시 확인한다.
- 말풍선 꼬리·상자·키캡은 코드 임시 모양이다. 아트 슬롯 5개에 스프라이트만 꽂으면 바뀐다(Codex 아트는 도현 통과 뒤).
- Galmuri 임포트 모드가 Smooth 다. fontSize 를 12/10 이외로 바꾸면 회색 테가 생긴다. 크기를 바꿀 때는 em 정수(G11=12의 배수, G9=10의 배수)를 지킨다.
