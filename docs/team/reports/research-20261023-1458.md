# 리서치 보고 — AI 에셋·사진 텍스처 거부감 (PD 20261023-1458)

근거 원문: `docs/research/2026-10-23-ai-asset-aversion.md` (모든 링크·[확인]/[2차]/[미확인] 표시는 거기)

## 결론 3줄
1. 반감은 "AI 를 썼다"보다 **"숨겼고 들켰다"** 에서 크게 터졌다. 찾은 논란 4건(The Alters·Clair Obscur·Crimson Desert·1666 Amsterdam)은 전부 **임시 자리표시용 AI 가 출시본에 남은 사고**다. 규칙 7개는 픽셀 규격만 검사하고 **출처 검사가 없다.**
2. 사진 텍스처로 칭찬받은 사례 중 확인되는 건 Easy Delivery Co 하나 — **환경만 사진 포토배시, 상자·트럭·캐릭터는 손 픽셀아트**, 전체를 456×256 가상 화면에 맞춤. Puppet Combo·Dusk·Signalis 는 제작 방식 자료를 못 찾았다.
3. 질감 원천 추천 = **CC0 사진(ambientCG/Poly Haven) → 64px → 공용 팔레트 양자화**. 단 **출처 장부**를 규칙에 추가한다.

## 프로젝트 규칙 제안 (브리프 7개 검토)
| 규칙 | 판정 | 조치 |
|---|---|---|
| 1 AI 는 원화까지만 | 고침 | "빌드에 AI 파생 파일 0" 추가. 원화가 스토어·트레일러·SNS 에 나가면 공개 |
| 2 질감=사진 | 고침 | "EDC 가 쓰는 방식" 문구 정정 — EDC 는 *환경만* 사진, 소품은 손 픽셀. 32색 양자화는 우리 선택(EDC 근거 없음) |
| 3 픽셀 격자 하나 | 유지 | 32px/m 는 "우리 기준"으로 표기 |
| 4 모양 실측 | 유지 | — |
| 5 진짜 폰트 | 유지+ | 텍스처 PNG 안에 글자가 굽혀 들어갔는지 검사 |
| 6 마모는 이유 있게 | 유지+ | 마모 위치를 에셋 메타에 기록 |
| 7 검사 스크립트 | 더함 | 아래 8~11 |

**더할 규칙**
- **8. 출처 장부** `art/provenance.csv`: 에셋 ID·질감 원천(CC0 URL+날짜 / 직접 촬영 / 스크립트)·도구·AI 여부. 장부에 없는 텍스처가 있으면 빌드 실패.
- **9. 출시 전 전수 감사**: 출시 빌드 텍스처 전부가 장부에 있고 AI 칸이 "아니오".
- **10. 공개 문구는 미리 도현이 정한다** (Steam 콘텐츠 설문). 숨기는 쪽이 더 비쌌다.
- **11. 조명·안개 한 규칙**으로 통일 (EDC 방식) → 에셋별 조명 차이 제거.

**질감 원천 추천 1개: CC0 사진 → 64px 축소 → 공용 팔레트 양자화.**
이유: 손으로 칠할 사람이 없고(도현 1명), 절차적 생성은 균일 노이즈가 되기 쉬워 브리프가 피하려는 단서를 만들며, CC0 사진은 출처가 깨끗하고 EDC 환경 방식과 같은 계열. 위험(스타일 충돌)은 양자화·Point 로 줄이되 **도현이 기준 원화 옆에서 1× → 흑실루엣 → 4× 로 판정하기 전엔 확정 아님.**

## 모르는 것
- 게이머가 AI 를 알아보는 **시각 단서**의 정량 연구와 **사진 텍스처 단독** 거부감 데이터 — 찾지 못함. 시각 원인 표는 개발자 글 경험칙 + 사례 기반이다.
- Puppet Combo·Dusk·Signalis·Mouthwashing 의 텍스처 제작 방식 — 자료 없음.
- **"AI 를 쓰고도 반감을 피한" 사례 — 이번엔 못 찾았다.** 찾은 건 전부 반감이 나서 되돌린 경우뿐.
- Valve 원문에서 **내부 콘셉트 아트가 공개 대상인지**(규칙 1 이 걸린 곳) — PD 가 Steamworks 문서로 확인 필요.
- CC0 사이트에 AI 생성물이 섞여 있는지, ambientCG 공식 라이선스 페이지.
