**1. 화물 깎는 도구** — 네 클릭 기다리는 중

**2. 한 판이 너무 짧음** (데모의 가장 큰 갭)

- 해결책 — 맵을 넓히거나, 갈수록 어려워지게
- 상태 — 아직 손 안 댐

**3. 정해야 할 작은 것들**
- 맵 넓히기 vs 난이도 단계 — 뭐 먼저?
- 포장대에 받침 깔기
- 타이어 종류 3개 vs 4개

## 🧭 일하는 순서 (이게 우리 "체계")

```
아이디어 → 기획 → 계획 → 만들기 → 점검 → 다듬기 → 완료
                                  └ 점검 = 컴파일 OK · 실제로 돌려보기 · 눈으로 확인
```
새 작업은 즉흥으로 시작하지 않고 이 순서로 들어와. 지금 하는 일이 이 중 어디인지 항상 "지금 하는 일"에 보이게.
