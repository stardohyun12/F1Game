## 🏢 에이전트 스튜디오 팀 (지금 하는 일)

진짜 게임회사처럼 역할 분리 + 게이트. **상시 켜진 건 2개**(나=구현허브, PM=별도터미널), 나머지는 일회용.

| 직원 | 역할 | 상태 |
|---|---|---|
| 나(메인) | 구현·Play·디스패치 | ✅ 가동 |
| PM | 백로그·우선순위·브리프(전문가 프로듀서) | ✅ 만듦, 실가동 대기 |
| 게임 디자이너 | 능동 기획 제안 | 🚧 데모 1회 (Phase2 정식) |
| 아트 디렉터 | 룩·톤 제안 | ⬜ Phase2 |
| 기획/그래픽 게이트 | 백지 판정 (편견0) | ✅ 기존 |
| QA·하네스 | 검증·운영체계 발전 | ⬜ Phase3 |

- ✅ 소통 규약·전문가 기준·PM 페르소나/메모리/런처(`.\pm.ps1`)
- ✅ 메인↔PM **양방향 대화 버스**(`bus.md`) + 라이브 대시보드(🎭 스튜디오 라이브)
- ✅ PM 검증: 맥락0 에이전트가 페르소나만 읽고 전문가처럼 행동(임계경로 재정렬·거짓 통과 적발)
- ⬜ **다음**: `.\pm.ps1`로 PM 실가동 → 작업 몇 개 돌려 효과 채점(통과면 Phase2)

> 한 판 짧음(8~12초) 등 **게임 자체 숙제는 PM이 백로그 1순위로 관리** — `backlog.md` / 🔧 파이프라인 탭.

## 🧭 일하는 순서 (이게 우리 "체계")

```
아이디어 → 기획 → 계획 → 만들기 → 점검 → 다듬기 → 완료
                                  └ 점검 = 컴파일 OK · 실제로 돌려보기 · 눈으로 확인
```
새 작업은 즉흥으로 시작하지 않고 이 순서로 들어와. 지금 하는 일이 이 중 어디인지 항상 "지금 하는 일"에 보이게.
