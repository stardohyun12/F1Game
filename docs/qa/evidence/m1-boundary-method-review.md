## 원인과 변경
기존 `qi%8<4`는 어깨 한쪽4분할 및 저장 순서에 묶였다. 분할8로 바꾸면 안쪽 경계가 바깥으로 분류됐다(프로그래밍팀 보고). 기존 중심선 최근접 방식도 교차점/평행도로에서 다른 길을 택할 수 있어 재사용하지 않았다.

삼각형의 좌표 기반 접합·경계 추출을 사용한다. 내부 공유변과 중복 뒷면을 제거하고 실제 보도/골목 메시 변에 붙은 경계를 안쪽으로 분류한다. 두 끝이 안쪽과 바깥에 각각 있는 변은 끝막음이다. 애매한 경계는 명시적으로 남긴다. 알고리즘은 Python 표준 라이브러리로 구현했고 새 패키지를 설치하지 않았다.
