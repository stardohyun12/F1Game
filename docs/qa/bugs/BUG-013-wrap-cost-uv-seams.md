# BUG-013 — 케이크 윗면 포장비 폭증 (UV 이음새)

- 보고: 도현 2026-10-22 "케이크 위쪽 매쉬가 빽빽해서 포장지를 잠깐 문질러도 엄청 돈이 듦"
- 원인: 포장비 = 프레임마다 **UV 이동 거리** × 띠 폭. AI 메시(cake_01, 54k tris)는 UV 섬이 잘게 쪼개져 있어(UV 정점 78k > 삼각형 54k)
  표면에서 조금만 움직여도 다른 UV 섬으로 넘어가며 UV 거리가 크게 뛴다. 같은 이유로 섬 사이를 직선으로 칠해 텍스처 엉뚱한 곳도 칠해졌다.
- 수정(`WrapPainter.cs`): 비용 = 화면 드래그 거리를 물건 깊이 평면으로 옮긴 길이(리본 월드 폭이 일정 → 끈 길이 = 쓴 포장지).
  UV 이동이 표면 이동으로 예상한 값(메시 평균 worldPerUV)의 3배를 넘으면 이음새로 보고 선을 잇지 않는다.
- 검증(Play, 같은 화면 0.6m 가로 스트로크, Bubble): 케이크 1407 → **54**, 박스 59 → 59(변화 없음), 계란 37 → 65, 생선(0.2m) 21.
