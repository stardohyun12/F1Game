## 1. 게임별 관찰 — 각 4줄

면적은 **선정한 한 장면**에서 960×540 좌표로 수동 그린 묶음 영역의 합집합 / 518,400이다. 글자 사이 여백·패널 바탕을 포함하므로 알파 불투명 픽셀 비율이 아니다. 소수점은 계산 출력이며 경계 판정의 정확도를 보증하지 않는다. **O**=겹친 HUD/메뉴, **D**=시계·종이·계기 같은 읽을 면. D의 조작 면적과 O의 풍경 가림을 서로 순위 비교하지 않는다. Papers, Please만 검은 바깥 여백을 빼고 계산했다. 보드의 ‘영역 표시’와 [좌표 장부](../../art/_review/2026-10-23-ui-refboard/measurements.json)로 재확인 가능하다.

스크린샷은 개발사/배급사가 Steam에 등록한 **공식 게시 이미지**다. 직접 플레이 캡처가 아니며 PC 스토어 게시 컷이지 버전 전체를 대표하지 않는다. [출처·원본 URL·해시 장부](../../art/_review/2026-10-23-ui-refboard/sources.json)에 등록자·조회일·해상도를 남겼다. 권리는 각 권리자에게 있고 조사 비교용이며, 게임 출시 자산으로 쓰지 않는다. 애니메이션·소리는 정지 화면에서 추측하지 않았다.

## 2. 물건이 UI일 때: 성공과 실패

여기서 O는 화면 위에 겹친 안내, D는 세계 속 물건 중 읽고 조작하는 면이다. 종이 무늬를 입힌 화면 패널은 **종이 모티프 UI**이며, 그것만으로 디제틱 UI가 되지는 않는다. 아래의 성공은 우리 목적에 유용한 관찰·설계 원리라는 뜻이고, 사용자 실험으로 입증한 순위는 아니다.

| 사례 / 근거 | 확인한 내용 | 우리 상황에 적용할 원리 |
|---|---|---|
| Papers, Please — [개발자 제작 기록](https://dukope.com/devlogs/papers-please/mobile/) | [제작자 설명] 책상에서 여권 위치를 맞추고 **누를 때** 도장을 찍는다. 모바일도 이 손맛을 보존하려고 별도 도장 책상을 도입했다. | 주문 수락·포장 완료의 도장은 결과가 확정되는 순간 1회. 도장 장식이 글자를 가리지 않게 할 것. |

## 3. 시간 압박을 주되 풍경은 남기는 방법

[SEGA 원 설명서 3~4쪽](https://store.steampowered.com/manual/71230)은 Crazy Taxi의 탑승 → 위 방향표·승객 시간 → 목적지 정차 → 잔여 시간 보너스를 설명한다. 스크린샷의 큰 숫자·방향표는 빠르게 찾기 쉽다는 **설계 가설**은 만들 수 있지만, 우리 게임의 긴장도를 검증해 주지는 않는다.

| 비교 | 그대로 쓸 원리 | 바꿀 부분 |
|---|---|---|
| Crazy Taxi / 택시 | 시간·목적지·보상을 구분 | 큰 중앙 화살표, 이중 큰 시계, 수입판 상시 노출은 제외 |
| Easy Delivery Co. / 배달 | 길·안개·먼 실루엣을 읽을 여백 | 원작의 주행 HUD와 시간 규칙은 이번 조사에서 직접 재현하지 않았다. 우리 출발 구간의 시간 압박은 D-125를 따른다. |
| DREDGE / 운송·항해 대조 | 항해와 재고·정산의 정보 밀도 분리 | 위 중앙 시계를 구석으로 옮기는 것은 **우리 변경안** |
| Mini Motorways / 압박 대조 | 긴장을 모두 경고음으로 번역하지 않기 | 음향 제작자는 초반 엔진 드론이 불협화음·과부하였다고 기록. 자동차마다 소리를 더하는 방식을 우리 경고 설계에 복제하지 않음. [원문](https://disasterpeace.com/blog/mini-motorways.postmortem.html) |

**우리 제안, 아직 승인·Play 검증 전:**

- 갈 때: 타이머 1개 + 남은 거리 + 배달 진행 + 화물 상태 + 속도. 시간/거리 같은 구석에 묶고, 단위와 숫자를 고정 자릿수 영역에 놓는다. 거리 값은 **기존 내비의 경로상 남은 거리**를 우선하며 직선거리로 슬쩍 대체하지 않는다. 경로값 공급 여부 [미확인].
- 960×540 논리 화면에서 UI 묶음의 합집합 목표 **8% 이하**(41,472px²), 돌아올 때 **3% 이하**(15,552px²). 이는 레퍼런스 평균이나 사용자 가독성 기준이 아닌 **첫 시안의 면적 예산**이다. 중앙 가로 60%×세로 60%에는 상시 판을 두지 않는다. 앞 코너·하늘의 시선 경로는 별도 검수한다.
- 타이머는 기본 24px, 긴급 숫자는 36px 후보. 남은 시간 20%/10%에서 색+짧은 라벨+단발 알림을 조합하는 안을 비교한다. 임계값은 **가설**, 화면 전체 점멸·글자 크기 반복 펄스는 쓰지 않는다. 소리를 꺼도 긴급 상태가 읽혀야 한다.
- 돌아올 때: 시간 제한 종료와 함께 타이머·거리·완료한 목표를 접는다. 남길 것은 속도/필요한 상태만. 복귀 길 안내가 꼭 필요한지는 기획·플레이 관찰로 결정한다. 음악·바다의 가청 여백을 남긴다.
- 정산 금액·전화 전문·포장 설명은 정차 화면. 긴급 전화는 주행 중 최소 알림만 남기는 안을 비교하되, 기존 D-120 시간 규칙·전화 흐름을 이번 조사에서 변경하지 않는다.
- 후속 검증: 같은 코스·같은 제한시간에 HUD A/B를 사용해 **시간/거리를 읽는 데 걸린 시간, 잘못 읽은 횟수, 코너 충돌, 풍경 회상**을 관찰한다. 밝은 바다·짙은 그늘, 음소거, 귀환을 포함한다. 이번에는 하지 않았다.

D-126의 속도감은 차 주변 카메라·근접 물체·엔진/바람 소리가 담당한다. UI를 더 크고 요란하게 만드는 근거로 쓰지 않는다. 새 카메라·라디오 시스템 구현은 이번 범위 밖이다.

**가독성 판단은 제안:** 24px/36px는 제작자 보증 최소 크기가 아니다. 받침이 복잡한 “볶음·값·흙”, 숫자 “0/O·1/I·8/B”, 단위 “m·km/h·초·원”을 동일 배경에서 비교하고 실제 주행으로 결정한다. 타이머 숫자 폭·문장 줄바꿈도 함께 확인한다.

**라이선스 확인:** [Galmuri OFL 원문](https://github.com/quiple/galmuri/blob/main/ofl.md)에 따라 폰트 파일을 게임과 함께 배포할 수 있으며 저작권·라이선스 고지를 동봉한다. 폰트 단독 판매는 금지되고 수정본의 Reserved Font Name 조건은 해당 고지에 따라 확인한다. 출력 PNG 자체에 OFL을 붙일 의무가 있다는 뜻은 아니다. 원래 둥근모꼴, 둥근모꼴+Fixedsys, Neo둥근모는 동일 배포물이 아니므로 라이선스를 섞지 않는다. 이번에는 저장소에 이미 있던 Galmuri11 v2.40.4 TTF와 LICENSE를 조사 폴더에 복사했다.

### 정수배를 두 단계로 구분

1. **글리프 격자 → UI 논리 픽셀:** Galmuri11 12px 원형을 2×/3×로 확대하면 24/36px. 폰트·9-slice 경계·좌표·이동량을 논리 정수에 맞춘다. 18px=1.5×는 원형 픽셀이 고르게 반복되지 않는다. 임의 회전·비정수 Tween·Auto Size도 같은 문제를 낸다.
2. **960×540 논리 화면 → 실제 출력:** 1920×1080은 2×, 2880×1620은 3×, 3840×2160은 4×. 2560×1440의 꽉 채우기 2.666…×나 1280×720의 1.333…×는 균일한 정수배가 아니다. Point만 켠다고 이 비율이 정수가 되지는 않는다.
3. 엄격한 픽셀 격자 모드는 `k=floor(min(출력폭/960, 출력높이/540))`로 잡고 남는 곳은 여백으로 둔다(원본보다 작은 화면은 별도 정책 필요). 예: 2560×1440 → 1920×1080 콘텐츠+좌우320/상하180; 1280×720 → 960×540+좌우160/상하90. **이 레터박스 정책은 제안이며 D-124가 이미 승인한 세부 구현이 아니다.**
4. 세계 렌더 960×540과 Screen Space Overlay UI는 다른 경로일 수 있다. `UIRoot.cs`는 referenceResolution **1920×1080**과 ScaleWithScreenSize, `UITheme.cs`는 본문26·보조20·숫자44의 옛 크기를 갖는다. 따라서 renderScale 0.5만으로 UI가 960 격자라고 판정할 수 없다. [Unity Canvas Scaler 문서](https://docs.unity3d.com/Packages/com.unity.ugui@2.0/manual/script-CanvasScaler.html).
5. 구현팀 검토안: UI를 960 논리 격자에 합성 후 Point 확대하거나, Overlay의 글자·정렬을 같은 격자로 맞추는 경로를 검증한다. TMP의 bitmap/raster와 SDF는 별도 설정이다. Galmuri TTF만 교체하고 기존 SDF·비정수 스케일을 유지한 결과는 [미확인]. [TMP Font Asset 문서](https://docs.unity3d.com/Packages/com.unity.textmeshpro@4.0/manual/FontAssetsProperties.html).

### 이번 재현과 검증 범위

- 원본 게임을 설치·실행한 재현은 **0회**. 공식 게시 스크린샷 72장을 모아 연락판 4장으로 살펴보고, 선정한 프레임의 UI 면을 수동 표시했다. 프레임 평균·전체 게임 평균은 아니다.
- **폰트 기준 결과:** 기존 공식 배포 TTF를 12px로 래스터화하고 정수 좌표에서 2×/3× nearest 확대. `font-proof-960.png`와 `font-proof-1920.png`를 생성. 픽셀 반복·출력 크기·사용 문자열의 누락 글리프 대조는 `validation.json`에 기록한다.
- **우리 변경:** 동일 문구를 960×540에 배치하고 24/36px의 정보 밀도를 비교했다. 이는 폰트 렌더 시험이지 출시 UI 원화·Unity 출력 재현이 아니다. 문서의 8%/3% 예산과 타이머 임계값도 새 제안이다.
- UITheme 7개(`paperPanel`, `paperCard`, `slipHeader`, `stampRing`, `buttonPlate`, `enamelPlate`, `gaugeFill`) + PackingScreen 3개(`stampSprite`, `gaugeTrackSprite`, `gaugeFillSprite`) **슬롯 이름만 정적 확인**. 이번 스프라이트 제작 **0개**, 크기·9-slice 신규 확정 없음. 후속 원화/제작 때 슬롯별 W×H·L/B/R/T를 보고한다.
- 미검증: 원작 UI 효과음 청취, 동영상 전체 시청, 게임별 실제 폰트 파일, Unity 임포트/TMP/Play/성능, 한국어 주행 사용자 테스트. UI 제작·임포트 단계에는 **QA/프로그래밍 임포트 필요**.
- 원문 접근 실패: Unpacking 공식 사이트 시간초과(공식 Steam·음향 제작자 페이지로 대체), Dead Space 디자이너 인터뷰 본문(위에서 제외), Sega Retro 설명서403(공식 Steam 설명서로 대체). 실패한 URL을 확인 완료 근거로 세지 않았다.

## 5. 우리가 가져올 것 10개

1. **EDC의 풍경 여백:** HUD 없는 홍보 컷을 감정 참고로만 쓰고 실제 HUD 최소화는 우리 코스로 검증한다.
2. **A Short Hike의 필요할 때 읽기:** 짧은 대화·정차 때 정보 면을 만들고 평소에는 접는다.
3. **Lunacid의 구석 묶음:** 시간·거리·상태를 고정 위치에 모아 중앙 도로를 비운다.
4. **DREDGE의 화면 역할 분리:** 달릴 때 필요한 것과 재고·정산 내역을 분리한다.
5. **Crazy Taxi의 구별되는 시간:** 중요한 숫자를 단위·라벨과 묶되 우리 타이머는 하나만 크게 쓴다.
6. **Papers, Please의 실제 종이 문법:** 얇은 표·실제 항목·번진 도장, 정차 화면 전용.
7. **도장의 확정 시점:** 명령을 누르고 결과가 확정되는 순간 시각·소리를 한 번 맞춘다.
8. **Unpacking의 재질 소리:** 종이·테이프·도장의 서로 다른 행동을 짧은 실제 재질음으로 구분하는 안을 검증한다.
9. **Galmuri의 원형 격자:** 12px 원형 → 24/36 논리 px, 정수 좌표·Point·라이선스 동봉.
10. **D-125의 귀환:** 제한시간이 끝나면 목표 HUD를 접고 풍경·음악이 보상이 되게 한다.

## 6. 하지 말 것 5개

1. Jua·둥근 카드·사탕색·통통한 아이콘으로 D-121의 장난감 톤을 되살리지 않는다.
2. Paradise Killer식 큰 사선 배너·Crazy Taxi식 큰 중앙 화살표를 주행 중 상시 덮지 않는다.
3. 필수 시간을 대시보드·라디오·작은 영수증 속에만 숨기거나, 종이 미감을 위해 추가 드래그 조작을 만들지 않는다.
4. 비정수 확대·합성 굵게·전체 노이즈·글자가 구워진 AI 그림으로 픽셀 UI를 흉내 내지 않는다.
5. 홍보 컷의 0%·정지 이미지·제작자 주장을 플레이 검증으로 포장하거나, 출처 게임의 그림·폰트·효과음을 우리 출시 자산으로 전용하지 않는다.
