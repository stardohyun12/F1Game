## 0. 결론 (3줄)
- 지금까지 빠진 건 **사람의 결정**이다. 형태·질감·판정을 다 AI 가 하면 "규칙 지킨 평균"(5~7점)에서 멈춘다 — 기준 게임 셋 다 사람이 손으로 고르고 만들었다 [확인: ref-games-production §2].
- 에이전트를 Blender 에 더 깊게 붙이는 방향(blender-mcp)은 근거상 **역효과**다(§2-6). 에이전트는 박스 형태·재칠·배치·검사만 하고, **취향 결정(사진 고르기·페인트오버·정면 1채)은 도현 손**으로 옮긴다.
- 추천 = **⑦ EDC식 단순화 + ② 페인트오버 루프 + ③ 사람 제작 팩 소품** (도현 3~4시간/주, $0~18). 대안 = **④ 소액 외주 1채 + ③**.

## 2. 후보별 메모 (근거·함정만)

### 2-1. 도현이 직접 형태 (1a~1c)
- Blockbench = 무료·브라우저/데스크톱, 모델 위에 직접 칠함, 상자 중심이라 건물·간판·카트에 맞음, 유기체는 약함 [확인].
- EDC 개발자 순서: "종이 설계 → 바로 모델·텍스처, 처음부터 완성도 있게. 형상은 거의 안 고치고 텍스처에서 고친다" [확인: 80.lv]. → 도현도 **형태는 상자 몇 개, 정면 텍스처에 시간**.
- 혼합 루프: BlockBenchMCP(오픈소스)로 에이전트가 도현의 .bbmodel 을 열어 다면 캡처·변형 가능 [확인: README, 미설치]. 도현 1채 → 에이전트가 높이·창 수·색만 바꾼 변형 2~3채(EDC 도 "변형 쉬움"이 로우폴리 이유) [추정].
- 위험: 학생 시간. 첫 집은 못생길 수 있음 — 그래도 "사람이 만든 비뚤어짐"은 AI 티의 반대 [추정].

### 2-2. 페인트오버 루프 (2)
- 형식: 에이전트가 Unity B 컷(1280×720) 보냄 → 도현이 **텔레그램 사진 편집 그리기**(또는 아무 그림 앱)로 빨간 선·동그라미 + 한 단어("여기 화분 무리", "이 벽 이 사진 색", "이 집 더 낮게") [추정: 텔레그램 그리기 도구 사용 가능].
- 효과 범위: 구성·밀도·색·크기 — 에이전트가 잘하는 쪽. 표면 손맛은 못 올림 → 단독으론 부족, 1a/3/7 과 묶는다.
- 규칙: 한 장에 지시 ≤5개, 다음 판은 같은 컷 전/후 나란히. 판정자(JUDGE)보다 도현 페인트오버가 우선.

### 2-3. 팩 (3) — 구체 후보 3개 (전부 No generative AI 표기 [확인])

### 2-4. 외주 (4) — 학생 최소 범위
- 크몽(원화·KRW): 로우폴리 프랍 소형 25,000원·중형 55,000원·간단 건물 95,000원(수정 1회) [확인 kmong.com/gig/660128]; 단순 로우폴리 건물 100,000원/2일 [확인 /gig/580614]. 대부분 "캐주얼·모바일" 스타일 포트폴리오 → PSX·사진 질감 작가를 찾아야 함 [추정].
- Fiverr: **Elegant Crow "PSX 건물" $20~ (4.9★·46)** [확인] — 우리가 이미 쓰는 무료 팩(#6·12·13·14) 작가라 스타일이 맞음. 실견적 1채 $40~100 [추정].
- **최소 시험 = 정면이 이야기하는 가게 1채, ₩50,000~100,000 / $40~80** [추정]. 조건: "생성형 AI(이미지·3D 생성) 사용 금지" 주문 전 명시(Fiverr 공식 안내가 그렇게 하라고 함 [확인]), 중간 WIP 스샷 + .blend 원본 납품, 우리 팔레트·32px/m·치수 표 첨부.

### 2-5. CC0 스캔 축소 (5)
- 에이전트가 잘하는 규칙형 작업(리메시 → UV → 고폴리 색을 저폴리에 굽기 → 팔레트 양자화) [추정]. 소품(통·상자·벤치·바위)에 한정 — 실물 결이 V5 재료와 맞음.
- 건물급 CC0 스캔은 드묾 → 건물 해결책은 아님.

### 2-6. 에이전트 GUI 모델링 (6) — 하지 않음
- 잘 되는 것: 장면 세팅·복제·배치·일괄 스크립트. 실패하는 것: "비례·미감·제대로 보이나" 판단 [확인: mindstudio]. 우리가 원하는 게 바로 그 판단이라 효과 근거 없음.
- 같은 결론의 내부 근거: bpy 다섯 판 5~6점 고정(quality-gap), 커뮤니티 §4.

### 2-7. EDC식 단순화 (7)
- 이미 ART-RULES V5 = 사진 바탕 × 구운 빛 → 양자화. **차이는 사진을 누가 고르나**뿐 → 도현이 면마다 3후보 중 1장, 또는 **동네 벽·간판·문을 폰으로 직접 찍기**(EDC 개발자도 "외출 때 사진" [확인]; 직접 찍은 사진은 라이선스 문제 0, 사람 손 확실).
- 함정(이미 기록): 벽 전체 점무늬 금지, 녹은 모서리·아래만, 따뜻한 색 사진 섞기.
