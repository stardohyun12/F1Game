# 게임의 분위기는 어디서 오나 — 읽은 것 정리 (PD, 2026-10-23)

| 출처 | 핵심 | 우리에게 |
|---|---|---|
| Böhme 분위기 미학을 게임에 적용 ([Analecta, Gone Home·Edith Finch](https://revistas.uma.es/index.php/analecta/article/download/22700/22585/128247)) | 분위기 = 플레이어와 공간 "사이"의 것. 생성기 = 빛·소리·사물·생명체. 게임에선 **이동 물리·조작도 생성기** | 분위기 = 보이는 것 + 들리는 것 + **차가 움직이는 느낌** |
| [Andiloro 2023, 장르는 분위기의 조합](https://journals.sagepub.com/doi/full/10.1177/15274764231171076) | 분위기 = "보고-움직이고-느끼는" 패턴, 장르는 분위기로 알아본다 | 시선·조작·감정이 한 박자로 맞아야 |
| [Jenkins 2004, 서사 건축](https://web.mit.edu/~21fms/People/henry3/games&narrative.html) | 공간은 플레이어가 이미 가진 기억·연상을 불러낸다(evocative space) | "그리움"은 플레이어 자신의 기억을 건드리는 **원형**이 있어야 |
| [Carson, 테마파크→게임](https://www.gamedeveloper.com/art/environmental-storytelling-part-iii-lessons-learned-in-the-virtual-world) | 현실 원형(문턱·내리막·터널)이 기대를 만든다. 덜 채우고 장식은 시선 끝에 하나 | 동네 슈퍼·전봇대·옹벽·내리막 끝 바다 = 원형. 커브 끝에 보상 하나 |
| [Totten, 건축적 레벨 디자인](https://www.routledge.com/Architectural-Approach-to-Level-Design-Second-edition/Totten/p/book/9780815361367) | 좁은 공간 ↔ 전망 공간(prospect-refuge), 도착(arrivals), 장소의 혼(genius loci), Lynch 랜드마크 | 좁은 골목(갈 때) → 탁 트인 바다(돌아올 때) 대비 |
| [EDC 개발자 인터뷰, 80.lv](https://80.lv/articles/inside-the-making-of-easy-delivery-co) | 조작 대상(트럭·상자·인물)은 귀여운 픽셀, 환경은 사진 — **대비**가 따뜻함을 살림. 목표는 "눈보라 속/겨울 해질녘 혼자인 무섭지만 고요한 느낌" 한 장면. 그림자·태양 없음, 앰비언트 한 색+안개 | 막연한 "그리움"이 아니라 **구체적 기억 한 장면**을 목표로. "귀여운" 금지 재검토 |
