- 1827 보고는 새 풍경 캡처를 **에디트 모드·원화 프리셋·960×540**이라고 명시했다. 본 작업은 이 제공 캡처를 합성 배경으로 썼다. 새 Play 스크린샷을 찍은 것은 아니다.
- 포장에는 이미 남은 시간이 구현됐고 제공 1920×1080 캡처에는 중앙의 ‘남은 시간 2:01’과 우상단 2:01이 함께 보인다. 이번 작업의 변경점은 새 기능 추가가 아니라 시간 표기를 하나로 정리하는 시안이다.
- 스냅샷·SHA256·기존 파일 출처는 [sources.json](../../art/_review/2026-10-23-course-ui/sources.json). 최종 집 캡처는 집에 도착하기 전 풍경이며 도착 UI 합성은 정지 프레임 제안이다.

## 화면에 적용한 판단 — 제작자 추론

| 판단 | 적용 / 영향 |
|---|---|
| 사람 기척은 안내문의 용도에서도 드러난다 | 영업중·오늘 수확·문 앞 배송·초인종·배달 접수. 무의미한 가짜 손글씨 없이 동네가 운영 중임을 보여줌 |
| 세월은 균일 잡음보다 덧칠/수리 위치 | 오래된 하단 도장색, 새 종이 공지, 볼트 아래 녹, 손 닿는 변. 원본 금속 사진은 국소 마스크만 |
| 풍경을 가리는 큰 UI는 도착 보상을 깎는다 | HUD정보 영역6.22~6.71%, 중앙60%×60% 비움. 귀로기본0%. 도착A 최초안의 차량 가림을 독립 검토 후 좌상단으로 이동 |
| 위기 정보는 위치를 바꾸지 않는다 | 시간은 포장·주행 우상단 공통. 색+텍스트, 동일 레이아웃. 실제 남은 시간을 UI가 따로 계산하지 않음 |
| ‘역전’은 결과가 좋아지는 이유를 보여준다 | 기록된 2.8초와 화물 상태, 집주인의 감사. 새로운 보상 수치나 실패를 성공으로 바꾸는 연출은 없음 |

최종 표지판은 모두32px/m. 64px/m 글자 예외는 물리 크기/투영 한계를 해결하지 않아 요청하지 않는다. 대신 주 이름·급경사/완만은 24texel로 키우고 작은 12texel 공지는 근거리로 구분했다. 단독 경고가 20m에서 읽히지 않는 문제는 남아 있어 HUD 접근 안내로 보완한다. 크기를 키운 표지가 기존 기둥·동네 비례에 맞는지는 실제 배치 확인이 필요하다.

## 실제 검증 / 남은 질문

독립 리뷰어는 제작 의도·문서 없이 PNG를 직접 봤다. 1차 세계표지6.5/HUD8/A6.5/B7.5/C8 → 한 번 수정 후 세계표지7.5(아니오)/HUD8.5(예)/A8(예)/B7.5·C8(이전 판정 유지). 원문과 파일별 해시는 [독립 게이트](../../art/_review/2026-10-23-course-ui/validation/independent-gate.md).

20m 불리한 조건에서 주 이름과 ‘급경사/완만’은 읽혔지만 작은 ‘화물주의’·MART 공지는 판독 불가. 이 점은 통과로 세지 않았다. 실제 속도·고저차·안개·시야 방향은 미검증이며 960 화면의 정적 투영 결과에 한한다. 72km/h에서10~20m는0.5초라 정적 판독 성공도 주행 판독 보증이 아니다.

정적 검사는 7PNG 팔레트·POT·32px/m·UV padding·폰트 레이어·provenance, 10목업의 정확한960 및2×, HUD중앙 비움/귀로0%,42투영, 로컬 HTML로 한정한다. 기존 ui-final 10슬롯도 `check_asset.py --ui-manifest`로 재검사한다. 컴파일·Play·임포트·출시 빌드 전체 AI감사는 하지 않았다.

`PIPELINE.md` §10: “시안 단계에서는 고치기·재판정 왕복을 1회로 제한하고, 남은 건 목록으로 붙여 도현에게 보여 준다.” 해당 1회를 마쳤다. **남은 표지 단독20m 경고 판독 문제와 큰 길가 식별판 비례를 승인 검토에 함께 제시한다.** 결과를 전체 통과로 바꾸어 기록하지 않는다.
