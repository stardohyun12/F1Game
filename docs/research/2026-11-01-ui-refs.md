# UI 레퍼런스 해체 — 세상 속 UI + 조금만 보이는 도트 HUD (D-238)

2026-11-01 · PitCrew 리서치 · PD 과제 20261101-0417 · **조사. 승인 아님, 규칙은 전부 "제안".**
배경: `docs/design/PACKING-UI.md`(초안) · D-238(포장=1인칭 작업대, 주행·걷기 UI 거의 없애되 "조금은 보여줘야 할 듯", 포장 타이머 없음).
앞선 조사(`docs/research/ui-01-references.md`, 10-23)와 겹치는 게임(Short Hike·EDC·DREDGE·Unpacking)은 **이번에 화면을 다시 열어 새 기준(①~⑤)으로 다시 셌다.** 나머지 7개(Lil Gator·Jalopy·TOEM·Mail Time·Wheel World·Death Stranding·Webfishing)는 이번이 처음이다.

- 표기: **[관찰]** 이번 세션에 내가 직접 연 스크린샷(공식 Steam 스토어 게시 컷, 게임당 6장 안팎) · **[개발자]** 개발자·제작사 글 · **[추정]** 내 판단 · **[미확인]** 화면에 안 나와서 모름.
- ⚠ 스토어 컷은 개발사가 고른 홍보 컷이라 **HUD 가 일부러 빠졌을 수 있다.** "HUD 0%" 는 "그 컷에서 0%" 이지 게임 평균이 아니다.
- 면적 % = 화면 1920×1080(Short Hike 만 1900×1080) 대비, 사람이 그린 박스 합집합(글자 사이 여백·패널 바탕 포함). 좌표는 `art/reference/ui-2026-11-01/measurements.json`, 재계산 `_scripts/measure.py`. 독립 검산: 10-23 보고서의 Short Hike 3.5% · EDC 3.8% 와 이번 값이 **같다**(다른 사람이 아니라 같은 방법이지만 박스는 새로 그림).
- 스샷: `art/reference/ui-2026-11-01/ref/`(640px 선별 25장) · `_sheets/`(연락판·잘라낸 조각) · 출처표 `SOURCES.md`. 원본 1920×1080 은 저장소 밖(TEMP).

## 1. 게임별 해체 (①~⑤)

> ① 화면에 남긴 HUD(위치·크기) ② 세상으로 옮긴 정보 ③ 대화창 문법 ④ 저해상도와 UI 해상도 ⑤ 상호작용 안내.
> 열어 본 화면: 괄호 안 번호 = 스토어 스크린샷 순번(`ref/` 파일명).

### 1.1 A Short Hike (6장: 00~05; 00·03 선별)
- ① **[관찰]** 6장 중 5장이 HUD 0%. 말풍선 한 장(03)만 3.5%. 깃털·체력 HUD 는 이 컷에 없다 **[미확인]**.
- ② 이 컷들에선 정보를 세상 물건(표지판·모닥불)으로 옮긴 흔적을 못 봤다 **[미확인]**.
- ③ **[관찰]** 03: 크림색 말풍선 + **말하는 사람 쪽으로 향한 꼬리**, 짙은 갈색 굵은 도트 글자 한 줄("be safe out there!"), 이름표 없음. 풍선은 말하는 NPC 머리 위쪽.
- ④ **[관찰]** 1:1 조각에서 풍선 모서리·꼬리가 **계단식**이고 글자 획 굵기가 세계 픽셀 한 칸 안팎(눈대중, 측정 아님) → **UI 도 같은 저해상도 격자에 그려져 있다.** **[개발자]** "flat cohesive shading and no anti-aliasing", "soft outline effect… stay readable with so few pixels", 픽셀 크기를 고르는 옵션 — [PlayStation Blog](https://blog.playstation.com/2021/08/05/crafting-a-tiny-open-world-a-look-behind-the-scenes-at-the-creation-of-a-short-hike/). (UI 를 어떻게 그렸는지 직접 쓴 글은 못 찾음: 풍선이 같은 격자라는 건 화면 관찰.)
- ⑤ 컷에 없음 **[미확인]**.

### 1.2 Lil Gator Game (6장; 01·03 선별)
- ① **[관찰]** 세계 컷(00,02,04,05) HUD 0%. 메뉴 컷(01)에 왼쪽 위 파란 알약 "314 / −100"(돈) + 아래 A/B 버튼 안내.
- ② **[관찰]** 메뉴 자체가 **수첩**(스프링 노트·가위·크레용·스티커). 화면 UI 를 "물건"으로 입혔지만 풀스크린 메뉴다(세상 속 물건은 아님).
- ③ **[관찰]** 03: 화면 아래 가운데 **큰 주황 테두리+크림 상자 19.1%**, 이름표(어두운 갈색 탭 "avery!")가 왼쪽 위 모서리, 오른쪽 아래에 다음 표시(잎 아이콘), 손글씨 풍 글꼴. 뒤에서 3D 인물이 연기.
- ④ **[관찰]** 매끈한 고해상도 UI 를 로우폴리 3D 위에 올림. 픽셀 격자 맞춤 없음.
- ⑤ **[관찰]** 메뉴에서 초록 원 A "equip" / 빨간 원 B "back"(왼쪽 아래). 세계 속 물건 옆 안내는 컷에 없음 **[미확인]**.

### 1.3 Jalopy (6장; 01·02·04 선별)
- ① **[관찰]** 6장 모두 화면 HUD 0%.
- ② **[관찰]** 정보가 전부 물건에: 대시보드의 속도계·연료계(02, 화면의 3.5%), 부품 설명은 손에 든 **수첩**(01, 11.7%), 경로·거리는 펼치는 **지도책 "DDR Autoatlas"**(04, **55.8%**), 도로 위 큰 표지판 "Dresden"(03). **켜면 화면 절반을 먹지만 켠 사람이 고른 것.**
- ③ 대사 컷 없음 **[미확인]**.
- ④ **[관찰]** 로우폴리 3D 에 UI 가 없어서 맞출 것도 없음. 단 02 의 계기판은 **어두워서 읽기 어렵다**(캡처 한 장 기준).
- ⑤ 컷에 없음 **[미확인]**.

### 1.4 TOEM (8장 중 6장; 02·04 선별)
- ① **[관찰]** 세계 컷(01,04,05) HUD 없음. 카메라 화면·커뮤니티 카드는 풀스크린 메뉴.
- ② **[관찰]** 카메라(찍기 UI)가 휴대기기 모양의 풀스크린. 세상 속 정보 이동은 컷에 없음.
- ③ **[관찰]** 04: 검은 가로 상자에 흰 굵은 대문자 한 줄 + 아래로 꼬리 + 끝에 말줄임(…) 표시, 5.9%.
- ④ **[관찰]** 글꼴·상자는 매끈한 고해상도. 세계(흑백 선화)와 **2톤 흑백**으로 통일해 어울림 — 격자 맞춤이 아니라 팔레트 맞춤.
- ⑤ 컷에 없음 **[미확인]**.

### 1.5 Mail Time (9장 중 6장; 01·04 선별) — 배달 소재라 중요
- ① **[관찰]** 세계 컷(00,03,05) HUD 0%.
- ② **[관찰]** 편지가 가방 속 물건(05 날다람쥐식 활공 장면에서 편지로 활공), 보상은 **엽서 종이**(04, 풀스크린 모달). NPC 머리 위 **"!" 말풍선**(01, 노란 느낌표)이 "할 말 있음" 표시.
- ③ **[관찰]** 01: 크림 상자에 굵은 갈색 테두리 19.6%, 이름표는 **오른쪽 위 모서리의 초록 알약 탭("Shelby")**, 상자 아래 가운데에 **[E] 키 칩**, 손글씨 풍.
- ④ **[관찰]** 매끈한 고해상도, 손으로 그린 선 느낌으로 세계(스토리북 3D)와 맞춤. 픽셀 격자 아님.
- ⑤ **[관찰]** E 키 칩이 대화 상자 안(가운데 아래)에 붙음.

### 1.6 Wheel World (10장 중 6장; 00·02·04 선별)
- ① **[관찰]** 레이스(00) **6.6%**: 위 가운데 가는 구간 막대 / 오른쪽 위 큰 "8/8" + 시계 알약 + 이름 / 왼쪽 아래 속도 호 "21 KPH"(작음) / 오른쪽 아래 코스 미니맵 / "LAP 1/3". **자유 주행(02) 1.7%**: 왼쪽 아래 속도 게이지(+기어 표시) + 왼쪽 위 가는 바. 장면 01·03 은 0%.
- ② **[관찰]** 길 안내를 **세상에 놓은 빛나는 아치·쉐브론**(00,03) — 화면 화살표 대신 길 위에 서 있다.
- ③ **[관찰]** 04: NPC 머리 위 **작은 어두운 알약 말풍선 "Bike parts…" + 꼬리 + "●●"(더 있음)** 0.8%, 글자는 말풍선 안에만.
- ④ **[관찰]** 매끈한 벡터 HUD 를 평면 셰이딩 3D 위에. 픽셀 격자 아님.
- ⑤ **[관찰]** 04: 자전거 옆(오른쪽)에 **청록 링 아이콘**이 물체 곁에 떠 있음(약 0.2%) — 화면 구석이 아니라 **대상에 붙은 안내**.

## 2. 면적 한눈에 (1920×1080 기준, 사람이 그린 박스 합집합)

- 🟢 **계속 떠 있는 HUD**: Wheel World 자유주행 **1.7%** · Unpacking 모서리 아이콘 2.4% · EDC 떠오르는 돈 글자 2.4% · Short Hike 말풍선 3.5%(이건 말할 때만) · EDC 가게 대사 3.8% · DREDGE 항해 4.2% · TOEM 말풍선 5.9% · DS 타이머 2.8%.
- 🟡 **레이스·경쟁 HUD**: Wheel World 레이스 6.6% · DS 레이스 9.2%. 시간·순위·미니맵이 다 붙으면 7~9%.
- 🔴 **큰 대화 상자**: Lil Gator 19.1% · Mail Time 19.6% · Webfishing 12.7%. 화면 아래 1/5 를 한 번에 가린다. (장면 정지·대화 중이라 허용되는 문법)
- 🔵 **세상 속 읽을 면(D)**: Jalopy 계기판 3.5% · 수첩 11.7% · 지도책 **55.8%**. 켜면 큰 면적을 쓰지만 **켠 사람이 부른 것**이고, 내려놓으면 0%.
- 기존 초안 예산(`PACKING-UI.md` / 10-23 보고서): 갈 때 8% 이하 · 돌아올 때 3% 이하. **이번 11곳에서 상시 HUD 는 1.7~4.2% 대**라 예산 8% 는 넉넉한 쪽이고, 3% 는 Wheel World 자유주행(1.7%)·Unpacking(2.4%)과 같은 줄이다 (스토어 컷 한정 **[추정]**).

## 3. 해체해서 보인 것 (제일 센 4개)

1. **끄는 UI 는 "대상에 붙인다".** Unpacking 의 틀린 물건 위 "!" 풍선(04), Wheel World 의 자전거 곁 청록 링(04), Mail Time 의 NPC 머리 위 "!". 화면 구석 안내가 아니라 **그 물건 곁**에 작게 뜬다. 우리 "상자 쪽 작은 도트 아이콘 한 번"(PACKING-UI §주행)은 이 문법과 같다 **[관찰]**.
2. **길 안내는 화면 화살표 대신 길 위의 물건.** Wheel World 의 빛나는 아치·쉐브론(00,03), DREDGE 의 등대 불빛(00), Jalopy 의 길가 큰 표지판 "Dresden"(03). 걷기·운전 중 방향은 이게 가장 비용이 싸다 **[관찰]**. 지도·약도는 **꺼내 볼 때만** 크다(Jalopy 지도책 55.8%).
3. **픽셀 격자에 UI 를 맞춘 건 Short Hike·EDC·Unpacking 셋뿐.** 나머지 8곳(Lil Gator·Jalopy·TOEM·Mail Time·Wheel World·DS·Webfishing·DREDGE)은 고해상도 매끈한 UI 를 3D 위에 얹었다. 우리 세계는 960×540 Point(D-124)라서 **격자 맞춘 셋이 직접 참고 대상**, 나머지는 레이아웃·위치·크기 참고만 쓴다 **[관찰]**.
4. **"전표=종이"의 근거는 Jalopy 수첩이지 Death Stranding 이 아니다.** DS 의 주문·결과는 전부 풀스크린 홀로그램 목록이었다. 손으로 쓴 종이를 들어 읽는 건 Jalopy(수첩 11.7%, 지도책 55.8%)와 Mail Time(보상 엽서)이 맞다 **[관찰]**.

## 6. 프로젝트 규칙 제안 (전부 제안 — 도현 승인 전엔 확정 아님)

1. **세상 물건이 먼저, 화면 HUD 는 나중.** 방향=길 위 물건+전표 약도, 속도=계기 바늘·소리, 화물=상자 흔들림·소리. 화면에 얹는 건 위 후보 표 2·3·6·7 처럼 **대상에 붙는 작은 것**만.
2. **상시 HUD 면적 상한은 4% 부터 시작.** 11곳에서 상시 HUD 가 1.7~4.2% 였다(스토어 컷 한정). 기존 초안 8%/3% 와 겹치는 구간. 대화·정산은 **말할 때만 3.5~4%**, 하단 큰 상자(12~20%)는 쓰지 않는다 **[추정]**.
3. **UI 는 세계와 같은 960×540 격자에 그린다.** 격자 맞춤은 Short Hike·EDC·Unpacking 셋뿐이고 우리 D-124 가 이미 960×540 Point 이므로 같은 길. 매끈한 UI 를 3D 위에 얹는 8곳은 레이아웃만 참고. (`UIRoot.cs` 1920×1080 Overlay 는 격자 밖 — 10-23 보고서 지적 그대로, 구현은 구현팀 몫.)
4. **상호작용 키는 물건 곁의 작은 칩 하나.** 문장 띠 없음. 키 + 아이콘, 글자 0~1단어.
5. **화물 위험 경고는 상자 곁 도트 "!" 한 번 + 소리.** % 막대·숫자 상시 표시 없음. 정확한 값은 전표 뒷면(D-238 초안과 같음).

7. **대화 문법은 둘 중 하나로 고정**: ⓐ 작은 말풍선+꼬리(Short Hike) ⓑ 박스 없는 도트 글자+그림자(EDC). 이름표는 모서리 탭을 쓸 때만. 간판·대사의 **글자 내용은 도현이 정한 것만**(체크리스트 7).
8. **판정은 게임 화면 같은 카메라 전/후**(체크리스트 14). 이 문서의 % 는 스토어 홍보 컷 기준이므로 **우리 화면에선 다시 잰다.**
