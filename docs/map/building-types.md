## D-137·D-139·D-140 적용 계약 (2026-10-25)

- 위 치수는 제작 가설이며 본체 폭×깊이다. 차양·계단·마당·담장·헛간 돌출은 manifest의 전체 bounds로 별도 기록한다. 생성기 입력 폭은 4~10m이며 기존 `harbor_warehouse`의 12m 상한은 기존 에셋 계약으로 유지한다.
- 모든 새 type도 피벗 = **본체 바닥 앞면 가운데**, 앞면 +Z, y=0, 1단위=1m. 앞마당을 더해도 피벗을 전체 bounds 가운데로 이동하지 않는다. 열린 `bus_stop`·`fuel_stand`는 주 구조물 전면 기준을 manifest에 명시한다. 공통 기단은 빌더 소유다.
- `dense`는 붙은 집·항구 앞·상점가 중심, `medium`은 집 사이 틈·마당·담장, `sparse`는 큰 빈터·밭·나무 사이 독립 건물이다. 지도 면적 25/40/35%와 길 폭 3.5~4.5/5~6/큰길6~8m는 D-140의 **배치 가설**이며 건물 파일 생성만으로 달성했다고 판정하지 않는다.
- D-139의 1.2~3m 인도·길가띠 및 8~12cm 경계석은 배치팀 소유다. 아트는 건물 앞 출입구·계단·마당의 범위를 기록하고 인도까지 소품으로 막지 않는다.
- 형태는 이탈리아 해안(회벽·아치·옥상·테라코타·덧창), 눈높이는 일본식 생활의 밀도(작은 간판·실외기·화분·빨래)다. 교토 마치야 격자·연속 처마·일본 기와 형태는 사용하지 않는다. 시설도 같은 공용 팔레트·32px/m·사진 기반 마모를 공유한다.
- 새 변형 파일은 `<type>_<nn>.fbx`; 기존 `_a/_b/_c`는 빌더 참조용으로 보존한다. 프리팹화·Point 임포트·인게임 배치는 프로그래밍팀이 수행한다.
