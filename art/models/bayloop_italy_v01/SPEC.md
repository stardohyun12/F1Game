# D-137 — 기억 속 항구 건물

실루엣·회벽·아치·덧창·발코니·옥상은 이탈리아 해안의 형태, 간판 겹침·배관·계량기·화분 배치는 일본 골목의 생활 밀도를 적용한다. 소품 자체가 특정 국가 전용이라는 뜻은 아니다. 교토식 격자·연속 처마·기와 지붕을 새 상점에 쓰지 않았다.

| type | 본체 폭×깊이 / 층 | 차이 |
|---|---|---|
| shop_house_a | 5.5×8m / 2층 | 바랜 흰 회벽·옥상 출입실·좁은 발코니 |
| shop_house_b | 6.75×8m / 3층 | 황토 회벽·3층 매스·비대칭 발코니 |
| shop_house_c | 6.25×8m / 2층 | 청회색 회벽·상층 아치·옥상 퍼골라 |
| terrace_house_a | 5.5×6m / 2층 | 흰 회벽·후퇴 테라스·아치와 덧창 |

**1unit=1m, Y-up, 앞면+Z, 피벗=본체 바닥 앞면 가운데.** 바닥Y0. 계단·소품·차양이 본체 밖으로 나오므로 실제 배치 여유는 manifest의 bounds를 사용한다. 내부 계단·실내·문 개폐·콜라이더·LOD·게임 배치는 제공하지 않는다. 모든 형상은 설계 치수이며 사진을 측량·복원했다는 뜻이 아니다.

## 재현·사진·팔레트

`bayloop_buildings.py`의 metre UV 절단·FBX/GLB 축 변환·실제 렌더를 재사용했다. `bayloop_italy_buildings.py --type <type>`가 새 형상을 만든다. `--ids shop_house_c`처럼 선택 재생성 가능. 선택 생성된 `<id>.blend`가 전체 type.blend의 이전 변형보다 최신이다. 정확한 최종 geometry는 각 `<id>.geometry.json`과 GLB이다.

`bayloop_italy_textures.py`: A1 및 이전 BayLoop CC0 사진 아틀라스를 재사용, 사진 밝기를 공용 팔레트의 가까운 색 쌍으로 치환. 흰색19/14, 황토29/30, 청회색13/19. 원본이 이미 2색인 경우 min/max 중간값으로 나눠 사진 변화가 단색으로 소실되지 않게 했다. 무작위 얼룩을 생성하지 않았다. 기존 사진의 반복 얼룩은 여전히 시각 한계로 보고한다.

세계32px/m, atlas1024², 256px칸/2px여백/유효252px. 32색 검사는 조명 전 albedo에만 적용한다. 조명·그림자·AA로 생기는 최종 화면 색수는 별도이다. 글자는 OFL Pretendard의 짧은 한국어 `상점 / 수리 / 배달 / 영업`만 사용한다. 외국어 혼합·가짜 문자 없음. 아틀라스 URL·사진 실측·가공은 texture-manifest.json, 원본사진 메타데이터는 manifest.source_manifests, 최종 장부는 art/provenance.csv.

실사 Procida·Atrani·Positano는 검토 폴더 references/에 저자·라이선스·직접 다운로드 원문과 함께 보존했으며 비례 참고만 하고 게임에 넣지 않는다. 검토판 배경·건물은 실제 bpy 렌더, AI 이미지0.

## 창고 판단

`harbor_warehouse_a/b`는 지난 판의 바랜 함석 지붕·셔터·적재 체적을 유지한다. 주택과 다른 작업용 항구 건물의 용도 차이를 남기는 제작 판단이다. 이번 실사 사진이 창고 지붕 재료의 고증 근거라고 주장하지 않는다. 파일을 다시 쓰지 않고 이전 수치/시각 통과 판과 SHA를 유지한다. 테라코타로 일괄 바꾸지 않았다.
