# cargo_wine_v01
750ml Bordeaux 병, 높이300mm×직경75.2mm. Galmuri7 가상상표 M. 64px/m, 64² 공용32색, Point, floor-centre pivot. 앞·뒤·좌·우·위·아래 UV 영역 구분. 곡면 삼각형도 직교국소평면 UV로 밀도 보존. 표면마다 1~2px 세로 명도단계, 바닥 접촉부 vertex AO. 반짝이는 PBR·노멀맵 없음.

`py build_atlas.py` 다음 Blender `-b -P generate.py`. 검사는 루트 통합 보고 참조. Unity 미실행, 프로그래밍 임포트 필요. 6면 순환 UV 중 좁은 면은8px창 검사 대상이 아니므로 작은 창 보조검사만 유효. 실제 병에는 넓은 라벨을 두르는 비례가 정상으로 택배상자30% 송장 규칙과 분리.
