# D-141 길가 생활 소품 — geometry 모듈

- 생성 원본: `tools/asset-gen/bayloop_props2_street.py`, 진입점 `build(p, b)`.
- 입력: `p={'type': <아래 종류>, 'variant': 0}`; 종류 별칭 `kind`도 허용. 반환은 `dimensions`(Blender XYZ m), `design_notes`, `mount_height_m`, `placement_offset_m`, `pivot`.
- 메인 생성기가 바닥 중앙으로 재중심화하고 재질·익스포트·검토 렌더를 담당한다. 이 모듈은 `b.box/face/beam`만으로 `V/F/UV/PARTS`를 채운다.
- 참조: PIPELINE §5, 아트 방향 v2 규칙 1~14, D-137의 생활층, D-141의 수리 흔적과 길가 사용 흔적, TASTE의 세월이 남은 표면.
- 재사용: `bayloop_buildings.py`의 32px/m planar metric UV와 photo atlas, `bayloop_italy_props.py`의 실물 구조를 작은 부품으로 나누는 방식. 원본 코드의 geometry collector를 실제 Blender에서 그대로 사용해 검증했다.
- 변경: 별도 실린더·판·링 보조함수, 의자의 회전된 프레임, 속이 열린 청과 진열대, 불투명 잘린 횡단보도와 비정형 포장 수리, 벽부착물 설치 높이 메타. AI 이미지·외부 mesh·새 텍스처 없음.
- 치수는 생활 소품에 맞춘 설계 가정이며 제품 실측 또는 도로 법규 인증이 아니다. 외부 사례의 정확한 원본 재현이라고 주장하지 않는다. 질감의 사진 출처·CC0/팔레트 감사는 공유 atlas와 메인 장부를 계승한다.

## 실제 실행한 정적 geometry 검증

## 설치·남은 검증

- 벽부착 우체통: 자산 바닥 높이 1.10m. 빨래: 가장 낮은 옷자락 높이 2.7m. 자산 자체 pivot과 설치 지상고를 혼동하지 않는다.
- 횡단보도 지면에서 +0.014m, 땜질 +0.012m; collider 금지. 기울어진 도로는 배치자가 도로면에 정렬해야 한다.
- 차고는 실제 호스트 벽 개구부에 넣어야 한다. 반사경은 사진 질감의 볼록 모양이며 실제 동적 반사 기능은 없다.
- STOP 문자는 사용하지 않는다. R2 정지 표지판은 손바닥 기호만 사용한다. 진열대 가격표·우체통 이름표는 의도적으로 빈 종이 홀더다.
- 사진 기반 tile의 실제 색으로 표지판·과일이 충분히 구분되는지, 작은 부품과 양면 천의 렌더, 밑면 중앙 pivot, exporter 이후 치수·UV밀도·면 방향은 메인 생성 및 4면 렌더에서 확인해야 한다. 그래픽 게이트 판정은 아직 없다.

## R2 — 독립 시각 판정에 따른 수정

`art/_review/2026-10-25-bayloop-props2/first-street-gate-r1.md`와 해당 3개 front PNG를 직접 열었다. R1 점수는 빨래 6/10, 거울 4/10, 정지표지 5/10이며, 위 표의 수치는 수정 전 R1이다.

- 빨래: 반복 사각 천 네 장을 소매·V목이 있는 셔츠, 수건, 다리 사이가 실제로 뚫린 바지, 발끝이 있는 양말 두 개로 바꿨다. V자 깊이 90mm → 잔주름 16mm 범위로 완화했다. 벽 고정구는 호스트 벽 설치 대상이라 단독 렌더에서는 떠 보일 수 있다.
- 거울: 검은 glass 삼각 부채를 흰 사진 trim 상부·금속 사진 metal 하부·수평 띠로 나눠 밝은 하늘과 지면 반사를 구분했다. 55mm 볼록면 유지, 후드 돌출을 50mm 줄이고 조절 볼트를 추가했다. 실제 환경 반사는 아니다.
- 정지표지: 사용자 지정대로 글자를 넣지 않고 열린 손바닥·엄지·네 손가락·손목을 실제 불투명 geometry로 넣었다. 면 색의 광범위한 황갈 얼룩은 공유 atlas에서 최종 검토한다.
- R2 수행 검증: Python AST parse PASS. R2 실제 collector 삼각형 수·렌더·재판정은 루트가 실행한다. Unity는 건드리지 않았다.

## 후속 geometry 수정·검증

빨래 R3는 R2 PNG와 보고서를 보고 곡선 밑단·완만한 분할 천·작게 접힌 소매·둥근 발끝으로 수정하고 연속 의복 UV를 적용했다. 실제 collector 794 tris, 650 faces, 3.29×0.1416×1.36m. UV 위치가 작은 삼각형마다 다시 시작하지 않게 했으며 새 색 노이즈는 없다.

도로 R2는 밝은 테두리를 없애고 수리면(01)과 긴 굴착 복구면(02)을 다른 실루엣으로 만들었다. 횡단보도는 줄마다 다른 1~2개 침식 틈과 연속 UV, 모든 도로 표면 geometry 두께 0·배치 오프셋 2mm다. 실제 collector 횡단보도 136 tris / patch01 18 / patch02 14 / 자동차 금지 표지03 240. 표지03은 글자 없이 자동차와 빨강 warning 사진 tile의 테두리·사선이다. 표지02는 지주를 2.36m로 낮추고 지름 28mm 볼트 두 개를 더했다. 이 후속 작업에서 통과한 표지01·거울은 수정하지 않았다.

### 도로 R3

`roads-final-gate.md` 피드백에 따라 횡단보도 관통 틈을 모두 없애고 줄마다 측면 2~3군데에 작은 침식만 남겼다. 도로패치는 115mm 이하로 외곽을 분할하고 1cm 미만의 미세 불규칙을 추가했다. 접합부는 `seam` alias13 실제 사진 tile의 29~57mm 비균일 타르 띠이며 밝은 프레임이 아니다. 기존 asphalt alias15 유지. 실제 Blender collector 검사: 횡단보도 378 tris·Z두께0, patch01 183 tris, patch02 234 tris·타르층 0.4mm, 모두 1500 이하·F=UV=PARTS PASS. 표지3종·거울·빨래 geometry는 변경하지 않았다.

빨래 후속 기술 수정: 기하·시각 보류 상태를 유지하고, XZ 투영으로 밀도가 줄어드는 급경사 삼각형만 원래 `b.face`의 3D metric UV로 복원했다. 평탄한 면의 연속 UV는 유지한다. Blender collector의 모든 삼각형에 대해 3D 접평면→UV pixel 변환의 특이값 두 축을 직접 검사: 최저 29.69515·최고 32.00031px/m, 허용범위 28.8~35.2 PASS, 794 tris 유지. GLB 재생성 후 기존 감사 도구 확인은 루트 담당이다.

### 가구 최종 R3 — 파라솔·차고만

`shop-kit-gate-r2.md`와 해당 정면 PNG 2장을 직접 확인했다. 통과한 진열대·카페·우편함은 변경하지 않았다.

- 파라솔: 넓은 스커트를 없애고 18mm 접힌 천 끝단으로 줄였다. 3단 곡률·살대 사이 20mm 처짐·2mm 안감으로 천을 구성하고 상부 허브·슬라이딩 러너·분절된 8살·받침 링크·손잡이 크랭크를 추가했다. 실제 Blender 884 tris, 2.24×2.24×2.3m, F=UV=PARTS PASS.
- 차고: 슬랫 높이를 112→124mm로 늘려 18mm 검은 줄을 6mm 이음새로 축소했다. geometry는 나머지 유지. 실제 Blender 300 tris, 2.75×0.55×2.33m, F=UV=PARTS PASS. 차고 전용 낮은 대비 금속 atlas는 루트가 적용한다.
- 렌더·최종 그래픽 판정·Unity 실행은 이 담당이 수행하지 않았다. 모듈과 SPEC 외 파일 변경 없음.
