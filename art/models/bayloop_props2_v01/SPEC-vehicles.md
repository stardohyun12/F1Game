# D-141 길가 탈것 지오메트리

## 산출물·계약
- `tools/asset-gen/bayloop_props2_vehicles.py`, `build(p,b)`; `p.type/variant` (0부터), 반환값은 형태·설계치수·휠베이스·바퀴 수·접지영역·예산·마모 위치.
- metre, Blender Z-up, 앞 -Y; 내보내기·재질·최종 바닥중심 피벗 정규화는 root 생성기가 담당한다. Unity·F1/·커밋 작업 없음.
- 전 모델 정적 주차 소품, 리깅 없음. 실제 로고·번호판·브랜드명 없음. AI 이미지 0.
- atlas alias: body, trim, glass, darkroof, rubber, metal, rust, cloth, wood_dark. 모든 면은 기존 `bayloop_buildings.face`를 통과해 32px/m UV를 사용한다.

## 조사 → 재사용 → 변경
1. Suzuki 공식 Digital Library의 [1993 Wagon R](https://www.suzuki.co.jp/suzuki_digital_library/1_auto/wagonr.html): 공식 사진·설명·치수 3295×1395×1640/1680mm, 축간 2335mm 확인. 높은 사각 차체와 짧은 보닛 비례를 variant 2에 적용; 문 구획은 익명 생활 소품으로 단순화. 특정 실차 복제품은 아니다.
2. Piaggio 공식 [Primavera 발표·제원](https://www.piaggiogroup.com/sites/default/files/news/vespa_primavera_eng_2.pdf): 1860×735mm, 축간 1340mm. 낮은 발판·앞 방풍판·단일 좌석 실루엣과 축간거리 채택. 후면 배달 상자 변형 추가; 실물 완전 재현을 주장하지 않는다.
3. Piaggio 영국 상용차 사이트의 [Ape 50 제원·정투상도](https://piaggiocommercialuk.com/wp-content/uploads/2018/01/Ape-50-technical-info-EN-1.pdf): 폭 1260mm, 2490~2660mm 차종별 길이, 작은 앞바퀴 1개와 뒤바퀴 2개 배치 확인. 2530mm급 설계·개방 적재함 채택; 치수 세부는 익명형으로 조정.
4. 유럽 차 2종은 위 소형차 크기 범주의 독자 설계: 둥근 3도어와 긴 각진 해치백, 실제 브랜드 복제 아님. 모델 0은 3.20×1.48×1.43m, 모델 1은 3.64×1.54×1.44m 차체 설계치. 미러·범퍼는 이 치수 밖에 있다. 유럽 실차 공식 도면과 일치시킨 결과라고 주장하지 않는다.
5. 검증된 원본 워크플로우는 저장소 `bayloop_buildings.py`의 metric face UV이며 수정 없이 재사용. wheel ring·휠하우스·경사창·베벨 차체는 신규 작성했다. 사진/도면 파일은 텍스처나 납품물로 복사하지 않으며 관찰 참고만 한다. CC0 사진 아틀라스의 출처 장부는 root 담당이다.

## R3 실제 정적 검증 (Blender 5.2.2, 2026-10-25)
실제 host `b.face/box/beam` 호출로 6종 지오메트리 생성, 삼각형 수·bounds·UV 변 길이 비교 실행. Python 구문 검사 통과.

| 종류 | variant | tris | 미러·범퍼 포함 X/Y/Z 크기 m |
|---|---:|---:|---|
| 유럽 둥근 해치백 | 0 | 1312 | 1.740 / 3.316 / 1.445 |
| 유럽 각진 해치백 | 1 | 1292 | 1.800 / 3.756 / 1.440 |
| 일본 경차 | 2 | 1368 | 1.655 / 3.411 / 1.680 |
| 삼륜 화물차 | 0 | 746 | 1.380 / 2.580 / 1.590 |
| 스쿠터 | 0 | 860 | 0.730 / 1.835 / 1.305 |
| 배달함 스쿠터 | 1 | 944 | 0.730 / 1.955 / 1.305 |

- 6종 모두 1500 tris 이내. 최저 Z 절댓값 < 1e-7m(부동소수점 오차), 타이어 접지.
- 원본 UV API의 실제 면 변별 텍셀 밀도 상대 오차 최대 0.0000024; 32px/m 대비 ±10% 기준 이내.
- 승용차 바퀴 주변 외판을 잘라 실제 반원형 열린 휠하우스와 내부 어두운 면 구성. 16각 타이어+12각 허브, 경사 전후창+분리된 측창, 문손잡이·미러·범퍼.
- 삼륜차는 적재함 바닥·3개 옆판·상자, 스쿠터는 핸들·두 거울·안장·발판·스탠드로 구별.
- 지오메트리 검증만 수행. root 최종 bpy 렌더·재질 대비·FBX roundtrip·Unity 임포트·그래픽 게이트 미실행. 자기 검증을 최종 그래픽 PASS로 취급하지 않는다.

## R2/R3 시각 결함 수정 기록
- R2: 전후 fascia를 닫고 작은 라디에이터 그릴과 슬랫 추가. 어깨 cap와 옆판이 겹치던 검은 허리선 제거. 도어선을 추가하고 문손잡이를 외측으로 옮김.
- R3: 전후 fascia 깊이 0.11m에 맞춰 옆판 span을 양끝에서 0.11m 줄여 맞댄 이음으로 수정. 기존에는 fascia 전후면과 옆판 끝면이 동일 평면에서 겹쳤음을 코드로 확인. 검은 수직 모서리 결함 원인이라는 판단은 렌더 재검증 전 추론이다.
- 타이어는 root가 제공하는 `rubber` 실제 사진 alias, 허브는 밝은 `trim`으로 분리. 타이어 12→16각·허브 8→12각으로 바꿔 외곽 계단을 줄임. 모든 바퀴 공용 함수 변경이므로 삼륜차와 스쿠터도 위 표처럼 tris 증가.
- R3 실제 host API preflight: 6종 모두 1500 tris 이하, 접지 오차 <1e-7m, UV 밀도 최대 상대오차 <0.0000024. 위 표는 R3 재측정값.
- R3 최종 사진 아틀라스·렌더·독립 그래픽 재판정·Unity 확인은 root 담당이며 이 작업에서 수행하지 않음. R1/R2 독립 게이트는 모두 시각 마감 미통과로 기록되어 있음.

## 모터 R2 — 2026-10-25 독립 게이트 결함 보완
- 범위: `_three`, `_scooter`만 수정. `parked_car`와 공용 wheel 함수는 R3 보류 상태 그대로 유지.
- 삼륜: 운전실 하단을 0.52m로 올려 바퀴 간섭을 없애고 앞바퀴를 -Y로 0.20m 옮김. 두 포크·가로 차축·곡면 흙받이·뒤차축/서스펜션 받침 추가. 문 경계·승하차 발판 추가.
- 스쿠터: 아래의 1.33m 긴 사각 프레임을 발판 안쪽 0.62m 짧은 프레임으로 변경. 양쪽 포크·앞차축·뒤 스윙암/차축 추가. 양쪽 센터스탠드 발을 Z=0에 닿게 수정.
- 배달 스쿠터: 안장을 0.52m로 줄여 뒤 상자와 분리. 랙 높임·네 대각 받침·두 장착블록·옆 고정쇠 추가. 상자와 안장 사이 실제 0.12m 간격.
- 실제 host preflight: 삼륜 930 tris / 1.380×2.660×1.590m, 스쿠터 944 tris / 0.730×1.835×1.305m, 배달 스쿠터 1124 tris / 0.730×2.000×1.305m. 미러·펜더·랙 포함 bounds. 바닥오차 <1e-7m, 32px/m UV 최대상대오차 <0.0000032. parked 3종은 1312/1292/1368 tris로 불변.
- 모터 R1 독립게이트는 6~6.5점 미통과. 이 수정본 최종 렌더·모터 R2 독립 판정·Unity 검증은 미실행; root 담당. 표면 반복무늬는 지오메트리에서 수정하지 않았다.

## 삼륜 최종 R3 — 나머지 5종 변경 없음
- motor-gate-r2 front/side 직접 확인. 실제 이전 앞·뒤 타이어 모두 최저 Z=0이므로 차 앞을 내리거나 지면에 박는 수정은 하지 않았다. 중앙 앞바퀴와 카메라에 가까운 뒤바퀴가 다른 X에 있어 약간 내려다보는 side 렌더의 화면상 바닥선이 달라질 수 있다(추론). 정확한 비교는 수평 정사영 side 카메라가 필요하다.
- 삼륜 앞바퀴만 하단 3cm 내 베벨의 접지 폭을 넓혀 측벽까지 Z=0으로 접지. 접지 형상 변경 후 삼각면을 host face에 넣어 UV 재투영. 최초 UV 이후 좌표를 바꾼 시도는 밀도 검사에 실패하여 폐기했고, 최종 방식은 통과했다.
- 측창에 얇은 쿼터글라스 분할대·상하 창틀, 전면 상단 프레임·정지한 와이퍼 추가. 문 하단 경계 metal, 손잡이 trim으로 명도 분리.
- 최종 실제 host preflight: 삼륜 1026 tris, bounds 1.380×2.660×1.590m, 접지 오차 <1e-7m, UV 최대상대오차 0.0000012. 나머지 5종 tris와 bounds 불변.
- R2 스쿠터 2종은 독립 정적 그래픽 판정 7점 YES; 삼륜은 6.5점 NO였다. 삼륜 이 최종 수정본의 렌더·독립 판정은 root 담당이며 아직 수행하지 않았다. Unity 검증도 미실행.
