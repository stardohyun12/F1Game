# 카트 v6b — 도현 승인 필요

- FBX `kart_v6b.fbx` + 텍스처 `kart_v6b.png`를 함께 사용. 승인 전 F1/Assets 투입 금지.
- 텍스처만 수정. FBX는 새 PNG 경로를 연결하려 재출력했다. 기존 v6 파일은 유지.
- 4096×1024 RGB, 기존 UV 그대로. 번호판 획 보존을 위해 원본 대비 가로·세로 4배(밀도 128 texel/m); 큰 명암 덩어리와 노이즈 블록의 월드 크기는 유지. 타이어·금속은 모든 해당 텍셀이 R=G=B. 플라스틱 주황빨강, 시트 회갈, 번호판 흰색/07.
- 명암 3단, 노이즈는 RGB 공통 배율 0.96/1/1.04. 색상 노이즈 없음(유색 면의 8비트 반올림 오차 제외).
- 원본 정비소 팔레트 32칸을 보존하고 재질별 램프 47칸 추가: 총 79칸, PNG 실제 사용 47색. 이전 32색 제한보다 이번 색 교정 지시의 팔레트 추가 허용을 우선했다.
- QA/프로그래밍 임포트 필요: Unlit, Base Map=새 PNG, Tint 흰색, sRGB 켬, Point 필터, 압축 없이 먼저 비교. 기존 재질의 녹색 Tint/버텍스 컬러 곱/조명 재적용 여부도 확인.
- Blender에서 FBX 텍스처 경로·UV·좌표·피벗·명칭·tris 검증. Unity 임포트/씬 결과는 확인하지 않았다.
- 재현 스크립트: `art/source/kart-v6b/{probe,recolor,export_render,package}.py`.
- 생성형 AI 이미지 사용 없음. 기존 프로젝트 모델과 코드로 그린 표면만 사용.
