# D-124 검사 범위

`check_asset.py --shape cargo`는 GLB의 실제 위치·노드 변환·UV를 읽는다. 모든 삼각형의 월드→UV Jacobian 특이값 두 축으로 텍셀 밀도를 검사한다. 곡면에도 기존 밀도 허용 오차를 그대로 적용한다.

- 여섯 방향: 월드 법선의 절댓값이 가장 큰 축과 부호로 분류하여 각 방향 최대 면적 삼각형을 대표로 선택한다. 대표 여섯 UV 경계 상자는 서로 달라야 하고 양의 면적 겹침이 없어야 한다. 기존 `beveled-box`의 0.98 법선·투영 면적 10% 기준은 그대로 보존한다.
- 이는 실제 여섯 방향 대표 영역의 분리 증거다. 전체 UV 섬의 겹침 없음, 인쇄 의미, 표면 manifest의 전체 커버리지를 증명하지는 않는다.
- 8×8 창이 가능한 선언 영역은 기존 stride 1 검사를 그대로 한다. 와인병처럼 좁은 영역은 `min(8,w)×min(8,h)`의 보조 창에서 2색 이상을 요구한다. JSON에 실제 창 크기, 정규 8×8 창 수, 좁은 보조 창 수를 따로 기록한다. 좁은 영역을 8×8 검사 통과로 보고하지 않는다.
- 좁은 영역은 종전의 무조건 크기 오류에서 위 보조 검사로 바뀌었다. 단색 거부 및 두 색 보조 검사 통과 사례는 회귀 스크립트에 포함했다.
- 64² PNG, 공용 팔레트, 내장 PNG 일치, Point, provenance 해시, 삼각형 예산, 실측 치수, 바닥 중심 피벗 검사 유지.
