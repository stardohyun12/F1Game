# PD 1720 — 기존 결함과 식별 요소

원문: `../2026-10-23-cargo-set/visual-gate.md`. 아래를 제작 전에 목록화했다. D-124 64px/m·960×540 유지. 최대 3판, 각 판 수치 검사와 별도 평가자 이미지 게이트를 보존한다.

| 종 | 기존 결함 3개 | 텍셀·실루엣 집중 요소 |
|---|---|---|
| 계란 4 | 평평한 갈색 기둥 / 내용물과 포장 색이 같음 / 측면·축소에서 계란 단서 없음 | 뚜껑 창/틈 안의 크림색 둥근 알 머리 줄. 30구 종이판 비례 유지 |
| 생선 5 | 눈·아가미·지느러미 없음 / 파란 동일 블록이 냉매처럼 보임 / 앞벽에 가림 | EPS 상자 위의 밝은 얼음·비닐 접힘과 갈라진 꼬리 실루엣 |
| 케이크 6 | 창의 미세 노이즈 / 갈색 각뿔 장식 / 축소에서 흰 상자로만 보임 | 투명창 안 크림색 띠·붉은 딸기 점 |
| 상자 8 | 뚜껑 검은 틈 / ↑↑가 십자 / 넓은 면과 사각 얼룩 | 이번 범위는 ↑↑만: 삼각 머리를 넓히고 줄기 길이를 줄임 |
| 와인 7 | 고정 반사띠 / 단순 캡 / M 판독성 | 지시대로 기존 파일 유지 |

선행 방법: 기존 v03→세트 파이프라인을 그대로 재사용한다. CC0 사진 바탕·공용32색·분리된 정보 스탬프·접힘 AO를 유지하고, 식별에 쓰이지 않는 정보를 줄인다. 실제 치수와 팔레트·밀도를 임의로 키워 읽힘을 만들지 않는다. 1초 식별은 독립 평가자의 첫인상 판단이며 시간 계측 실험으로 표현하지 않는다.
