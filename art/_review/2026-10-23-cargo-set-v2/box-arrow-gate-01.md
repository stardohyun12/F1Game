# 상자 옆면 인쇄 독립 시각 검토 — 2026-10-23

- 검토 근거: `box/right.png`, `box/close.png`를 `view_image`로 직접 확인했다. 코드·제작 설명·기존 보고는 읽지 않았다.
- 첫인상: 운송 라벨과 중앙 테이프가 붙은 갈색 택배 상자다. 옆면의 검은 인쇄는 짧은 줄기가 달린 픽셀 나무 두 그루로 먼저 읽히며, 위쪽 화살표로도 해석된다.
- **방향을 분명하게 전달하는가: 아니오.** 위쪽을 암시하지만, 넓고 계단진 머리와 짧은 몸통이 나무 형태와 겹쳐 운송 방향 표식으로 즉시 확정하기 어렵다. 특히 `close.png`의 비스듬한 옆면에서 혼동이 커진다.
- **물체 전체: 7/10.** 상자 형태·라벨·봉합 위치는 잘 읽히지만, 인쇄 의미와 표면 재질 표현에 모호함이 남는다.

| 구체적 결함 | 위치와 관찰 |
|---|---|
| 1. 검은 기호의 실루엣이 나무와 겹친다 | `right.png` 옆면 중앙 두 기호. 넓은 계단형 머리 아래에 짧은 줄기가 붙어 있어 화살촉·긴 축의 구분이 약하다. |
| 2. 중앙 봉합부가 두꺼운 별도 판처럼 보인다 | `close.png` 상단 중앙의 긴 띠. 가장자리의 단차와 진한 선 때문에 얇은 포장 테이프보다 덧댄 판재로 읽히는 부분이 있다. |
| 3. 표면의 사각 얼룩이 재질보다 반복 무늬로 보인다 | `close.png` 윗면과 앞면에 흩어진 각진 색 패치. 비슷한 크기와 직선 경계가 두드러져 종이의 얼룩·마모라는 인상이 약하다. |

확인 방법: 위 두 PNG를 열어 정면 기호의 실루엣과 사선 화면의 판독성을 비교한다. 남은 이슈: 방향 기호의 즉시 판독성. Unity·Play·실제 게임 거리에서의 판독성은 검증하지 않았다. 피드에는 게시하지 않았다.
