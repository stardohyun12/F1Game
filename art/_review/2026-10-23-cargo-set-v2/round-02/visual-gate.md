# Round 02 독립 시각 게이트

## 첫인상 고정 기록 — 클로즈업 보기 전

960×540 장면 PNG 세 장을 원본 크기로 직접 보았고, 자르기·확대 없이 왼쪽 아래 도로 위 물건만 판정했다. 실제 1초 노출·반응시간 측정은 하지 않았다.

| 코드 | 첫인상으로 떠오른 종류 |
|---|---|
| B | 열린 상자에 든 동그란 케이크. 흰 윗면에 갈색 장식이 박힌 디저트로 보인다. |
| C | 흰 달걀이 줄지어 든 달걀판. 길쭉한 흰 알들이 반복되는 포장으로 보인다. |
| E | 길쭉한 생선 한 마리가 든 얕은 나무 상자. 꼬리와 몸통이 먼저 읽힌다. |

위 세 줄은 클로즈업과 기준 원화를 열기 전에 파일에 먼저 저장했다. 이후 관찰로 이 첫인상을 수정하지 않는다.
## 판정

| 코드 | 작은 화면에서 즉시 종류 식별 | 점수 | 이유 |
|---|---|---:|---|
| B | 예 — 케이크 | 7/10 | 흰 원형 윗면과 세 장식이 디저트로 읽힌다. 케이크 옆면과 상자가 같은 밝기로 뭉쳐 전체 실루엣은 다소 둔하다. |
| C | 예 — 달걀판 | 7/10 | 흰 알이 줄지어 반복되는 모습이 종류를 전달한다. 작은 화면에서는 개별 알보다 세로로 촘촘한 무늬가 강하다. |
| E | 예 — 생선 상자 | 8/10 | 밝은 상자 속 어두운 몸통과 갈라진 꼬리가 서로 분리되어 세 종류 중 형태가 가장 빠르게 읽힌다. |

점수는 제공된 정지 장면에서의 식별성과 기준 원화와의 시각적 어울림에 대한 주관적 평가다. 예/아니오는 위 첫인상에 근거하며, 클로즈업을 본 뒤 첫인상을 덮어쓰지 않았다. 실제 1초 측정값이 아니다.

## 구체적 결함 — 코드별 3개

| 코드 | 위치 | 관찰한 결함 |
|---|---|---|
| B | 상자 상단 테두리와 좌우 바깥 모서리 | 검은 윤곽선이 너무 또렷하다. 기준 원화의 건물·차량은 면의 명암과 픽셀 질감으로 경계가 생겨서 이 상자만 선으로 그린 장난감처럼 튄다. |
| B | 케이크 앞쪽 옆면과 상자 앞 바닥 | 크림색·베이지색 값이 겹치고 상자 전면 가로선이 원형 몸통을 가로막는다. 작은 화면에서는 케이크 높이와 포장 두께가 합쳐져 짧은 통처럼 보인다. |
| B | 케이크 윗면 세 장식 | 장면에서는 갈색 점 정도로 남는다. 클로즈업에서 보이는 초록 꼭지와 붉은 과일 형태가 사라져 신선한 과일의 인상이 약하다. |
| C | 알이 모인 중앙 전체 | 동일한 크기·높이·간격의 긴 알이 빽빽하다. 작은 화면에서 각 알의 아래 경계가 사라져 흰 세로줄 또는 옥수수 알 같은 반복무늬가 된다. |
| C | 달걀판 앞·좌우 상부 프레임 | 가늘고 높은 사각 테두리가 알 앞을 가로지른다. 달걀을 받치는 오목한 포장 구조보다 전시 케이스나 울타리 같은 외곽이 강조된다. |
| C | 클로즈업의 알 윗부분·앞쪽 알 | 각 알의 각진 면과 밝은 면이 같은 리듬으로 반복되어 껍데기보다 깎은 돌처럼 단단해 보인다. 기준 원화의 거친 질감과 별개로 알의 둥근 인상이 약하다. |
| E | 생선 몸통 아래쪽과 머리 | 어두운 배·지느러미·몸통이 한 덩어리로 합쳐진다. 장면에서 꼬리 외의 생선 특징은 거의 남지 않고, 눈과 아가미는 식별에 기여하지 못한다. |
| E | 상자 바닥의 흰 조각들 | 클로즈업에서는 각진 얼음 같은 조각이 보이지만 장면에서는 밝은 바닥에 묻힌다. 생선을 담은 신선식품 상자라는 보조 단서가 약하다. |
| E | 상자 앞 벽과 도로 접점 | 앞 벽이 밝은 직사각형 띠로 튀며 접지 그림자는 주변 차량보다 약하게 느껴진다. 도로 공간에 놓인 물건보다 화면 위에 붙인 작은 아이콘처럼 보인다. |

## 기준 원화와 비교

세 종류 모두 따뜻한 아이보리·갈색과 단순한 면 구성은 기준 원화에 대체로 어울린다. 다만 기준 원화의 입자가 굵은 질감에 비해 상자의 얇고 또렷한 모서리와 규칙적인 면 분할이 깨끗하게 남는다. B의 검은 테두리가 가장 두드러지고, E는 꼬리 실루엣과 명암 대비로 축소 상태에서 가장 유리하다. 종류 식별은 세 개 모두 예이지만 이 결과는 게임 적용·움직임·조명까지 통과시킨 판정이 아니다.

## 확인 범위·증거·독립성 한계

- 직접 연 이미지: `blind/B-scene.png`, `blind/C-scene.png`, `blind/E-scene.png` → 첫인상 파일 저장 → `blind/B-close.png`, `blind/C-close.png`, `blind/E-close.png` → `art/concept/lofi-styles-2026-10-13/02_warm_street.png`.
- 장면 세 장은 제공된 960×540 전체 이미지를 원본 크기로 보았으며 확대·자르기를 하지 않았다. 클로즈업은 따로 제공된 파일을 열었다.
- `index`, `compare`, 제작문서, 기존 코드, 이전 판정은 읽지 않았다. 다만 필수 운영문서를 먼저 읽는 과정에서 `docs/CONTROL.md`의 일반 화물 종류 이름(계란·생선·케이크)이 노출됐다. 코드별 대응은 노출되지 않았지만 이 선행 정보 때문에 완전 무정보 블라인드로 인증할 수 없다.
- Unity·Play·씬 저장·컴파일·성능·폴리 수·치수·물리는 실행하거나 검증하지 않았다. 실제 1초 노출 또는 인지시간 측정도 하지 않았다.
- 이 파일만 작성했으며 피드 게시를 하지 않았다. 남은 이슈는 위 시각적 결함과 독립성 제한이며, 엄격한 무정보 판정이 필요하면 이 파일 및 화물 종류가 적힌 상태 문서를 읽지 않은 별도 리뷰어의 재검토가 필요하다.
