# Imagegen 작업 기록 — D-123

내장 imagegen 사용. 아래는 사용 프롬프트의 작업별 요구사항 기록이다(원문 전사 아닌 정리본). 생성 이미지는 원본 파일 그대로 보존하고, 코드로 슬롯 크기·화면 구성을 출력했다.

1. `materials/paper.png`: 1990년대 배달 사무소의 바랜 회백색 종이 스캔. 정면, 화면 전체가 종이, 섬유·옅은 얼룩·접힌 자국, 중앙은 읽기 좋게. #D7CFB9/#B8AE96. 글자·도형·만화 테두리·둥근 모서리·판타지 양피지 금지.
2. `materials/stamp.png`: 실제 고무도장의 얇고 불균일한 이중 원 테두리, 잉크 번짐·누락, 바랜 녹슨 적색 #854D43. 투명 배경·빈 중심. 글자/숫자/종이/그림자 금지. export에서 일반 stampRing은 알파 유지 흰 마스크, stampSprite는 원색 유지.
3. `cargo-concepts.png`: 기준 원화 02_warm_street를 스타일 참조로 사용. 5행×3열 TOP/FRONT/SIDE. 상자40×30×28cm, 케이크지름24×12cm, 닫힌 6구 계란판24×16×8cm, 와인8×8×30cm, 생선상자50×22×15cm. 생활 비례·실물 형태·64px Point 질감 의도, 플랫 셰이딩, 앞 송장·옆 ↑↑, ≤2,000tris 제작 가능한 디테일. 장난감 비례·큰 눈·과장된 크림·통통한 병·사진 질감·노멀맵 금지.
4. `cargo-concepts-v02.png`: 원화 유지, 케이크 투명 덮개 제거 및 앞 받침 라벨·옆 ↑↑, 와인 SIDE 목 아래 작은 ↑↑ 배송 태그 추가.
5. `reference/street-no-hud.png`: 기준 원화의 기존 HUD(좌상 DELIVERIES 1/3, 좌하 CARGO OK와 작은 상자 아이콘, 우하 38 km/h)만 제거, 풍경·자동차·자동차 위 화물·빛·구도·픽셀 질감 유지. 한글은 별도 HTML에 Galmuri로 배치.
6. `materials/packing-box.png`: 화물 원화 상자를 참조한 별도 포장용 컷아웃. 실제40×30×28cm, 정면 송장·우측 ↑↑·윗면 테이프가 동시에 보이는 3/4뷰. 바랜 골판지·거친 픽셀 질감, 투명 알파. 호출용 영문 주석·화살표 선·바닥·그림자·장난감 모서리 금지. 결과에 희미한 주변 반투명 픽셀이 있어 엔진 합성 시 테두리 확인 필요.
