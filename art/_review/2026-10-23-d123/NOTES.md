## 전달 계약

- `paperPanel`, `paperCard`, `enamelPlate`, `stampSprite`: 원색/흰 틴트. 나머지: 중립 회색·흰색에 코드 틴트. 기존 tint가 D-121 고채도 색이면 D-123 바랜 색으로 프로그래밍 변경 필요.
- `stampRing`, `stampSprite`: border=0, Simple, 정비율. 글자는 코드 별도. 슬롯 300px는 유지하되 목업 포장 도장은 150px 표시 제안이므로 코드 표시 크기 확인 필요.
- 9-slice 여백은 동일하지만 종이 섬유·얼룩은 중앙을 늘리면 왜곡될 수 있다. PNG만 교체한 엔진 결과는 미검증. 9-slice 모서리 보존과 재질 샘플링은 별개다.
- 주행 HUD에는 enamelPlate를 사용하지 않는다. 슬롯 호환용 낡은 법랑 표본은 제공하되 작은 흰 글자만 주행 시안에 사용.
- 화물 ≤2,000 tris 예상: 상자240 / 케이크1,440 / 계란판960 / 와인560 / 생선+상자1,520. **실측 아님.** 피벗 바닥 중심·m·Y-up.
- 64×64 아틀라스·6면 별도 UV는 **후속 제작 규격**이며 고해상도 원화에 픽셀 질감을 표현한 것을 실제 64px 제작물이라고 부르지 않는다. 앞 송장 / 뒤 바코드 / 좌 무지 / 우 ↑↑ / 위 개봉선 / 아래 제조표기. 케이크·병 같은 곡면은 방향별 UV 구역으로 나눈다.
- 이미지의 TOP 라벨·SIDE 각도는 정확한 UV 배치 도면으로 쓰지 않는다. 포장 목업의 상자는 앞 송장·우측 ↑↑·위 테이프가 분리되어 읽히는 구도를 따로 제공.
