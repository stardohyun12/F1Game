# 코스 UI 구현 메모

상태: **도현 승인 필요 / QA·프로그래밍 임포트 필요**. UI팀은 정적 PNG·스크립트·HTML만 제작했다. Unity, 런타임 UI 변경, 씬·프리팹 저장, `F1/Assets` 쓰기, git commit/push는 하지 않았다.

## 세계 표지

치수·UV·폰트 크기 전체 표: [tables.md](tables.md). 새 ID 7개는 제안용 식별자이고 기존 UITheme 슬롯이 아니다. 원문 이름은 `signs.json.title`, 글자 레이어의 실제 축약 표기는 `letters[].text`로 분리했다. `LoneHouse`에는 큰 ‘외딴집’과 작은 ‘04 언덕위 / 초인종 →’를 쓴다.

- PNG 모두 128×64 RGBA, Point, Clamp, 무압축, sRGB 색. 모든 활성 면 32px/m. 기본 재질은 기존 세계의 동일 주변광/안개 규칙을 적용하고 Normal/Metallic은 사용하지 않는다. 이번 투영은 조명·안개 영향을 시뮬레이션하지 않았다.
- `active_xywh`는 PNG 위쪽 기준. `uv_bounds_bl`은 Unity 아래쪽 기준 L,B,R,T. 활성 면이 112×64라면 물리 표지면 3.5×2m에 UV (0,0)~(.875,1)만 쓴다. 투명 padding까지 3.5m에 늘리면 32px/m가 깨진다.
- 기존 fork 판 3.2×0.9m에 그대로 맞추지 않는다. 새 제안은 각 3.5×2m, 별도 지지대에 병렬 또는 분리 배치. 원래 기둥에 상하 2장을 쌓으면 높이/차량 시야 문제가 생기므로 아트팀이 실제 지지대 비례를 확인해야 한다. 표지면과 접근 방향 각도는 30° 이내를 목표로 한다.
- 집 2종 2.5×2m는 **길가 식별판**이며 작은 문패의 실물 크기를 주장하지 않는다. 작은 문패로 바꾸면 20m 이름 판독을 포기하고 진입 시 HUD에 목적지를 유지해야 한다. 크기 승인 항목이다.
- mipmap off를 정적 기준으로 제안한다. 주행 중 반짝임은 미확인; mip를 켜는 대안은 텍스트가 뭉개질 수 있어 10/15/20m 캡처를 다시 비교한다. 흐림 필터로 임의 해결하지 않는다.
- 9-slice 없음. 글자는 Galmuri11 폰트로 PNG에 구웠고 글자/바탕을 `layers/`로 분리 보관했다. 3D TMP를 중복으로 덮지 않는다. 기존 ForkSign TMP 제거/비활성은 프로그래밍팀 적용 항목이다.

## 거리 가독성 / 밀도 예외 제안

세계와 글자 모두 **32px/m 유지, 현재 글자 영역 예외는 요청하지 않는다**. 같은 물리 글자를 64px/m로 굽는 것만으로 화면의 글자 높이는 늘지 않는다. 현재 글자 모양은 12texel 기본 격자에서 제작되어 추가 texel은 반복이다.

카메라 설정 스냅샷은 FOV 50~62°, chase distance 4.2m. 정면·30° 측면, 차–표지 10/15/20m 총 42장이다. 정면 공식은 `screenHeight = 540 × physicalHeight / (2 × (distance+4.2) × tan(FOV/2))`. 측면은 표지 네 모서리를 각각 원근 투영했다. 수평 거리를 광학 깊이로 근사하므로 경사·카메라 pitch·측방 배치가 있는 실제 씬의 정확한 측정은 아니다.

독립 검토: 20m에서 ‘지름길/급경사’, ‘해안길/완만’, ‘MART’, ‘골목 끝집’, ‘외딴집’은 읽혔다. 12texel 보조문구·번호는 미통과. 지름길 ‘화물주의’도 10m에서 시선 고정 시에만 읽혔다. **세계표지 판정은 아니오 7.5/10**, HUD 보완 8.5/10이다. 모든 문구의 20m 판독이나 실제 고속 주행 통과라고 보고하지 않는다.

갈림길 45m 전부터 HUD 둘째 줄을 ‘지름길: 급경사 · 화물 주의’로 교체하고 갈림길 통과 후 거리 표기로 되돌리는 안을 제안한다. 72km/h에서 10~20m 구간은 0.5초뿐이다. 경고를 가까운 표지 작은 글씨에만 맡기지 않는다. 발동 거리·실제 분기 방향은 런타임 경로로 산출해야 하며 현재 목업 값은 예시다. 아직 구현하지 않았다.

## 기존 UI 슬롯 / 화면 픽셀

[tables.md](tables.md)의 10종은 ui-final에서 변경 없이 재사용한다. 원본 PNG 경로는 `../2026-10-23-ui-final/sprites.json`. 승인도 별도로 완료된 것으로 간주하지 않는다.

- 원본 여백 L/B/R/T 유지. paperPanel/paperCard/slipHeader는 **Tiled**로 종이결을 늘리지 않는다. 나머지는 표의 Simple/Sliced를 사용한다.
- 정적 목업의 소스 표시 비율 0.5×: 원본 종이 4px 셀이 논리960의 2px로 보인다. 프로그래밍 제안은 Canvas reference resolution 960×540, referencePixelsPerUnit100, spritePixelsPerUnit200, pixelsPerUnitMultiplier1. 실제 Unity의 tiled/sliced 배율은 미검증이다.
- Image.color 흰색. 기존 테마의 색 곱하기/tintColorBlock을 끄거나 원본색을 보존하도록 변경 필요. 원본 투명 alpha는 유지한다.
- RectTransform 위치·크기는 정수, 이 시안의 UI 좌표는 짝수 픽셀. 화면 1920×1080은 Nearest 2×, 2880×1620은 3×. 임의 화면 비율 확대 대신 정수 viewport와 letterbox/pillarbox를 사용한다.

|---|---|---|---|
| 목적지·진행 | Galmuri11 | 24px | (24,24), 둘째 줄 (24,58) |
| 시계 / 남은 시간 | Galmuri11 | 36 / 24px | (808,24) / (808,66) |

폰트 목업은 Galmuri/Pretendard의 12px 원형 이진 마스크를 Nearest 2×/3×했다. TMP SDF를 일반 smooth 설정으로 쓰면 같은 모양이 나오지 않는다. 프로그래밍팀이 bitmap atlas/point 또는 동등한 pixel font 설정을 구성하고 한글·숫자·화살표·₩의 실제 래스터를 캡처 비교해야 한다. atlas/폰트 에셋은 아직 만들지 않았다.

## 두 박자와 공용 시간

| 단계 | 꼭 유지할 것 | 전환 제안 |
|---|---|---|
| 포장 | 하나의 남은 시간, 화물, 보호/비용 | 이미 구현된 TimeLeftLabel과 전역 시계를 한 자리로 통합. 포장 중 감소 유지 |
| 갈 때 | 시간, 목적지, 화물 상태 | 속도는 작은 보조. 긴급 상태도 동일 위치·크기, 색+짧은 문구만 변경 |
| 도착 성공 | 완료 시점 시간, 화물 상태, 고객 반응 | 아래 3안 중 하나만 적용. 마지막 배달 성공 이벤트에서만 |
| 정산 | 영수증의 실제 확정 수치 | 기존 정산 흐름 재사용. 새로운 점수·보상 만들지 않음 |
| 돌아오는 길 | 기본 HUD 없음 | 정산 닫기 → 자유 귀로. 4초 진입 문구 뒤 0%. 필요시 길안내만 |

시간 포맷 제안은 공용 `max(0, ceil(remainingSeconds))`의 m:ss. 현재 PackingScreen 스냅샷은 `(int)t`로 버림하므로 화면 간 1초 차이를 없애야 한다. 만료 판정은 포맷된 문자열이 아닌 원래 실수 타이머로 한다. 도착 기록 2.8초는 성공 이벤트의 잔여 시간을 0.1초 단위로 버린 값으로 제안한다. UI가 자체 카운터를 돌리지 않는다.

경고 임계값은 기존 포장의 30초 미만 유지 제안. 색은 호박색+문구/막대; 0:08 목업은 색만으로 뜻을 전달하지 않는다. 루프 경고음·점멸 애니메이션은 제안하지 않는다.

귀로는 D-125의 정산 이후 단계다. 기존 Returning enum 이름만으로 이 흐름이 구현됐다고 간주하지 않는다. 실제 입력/카메라/충돌/타이머 정지·다음 주문 연결은 프로그래밍팀 확인이 필요하다. 현재 귀로 목업은 같은 전망 캡처를 재사용했으며 실제 반대 방향 주행을 촬영하지 않았다.

사운드·애니메이션은 설명만 작성했다. 정지 프레임은 960×540과 정확한 2×. 조건 제안: 마지막 배송 성공 + 0 < 남은 시간 ≤ 3초일 때 ‘아슬아슬’; 화물 상태 ≥90%일 때 ‘무사’, 아니면 ‘도착’. 실패·만료·중간 배달에는 이 성공 문구를 띄우지 않는다. 결과를 바꾸는 보상 로직은 추가하지 않는다. 음성 재생 시 자막은 유지한다.

## 적용 후 필요한 확인

1. 승인된 판 치수·UV로 실제 10/15/20m, FOV50/62, 정면/30°를 Play 캡처. 낮은 해·해무·속도에서 주요 단어와 주의 문구를 따로 판정.
2. 갈림길 지름길/해안길 화살표가 실제 도로 방향과 일치하는지, 큰 판과 기둥이 차·풍경을 가리지 않는지 확인.
3. 포장→주행의 동일 시간 값, 0초 만료, 도착 성공 시간 고정, 실패 문구, 화물 90% 경계 확인.
4. 정산 이후 귀로에서 HUD/시계가 사라지고 요청 안내만 뜨는지, 960 Point·한글 실제 래스터·9-slice 반복·바 음영 확인.

이 단계는 본 작업에서 실행하지 않았다. 독립 그래픽 판정과 자동 정적 검사는 `validation/`에 있다.
