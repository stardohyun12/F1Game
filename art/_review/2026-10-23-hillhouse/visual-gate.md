# 독립 시각 리뷰 R2

지정 PNG 7장을 `view_image` 원본 해상도로 직접 열어 비교했다. 제작 코드·브리프·이전 리뷰는 보지 않았다. 아래는 이미지에 대한 시각 판정이며 Unity·실제 거리·게임 조명은 검증하지 않았다.

| 질문 | 판정 |
|---|---|
| 무엇으로 보이나 | 바다가 내려다보이는 가을 들판의 작은 단층집. 의자·화분·빨래와 불 켜진 창 때문에 현재 사람이 사는 집으로 보인다. |
| 사람이 오래 사는 들판의 고립된 작은집인가 | **예.** 가까운 이웃 없이 혼자 놓인 집이고, 벗겨진 문과 벽 하단·생활 소품이 사용 흔적을 만든다. 다만 오래된 느낌은 표면 얼룩에 많이 의존한다. |
| 30~60m 실루엣 판독 | **예.** 세 이미지 모두 붉은 박공지붕·굴뚝·작은 몸체가 분리된다. 60m에서는 의자·화분의 의미가 거의 사라지지만 집 자체는 읽힌다. |
| 30~60m 빛 판독 | **예.** 오른쪽 창이 세 거리 모두 즉시 보인다. 다만 실내 빛보다 밝은 색판처럼 보이는 문제가 있다. |
| 기준 원화와 같은 게임처럼 보이나 | **아니오.** 따뜻한 색과 단순한 형태는 가깝지만, 집의 매끈한 큰 면과 가는 반복 무늬가 기준 원화의 고른 픽셀 질감·입체적인 창과 다르다. 배경에 비해 집만 덜 마감된 인상이 남는다. |
| 종합 | **7/10.** 장소·거주감·원거리 표식은 성립한다. 지붕 재질과 창 깊이, 표면 질감의 일관성이 완성도를 제한한다. |

| 어색한 결함 3개 | 위치·관찰 |
|---|---|
| 지붕이 기와보다 무늬 찍힌 판처럼 보임 | `close.png` 지붕 넓은 경사면. 가는 밝은 선과 회색 얼룩이 반복되고, 기와의 겹침은 처마 끝에 몰려 있다. `composite-30m-960.png`에서도 줄무늬가 먼저 읽힌다. |
| 발광 창의 깊이 부족 | `entry-detail.png` 오른쪽 창. 네 칸이 거의 같은 노란 면이고 유리·커튼·실내의 구분이 없다. 원거리에서도 노란 표지판 같은 인상이 남는다. |
| 벽의 표면 정보가 하단에만 몰림 | `close.png` 정면·오른쪽 벽. 넓은 상부는 균일하고, 하단은 뚜렷한 계단형 갈색 띠로 갈린다. 기준 원화의 벽·석축보다 질감의 밀도 차이가 커서 집이 배경에서 따로 붙은 듯 보인다. |

표면 8종 시트: **7/10.** 색 구분과 큰 형태는 명확하다. 시트의 이름을 가리고 보면 ‘수리·손때·생활 천’ 같은 구체적인 의미는 일부에서 약하다.

| 표면 | 읽힘 평가 |
|---|---|
| 51 벽 | 벽 하단의 오염·박락은 읽힘. 덧칠보다는 젖거나 더러워진 벽에 가까움. |
| 52 문틀 | 페인트 벗겨진 목재로 읽힘. 손이 닿아 닳은 자리보다는 가장자리 전반의 벗겨짐. |
| 53 지붕 | 붉은 도장면의 긁힘·얼룩으로 읽힘. 기와와 국소 수리는 시트 단독으로 불명확. |
| 54 보도블록 | 블록 줄눈과 색 차이 명확. 반복이 규칙적이어서 마모보다는 색 다른 블록에 가까움. |
| 55 겹친 간판 | 위 간판과 아래 남은 글자가 분명하여 덧붙인 이력이 가장 잘 읽힘. |
| 56 도로 | 어두운 보수 패치로 잘 읽힘. 주변 얼룩과 중앙 패치의 구분도 가능. |
| 57 기단 | 석재·모르타르 줄눈은 명확. 어느 부분을 수리했는지는 불명확. |
| 58 천 | 가장자리와 주름 선은 보이나, 시트만 보면 낡은 종이나 패널도 가능. `close.png`의 접힌 빨래 형태가 천으로 읽히게 해 준다. |
