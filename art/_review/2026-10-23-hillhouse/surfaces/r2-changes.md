# 표면 R2 — 독립 게이트 결함 수정

R1 표면 5.5/10 원문은 상위 `visual-gate.md`; 당시 시트·아틀라스·검사는 `r1/`에 보존했다. R2 점수는 재판정 전이며 자체 통과 점수를 붙이지 않는다.

| 슬롯 | R1 결함 | R2 적용 |
|---|---|---|
| 51 벽 | 회청색 박락이 전면에 흩어짐 | PNG y0~41을 크림으로 재도장, y42~63의 옛 도료 경계 한 곳에만 사진 명암을 남김. 상부 벽과 하부 벽이 다른 UV 영역을 사용한다. |
| 52 문틀 | 목재 단서가 약함 | 기존 가장자리·손잡이 접촉 마모 유지. 이 판에서 변경 없음. |
| 53 지붕 | 균일한 줄무늬와 밝은 잔점 | 실물 곡면 기와 사진 `clay_roof_tiles`로 교체. 4m 사진에서 실제 2m를 잘라 32px/m로 변환. #795244/#8a4631/#887963만 사용하며 사진에서 5px 이상 연속된 밝은 세로 대역 중 최대 5개만 남김. 노란색·인공 수평 줄눈 삭제. |
| 54 보도 | 블록 경계가 마모에 묻힘 | 사진의 20×40cm 격자를 실제 32px/m에서 6.4×12.8px로 따라 그려 1px 줄눈을 보강. 사진 명도는 회갈색 3색으로 정리. |
| 55 간판 | 7점 | 유지. |
| 56 도로 | 어두운 띠가 판재 같음 | 세로 띠 삭제, 국소 포트홀을 메운 비직선 경계. 실제 사진의 잔골재는 중앙값 필터로 소수 큰 평균값만 유지. 회색 3색. |
| 57 기단 | 흰색·갈색 위장무늬 | `stone_brick_wall_001` 실제 2.5m 사진 중 2m 영역으로 교체. 사진의 석재 경계를 64px 좌표로 추적하고 각 실물 블록의 평균값으로 면을 단순화. 좁은 회갈색 명도 사다리·줄눈·한쪽 짧은 모르타르 보수. |
| 58 천 | 6.5점 | 바랜 밝은 천과 2개 접힘선 유지. |
