01

현재 UI 감사

V는 화면 관찰, C는 코드 근거. 원본 캡처를 바꾸지 않고 별도 파일에 주석을 겹쳤습니다. 작은 글자 환산은 1920 UI를 960으로 줄였을 때의 조건부 em 크기입니다.

주문판 — 전화 아래 노출 부분만 감사

原 캡처: 20261023-qa-0-board.png

  1. V · 짙은 보드 + 밝은 카드 + 전화가 겹쳐 단계 구분이 흐림. 종이 전표 한 층으로 정리.
  2. V · 카드가 전화에 가림. 전체 카드의 위계·줄바꿈은 [미확인]; 전화 없는 캡처 필요.
  3. V/C · 하단 안내가 작고 “출발”은 실제 포장 진입과 다름. “포장하러”로 행동 명시.
  4. C · 주문판부터 90초가 흐르지만 시작 규칙이 보이지 않음. 공용 타이머에 단계 안내.

긴급전화 — 같은 시간은 한 군데만

原 캡처: 20261023-qa-0-board.png

  1. V/C · 1:22 / 1:21 중복. 전화 CeilToInt, HUD FloorToInt. 한 데이터·한 표기로 통일.
  2. V/C · 배달지·화물·보상이 작고 옅음. 코드 22px → 960 기준 약 11px em.
  3. V · 넓은 빨강 띠와 둥근 제목이 D-123과 불일치. 얇은 잉크선·짧은 긴급 표식으로.
  4. C · “받을게요!”는 주문 선택 후 보드 복귀. “이 주문 추가”와 선택 결과를 명시.

포장 — 작업면과 판단 정보의 위계

原 캡처: 20261023-1551-card-Order_04_WeddingCake.png

  1. V · 짙은 남색 패널이 화면을 분할. 작업면 주변을 바랜 작업 전표로 통합.
  2. V · 세 재료 비용·합계와 좌측 예상 비용이 동시에 경쟁. 합계 우선, 내역 접기.
  3. V/C · 면 설명은 코드 16px → 960 기준 약 8px. 작은 주석 대신 24px 핵심 행동.
  4. V · 큰 빨강 “앞”이 작업 화물을 덮음. 면 외곽의 작은 방향 라벨로 이동.
  5. V/C · 이 캡처에 “배치하기”가 안 보임. 코드 버튼·타이머 위치 충돌/배선은 QA 재현 필요.

주행 — 풍경 위 UI 판과 마커

原 캡처: 20261023-flow-3-driving.png

  1. V · 트렁크 화면만 약 7.2%. 기본은 상태 1줄, 상세 화면은 정차/요청 시로 제안.
  2. V · 노란 월드 마커가 지붕·하늘을 가림. 화면 구석 방향 정보로 축소.
  3. V · 목적지 중앙·시간 우측·화물 좌하단으로 시선 왕복. 상단 좌우 고정, 상태는 한 묶음.
  4. V · 0 km/h와 N 판이 큼. 핵심 3정보보다 속도·기어가 강함; 배경 판 제거.
  5. V/C · 큰 초록 상태바 + 별도 경고 5Hz 코드. 상태 단어·숫자, 경고 한 번 전환으로 제안.

정산 — 손에 남은 돈과 돌아갈 행동

原 캡처: 20261023-1536-result-profit.png

  1. V · 큰 종이가 화면 약 80%를 차지하지만 아래 절반은 비어 있음. 세로 영수증으로 집중.
  2. V · 라벨과 값이 양끝. 순이익도 같은 행 위계. 순이익을 첫 줄, 보상·비용을 바로 아래.
  3. V/C · 긴 시간 문장·자동 축소(18~32 코드px). 960에서 약 9~16px; 두 항목으로 분리.
  4. V/C · “다시 / 차고로”만 있음. 정산 뒤 느린 복귀가 없음. “돌아가기”를 주 행동으로.

별도 재현 필요: 전화가 포장 위에 남은 캡처. 현재 소스는 보드에서 전화를 띄웁니다. 호출/종료 경로는 Play로 확인하지 않았습니다.

02

한 판의 화면 흐름

주문판 → (긴급전화 ↩ 선택 갱신) → 포장 → 갈 때
→ 정산 → 돌아오는 길 → 차고에서 다음 주문

전화 거절도 주문판으로 복귀. 전화 없이 포장 가능. 공용 시계는 주문판에서 시작하고 정산에서 끝납니다. 0초 도달은 어느 작업 단계에서도 정산으로 보내는 변경안입니다. 기존 출발 시 실패 처리와 다릅니다.

01 · 주문판

  1. 남은 제한 시간
  2. 목적지·화물 묶음
  3. 선택한 주문과 보상

전화 수락/거절 뒤 이 화면으로 복귀. 포장 진입 버튼을 출발과 구분.

02 · 긴급전화

  1. 누가·무엇을 요청하는가
  2. 기본 보상·긴급 추가금
  3. 공용 남은 시간

위 타이머 하나 유지. 별도 전화 타이머 없음. 수락은 선택 갱신이며 자동 출발 아님.

03 · 포장

  1. 남은 제한 시간
  2. 현재 면·보호 상태
  3. 누적 포장비 / 보상

포장 안에 배치 하위 단계 유지. 배치하기 → 적재 확인 → 출발. 화물 모델 제작 아님.

04 · 주행 · 갈 때

  1. 남은 시간
  2. 다음 목적지·방향
  3. 화물 상태

속도는 보조 정보. F1 속도감은 카메라·근경·소리 담당. 중앙 60%×60%에는 HUD 없음.

05 · 정산

  1. 성공·실패와 화물 결과
  2. 실수령 순이익
  3. 다음 행동: 돌아가기

도착 시 보상·비용 확정 1회. 타이머 종료. 시간 초과도 정산 후 복귀, 즉시 재주문 없음.

06 · 주행 · 돌아올 때

  1. 시간 제한이 끝났다는 확인
  2. 차고 방향: 요청할 때
  3. 도착 후 다음 주문 행동

3정보 동시 상시 표시 아님. 진입 문구 4초 후 숨김 / 안내 키를 누를 때 방향 / 차고에서 주문 버튼.

각 와이어프레임의 번호 목록이 필수 정보 3개입니다. 돌아오는 길의 3개는 진입 / 요청 / 도착 시 나눠 보입니다. 흐름 PNG 시트
