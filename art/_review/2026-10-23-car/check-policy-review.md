# 차량 단색면 검사 기준 재검토

## 근거와 범위

- `docs/team/reports/research-20261023-1522.md:27`의 화물 v02 체크리스트에는 **"어느 8×8 텍셀 창에도 팔레트색 ≥2"**가 실제로 적혀 있다. 최초 차량 검사기는 이 화물 규칙을 그대로 확장했다. 이 출처를 삭제하거나 원래 규칙이 없었다고 주장하지 않는다.
- 1919 차량 지시는 공용 팔레트·64px/m·이유 있는 마모를 요구한다. 화물 v02의 모든 8×8 창 규칙을 차량에 적용하라고 명시하지 않았다.
- 현재 브리프 제작 규칙 6은 **"마모는 이유 있는 곳에만"**, **"전체 노이즈 금지"**이다. 차량의 넓은 도장 패널·윙·좌석에 8×8마다 무조건 색차를 넣으면 빈 면을 잡는 것을 넘어 균일한 잔점을 강요할 수 있다.
- `TASTE.md`의 세월 흔적은 닳음·바램·손때라는 표면의 이유에 있다. 통계량만으로 그 이유와 미적 완성도를 판정할 수 없다.

독립 검토 결론: **기존 화물 검사기·기존 화물 PASS/FAIL은 그대로 유지한다. 새 차량 검사기에만 넓은 면 전체의 단색/거의 단색 방지 조건을 적용한다.** 8×8 단색 창은 삭제하지 않고 위치·개수를 진단 정보로 보존한다.

## 차량 검사 v2

| 조건 | 방식 |
|---|---|
| 검사 대상 | 실제 GLB에서 복원한 면적 ≥0.04m²의 연결된 동일 평면 표면 |
| 팔레트 | 기존 공용 32색 밖 RGB 0, 별도 필수 조건 그대로 |
| 색 변화 | 실제 해당 표면의 UV가 덮는 texel center에서 RGB 2색 이상 |
| 거의 단색 방지 | 주색이 해당 표면 texel의 98%를 초과하면 FAIL |
| 이웃 면으로 속이기 방지 | 패딩·이웃 UV·같은 평면의 떨어진 다른 패널은 통계에 합치지 않음 |
| 불투명도 | 큰 표면에 비불투명 pixel이 있으면 FAIL |
| 8×8 단색 창 | 완전히 해당 표면 안에 든 모든 창을 계속 세고 좌표 기록; 자동 FAIL에는 사용하지 않음 |
| 나머지 검사 | 삼각형 3,000 이하, 전 삼각 두 UV 축 64px/m±10%, 원본 bounds·pivot, 4휠, Point, embedded texture, provenance 모두 변경 없음 |

**0.04m²와 98%는 외부 연구에서 증명된 미술 기준이 아니라 이번 검사기의 명시적인 공학적 최소 검출 기준이다.** 약 164 texel을 차지하는 0.04m² 패널에서 다른 색 1 pixel만 찍어 통과시키는 방법을 막는다. 반대로 모서리 한 줄처럼 이유 있는 국소 변화가 있고 넓은 중앙은 조용한 도장면을 허용한다. 최소 통과가 좋은 마모를 보증하지 않으므로 이미지 기반 독립 게이트는 여전히 필수다.

- `check_car_r02_policy_v2.json`: 동일 R2 export에 새 차량 규칙을 적용한 결과.
- `check_car_selftest_v2.json`: 빈 면 FAIL, 이웃 변화로 구조 FAIL 회피 불가, 다른 색 1 pixel FAIL, 모서리 띠+조용한 중앙 PASS, 떨어진 동일 평면 패널 분리 등 자동검사 결과.

판정 경계를 변경한 기록을 남기며, 과거 FAIL을 새 규칙으로 소급해 PASS로 덮어쓰지 않는다.

## 장부 형식 호환 수정

현재 `art/provenance.csv`는 날짜 열 이름으로 `accessed`, AI 여부로 한국어 `아니오`도 사용한다. 최초 차량 검사기는 `download_date`와 `no`만 허용해 실제 기록이 있어도 FAIL로 판정했다. 이를 `accessed` 또는 `download_date`의 유효 ISO 날짜, `no/false/0/아니오/비AI`라는 명시적인 비AI 값으로 정규화했다. 빈 값·unknown·yes/true/1/예/AI는 계속 FAIL이다. 경로·현재 SHA-256 일치·출처 URL·라이선스·도구·날짜 필수 조건은 유지하고 CSV는 수정하지 않았다. R2 최초 정책 결과의 provenance FAIL은 이 형식 불일치도 포함하므로 단순 미등록이라고 읽으면 안 된다.
