# UI 레퍼런스 스크린샷 — 출처·이용 메모 (2026-11-01)

- **내부 참고·분석 전용. 게임에 넣지 않는다.** 저작권은 각 개발사·배급사에 있다. 저장소엔 가로 640 저해상도 선별본(`ref/`)과 연락판(`_sheets/`)·일부 1:1 잘라낸 조각(`_sheets/crops_*.jpg`, 한 장면의 4~8%)만 둔다.
- 출처 = Steam 스토어에 개발사가 올린 **공식 게시 스크린샷**(스토어 API `appdetails` 의 `screenshots[].path_full`). 직접 플레이 캡처가 아니다 — 개발사가 고른 홍보 컷이라 HUD 가 빠졌을 수 있다.
- Death Stranding 의 주문·결과 화면 2장은 스토어 컷에 없어 [fontsinuse 갤러리](https://fontsinuse.com/uses/67648/death-stranding-video-game) 의 게임 캡처(700px 판)를 썼다.
- Easy Delivery Co. 는 이미 `art/reference/edc-2026-10-26/` 에 9장이 있어 다시 받지 않았다(SOURCES.md 참조).
- 원본 1920×1080 은 저장소 밖(TEMP `ui-2026-11-01-raw`)으로 옮겼다. 다시 받으려면 `_scripts/fetch.py`.
