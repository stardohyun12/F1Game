### 3. 제작 방식 — Blender 부품 19종 → 승인된 조합만 출력

| 부품 | 종류 | 개당 tris 상한(계획) |
|---|---:|---:|
| 벽: 직선·모서리·박공끝·아치·단차 연결 | 5 | 12~80 |
| 창: 직사각·아치·덧문 | 3 | 24~80 |
| 문: 주거·상점 | 2 | 24~80 |
| 발코니: 돌출·매입 | 2 | 120~240 |
| 지붕: 평지붕 테라스·박공·둥근 볼트 | 3 | 120~400 |
| 차양 | 1 | 80 |
| 화분: 낮은형·큰형(단순 식생 포함) | 2 | 80~160 |
| 아래 한 층/지형 접합용 벽 조각 | 1 | 120 |

Blender에서 부품 원본을 만들고 bpy가 **메시 위치·개수·연결**을 조합한다. UV/문·창까지 건물 전체를 비균일 확대하지 않는다. 선택 A/B 공통 팔레트 제안: 벽 `#D9C7A7/#CFA58D`, 청록 `#416B68`, 창 `#303D43`, 지붕 `#A86F50`, 돌 `#96917E`, 창빛 `#E6B66B`. **버텍스 컬러로 큰 면 + 공용 512×512 Point 아틀라스(64px 칸)로 창/진열/얼룩**, 공용 불투명 재질 1개가 기본. B도 재질을 늘리기보다 형상 장식을 더한다. 이전의 큐브 잎·낱장 기와를 대량 모델링하지 않는다.

규격: **1 unit=1m**, 층고 2.8~2.9m, 현관 0.92×2.15m, 폭 6/8/10/12m, 깊이 8/10/12m(깊이는 설계 가설). [REAL_SCALE](../source/street-furniture/REAL_SCALE.md)의 사람 1.70m·차량 검토안 4.885×1.900m를 비교 기준으로 사용(차 길이는 확정 실차 규격 아님). Unity Y-up, 건물 피벗은 **주출입층 바닥의 평면 중심**; 반지하가 있어도 원점은 유지, entrance/ground-contact 소켓을 별도 기록. Blender Z-up은 내보낼 때 변환·회전/스케일 적용. 집은 **부품 반복·반지하·장식 모두 합쳐 ≤4,500 tris / 배치 평균 ≤3,500**, 초과 조합은 출력 거절. 아직 측정값이 아닌 예산이다.

### 4. 종류·반복 규칙 / 광장

기본 실루엣 **8종**: 좁은 장방형 테라스 / 긴 장방형 박공 / 낮고 넓은 볼트 / L자 테라스 / 쐐기형 박공 / 두 단 테라스 / 안마당형 볼트 / 측면 날개 테라스. 호환되는 폭·층수·지붕만 골라 **검토 조합 20종**을 먼저 만든다. 색·간판 변경은 종류 수에 넣지 않는다. 현재 §11.5 기준 **1/2/3/4층=5/40/40/15%**를 적용하고, 이전 원화의 5층은 이번 기본 배치에서 제외한다.

배치는 무작위 추첨 대신 **수량 할당 후 이웃 검사**: 100채 예시에서 기본 실루엣 할당 15/15/15/15/10/10/10/10채 → 최대15%; 세부 20조합은 이 할당 안에 나눔. 폭 6/8/10/12m=20/35/30/15%, 지붕 평/박공/볼트=50/30/20%를 동시에 맞추는 조합표를 승인 후 검산한다. 색 변경으로 상한을 우회하지 않으며 이웃 동일 모델+동일 색 금지(가능하면 같은 실루엣도 피함). 지형 조건 때문에 충족 불가능하면 무리한 치수 변형 대신 빈 필지/부족분을 보고한다. **현재는 할당 설계 예시이며 전체 제약 동시 충족은 미검증.**

상점 3종은 같은 키트에 **빵 진열/카페 좌석/식료품 진열** 정면을 추가; 광장 포장과 종탑은 별도 규격 조합(광장30×24m, 종탑8×8×20m 가설), 꼭대기 랜드마크 1종도 별도 승인 대상. 종탑은 같은 팔레트·아치/벽 재사용, 고유 탑 몸체/종루/지붕 3부품 추가를 제안한다. 총 **주거19+상점 정면3+탑3=25부품**, 광장은 평면 배치 산출. 상점도 집 예산 적용, 탑≤6,000 tris 제안(미승인). 땅 앉히기는 §11.1의 벽 연장·반지하 소켓으로, 공용 계단은 도시 생성기가 담당한다.

### 5. 승인 단계·일정(승인 대기 제외 추정)

**지금 계획 A/B 선택 → 부품 시안 1차(1~2h, 벽/창/지붕과 조합 2종의 640×360 그림) → 도현 → Blender 키트(0.5~1일) → 조합기(0.5~1일) → 8실루엣·20조합 미리보기(0.5일) → 도현 적용 승인 → 프로그래밍팀 임포트.** 각 제작 구간은 1~2h마다 작은 결과를 보여 준다. 마감에는 JSON으로 치수·tris·재질·소켓·모델별 배치수/비율을 내보내 QA와 아트가 캡처와 함께 확인한다. 시안은 눈에 띄는 결함만, 수정 왕복 1회 후 남은 목록을 붙인다.
