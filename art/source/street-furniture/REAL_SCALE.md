# 실제 치수 기반 검토안

1 Unity unit = 1 metre. 2026-10-13 사용자 요청에 따른 **별도 검토 씬**이다.
이 파일의 비율 수정은 메인 씬과 공유 FBX/프리팹에 적용하지 않았다.
메인 씬에는 앞서 승인됐던 3.785m 차량과 새 소품 적용본이 남아 있다.

## 기준과 검증 결과

| 항목 | 검토안 | 근거/성격 |
| --- | --- | --- |
| 포뮬러 차량 폭 | 1.900m | F1 2026 공식 안내의 폭 기준 참고 |
| 앞뒤 차축 간격 | 3.400m | 공식 안내의 최대 휠베이스를 검토 기준으로 선택 |
| 차량 전체 길이 | 4.885m | 기존 메시에서 차축 사이를 연장한 결과. 실존 차종의 정확한 복제품 아님 |
| 차량 전체 높이 | 1.072m | 운전자/짐 포함, 기존 모델 유지 |
| 타이어 지름 | 앞 .70m / 뒤 .75m | 기존 디자인 유지, 실제 타이어 규정 재현 아님 |
| 주택 현관 | .92m × 2.15m | 기존 모델 원본 치수. Hörmann 2.1m 출입문 사례와 비교 |
| 상점 유리문 | 1.5m × 2.33m | 기존 모델 원본, 주택보다 큰 상점 출입문 |
| 주택 층고 | 2.8m / 2.9m | 기존 원본의 층 구분 기준 |
| 벤치 | 길이 1.8m / 좌면 .45m | 승인된 에셋 유지 |
| 쓰레기통 | 높이 .952m | 승인된 에셋 유지 |
| 주황색 사람 기준 | 1.70m | 크기 확인용 도형, 캐릭터 디자인 아님 |
| 일반 승용차 | 4.3m × 1.8m × 1.45m | 흔한 승용차 크기로 잡은 비교용 설계값, 특정 실차 치수 주장 아님 |
| 차도 | 6m = 3m × 2차선 | NACTO 도시 차선 10ft 사례를 참고해 반올림한 설계값 |
| 상점측 보도 | 2.2m | 이번 검토안의 설계값, 배치 후 유효 보행 폭은 별도 검토 필요 |

기존 모델을 통째로 길게 늘리지 않고, 타이어와 운전자/가방은 원래 형상을 유지해 이동시켰다.
차체/서스펜션/날개는 검토용 복제 메시의 길이만 구간별로 조정했다. 원본 메시 데이터는 변경하지 않았다.
실제 적용 때는 수정 원본, 휠 리그, 충돌체, 카메라, 회전 공간과 배달 경로를 함께 검증해야 한다.
