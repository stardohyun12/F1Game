# 실제 치수 기반 검토안

1 Unity unit = 1 metre. 2026-10-13 사용자 요청에 따른 **별도 검토 씬**이다.
이 파일의 비율 수정은 메인 씬과 공유 FBX/프리팹에 적용하지 않았다.
메인 씬에는 앞서 승인됐던 3.785m 차량과 새 소품 적용본이 남아 있다.

차체/서스펜션/날개는 검토용 복제 메시의 길이만 구간별로 조정했다. 원본 메시 데이터는 변경하지 않았다.
실제 적용 때는 수정 원본, 휠 리그, 충돌체, 카메라, 회전 공간과 배달 경로를 함께 검증해야 한다.

## F1 2026 치수 (2026-10-19 조사, D-103)

**결론: 폭 1.90m·휠베이스 최대 3.40m는 근거가 있다. 전장 5.0m는 규정 확정값이 아니며, 현재 모델의 균일 확대는 이 폭과 양립하지 않는다.** 규정 한계, 제조팀 공개 제원, 게임 설계값을 구분한다. 원화·모델·씬은 변경하지 않았다.

### 확인한 1차 자료

1. [FIA 2026 Section C, Issue 20 원문](https://www.fia.com/system/files/documents/fia_2026_f1_regulations_-_section_c_technical_-_iss_20_-_2026-08-05.pdf): 본문 표지/쪽 머리 날짜 **05 August 2026**, 254쪽. 검색 결과 제목 일부는 08-03으로 표시되지만 본문 날짜를 채택했다. [FIA 규정 목록](https://www.fia.com/regulation/category)에서 Issue 20 등록을 확인하고 원문을 열었다. 먼저 읽은 Issue 16보다 새 판인 Issue 20의 조항으로 최종 정리했다.
2. [Mercedes-AMG PETRONAS W17 공식 제원](https://www.mercedesamgf1.com/f1-w17-2026-technical-specifications): 2026 실제 참가차의 공개 제원. 팀의 발표값이며 실차 독립 측정 결과는 아니다.
3. [Pirelli 2026 타이어 발표, 2025-12-09](https://press.pirelli.com/pirelli-reveals-2026-f1-tyres-a-fresh-logo-design-and-new-compounds/): 새 외경 감소량·18인치 림 유지. 본문에 연결된 [2025/2026 후륜 비교 원본 그림](https://content.presspage.com/uploads/2363/b81780a5-fc40-425b-aa65-7b69760264f6/2025-2026-tyrecompare.jpg?10000)도 직접 열어 710mm 표기를 확인했다.
4. [Pirelli 2022 18인치 타이어 발표](https://press.pirelli.com/a-look-into-the-future-of-formula-1-with-new-18-inch-tyres-for-2022-cars/): 종전 외경 720mm의 근거. 전륜 705mm는 이 값과 자료 3의 전륜 -15mm를 결합한 계산이다.

### 규정과 공개 제원

| 항목 | 확인값 | 근거 / 해석 |
|---|---|---|
| 폭 | **1.900m** | FIA Issue 20 **C2.3.1**, PDF 10쪽(C10): 중심면 Y=0에서 양쪽 950mm. **타이어·휠 림·C10.7.6 부품은 이 조항의 예외**다. 따라서 타이어 포함 렌더 경계의 절대 상한이라고 단순 해석하지 않는다. W17 공식 전체 폭도 1900mm로 공개되어 게임 전체 폭 목표의 별도 근거가 된다. |
| 휠베이스 | **최대 3.400m** | **C2.3.3**, PDF 11쪽(C11): Legality Setup에서 앞·뒤 휠 기준면 XF=0와 XR=0 사이 거리 상한. 모든 실차의 실측값이 정확히 3.400m라는 뜻은 아니다. |
| 전장 | **5.0m 확정 불가**; W17 공개값 **5.505m 미만** | C2.3에는 전장 5.0m라는 항목이 없다. C2.4·Appendix C2는 부품별 기준 체적을 정의한다. 예: Appendix C2 §22의 앞날개 체적은 XF=-1250부터 시작하지만 이것만으로 차량 전체 전장을 확정할 수 없다. W17 페이지의 “Under 5505mm”는 단일 차종의 공개 범위이며 5.505m 정확값이나 FIA 전체 차량의 최대 전장으로 바꾸어 쓰지 않는다. |
| 높이 | W17 공개 전체 높이 **0.970m** | FIA **C2.3.2**는 기준 체적 아래로의 돌출 제한이며, 지면→차량 최고점 0.970m를 정한 조항이 아니다. **C2.2(a)**의 Z=0도 플랭크를 제외한 스프렁 부분 하단 기준이라 지면과 다르다. 이번 조사에서 공통 전체 높이 단일 상한은 확정하지 않았다. 0.970m는 W17 참고값으로만 사용한다. |
| 슬릭 전륜 외경 | **0.705m** | Pirelli 종전 720mm에서 2026 전륜 -15mm → 705mm. 제조사 발표를 결합한 계산이며 FIA의 직접 외경 상한 인용이 아니다. |
| 슬릭 후륜 외경 | **0.710m** | Pirelli 공식 2026 비교 그림에서 710mm 직접 확인; 종전 720mm에서 -10mm라는 본문과 일치. |
| 림 | **18인치 유지** | 타이어 바깥지름과 림 호칭은 다르다. FIA **C10.7.2**는 림 상세 치수, **C10.8.2**(PDF 114쪽/C114)는 FIA와 합의한 공급사의 타이어 규격 결정 절차를 규정한다. 위 슬릭 외경을 웨트·하중 상태·공기압별 실측치 전체에 일반화하지 않는다. |

규정 치수 요약은 해당 조항 범위만 확인한 결과다. 전체 CAD 체적·충돌시험·형상 적합성 검증은 수행하지 않았다. 인터넷 요약의 “높이 950mm”를 2026 전체 높이 확정값으로 가져오지 않았다.

### 현재 모델 대비 계산

현재 기준: **전장 3.785 × 폭 1.959 × 높이 1.072m** — [2026-10-19 Unity 렌더 경계 기록](../../_compare/2026-10-19-scale/validation.txt). 운전자·짐 포함 경계이며 이번 조사에서는 재측정하지 않았다. 아래는 목표÷현재 계산으로, 적용 승인이 아니다.

|---|---|---|---|
| 폭 1.900m | 1.900 / 1.959 | **0.969883배 / -3.012%** | 전체 폭을 W17 공개 폭에 맞춘다는 게임 설계 선택 |
| 높이 0.970m | 0.970 / 1.072 | **0.904851배 / -9.515%** | W17 참고값. 현재 높이는 짐·운전자 포함이라 구성품을 분리한 검토 필요 |

**스펙 §5의 균일 확대 모순:** 전장 5.000m에 맞춰 전체를 1.321004배 키우면 폭은 **2.587847m**, 높이는 **1.416116m**가 된다. 목표 폭 1.900m보다 **0.687847m** 넓다. 따라서 `5.0 × 1.90m` 대역을 원하는 실험이라면 길이·폭·높이와 충돌체를 각자 정의해야 하며, 균일 확대 결과를 “실제 크기 2026 F1”이라고 부르면 안 된다. 모델 수정은 원화 승인 뒤 별도 작업으로 남긴다.

### 검증 / 인계

- FIA Issue 20 C2.2·C2.3·C2.4·Appendix C2 §22·C10.8.2를 원문 텍스트로 확인. W17 제원과 Pirelli 본문·후륜 비교 그림으로 축이 다른 자료를 대조했다.
- 배율 6개와 균일 확대 후 폭·높이 2개를 Python 산술로 계산했다. 코드·모델·Play 테스트 및 에셋 린트는 해당 없음.
- 전장 5.0m는 여전히 가설. 특정 차종의 정확한 전장, 메인 모델 휠베이스, 짐 제외 높이는 미확정이다. 기획팀에 §3·§5의 균일 확대와 목표 폭 불일치 수정을 요청한다.
- 위 자료는 치수 근거로만 사용하며 로고·차량 디자인·제조사 사진을 게임 에셋으로 재사용하는 권리를 확인한 것이 아니다. 외부 그림은 열람만 했고 저장소나 모델에 투입하지 않았다.

### 기획 반영 확인 (2026-10-19)

기획팀이 마을 생성기 스펙 §3·§5·§9를 수정한 것을 파일에서 확인했다. 균일 확대를 폐기하고 실험 대역을 기존 구간별 연장 검토안 **4.885 × 1.900 × 1.072m / 휠베이스 3.400m**로 변경했다. 위 “스펙 §5의 균일 확대 모순”은 수정 전 문제의 계산 기록이다. 실험 씬 대역 제작·검증은 프로그래밍/QA 영역이며 이번 확인에서 실행하지 않았다.

최종 모델 전장 5.0~5.5m 범위는 **기획 가설**로 전달받았다. 별도 아트 배정 후 차체·운전자·짐의 높이를 분리해 제안하고 원화 단계에서 도현 승인을 받는다. 이 범위는 FIA가 정한 전장 범위가 아니다. “전장 항목 없음”은 확인한 C2.3 기본 치수 절의 범위이며 전체 규정의 부품별 간접 제한이 없다는 뜻은 아니다.
