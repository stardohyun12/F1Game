# art/ — 아트 산출물 (Manus + AionUi 아트팀)

Manus와 AionUi 아트팀(Codex)이 만든 이미지·에셋·모델 소스를 두는 곳. 폴더 규칙:

- `concept/` — 컨셉아트, 무드보드, 분위기 탐색
- `ui/` — UI/HUD/메뉴 아트
- `sprites/` — 캐릭터·오브젝트 스프라이트
- `_prompts/` — 각 이미지를 만든 프롬프트 기록 (파일명: `YYYYMMDD-용도.md`)
- `models/` — 아트팀(Codex)이 만드는 3D 모델의 생성 스크립트·스펙·프리뷰. 엔진 투입물은 `F1/Assets/Model/Custom/`. 규격은 `PIPELINE.md` §5

2D 규칙은 repo 루트 `MANUS.md`, 팀 운영과 모델링은 `PIPELINE.md` 참고.
