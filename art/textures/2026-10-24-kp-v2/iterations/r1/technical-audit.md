# A1 2차 독립 정적 검증

판정: **통과**. 작성 스크립트를 실행해 결과를 다시 저장하지 않고, 현재 PNG·GLB·manifest·장부를 직접 읽어 검사 함수를 재실행했다. `technical-audit.json`에 검사 전체와 감사 시점 SHA를 보관했다.

| 항목 | 확인 결과 |
|---|---|
| 공용 팔레트 | `pitcrew_d123_32.json` 32색, 4개 원본 albedo의 팔레트 밖 색 0 |
| 출력 | 모두 128×128 PNG, 각 실제 반복 범위 2×2m |
| GLB | 각 2 tris, 실제 버텍스·UV Jacobian의 두 축 모두 64.0px/m |
| Point | 내장 PNG가 전달 albedo와 일치, GLB sampler NEAREST/REPEAT |
| 원본·산출 SHA 및 장부 | `check_texture_tiles.inspect_manifest()` 재실행 4/4 통과 |
| 회벽 추가 사진 | 실제 파일 SHA, 제공자 MD5, 공식 다운로드 URL, CC0, 장부 1행 일치 |
| 회벽 최종 픽셀 | 원본 사진·마스크·배율·기록된 RGB 보정·seam 처리·양자화를 메모리에서 재현하여 현재 PNG와 픽셀 전체 일치 |

회벽 추가 사진 [Rough Plaster Broken](https://polyhaven.com/a/rough_plaster_broken)은 공식 페이지에 폭 1.5m, Rob Tuytel, CC0가 표시된다. [Poly Haven 라이선스](https://polyhaven.com/license)에서도 에셋의 CC0 배포를 확인했다. 웹페이지 예시 렌더를 재료로 쓰지 않았고, `rough_plaster_broken_diff_1k.png`의 다운로드 파일을 검사했다.

| 손상 조각 | 원본 마스크 bbox (px) | 실제 사진 범위 (m) | 최종 크기 (px) | 실효 밀도 x/y (px/m) |
|---|---|---|---|---|
| 1 | (322,8)–(520,197), 198×189 | 0.290039×0.276855 | 19×18 | 65.508 / 65.016 |
| 2 | (176,580)–(295,806), 119×226 | 0.174316×0.331055 | 11×21 | 63.104 / 63.434 |

계산: 원본 픽셀 길이÷1024×1.5m로 물리 길이를 구하고, 최종 정수 픽셀 수를 그 길이로 나눴다. 두 조각 모두 64px/m ±10% 이내이며 manifest의 최종 배치 범위와 일치한다. 사진상 실제 박락 영역을 사용했는지도 원본과 최종 PNG를 직접 열어 확인했다.

교체 전 시험 PNG 4개는 `research/trial-before/`에 백업했다. PNG·기존 `.meta` 총 8개의 SHA는 `trial-before.json`에 기록했다. 이 감사 작업은 F1·장부·제작 스크립트를 수정하지 않았다.

한계: **32색 검사는 조명 전 원본 albedo 기준**이며 조명·안개가 적용된 최종 화면의 색 수와 별개다. Unity 실행·임포트·씬의 실제 UV/스케일·이동 중 필터링은 검사하지 않았다. 사진의 세부 촬영 방식은 제공자 설명 범위까지만 확인했으며 픽셀만으로 AI 여부를 판별했다는 주장은 하지 않는다. 시각 게이트는 이 정적 검사와 별도로 판정한다.
