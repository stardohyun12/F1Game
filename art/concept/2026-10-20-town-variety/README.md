# D-112 해안 마을 다양화 — 원화 승인 대기

상태: **CONCEPT / 도현 승인 전**. 엔진 투입용 FINAL 에셋이나 모델이 아니다. 모델·텍스처 제작 및 Unity 적용은 진행하지 않았다.

## 그림 여는 방법

- **제출본 `01_house_variants_v02.png`**: 01~10 집 변형 시트. 색을 가리고도 폭·층수·지붕·발코니 덩어리가 구별되는지 판단.
- **제출본 `02_town_center_slope_v02.png`**: A 광장·성당/종탑·상점 둘레, B/C 비탈 집 접지. 마을 중심이 명확한지, 집이 받침대 위 소품처럼 보이지 않는지 판단.

두 PNG를 이미지 뷰어로 원본 크기에서 연다. 그림 속 숫자는 디자인 식별자이며 실측 치수나 엔진 성능을 보증하지 않는다. 생성 원화이므로 정밀한 구조·계단 치수는 승인 후 설계 단계에서 별도 검증해야 한다.

참고 자료·차용/변경 구분·전체 프롬프트: `art/_prompts/20261020-town-variety.md`.
생성 경로: 사용자 지정 `codex exec` → `image_generation`, 내부 승인 스타일 이미지는 분위기 참조로만 제공.

## 검증

- 두 제출본 PNG 열기·크기·파일명 검사 통과, 파일 검사 위반 0. 각 1672×941, SHA256/바이트 수는 `validation.json`.
- 원본 크기로 직접 열람: 01~10 번호와 10개 집 확인. 좁은 탑형·낮고 넓은 아케이드·계단형 테라스·쐐기형·퍼골라형 등이 구별됨. 장식·색만 바꾼 동일 실루엣 복제는 아님.
- A에 성당·종탑·광장·카페·빵 진열·과일 상점, B/C에 경사지와 여러 층 출입구 확인. 받침대 블록 위에 집 전체를 올리는 표현은 없음. B의 밝은 삼각 면은 지면 절개 표현이며 벽 기단이 아님.
- 1차는 부드러운 고밀도 표현이 강해 수정했다. v02는 벽의 픽셀 색면·각진 식생으로 단순화됐지만, 기존 게임보다 장식이 많고 복셀 같은 식생이 두드러질 수 있어 최종 톤 승인은 필요하다.
- 생성 오차: 두 번째 시트의 하단이 요청 30%보다 크고, B 배경이 회색에서 하늘로 바뀜. 접지 설명과 원화 승인 목적에는 지장이 없지만 정밀 단면도는 아님. 문·창의 실측 균일 척도, 메시/텍스처 규격·폴리·성능은 검증하지 않았다.
- 접미사 없는 PNG 2개는 1차 비교 기록이며 제출본은 v02 두 장이다. 새 모델·엔진 투입물 없음.

## 디렉터 판단 요청

1. 집 10종 중 채택/제외할 번호와 전체 형태 다양성.
2. 광장과 성당·종탑이 마을의 구심점으로 충분한지.
3. 비탈에는 기단 블록 대신 하부층을 지형에 맞춰 매입하는 방향을 승인할지.
