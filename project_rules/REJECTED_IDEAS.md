# F1 프로젝트 한정 거절 아이디어 [project]

이 파일은 **F1 게임 프로젝트 내에서만** 거절된 접근을 기록한다.

다른 게임 프로젝트에는 적용되지 않을 수 있다. 적용 범위가 보편적으로 확인되면 `harness-core/REJECTED_IDEAS.md`로 승격.

---

## (아직 항목 없음)

이 파일은 작업 중 F1 한정 거절 사항이 발생하면 채워진다.

예시 (실제 발생 시 추가):
- F1 게임에서 X 라이브러리 사용 거절 — 이유: ...
- 특정 UI 패턴 거절 — 이유: ...
- 특정 물리 모델 거절 — 이유: ...

---

## 형식

```
## N. <짧은 제목>

**아이디어**: 무엇을 제안했는가
**거절 이유**: 왜 안 했는가
**대신 채택**: 무엇을 선택했는가
**보편화 가능?**: 다른 프로젝트에도 적용될 거절인가
  - Yes → `harness-core/REJECTED_IDEAS.md`로 승격 검토
  - No → 여기 유지
```
