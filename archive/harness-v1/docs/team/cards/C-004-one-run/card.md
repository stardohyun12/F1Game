# 한 판 5분 — 배달 결과(돈·반응)와 노을 귀가로 하루가 닫힌다

## 왜
도현 목표(11/5): 한 판(5분). D-250 4번 원문 "돈을 덜 받고 그 때 그자리 반응만 아쉬움" — 배달 결과가 돈과 문 앞 반응으로 보이고, 노을 귀가·일기장으로 하루가 닫혀야 한 판이다.

## 범위 (만질 파일)
- 건네기 결과(돈·반응) 표시, 귀가 트리거, 일기장(docs/qa/evidence/diary-calendar 기존 것 재사용)
- 새: F1/Assets/Scripts/OnFoot/DayEnd.cs (필요하면)

## 하지 말 것 (잠근 것)
- 코스·길·지형, 차 조작값(ArcadeCarController·DriveFeel), 화물·돈 핵심 수치, 도현이 놓은 건물 위치
- 정한 값(내부 해상도 360·Nearest 등), 손에 든 종이(HeldPaper)·방향 표시·[E] 칩 방식

## 시작 장면
- 씬 Map_TownV6 → Play → 디버그 창 "첫 배달 찻집" (화물 실은 상태로)
- 도현이 처음 할 행동: 문 앞에서 건넨다

## 수용 기준
1. 도현이 상자를 성하게 건네면 받는 사람이 고마워하는 반응과 받은 돈(도트 숫자)이 보이고, 깨뜨렸으면 덜 받은 돈과 아쉬운 반응이 보인다.
2. 도현이 건네고 나면 하늘이 노을로 넘어가고 방향 표시가 집을 가리킨다.
3. 도현이 집 방에 들어가 일기장을 E 로 열면 그날 배달·번 돈이 손글씨로 적혀 있고, 닫으면 다음 날로 넘어간다.

## 기계 확인
- 하네스 증거 묶음 `bash tools/evidence/bundle.sh <ID> after`: 프레임 증가(frames_ok), 클립 동안 에러 0(log_ok) — 자동
- 이 기능이 안 됐으면 실패했을 검사: exec 로 화물 파손 0%/50% 두 번 건네서 받은 돈이 다르게 기록되는지

## 사람 확인 (도현 한 판)
- Play → 찻집에서 건네기(한 번은 깨진 채로) → 집으로 → 일기장
