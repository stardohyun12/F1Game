> 카드 하나 = 기능 하나. PD 가 쓴다. 새 카드는 손으로 복사하지 말고 `python -X utf8 scripts/card.py new "<제목>" --slug <영문> [--start-place N] [--opus]`

> 수용 기준은 「도현이 ○○ 하면 △△가 보인다」 꼴로만 쓴다 — 검증 일꾼은 이 문장과 증거 묶음만 보고 통과/불통과를 낸다.
