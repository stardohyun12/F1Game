# 아트 교훈 (art·art2 공통, 15줄 이하 — 매 과제 앞에 붙음)
1. 표면은 사진 재료 albedo. 단색 채우기 + 노이즈 = "벡터/장난감"으로 거부됨(D-189).
2. 빛·그림자·AO 를 텍스처에 굽지 않는다. 게임 안 실시간 빛(D-185).
3. 녹·때·얼룩 넓게 금지. 손질된 낡음만(도현 취향).
4. 도현이 고른 색(파랑·초록 덧창 등)이 팔레트에 없으면 칸을 추가. 회색으로 빨려 들어가지 않게.
5. 작은 물건 정면(자판기·실외기)은 64px/m + 큰 덩어리로 다시 칠하기. 32px/m 에선 얼룩.
6. 간판은 20m 판독 + 정면을 과하게 채우지 않기(MART 교훈).
7. 게이트 시트엔 게임 기준 화면 크롭을 같은 배율로 옆에 + audit_lite 수치. 단품만 보면 장면에서 안 맞음.
8. 같은 점수가 2회 안 움직이면 더 돌리지 말고 보고(도현 판정 필요).
9. 커밋 금지. Unity 금지(artlive 는 Unity 사용 — 과제 지시 따름). 턴 한도 근처면 보고서부터.
10. 에셋 수치 게이트는 기준 컷 값과 나란히(±범위). 아래 빈칸·밝기 폭은 장면 지표라 에셋 시트엔 안 씀. 바닥 원형 얼룩(옛 가짜 그림자)이 원본 텍스처에 남아 있는지 항상 확인.
11. 건물을 고치면 끝에 `bash tools/viewer/export_all.sh` 실행(도현 웹 뷰어 http://127.0.0.1:8770 갱신). 판정 캡처는 Unity 스튜디오, 도현 둘러보기는 뷰어.
12. 글씨는 세상과 같은 텍셀 밀도의 픽셀 글씨(매끈한 글꼴 금지). 원통은 16면 이상. 전등은 실제로 빛이 나게.
13. 새로 그리는 작은 물건·트레드·칠한 면에도 사진 결(±4~8% 명도 + 약한 얼룩)을 깐다 — 깔끔한 단색 그림은 "노이즈 빠짐"으로 거부됨(D-194).
14. 겹친 면 금지(z-fighting = 도현 "치지직"): 데칼·띠·스티커·테두리는 면에서 1~3cm 띄우거나 합침. 끝에 겹친 삼각형 자동 검사 0.
15. 게임에서 만질 수 있는 물건(택배·시계 바늘·의자·타이어)은 낱개 오브젝트 + 이름 + 피벗. 통 메시로 합치지 않음(D-195).
16. 보고 전 `python -X utf8 tools/art/check_rules.py --only <건물> --gate` 실행, 마지막 줄을 보고에 붙임(규칙 검사 docs/art/RULE-AUDIT-2026-10-28.md). 결을 넣은 뒤엔 반드시 그 건물 .gpl 로 다시 양자화(결이 팔레트를 깨면 안 됨). 글씨·아이콘·데칼도 세상 텍셀 격자(32 또는 64px/m)에 맞춤.
