# 스코프 관리 규칙 (절대)

## 규칙 1: MVP는 4주
- 1~4주차 안에 코어 루프가 굴러야 함.
- MVP 중 신규 시스템 추가 금지.
- 새 아이디어는 즉시 `notes/ideas-parking.md`로.

## 규칙 2: 주간 재미 검증
- **1주차 끝:** 차 몰기 자체가 재밌는가? (NO면 튜닝)
- **2주차 끝:** 화물 관리가 긴장감을 주는가?
- **3주차 끝:** 경로 계획이 의미 있는가?
- **4주차 끝:** 5~15분 한 런이 실제로 굴러가는가?

## 규칙 3: 비주얼 폴리싱은 4주차 이후
기능이 다 돌아가기 전까지 셰이더/파티클/UI 꾸미기 금지.

## 규칙 4: 추가 제안 시 체크리스트
- [ ] 이 기능이 없으면 MVP가 재미 없는가?
- [ ] 3단계 루프(계획/실행/정산) 안에 들어가는가?
- [ ] 1~4주차 스코프 안에서 가능한가?

**하나라도 NO면 `ideas-parking.md`로 즉시 이동.**

## 컨셉 (D-051)
**망한 F1 팀이 배달로 자금 → 머신 복원 → F1 그랑프리 복귀.** 배달은 수단, F1 복귀가 목적. 마이크로 루프(한 런 5~15분) ↔ 매크로 루프(머신 복원) 직각 관계.

## 결정 채널 9 (D-053)
플레이어가 시간이 지나며 조절하는 dial 9개:
1. 속도 / 2. 외형 / 3. 맵 접근도 / 4. 배송물자 종류 / 5. 보관박스 크기 / 6. 랩핑 / 7. 기본 기능(F1 복원 트리) / 8. 지도/내비 / 9. 연료탱크(스타듀 스테미나)
