# 세션 오프닝 템플릿

> **매 세션 첫 메시지를 즉흥으로 쓰지 말 것.**
> 아래 템플릿을 복사해서 채워 넣으면 Cowork가 엉뚱한 방향으로 튀는 빈도가 크게 줄어듦.
>
> 영상 기반: 앤트로픽의 세션 시작 루틴(폴더 확인 → 지금까지 뭘 했는지 → 다음에 뭘 → 최근 로그 훑기)을 도현 환경에 맞춘 버전.

---

## 매 세션 첫 메시지 템플릿

```
[Cowork 세션 시작]

1. 먼저 다음 파일을 순서대로 읽어:
   - CLAUDE.md
   - notes/session-log.md (마지막 블록)
   - dev-plan/feature-list.md (현재 작업 위치)

2. 오늘 목표: [여기에 한 줄 목표]
   예: "Day 1 — Unity 6 프로젝트 생성 + Kenny 에셋 임포트"

3. 작업 후 갱신할 파일:
   - dev-plan/feature-list.md (체크박스 갱신)
   - notes/session-log.md (세션 블록 추가)
   - (필요 시) notes/decisions-log.md

4. 스코프 분류: [MVP / 확장 / 불확실]

5. 예상 컨텍스트 부담: [가벼움 / 보통 / 무거움]
   - 무거움이면 작업 중간에 컨텍스트 체크 요청할 것

시작.
```

---

## 세션 종료 시 요청 템플릿

```
[세션 종료 준비]

1. notes/session-log.md에 "세션 N" 블록 추가해줘.
   - 목표, 한 일, 다음 세션 할 일, 관련 문서, 메모, 컨텍스트 상태.

2. dev-plan/feature-list.md 체크박스 갱신.

3. 오늘 한 작업을 git 커밋.
   - 커밋 메시지는 기능 단위로 간결하게.

4. 다음 세션에 가장 먼저 해야 할 일 한 줄 정리.
```

---

## 컨텍스트 관리 원칙 (영상 기준)

- **구현 작업 끝난 직후 컨텍스트 40% 이하**가 이상적.
- 40% 초과 시:
  - 작업 단위가 너무 컸거나
  - 불필요한 정보가 쌓였거나
  - 둘 다.
- **해결책:**
  - `/compact` (요약 압축) — 자연스러운 정리.
  - `/clear` (완전 재시작) — 주제가 바뀔 때.
  - **포크** — 값진 논의 맥락을 보존하고 실험만 따로 할 때 (Cowork 지원 여부 확인 필요, 2주차 이후).

## 안티 패턴 (하지 말 것)

- **한 번에 여러 기능 요청.** "차량 컨트롤러 만들고 카메라도 만들고 트랙도 깔아줘" — 컨텍스트 고갈 직행.
- **이전 세션 맥락을 말로 설명.** 파일(session-log.md)로 넘겨야 토큰 절약되고 오해 없음.
- **스킬·MCP 전부 켜놓고 시작.** 필요한 것만 켜자.
- **작업 중간 방향 전환.** "아 잠깐 이것도 해볼까?" → `ideas-parking.md`로.
