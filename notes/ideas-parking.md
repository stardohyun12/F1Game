# 아이디어 보관소 (Ideas Parking Lot)

> **MVP 기간 (1~4주차) 동안 떠오른 모든 확장 아이디어는 여기로.**
> GDD에 바로 추가하지 말 것. 4주차 이후에 꺼내 볼 것.

---

## 시스템 작업 (Phase 2 예정)

### 메타데이터 시스템 외부화 + 검증 도구
- 도로 회전 매핑/native size를 코드 상수 → ScriptableObject (`RoadTileSet.asset`)로 외부화
- 빌드 후 인접 셀 도로 끝점 거리 자동 측정 → 임계치 초과 시 콘솔 경고 (어긋남 자동 감지)
- 신규 타일 도입 시 빈 씬 4회전 자동 배치 + 톱다운 캡처 → 사람 라벨링 헬퍼

### 건물 시스템 Phase 2
- footprint > 1 (2×2 등 큰 건물) 처리
- 인접 규칙 (간격, 카테고리 연속 금지)
- 배달지를 실제 건물(가게/창고)로 교체 — 현재 녹색 기둥 placeholder
- industrial 키트 도입 (배달 게임 어울림)

## 이미 GDD에 언급된 확장 후보

### 화물 시스템 확장
- 온도 민감도 (아이스크림 녹음 타이머)
- 생명체 민감도 (움직이는 동물 배달)
- 누적 손상 (여러 번 맞으면 급증)
- 보험 시스템 (비용 내고 데미지 면제)

### 타이어 시스템 확장
- 타이어 온도 (예열/과열)
- 타이어 제조사별 특성
- 타이어 압력 조절
- 재생 타이어

### 연료 시스템 확장
- 연료 종류 (일반/고급/친환경)
- 주유소 이벤트
- 슬립스트림
- 전기차 모드

### 경로 계획 확장
- 업그레이드로 정보 공개 레벨 증가
- 지름길 발견 시스템
- 경쟁자 경로 표시
- 동적 이벤트 (교통 체증, 사고)
- 다중 차량 운영

### 2026-04-20 — F1 시뮬 요소 검토 결과
- **설명:** 기어박스(수동/반자동), 다운포스/공력, ERS/DRS, 슬립스트림, 서스펜션 세팅, 타이어 온도 고도화 등 F1 리얼리즘 구성요소. Day 5 드리프트 구현 후 "실제 F1처럼 만들고 싶다"는 요청에서 파생.
- **왜 지금 아닌가:** D-007(아케이드 + 무게감) 기획 정체성과 충돌. 각 항목이 독립 시스템이라 MVP 스코프 내 추가는 완성 실패 리스크. Shock/Spin 화물 긴장감 희석, 튜닝 비용 폭증, "배달"의 경쾌함과 부조화.
- **예상 이관 시기:** MVP 완성 후 (5주차~). "아케이드 기반 위에 선택적 F1 레이어" 형태로 재검토. 우선순위는 5주차 시점에 재평가.
- **기각 (비전 위배):** 풀 시뮬 물리(WheelCollider+서스펜션+슬립 커브), 실제 F1 라이선스/트랙, 브로드캐스트 컷씬 시스템.
- **수용된 Tier A (1주차 내 튜닝으로 흡수):** 고속 조향 둔화, airDrag, 브레이크 속도 곡선, angularDamping, FOV 확장, 코너 롤. D-019 참조.

### 2026-04-22 — 기어 시스템 (수동/자동 변속) 재요청
- **설명:** 세션 5에서 "속도감 부족" 문제 해결책으로 도현이 기어 시스템 재제안. D-019에서 이미 파킹된 항목이지만 맥락이 달라 별도 기록.
- **왜 지금 아닌가:**
  - 단수별 최고속/토크/RPM 커브 튜닝 + 기어비 + 자동/수동 분기 + UI 표시 = 최소 2~3일. 1주차 체크포인트(Day 7, "계속 놀고 싶나") 직전에 넣으면 판정 대상이 흐려짐.
  - 현재 체감 문제는 Tier A(maxSpeedKmh 60→90) + 맵 소품 배치(속도감 연출)로 해결 시도 중. 그게 통하면 기어는 불필요한 복잡도.
- **재검토 조건:** 1주차 재미 판정 **통과 후 (Day 7)**, 그때도 "속도 구간이 평탄해서 지루하다"는 구체 피드백이 있을 때만. 재검토 시점에도 Post-MVP 또는 4주차 폴리싱으로 배치.
- **관찰된 패턴:** 도현의 "F1 리얼리즘" 계열 요청 5번째 반복 (카메라 전환 → 에셋 쓸어담기 → F1 시뮬 → 리얼리즘 섞기 → 기어). D-019 방어선 재확인 필요.

## 규칙

1. 새 아이디어가 떠오르면 **즉시 여기에 기록.**
2. GDD나 dev-plan에 바로 추가하지 말 것.
3. 이 문서는 **MVP 완성 전까지 열람 최소화.** 매주 한 번 보관만.
4. MVP 완성 후 (5주차 시작 시점) 이 문서를 열고 우선순위 매기기.
