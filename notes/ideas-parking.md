# 아이디어 보관소 (Ideas Parking Lot)

> **MVP 기간 (1~4주차) 동안 떠오른 모든 확장 아이디어는 여기로.**
> GDD에 바로 추가하지 말 것. 4주차 이후에 꺼내 볼 것.

---

## 이미 GDD에 언급된 확장 후보

### 화물 시스템 확장
- 온도 민감도 (아이스크림 녹음 타이머)
- 생명체 민감도 (움직이는 동물 배달)
- 누적 손상 (여러 번 맞으면 급증)
- 보험 시스템 (비용 내고 데미지 면제)

### 타이어 시스템 확장
- 타이어 온도 (예열/과열)
- 타이어 제조사별 특성
- 타이어 압력 조절
- 재생 타이어

### 연료 시스템 확장
- 연료 종류 (일반/고급/친환경)
- 주유소 이벤트
- 슬립스트림
- 전기차 모드

### 경로 계획 확장
- 업그레이드로 정보 공개 레벨 증가
- 지름길 발견 시스템
- 경쟁자 경로 표시
- 동적 이벤트 (교통 체증, 사고)
- 다중 차량 운영

- **예상 이관 시기:** MVP 완성 후 (5주차~). 유저 피드백으로 콕핏 수요 확인되면 우선 추가.

## 규칙

1. 새 아이디어가 떠오르면 **즉시 여기에 기록.**
2. GDD나 dev-plan에 바로 추가하지 말 것.
3. 이 문서는 **MVP 완성 전까지 열람 최소화.** 매주 한 번 보관만.
4. MVP 완성 후 (5주차 시작 시점) 이 문서를 열고 우선순위 매기기.

## 절대 추가하지 말 것 (비전에 어긋남)

다음 아이디어는 기각됨:
- **PvP / 멀티플레이** — 솔로 프로젝트 범위 초과.
- **오픈월드** — "계획 → 실행 → 정산" 루프 깨짐.
- **전투 시스템** — "운송" 주제에서 이탈.
- **캐릭터 스토리 RPG** — 코어 루프 초점 흐림.
