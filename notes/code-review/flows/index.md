# Flows 인덱스

사용자 액션 → 함수 사슬 5종.

| 흐름 | 빈도 | 핵심 |
|---|---|---|
| [[Flow.GameStart]] | 매 런 1회 | 주문→포장→출발 (정상 흐름, 가장 친숙) |
| [[Flow.Cancel]] | 가끔 | PSP 취소 → OB 재진입 |
| [[Flow.HoverPropagation]] | 보드 위 호버마다 | 카드 색 + 마커 강조 |
| [[Flow.DeliveryComplete]] | 매 런 1회 (성공 시) | 배달 완료 → 정산 |
| [[Flow.TimeOver]] | 매 런 0~1회 (실패 시) | 시간초과 → 정산 |

---

## 첫 진입 추천

[[Flow.GameStart]] 5분 읽기. 그 안 함수들 클릭하며 깊게.

---

## 어떻게 그래프 활용?

Obsidian 그래프 뷰 (`Ctrl+G`) 띄우고:
- 흐름 노드 5개가 가운데 클러스터
- 각각이 함수 노드들로 뻗어나감
- 함수들이 스크립트 노드들로 묶임

→ 시각적으로 "어디서 어디로 흐르는지" 한 눈.
