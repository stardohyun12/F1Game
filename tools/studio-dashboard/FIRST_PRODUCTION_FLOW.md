프로젝트 이름은 **첫 제작 · 해안 차량 시험**이다. 기존 프로젝트·대화·미커밋 변경을 초기화하지 않았다. 자동 commit/push나 공개 업로드는 하지 않았다. `CODEX_PROMPT.md`, `REFERENCE_GUIDE.md`, 참고 PNG 네 장을 읽고 실제로 열어 확인했다. 네 번째 저해상도 이미지의 세부 문구는 기능 명세로 추정하지 않았다.

## 구현

- 제작 지도 / 팀 작업실 / 결과·플레이. 팀 관계와 실제 parent 작업 관계를 구분한다. 실제 영향 전달의 이유·원본·후속 작업을 표시하고 대화로 이동한다.
- 중앙 이미지 작업 대상과 옆 대화, 어두운 UI, 조절 가능한 대화 폭, 작은 화면, 초점 스타일. 결과 화면은 다운로드를 먼저 보여주고 긴 작업 이력은 접는다.
- 업로드·붙여넣기·드롭, 여러 이미지 선택, 용도, 버전 비교, 정규화 영역, 키보드 좌표 입력. 이미지 ID·해시·영역이 실제 실행 입력으로 전달된다. 사용자 대화에는 이미지가 표시되고 내부 JSON은 기본 화면에서 숨긴다.
- 참고 / 시안 / 적용 캡처 / 채택 / 빌드 분리. 명시적 사용자 채택만 공통 맥락으로 전파한다. 팀별 초안·대화 위치·이미지 선택은 보존한다.
- 실제 Codex/Claude Code ConPTY + xterm. CLI는 구조화 팀 대화와 별도 세션이다. 열기만으로 실행하지 않는다. 한글·붙여넣기, 크기 변경, Ctrl+C, 종료, 브라우저 재연결, 승인 화면 입력을 시험했다. 서버 재시작 후 같은 PTY를 복구한다고 주장하지 않는다.
- native CLI와 구조화 작업은 같은 프로젝트에서 동시 실행하지 않는다. 추가 요청은 다음 작업 예약 또는 명시적 중단 후 새 요청으로 처리한다. 현재 실행에 실시간 합치는 기능은 제공하지 않는다.
- `report_team_impact`를 두 구조화 제공자에 연결했다. 근거를 포함한 연결 작업이 현재 작업 뒤 직렬 실행된다. 원본당 최대 4건, 같은 체인에서 팀 재방문 금지, 10건 대기열·작업당 600초 제한을 적용한다. 모든 팀을 자동 실행하지 않는다.

## 실제 제작 결과

1. 사용자가 기존 해안 마을·배달 차량 자료 사용을 승인했다.
2. 실제 gpt-6-astra/low 아트 실행이 첨부 이미지의 붉은 차체, 크림색 장식, 주황색 상자, 화면에 해안 풍경이 없다는 점을 관찰했다. `art-options.json` 두 제안을 실제 파일로 등록했다. 이미지 생성 도구의 출력이라고 주장하지 않았다.
3. 기존 CoastalFormula prefab/텍스처/셰이더를 재사용해 별도 Unity 소재 A/B와 동일 카메라 캡처를 만들었다. 첫 캡처의 원래 장면 혼입은 전용 렌더 레이어로 해결했다.
4. 사용자가 **B: 차가운 색감**을 실제로 선택했다. 등록 이미지 버전 `d230b45886c240d2badbdf91e293c892`와 이유를 채택 기록에 저장했다.
5. 실제 조작감 팀이 현재 컨트롤러 코드를 읽고 `steerLag` 0.025 → 0.015초 실험을 제안했다. 다음 요청에서는 채택 B의 이미지 버전·색상 값을 정확히 받았고, 조작감은 미채택 실험이라고 구분했다.
6. 실제 팀 영향 도구 호출로 조작감 → 아트 검토가 직렬 실행됐다. parent `ce0a3bb0131847cbac11a16435c3c6c0`, child `5580100330dd4dc7950c76bf53f3510d`. 두 실행 모두 종료되었으며 자동 추가 호출은 없었다. 이는 카메라 검토 포인트 확인이며 시각 검증 통과를 뜻하지 않는다.
7. `F1/Assets/PitCrewTrial/CoastalTrial.unity`와 Windows 실행 파일을 만들었다. 기존 컨트롤러를 수정하지 않고, 시험 전용 입력·Driving 단계·카메라를 연결했다. 기존 `CarLowFriction` 소재와 현재 차량의 질량 100을 재사용한다. 시험은 짧은 직선 해안 구간이며 전체 배달 게임을 복제·검증한 것이 아니다.
8. 사용자는 **아직 플레이하지 않음**이라고 답했다. 아트 B만 채택, 조작감과 사용자 플레이는 미검증으로 남겼다. 실행 파일은 B 색감과 기존 조향으로 시작한다.

## 사용

프로젝트에서 아트 또는 조작감을 선택해 바로 요청한다. 이미지는 붙여넣거나 올리고 **다음 팀 요청에 포함**을 선택한다. 결과 화면에서 비교·다운로드·원래 작업 이동을 사용할 수 있다. CLI는 접힌 영역에서 명시적으로 시작하고 팀 요청 전 종료한다.

ZIP을 풀고 `PitCrewCoastalTrial.exe` 실행: WASD/방향키 운전, R 초기화, F1/F2 색감, F3 기존 조향, F4 실험 조향, Esc 종료. 브라우저 안의 Unity 플레이 임베드는 제공하지 않는다. 자동 시험 자료는 `TrialEvidence/`에 있다. 사용자 플레이 피드백과 전체 게임 통합·출시 검증은 남아 있다.

참고·라이선스·재현 조건은 `WORKBENCH_DEPENDENCIES.md`, 원본 모델 결과·실패·빌드·채택·후속 응답은 `art/pitcrew-first-flow/`, 브라우저/CLI/배포 증거는 `.ai_logs/pitcrew-studio/`에 있다. 이미지 생성 API나 Blender 연동을 구현·시험했다고 주장하지 않는다. 이번 아트 결과는 기존 자산의 실제 Unity 렌더다.
