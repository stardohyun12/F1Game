# Conversation-first UI revision · 2026-10-18

사용자 피드백: 대화 폭 부족, 이미지 과대, 화면 탭/스크롤 과다. 기존 방향 B 채택 및 플레이 미검증을 유지.

- 대화 중앙 고정, 오른쪽 결과 상시 표시. 1600px에서 대화 982px / 결과 370px.
- 화면 전환 탭 제거. 이미지 첨부·영역·비교·채택 및 독립 CLI는 펼침 도구로 유지.
- 실제 parent 작업 관계를 SVG 선으로 표시, 키보드/클릭으로 원래 대화 이동. 최근 30건, 전체 이력 별도 보존.
- 제작 팀장 컨텍스트가 필요한 작업을 report_team_impact로 배정하도록 안내. 기존 직렬 대기열 및 중복/순환 제한 재사용.
- 연결 작업 종료 시 팀장 대화에 출처가 있는 결과 보고 자동 추가. 요약은 원문 최대 4000자 발췌이며 별도 AI 종합 판단이 아님. 전체 검증 완료로 승격하지 않음.
- 팀장 다음 요청은 관련 작업 결과와 채택 방향을 참조.

참고: https://www.anthropic.com/engineering/building-effective-agents 의 orchestrator-workers 원칙(필요한 작업만 분해·전달)을 검토. 외부 프레임워크 도입이나 원본 실험 재현을 주장하지 않음. 저장소의 기존 큐와 전달 검증을 재현 후 확장. 새 의존성 없음.
