# 목표 한 줄로 계속 작업하기

대화 입력창에서 `/goal 목표 내용`을 보내면 그 대화가 목표를 맡습니다. `/goal`만 선택하면 목표를 적을 수 있고, 팀·회차·별도 완료 기준을 설정할 필요는 없습니다. 진행 막대에서 현재 작업과 확인 결과를 볼 수 있습니다.

담당자가 작업하고 검증한 뒤 남은 일이 있으면 같은 세션에서 다음 턴을 자동으로 시작합니다. 필요하면 연결된 팀원에게 위임하고 보고를 종합합니다. 사용자가 같은 대화에 추가한 지시는 다음 목표 단계보다 먼저 처리합니다.

QA는 결함과 테스트 결과를 확인하는 역할입니다. **QA 통과만으로 목표를 완료하지 않습니다.** 담당자가 완료 후보를 내면 별도 확인 턴에서 원래 목표 전체를 요구사항별로 대조합니다. 검증하지 못했다는 설명이 있으면 원래 목표에 속하는지 한 번 더 확인하고, 목표 안의 남은 요구나 검증 부족은 작업으로 돌아갑니다. 필요한 의존 조건은 포함하며 관계없는 작업으로 범위를 넓히지 않습니다. 이 과정은 AI의 판단이며, 완료 표시 자체가 결과의 정확성을 보증하지는 않습니다.

임의의 회차 제한은 없습니다. 사용자 결정·권한·정보가 필요하면 일시 정지합니다. 동일한 작업 보고가 세 번 연속 반복돼도 멈춥니다(내용을 바꿔 말하는 모든 무진전을 감지하는 기능은 아닙니다). 기존 권한 설정은 유지합니다.

- **중단**: 다음 목표 턴을 중단합니다. 이미 실행 중인 턴은 마무리합니다. 즉시 멈추려면 대화의 실행 중단 버튼을 사용합니다.
- **계속하기**: 막힘을 해결한 뒤 일시 정지/실패한 목표를 이어갑니다.
- 실행 서비스가 재시작되어 작업이 끊겼다면 목표를 일시 정지하고, 작업을 자동 재전송하지 않습니다.
- `/cycle`은 팀·단계를 직접 구성하는 기존 고급 흐름으로 남습니다. `/codex-goal`은 Codex 고유 목표 설정이며 `/goal`과 별개입니다.

참고한 원칙: [Codex Goals](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex)의 목표 기반 지속 실행, [OpenAI 장기 작업 안내](https://learn.chatgpt.com/docs/long-running-work)의 원래 목표·권한 유지, [Anthropic 평가 안내](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)의 보고와 실제 결과 구분. PitCrew는 이를 Codex·Claude 공통 스케줄러에 적용했으며, Codex 원본 구현을 그대로 복제한 것은 아닙니다.
