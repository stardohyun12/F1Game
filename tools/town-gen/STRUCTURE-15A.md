## 한 일

1. 윗길 가지 = SS163 을 뺀 OSM 차도를 같은 좌표 점으로 묶었을 때 Via Primo Maggio 가 든 덩어리(51 way, OSM 9,850m — 기획 실측 `branches.js` 와 같은 값). 생성 범위 반경 제한 없이 통째로 넣음.
2. 윗길 way 는 생성기에 전부 큰길(secondary)로 넣음. 그대로(residential·service) 넣으면 짧은 토막·서비스 길이 큰길로 안 올라가 덩어리가 끊기고, 생성기가 그 사이를 땅 위 생성 길로 이음 — 첫 빌드에서 생성 잇기 7개(생성 때 344m)가 생기고 콘카 입구 7b 잇기가 사라짐(아래 비교).
   - 그래서 콘카 안 윗길 쪽 OSM 길(Via Roma·Via Umberto I·Piazza Olmo 등)도 차도가 됨 → 7b 의 "마을 반경 80m 안 차도 = 입구 길 1개" 는 더는 성립 안 함(D-116 고리가 마을을 지나야 해서).
3. Via Miramare 는 마을 반경에 들어온 점부터 서쪽 끝(9.66, 445.94)까지.
4. **경계 잇기**: Via Primo Maggio 서쪽 끝 (21.78, 464.44) ↔ Via Miramare 서쪽 끝 (9.66, 445.94) 직선 22.1m(실제 공유 노드 40.6171748, 14.5689036 은 상자 서쪽 8m 밖, 지형 격자 밖이라 그 점을 지나는 실제 선 약 54m 대신 직선). 상자 자체는 넓히지 않음(좌표 원점·DEM 이 다 바뀜).
5. **7b 콘카 입구 잇기 유지**: 윗길을 넣으면 콘카가 윗길 쪽으로 이어져 생성기가 해안 쪽 입구 잇기를 더는 안 만든다 → 윗길 없이 한 번 더 돌려(같은 빌드 안, 약 5초) 그 잇기 선(214m, (372,545)→SS163 (514,567))을 받아 길로 넣음.
6. `carGraph`: 그린 길(큰길 + 골목). 골목은 코어에서 큰길과 노드를 공유하지 않아서 골목 끝 6m 안 길 점에 나눔 노드로 이음. 질문 점(항구·콘카 광장·윗길 마을)도 가장 가까운 길 점에 나눔 노드. 간선마다 종류(primary_SS163 / upper / entry7b / boundaryJoin / connector / lane / OSM 종류) 길이.

## 수용 기준 (2026-10-20 빌드 실측)

- **R6 실제 지도에 없는 잇기 ≤ 50m: PASS** — 경계 잇기 22.1m(입력 직선, 다듬은 뒤 그래프에 18m 로 잡힘). 따로: 7b 입구 잇기 214m(유지), 이 빌드 생성 잇기 1개 43.6m(항구 앞 (2809,2269)→(2818,2307), v14 에도 있던 것).
- **R1 항구 → 콘카 광장 서로 다른 경로 ≥ 2: FAIL(길이 기준)** — 경로 1 해안 3,870m(SS163 3,531 + 7b 입구 182), 경로 2 윗길 5,639m(윗길 3,309 + SS163 1,848) = **+45.7%**, 겹침 34%. 성격은 다름(primary_SS163 / upper). 1.3배를 넘어 "서로 다른 경로"로 안 셈 → 계획 §3 멈춤 조건.
  - 원인: 7b 입구 잇기가 SS163 에서 마을로 바로 오르는 지름길(214m)이라 해안 경로가 기획 실측(4,524m — OSM 그대로면 마을 오르막 878m)보다 650m 짧음. 윗길 경로 5,639m 는 기획 실측 5,318m 와 비슷.
